# 日记派生分段 v1

> 产物是**推理原料**，不是给用户看的成稿。它的用途是把一篇日记变成可被下游消费的语义段。

## 任务

把下面这篇日记按**语义边界**切成若干段。每段给出：原文逐字引用、简明复述、分类、置信度。

## 输入

<日记>
{{entry_text}}
</日记>

## 铁律

1. **只选边界，不改写原句**：`quote` 必须是从输入中原样复制的连续片段，一个字都不能增删改（标点也算）。不要在 `quote` 里拼接不连续的内容。
2. **按原文顺序**输出各段；段与段不重叠；不要把一句话从中间切开（引号、括号内不断开）。
3. 只有话题明显变化时才切段；**宁可少切，不要切碎**——一篇短日记可以只有一段。
4. `rewritten` 是简明复述：用第一人称、保留原文事实与口吻，不添加原文没有的信息，不解释、不评价、不安慰、不建议、不替用户下结论。
5. 分类只能从下面的取值中选**一个**；无法归类才用 `OTHER`。

## 分类取值

| 取值 | 含义 |
|------|------|
| `EVENT` | 事件·经历：有始有终的具体经历、见闻、发生了什么 |
| `WORK_STUDY` | 工作·学习：工作、项目、课程、考试、求职、技能 |
| `RELATIONSHIP` | 关系·他人：家人、伴侣、朋友、同事及与人的互动 |
| `FEELING` | 情绪·状态：情绪、心境、压力、对自身状态的描述 |
| `THOUGHT` | 思考·观点：想法、反思、判断、价值观、对世界的解释 |
| `PLAN` | 计划·决定：打算、目标、选择、待办、犹豫中的决定 |
| `BODY` | 身体·健康：睡眠、饮食、运动、疾病、身体感受 |
| `DAILY` | 生活·日常：吃穿住行、消费、家务、娱乐、天气等日常 |
| `OTHER` | 其他：无法归入以上、或纯语气/衔接；**兜底，应尽量少** |

判定顺序：先看这一段"主要在说什么"。能落到具体领域（工作/关系/身体/计划等）就落领域；只有具体经历、且没有更强领域时用 `EVENT`；纯情绪表达用 `FEELING`；实在无法归类才用 `OTHER`。

## 输出格式（严格 JSON）

只输出一个 JSON 对象，不要 Markdown 代码块、不要任何解释或前后缀：

```
{"segments":[{"quote":"原文逐字片段","rewritten":"简明复述","category":"EVENT","confidence":0.9}]}
```

- `segments` 至少 1 段；
- `confidence` 是 0 到 1 之间的小数，表示你对"这个边界 + 这个分类"的把握；
- 不要输出空段、不要输出只有标点的段。

## 全局表述约束

- 禁止负向表述与说教；不要替用户打气、不要安慰、不要给建议。
