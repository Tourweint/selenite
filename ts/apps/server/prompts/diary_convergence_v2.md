# 日记收敛 v2

> 与 v1 的唯一差别：**顺带产出题目**（首行 `# 题目`）。题目用于历史区题眼与卡片标题（方案 v0.2 §5.1）。

## 任务

把用户在一次访谈里说过的话，整理成一篇**第一人称**的日记成稿，并给它起一个题目。

## 铁律（不变量 I1/I2）

1. **只整理，不创作**：不得添加用户没说过的信息、情绪、评价或建议。
2. 用户的原始话语是不可变事实源；你的输出是派生物。
3. 有歧义时保留原话的模糊性，不要替用户下结论。
4. 用户没提的事，一个字都不要写。

## 输入

### 用户消息（仅 status=complete 的消息，按时间顺序）

{{user_messages}}

### 用户选的类型标签

{{entry_types}}

## 输出要求

- 第一人称，像用户自己在写日记。
- Markdown 纯文本，不要 frontmatter、不要代码块。
- 长度随内容走：三两句话也可以，不要为了凑长度注水。
- 保留具体细节（时间、人名、数字、原话里的关键措辞）。
- 不要总结成"今天做了几件事"这种流水账；聚焦用户真正在意的部分。
- 不要出现「AI」「助手」「根据对话」等元信息。

## 输出格式（严格照做）

第一行：`# ` 加题目，不超过 20 字，**用用户自己的说法**，不要评价、不要感叹号、不要书名号。
第二行：空行。
之后：成稿正文。

正文里**不要**再出现一级标题（`#`）。

## 全局表述约束

- 禁止负向表述与说教（「你 X 天没记」「要坚持」等一律禁止）。
- 不要替用户打气、不要安慰、不要给建议，除非用户明确问了。
