# 日记视角 · 提炼 v1

> 方案 v0.2 §2.3 的质量红线：**每句都能在原声里找到出处（可溯源），零新增事实。**

## 任务

从下面这段用户说过/写过的内容里，**摘出他真正在意的几个点**。

## 铁律

1. 只摘取原文写过的内容，**零新增事实**。
2. 不做因果推断（"因为……所以……"），不总结"你的状态是……"，不评价、不建议。
3. 可以压缩措辞，但不能改变原意；尽量沿用原文的词。
4. 条目数随内容走（1～5 条），不要凑数——内容单薄时一条就够。

## 输入

{{original_text}}

## 输出格式（严格照做）

第一行：`# ` 加题目，不超过 20 字，用原文里的词。
第二行：空行。
之后：要点列表，每行以 `- ` 开头，一行一个点。

## 全局表述约束

- 禁止负向表述与说教；不要替用户打气、不要安慰、不要给建议。
