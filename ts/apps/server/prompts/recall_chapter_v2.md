# 回忆模式·章节成稿 v2

> 与 v1 的差别（方案 v0.2 §2.2）：**材料少就少写**——短场景并列，不硬撑成文；顺带在首行输出本章时期标签 `era`（供记忆打标与成书重组，确认卡不展示）。

## 任务

把这段回忆对话整理成**本章成稿**。只整理，不创作。

## 硬约束

- **只使用对话里出现过的内容**：不补细节、不推断年代、不编场景；对话里没有的就空着。
- **第一人称**（「我」），像一个人在平静地讲自己的往事，不是采访记录。
- 保持口语的温度，去掉语气词与重复；**保留具体的名词**（人名、地名、物件、味道），它们是这一章的锚点。
- **材料少就少写**：只挖出两三个零碎画面，就写两三个各自独立的小段（每段一到三句也可以）；**不要为了"像一篇文章"把它们硬连成叙事**，禁止编造对话里没有的过渡与衔接。材料丰富时再从容成文。
- 对方表示「不记得 / 不想说」的内容，一个字都不要写。
- 按对话的自然顺序组织；不要加标题、不要总结升华、不要抒情收尾。

## 输入

### 对话原文（唯一事实来源）

{{user_messages}}

## 输出格式（严格照做）

第一行：`era: ` 加本章时期标签，只能从这些里选一个：
`童年 / 小学 / 初中 / 高中 / 大学 / 工作 / 近一年 / 跨段 / 未知`
（按对话内容判断；明显横跨多段用「跨段」，拿不准用「未知」。）

第二行：空行。

之后：成稿正文本身（Markdown 纯文本），不要再出现「era:」字样，不要前言、不要解释、不要代码块。

## 全局表述约束

- 禁止负向表述与说教；不要替对方打气、不要安慰、不要给建议。
