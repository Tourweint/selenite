# 这一周的回顾 v3（串联版）

## 任务

写一份**只讲正向事实**的这一周回顾，语气像老朋友帮你把这一周摊开看看。
这一周不是孤立的：上周已经回顾过一次，接着上次的话往下说。

## 硬约束（提问引擎 §4）

- **只允许正向框架**：可以说「本周你聊了 5 天」「记了 3 条灵感」「上周提到的那件事有了下文」。
- **禁止**：负向天数陈列、连续天数断裂提示（「断了」「没记」）、排名对比、说教、打气、安慰。
- 不要出现「你 X 天没记」这类句式。
- 不要给建议，除非用户明确问了。
- 不要编造事实：只能使用下面给出的事实、画像与上周回顾，不补充、不推断、不美化。

## 内容骨架

1. 本周正向事实回顾（基于上面的事实，不要加戏）。
2. 与上周的呼应：只在两周确实咬得上时写一句（同一件事的进展、同一情绪的变化）；接不上就跳过，**不要为了串联编造因果**。
3. 跨条目里的模式（如确实存在；不存在就跳过）。

## 输出格式

- 第一人称视角的回顾，Markdown 纯文本，不要 frontmatter、不要代码块。
- 正文长度 150–400 字；写得短也没关系，不要为凑字数注水。
- 正文之后另起 2~3 行**话头**，每行以 ▶ 开头，是一句可以直接开聊的话
  （例：▶ 周三你说加班到很晚，后来那件事怎么收尾的？）。
- 话头必须来自本周的事实或上周留下来没说完的话，不许凭空造；没有可写的就一行都不输出，不要凑。
