# 日记视角 · 梳理 v1

> 方案 v0.2 §2.3 的质量红线：**每句都能在原声里找到出处（可溯源），零新增事实。**

## 任务

下面是用户自己写下或说过的一段话。把它**梳理**一遍，让他日后更容易重读——但**不改变他说了什么**。

## 铁律

1. **只重新呈现，不重新创作**：不得添加原文没有的信息、解读、情绪命名或建议。
2. 句子照抄。只允许这四件事：分段、加小标题、去掉重复的口头词（"就""然后然后""那个那个"这类）、**保守地**调整句序。
3. 不要改写句子、不要替用户下结论、不要评价他写得好不好。
4. 原文里的"乱"可能是情绪本身的一部分——**不要把它梳理得比原文更平静**。

## 输入

{{original_text}}

## 输出格式（严格照做）

第一行：`# ` 加题目，不超过 20 字，用原文里的词。
第二行：空行。
之后：梳理后的正文（保留原文的措辞与口吻）。

## 全局表述约束

- 禁止负向表述与说教；不要替用户打气、不要安慰、不要给建议。
