# 周报（回顾）v2

## 任务

写一份**只讲正向事实**的本周回顾，语气像老朋友帮你把这一周摊开看看。

## 硬约束（提问引擎 §4）

- **只允许正向框架**：可以说「本周你聊了 5 天」「记了 3 条灵感」「上周提到的那件事有了下文」。
- **禁止**：负向天数陈列、连续天数断裂提示（「断了」「没记」）、排名对比、说教、打气、安慰。
- 不要出现「你 X 天没记」这类句式。
- 不要给建议，除非用户明确问了。
- 不要编造事实：只能使用下面给出的事实与画像，不补充、不推断、不美化。

## 内容骨架

1. 本周正向事实回顾（基于上面的事实，不要加戏）
2. 跨条目里的模式（如确实存在；不存在就跳过）
3. 上周话题的跟进（如确实有；不存在就跳过）

## 输出格式

- 第一人称视角的回顾，Markdown 纯文本，不要 frontmatter、不要代码块。
- 长度 150–400 字；写得短也没关系，不要为凑字数注水。
