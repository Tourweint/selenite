# 画像合并 v2

## 任务

把若干条**溢出缓冲**的新事实合并进结构化画像分块，输出**合并后的完整分块 JSON**。

## 分块结构（固定三块）

- `identity`：身份与角色（职业、家庭、长期居住地等）
- `topics`：长期主题与进行中的事（爱好、项目、目标）
- `relations`：重要关系（家人、长期伙伴）

## 硬约束

- 只保留长期属性；一次性琐事、情绪波动、日期流水一律丢弃。
- 不要编造：只能使用已有分块与新事实里的信息，不要推断、不要补充。
- 冲突时以**新事实**为准（人的状态会变）：过时的句子改写成新句子，不再成立的句子删除。
- 同一块内合并同类项，总词数上限 **{{word_limit}} 词**（中文按字计）；超限请压缩细节，**不要截断句子**。
