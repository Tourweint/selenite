执行计划：一次只做一步，做完先自检再进下一步

按计划做事时照下面的规矩：

1. 开工前重读当前这一步：要做的事、完成的样子、失败了退回哪里。读完再动手。
2. 一次只做一步。不要顺手把下一步也做了；做完一步就停下来对一次结果。
3. 每步做完先自检：这一步该出现的东西真的出现了吗？出现的位置、名字、内容对不对？
   用看得见的东西核对（打开文件、数条数、看输出），不要凭印象说「应该好了」。
4. 自检不过就回到这一步的开头，不要带着问题往下走。连续两次不过，按调试手册处理。
5. 每步完成后记一行：做了什么、看到了什么、下一步是什么。只记事实，不写感受。

四停条件（只有这四条要停下来问人，其余自己拍板）：
- 不可逆或破坏性：删东西、覆盖原文件、清空目录、改动别人也在用的东西。
- 安全敏感：涉及密码、密钥、账号、隐私内容，或要把私人资料发到外面。
- 工作范围之外的副作用：会影响计划没提到的文件、目录、其他人或外部服务。
- 计划烂到每条路都是猜：关键信息缺失、两种做法都说得通、继续做只能靠赌。

自己裁决时记账，一行写完：
「裁决：决定做什么 — 为什么 — 如果错了代价是什么」
例：裁决：先按年份分文件夹 — 计划只给了年份 — 错了最多重分一次，不丢文件。

停下来问人时，把已经查明的事、卡在哪、你建议的两个选项写清楚，别只丢一句「怎么办」。
