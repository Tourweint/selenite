# 2026-11-25 界面显隐注册表（第一批 4 个缺口）

> 本文是第一批落地记录。同日收口到 13 条、加总闸 / empty / 深链空态、
> 并连带记忆页/用量页/字体精简，见 `2026-11-25-界面显隐收口与精简.md`；
> 本文保留当时的第一批口径，不删。

## 改了什么

1. **`ts/apps/server/web/surfaces.js`（新增）**：声明式注册表 + applier。
   - `SURFACES`：`{ id, selector, requires, mode }`，第一批 4 行——
     `#rail-partners` / `#sec-partners`（`COMPANIONS_ENABLED`）、
     `#skill-advice-run`（`SKILL_ADVICE`）、`#settings-export-all`（`EXPORT_BUNDLE`），全部 `mode:"hide"`。
   - `flagOn(key)`：读 `state.flagsCache` 行的 `effectiveValue ?? value`；`false / 0 / off` 算关
     （与 `flags.ts` 的 `flagIsOff` 同口径）；**缓存里没这一行 → true**（读不到不隐藏）。
   - `loadSurfaceFlags()`：缓存为空时 `GET /api/v1/agent/flags` 一次，装成与
     `settings-switches.js#renderFlagRows` 同形状的 `Map(key → 行)`；并发合流、成功一次后不再重复打；
     失败**不写空 Map**（保持 null，下一次 refresh 再试）。
   - `applySurfaces(root = document)`：`requires` 全部开才显示；`mode:"hide"` 用 `hidden` 属性
     （`style-01-tokens.css` 里有 `[hidden] { display:none !important }`，作者样式的 `display` 盖不掉），
     不写 `style.display`、不摘 DOM；`mode:"disable"` 用 `disabled` + `aria-disabled`；
     选择器找不到就跳过，不抛错；重复调用结果一致。
   - `refreshSurfaces(root)`：`loadSurfaceFlags()` 后 `applySurfaces(root)`。
2. **`web/app.js`**：启动区 `void loadCapabilities();` 旁加 `void refreshSurfaces();`。
3. **`web/settings-router.js`**：`renderSettings()` 末尾（`replayPageEnter()` 之后、所有分支之后）
   加 `void refreshSurfaces();`——这几页的入口是现画的，必须在新 DOM 上重铺。
4. **`web/settings-switches.js`**：`loadFlagsSettings()` 读回并 `renderFlagRows` 之后调
   `applySurfaces()`（复用同一份缓存，不发第二次请求）；`toggleFlag()` 每次 PUT 成功后，
   在既有「写回 `state.flagsCache`」那段之后调 `applySurfaces()`。
5. **`web/settings-tools.js`**：用量列是渲染期产物，注册表抓不到，这里自己判。
   `TOOL_USAGE` 关 → `cardHtml` 不渲染 `.tool-pool-usage`，`fetchToolUsage()` 直接返回空 Map
   （连 `/api/v1/agent/tool-usage` 都不请求，与服务端 404 同一条回滚）；`loadToolPool()` 先
   `await loadSurfaceFlags()` 再画，第一帧就按真实开关判。打开时行为不变。

## 为什么这么做

显隐原来散在各页各写一遍 `if`，同一个开关关掉后总有一两处入口忘收。登记成一张表之后，
新增一处要么加一行、要么在渲染处 `flagOn()`，不再靠记性。第一批只接 4 个已确认的缺口，不扩面。

读不到 flags 时按「开」：藏错了用户找不到东西，也没法自己开回来；多显示一个入口只是不理想。

## 回滚

没有单独开关：这几处本来就是被各自 env 开关控制的，把开关拨回开即恢复原样；
`AGENT_FLAGS_UI=false`（端点不给清单）时全部按开，界面回到旧形态。
