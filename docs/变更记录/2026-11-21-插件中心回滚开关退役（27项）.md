# 2026-11-21 插件中心回滚开关退役（27 项：删卡片 + 删旧代码 + 删开关）

方案：`docs/设计方案/2026-11-21-插件中心回滚开关退役.md`（用户拍板"一+二+三全做"）。

## 为什么

插件中心（`plugins.json`）里有一类开关的"关"分支是**改动前的旧形态**，旧代码纯为回滚保留。功能早已落地验收、口径已定，回滚路径成了死重量：前端旧版整套还活着等开关拨 false、服务端每条旧分支随新形态一起维护。本批把这类"纯回滚开关"退役——**删卡片（plugins.json 行）+ 删旧代码（off 分支）+ 删开关（辅助函数 / env 直读 / .env.example 行 / 接口文档 §6 行）**。退役后语义 = 原"开"形态成为唯一形态。

判据：关分支 = 旧形态（代码/文档自称"回滚开关/回滚形态/旧行为"）且功能已 settled。能力关停型（关=端点 404/工具不上架）与偏好/成本型（插话 vs 排队、缓存 vs 新鲜）**不在退役范围**。

## 关键顺序（本批照做）
