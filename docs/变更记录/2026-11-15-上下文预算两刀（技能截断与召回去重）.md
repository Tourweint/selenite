# 上下文预算两刀（技能索引截断 + 召回后去重）· 2026-11-15

**承接**：`2026-11-15-记忆注入预算开关.md`（同一天第三次因"上下文装不下"而动手）。用户拍板"只做最简单的两件"。

## 为什么

实测上下文构成（隔离实例 + 真库统计）：

| 组成部分 | 实测 |
|---|---|
| 技能索引 | **3889 字**（开 19 个技能，摘要平均 205 字，最长 1018 字） |
| 执事上下文注入 | 1782 字 |
| 记忆注入 | ≤2000 字（默认） |
| 记忆库本体 | 267 条 / **17.5 万字**，事实类平均 **951 字/条** |

两条结论：
1. **技能索引比记忆注入还大**，而且每轮都在 system 段里；摘要被写成了整段说明。
2. 记忆真正的问题是**库里的条目太长**（一条 = 半屏文档），2000 字预算只能装 2 条事实。
   修库要重写压缩 / 原子拆分，用户明确"以后再说"；本轮只做**不动库**的注入层优化。

## 改了什么

### 1. 技能索引摘要截断（带开关）

- `createSkillStore` 加 `indexSummaryChars`；`skills.ts` 导出 `skillsIndexSummaryChars(env)`：
  `SKILLS_INDEX_SUMMARY_CHARS`，缺省 **120**，`0` = 不截断，非法值回落默认，clamp `0..2000`。
- `renderIndex` 里对 `summary` 截断并补 `…`；**`manual(name)` 取的手册仍是完整正文**，信息不丢。
- assist 装配处两处 `createSkillStore` 都接线。
- 预期：19 个技能从 3889 字降到约 2200 字（全开 137 个从 34405 降到约 11000）。

### 2. 召回后去重（`MEMORY_INJECT_DEDUPE`，默认开）

- memory 包新增 `dedupeRecallHits(hits, { similarity })`（纯函数、同步、不调模型）：
  规范化全等 → 包含关系（短的是长的摘要）→ 字符二元组 Jaccard ≥ **0.8**；保留 `score` 更高的那条。
- **保守边界**：只比同 kind（fact 与 experience 撞正文 = 结论与做法，都留）；正文 <12 字不做近似判重；
  长度比 >2.5 倍直接跳过集合运算。
- 阈值 0.8 是实测定的：中文只把"确认"改成"验证"，Jaccard 就从 1 掉到 0.83，0.85 会把同一件事判成两件。
- 接在 `engine.buildContext` 的 `recall()` 之后（`InjectOptions.dedupe`，库层默认 false 保持旧行为）；
  assist 按 `MEMORY_INJECT_DEDUPE` 传 true（默认开），`false`/`0`/`off` 一行回滚。
- **只影响本轮注入、不动库、不删记录**。已知副作用：被去掉的那条在 `recall()` 里已经 touchRecall 过
  （召回次数 +1、重要性 +0.05 的轻微失真），换的是不动召回主链路。

## 界面开关（2026-11-16 补）

用户口径：这两个应该能在界面上开关，不要逼人去改 env。

- `SKILLS_INDEX_CLIP`（新增总开关，默认开）与 `MEMORY_INJECT_DEDUPE` 都进了 `FLAG_DEFS` 白名单，
  设置 → 服务 → **行为开关**页自动渲染（前端从 `GET /api/v1/agent/flags` 拉，新键自动出现，
  已归组：技能索引截断进「技能与课题」，召回去重进「记忆」）。
- 两者 `hot: true`，但生效时机不同：召回去重**下一轮**生效（消费处每轮懒读 env）；
  技能索引截断只影响**新开的会话**（索引按会话冻结，改它会让已命中的 system 前缀作废）。
- 机制沿用既有 flags 层：界面改 → 写 `.data/agent-flags.json` → 同步覆盖 `process.env`。
  为让技能截断也能"改完对新会话生效"，`createSkillStore` 的 `indexSummaryChars` 支持收**函数**
  （assist 传 `skillsIndexSummaryChars` 引用，每次首渲染现读 env）。
- 浏览器实机验收（隔离实例）：两个开关在「行为开关」页渲染（31 个开关），状态回显正确，
  点一下 → 服务端 `value` 变化、`overridden: true` 落盘。
