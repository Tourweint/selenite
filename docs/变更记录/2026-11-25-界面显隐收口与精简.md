## 一、显隐注册表收口

`ts/apps/server/web/surfaces.js` 从第一批 4 条扩到 **13 条**：
每条 `{ id, selector, requires, mode: "hide"|"disable"|"empty", emptyCopy? }`。

| 组 | 条目 |
|---|---|
| 侧栏 | `#rail-partners` / `#sec-partners` ← `COMPANIONS_ENABLED`（hide） |
| 设置左栏 | `#settings-tab-agent` ← `CHANCELLOR_ENABLED`、`#settings-tab-reminders` ← `AUTONOMY_ENABLED`（hide） |
| 注入 tab | personas / memory / skills / context / about-me ← 各自开关（hide） |
| 页内按钮 | `#skill-advice-run` ← `SKILL_ADVICE`、`#settings-export-all` ← `EXPORT_BUNDLE`、`#project-add` ← `CURRENT_PROJECT`（disable）、`.executor-probe-btn` ← `EXECUTOR_PROBE`、`.tool-pool-usage` 由 `settings-tools.js` 自己判 `TOOL_USAGE` |

口径：

- 只读 `effectiveValue ?? value`；行上带 `offValue` 时按它判关（`AGENT_TOOL_POLICY` 的 `"full"` 不会被当成开），否则 `false/0/off`。
- 缺键 / flags 拉失败 **fail-open**（按开、不隐藏）。
- 总闸 `PLUGIN_SURFACE_HIDE`（默认开）经 `/agent/policy` 的 `pluginSurfaces` 下发，门在 `applySurfaces` 内，三个调用点统一停。
- PINNED 白名单禁止 `hide`：设置入口 / 返回 / 左栏容器 / 总管 / 会话分区 / 地图返回 / 搜索返回 / 插件中心 / 归档恢复。
- `mode:"empty"` 保留容器、只换内容，深链不白屏；「去插件中心」是 `<a href="#/settings/plugins">`。

## 回滚

- 显隐总闸：`PLUGIN_SURFACE_HIDE=false` → 注册表停用，界面回到「关了照旧显示、点了才 404」。
- 单页回滚：删该页在 `SURFACES` 的条目 / 删 `settings-router.js` 的对应空态分支。
- 记忆页 / 用量页 / 字体：`git revert` 对应文件即可；字体选择值存在 localStorage，未知 key 会自动回落宋体。

## 没验证 / 已知边界

- `hot:false` 的开关：界面立刻收，后端能力重启后才停；「待重启」只在插件卡上显示。
- `AGENT_FLAGS_UI=false` 时注册表 fail-open，需求「关了界面就消失」在该部署下不成立。
- 深色主题下新增的 `.surface-empty` / 工作台样式只按 token 走，未逐主题截图。
- 窄屏 <820px 只做了 CSS 降级，未在真机窄窗逐页验收。
- 桌面壳内嵌页面有静态缓存，验收前要 `?v=` 破缓存（沿用既有口径）。
