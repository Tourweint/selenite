# 变更记录：界面细节批（绿点 · 悬停提示 · 侧栏浮出 · 脚注 · 审批浮窗 · 默认工作区 · 主题柔化）

日期：2026-11-08 方案定稿 → 2026-11-09 落地。
方案：`docs/设计方案/2026-11-08-界面细节批方案（绿点·悬停提示·侧栏浮出·审批浮窗）.md`（落地后状态头已补下沉落点表）。
背景：用户在刀二运行期间提了一批界面与交互要求；刀二/刀三当天入库后开工，无文件冲突。

## 改了什么

### web 前端（ts/apps/server/web/ 三件）

1. **主题柔化**：white `#ffffff`→`#fafaf8`（card `#f4f4f1`、backdrop `#f1f1ee`、outline `#d7d7d3`），
   black `#000000`→`#17171a`（card `#1d1d21`、backdrop `#101013`、text `#e6e6ea`、outline `#3a3a44`）。
   只动 token，四个 token 块纪律不变。预览方块色同步，名称改「暖白/炭黑」。
   **手机端 Theme.kt 未跟随**（跨仓库，等用户看完效果拍板）。
2. **设置绿点退役（收起态）**：删 `#rail-status`，收起轨道只留齿轮；`setStatus` 不再写轨道点，
   改为动态更新 `#rail-settings` 的 data-tip（「设置 · 服务在线/离线/连接中」）。
   展开态 `.side-foot` 改横排（齿轮左、状态点右侧剩余宽度居中）——用户拍板"左右排列"。
3. **消息脚注**：复制按钮文字→Lucide 图标（点击 ✓/× 反馈 1.2s）；`margin-top -6px→2px`、列距 10→12px；
   「完成于 HH:MM」→ 只剩时刻（跨天补 M/D），完整时间进 title。
4. **全局悬停提示**：rail-tip 泛化为 `data-tip` 全局委托（挂 body、fixed、450ms 延迟、12px 圆角、
   纯 opacity 进场、越界翻转、滚轮/缩放即收、键盘 focus 立即出）。Cindy 同款参数。
5. **设置页解释文字悬停化**：rowMarkup 的 hint 默认不再常驻——标签旁 ⓘ（`.row-tip`）悬停出全句；
   状态/结果类文案走 `inlineHint: true` 保持常驻（已移除的会话计数、搜索变量名两处）。
   侧栏项目区常驻图例挪进「项目」分区头 data-tip；五个分区头原生 title 统一转 data-tip。
6. **记忆页重排**：分组标题（偏好/事实/人事物/经历）从大卡内部挪到**卡片外**（每类自己的卡），
   空分组不出现；每组配悬停解释（"经历是干啥的"）。
7. **抽屉模型页**：删「清单里没有这个模型？」手动输入卡（csBatchCard + importBatchModels 连根删，
   死样式 .chat-settings-batch 一并清）；原生 `<select>` 主选退役，改触发钮 + 复用 composer 的
   renderModelMenu（供应商分段/12px 圆角/思考档全套现成）；chooseModel 成功后在菜单宿主派发
   `modelchange`（冒泡），触发钮文字跟上；点外/Esc 收起接入既有全局处理器。
8. **侧栏悬停浮出（peek）**：收起态悬停顶栏收起/展开钮 120ms → 面板 fixed 浮层出现在轨道右侧
   （200ms `cubic-bezier(0.22,1,0.36,1)` 滑入）；离开 160ms 宽限后滑出；浮出中点按钮 = 正式展开；
   点面板内东西用完即收。浮出期间解除 inner 的 inert（收场交还）。窄屏/reduced-motion/已展开不启用。
9. **审批浮窗**：全局待审批 5 秒轮询提出来常驻（启动即跑，一份数据与群胶囊共用端点、不造第二个轮询），
   右下角浮卡（工具名/来源/倒计时或"等待处理"/批准拒绝/忽略），同屏最多 3 张余下收计数；
   只弹"当前看不见的"（当前会话对话流卡已挂的、点过忽略的不重复）；点卡跳那条会话。
   设置→权限区「待处理审批」计数+列表块、抽屉权限页「待处理审批 N 条」入口**退役**（审批档三档保留）。

### 默认工作区（ts/apps/server/）

10. **首次使用播种**：`seedDefaultWorkspace()`（projects.ts）——启动时若从未设过工作区，静默落
    `<主目录>/lifediary`（不存在则建），在 index.ts 挂载后调用。回滚开关
    `LIFEDIARY_DEFAULT_WORKSPACE=off`（=路径换落点）；已设置过的一律不动（用户 2026-11-09 明确：
    他已设好，不能影响）；换 `PROJECTS_DB_PATH` 跑（测试/探针）且未显式给值时不播种（不碰真实主目录）。
    "不能选用户主目录"防线原样保留（默认落的是子目录）。侧栏「设置主项目」行保留作兜底。

## 落地偏差（相对方案）

- 方案原定 rowMarkup 加 hintMode 参数名，落地为 `inlineHint`（语义更直白）。
- 「当前模型已不在清单」从原生 select 占位 option 改为触发钮提示语（自绘菜单没有 option 可占位）。
- 新发现并当场修掉：审批答复后浮窗原先要等 5 秒轮询才消失——decideGlobalApproval 现在把已答复
  callId 从待弹清单剔除并立即重画。
