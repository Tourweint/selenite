# 派活设置三修：模型下拉换自定义面板 · 模型清单拉全 · 文案与解释收口

**日期**：2026-11-16
**范围**：`ts/apps/server/web/settings-executor.js`（整页交互重写）、`style-14-settings-pages.css`（下拉面板样式）、`src/executor-probe.ts`（清单来源）、`src/executor-config.ts` / `executor-mount.ts` / `src/tools.ts`（文案）、`src/executor-config.test.ts`（断言同步）
**状态**：已落地（当日验收）

## 用户口径（三条，同日提出）

1. 模型输入框那个**向下的原生箭头太丑**——datalist 的浏览器原生下拉钮改不了样式；
2. **模型清单拉不全**——Claude 只给 4 个别名、Codex 只有 config.toml 当前一个；
3. 「**执行器**」用词不准确——它就是一个普通工人，界面应该说「默认派给谁」；
   且设置页的解释性文字**全部收进悬停黑色小卡**（对齐 2026-11-12 文案密度口径）。

## 改了什么

### ① 模型选择：datalist → 自定义下拉面板

- `<input list>` + `<datalist>` 退役（原生箭头丑、清单窗口窄、样式不可控）。
- 新形态：输入框内嵌**自画 Lucide 箭头**（`arrowDown` 路径，与全站 select/菜单同款视觉）+
  **挂 body 的 fixed 定位面板**——`.card` 是 `overflow:hidden`，absolute 弹层会被裁，
  与 hover-tip 同一个绕法；行条目直接复用 model-menu 的 `.model-row / .model-item`（style-12）。
- 行为：点箭头开面板（没拉过清单就先拉，同 kind 并发去重）；**输入框打字实时筛选**；
  点行回填输入框并关闭；点外面 / Escape / 页面滚动关闭；下方放不下自动朝上开。
- 视口放不下 500+ 行时截断到 800 行并在面板尾部说明「打字筛选」。

### ② 模型清单拉全（executor-probe.ts `listModels`）

- **Codex**：从 `~/.codex/config.toml` 挖三处——顶层 / `[profiles.*]` 的 `model = "..."` 行 +
  `[notice.model_migrations]` 里 Codex 自己登记的改名映射（旧名→新名，两边都是真模型名）。
  本机实测 1 个 → 4 个（`gpt-5.6-luna` / `gpt-5.2-codex` / `gpt-5.4` / `gpt-5.2`）。
- **OpenCode**：清单排序去重（`opencode models` 本来就是全量，实测 518 行一条不丢）。
- **Claude Code**：维持 4 个官方别名。**边界如实写**：CLI 没有 models 子命令，完整模型名
  枚举不出来（`claude models` 不是子命令），只能用户直填 + 检测验证；提示语文案已改说清。
- **CodeBuddy / Qoder**：不动（`--help` supported 列表 / `--list-models` 本来就是全量）。
- 拉清单只是本地命令**不耗模型额度**；只有填了模型点「检测」才真调（原口径不变）。

### ③ 文案与解释收口

- 「执行器」→「**默认派给谁**」（设置页行标签、aria、锁定说明、错误文案）；
  系统提示 `<delegate_executor>` 行改为「派活默认交给：X（模型 Y，权限 Z）。换默认只影响新单；
  续跑沿用原单的工人。」；`delegate` 工具返回「续跑沿用原单的工人」「；交给 X」。
- 设置页**常驻解释全部退役**，收进 `data-tip`（全局 hover-tip 黑卡）：卡片标题挂额度/边界 +
  留空语义、权限标签挂三档解释、箭头挂拉清单说明、检测挂真调提醒。卡面只剩
  名字 + 控件 + 状态行；页脚说明段整个删除。
- **Esc 分层**：模型面板开着时 Escape 在捕获阶段截下（`stopImmediatePropagation`），只关面板——
  否则全局「Esc=返回」会把整个设置页一起退掉（2026-11-16 浏览器实测踩到，sec-menu 同款收口）。

## 缓存前缀影响

`<delegate_executor>` 是系统提示固定前缀段，措辞变化会打掉一次上游 prompt cache——
属用户主动改口径的预期成本，一次性。

## 回滚

- 下拉面板 / 文案：`git checkout` 本批三个 web / src 文件即回 datalist 形态（feature 文件未跟踪，
  以本变更记录为界）。
- 措辞回滚无开关；env 开关（`EXECUTOR_CONFIG` / `EXECUTOR_PROBE`）不受本批影响。

## 刻意不做

- **Claude Code 完整模型名枚举**：CLI 无此能力，编一份"全家桶"清单是造假，不做；
  别名 + 自由填写 + 检测验证是如实边界。
- **进页自动拉清单**：OpenCode `models` 要起 CLI（秒级），设置页首开不该背着它；
  只在点箭头 / 点检测时拉。
- **Codex 走 app-server 枚举**：experimental 进程级接口，为拉清单起常驻服务不成比例。
