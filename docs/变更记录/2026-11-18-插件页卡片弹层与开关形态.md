# 插件页卡片弹层与开关形态

**日期**：2026-11-18。
**范围**：纯前端（`web/settings-switches.js`、`web/style-14-settings-pages.css`）+ 基线文档回写；
不碰契约、不碰服务端、不改 `plugins.json`。

## 问题（2026-11-18 用户反馈）

1. 有些插件有多个选项（分段选择器），没有统一的开关按钮；需要想清楚这类插件怎么开、怎么关。
2. 插件说明太长：卡面两行装不下会被省略号截断；完整解释全挂在 `data-tip` 悬停黑块里，文字量大，悬停也读不完。
3. 「工具活动」此前压成卡尾一句只读说明；用户要求也做成一张卡片（可以不提供开关）。

## 改了什么

- **卡面只留放得下的内容**：名字 + 例外徽标 + 简介第一句 + 控件。
  简介按最终列宽量一次，两行放不下就整句藏起来（`.is-clipped`），**不再出现省略号**；
  窗口变宽 / 变窄时用 ResizeObserver 重新量，宽回来能恢复显示。完整说明一律进弹层。
- **点卡开详情弹层**：卡体是按钮（`aria-haspopup="dialog"`），弹层内容是完整 `summary`、
  当前值 / 默认值 / 生效方式（即时 / 重启后） / 总闸，以及和卡面同一套控件；
  在弹层里改动会同步卡面控件（`applyFlagControlValue` 按 key 扫所有控件）。
  完整解释不再挂卡体的长 `data-tip`；徽标上的短提示保留。
- **多档插件的开关形态**：
  - 带「关」档的多档（`AUTONOMY_ENABLED` 关 / 只观察 / 开）画成**拨杆 + 档位**：
    拨杆只管开停，开时在右侧选档；关时档位禁用、滑动高亮藏起；再打开回到本次最后选过的档。
  - 纯档位插件（`MEMORY_EXTRACT` / `PARTNER_LEARNING_FREQUENCY` / `CHANCELLOR_INTERNAL` /
    `AGENT_TOOL_POLICY`）没有「关」档，**不硬造开关**——把某一档映射成「关」等于骗人。
    弹层里写明「这是档位选择」，并指出由哪个总闸关闭（没有父闸的写明它决定的是做法）。
- **工具活动改成「始终开启」分组里的常开卡**：带「常开」徽标、卡尾写「常开 · 无开关」，
  点开是说明；不参与页首开关计数。卡尾原来那句「工具活动常开」删掉，其余说明保留。
- 页首计数措辞从「N 个插件」改为「N 个开关」，避免把常开卡算成开关。

## 验证

- `node --check web/settings-switches.js` 通过。
- 浏览器实测（本地 39847，真数据，`#/settings/plugins`）：
  - 89 张卡（88 个开关 + 工具活动）；卡面简介 54–56 张完整显示、33–35 张整句隐藏（随列宽变化），无省略号。
  - 视口 900×800 → 列宽变窄，隐藏数变 38；调回 1272×800 后恢复显示（ResizeObserver 生效）。
  - 点「打手工具结果整理」（长说明）弹层：全文完整、当前/默认/生效/总闸正确，卡面原来的长悬停提示消失。
  - 点「记忆提取方式」弹层：高亮在「模型」（当前值），焦点落在「关闭」而不是第一个档位；
    切「规则」→ 卡面与弹层同步、API 值 `rule`；切回「模型」→ 恢复 `llm`（原值）。
  - 「自主轮」卡：拨杆关 → API `false`、档位禁用；再开 → API `true`、档位恢复，回到「开」档（最后选过的档）。
  - 布尔插件（进度汇报工具）弹层里拨杆关→开，卡面拨杆与 API 同步，测试后已把临时覆盖行从
    `.data/agent-flags.json` 清掉。
  - 「工具活动」卡与弹层：常开徽标、无控件、说明完整。
- 未跑 `pnpm typecheck` / 单测：本次只改 `web/` 静态 JS/CSS 与文档，不在 TS 编译范围；
  插件页也没有前端单测覆盖。

## 刻意不做

- 不给纯档位插件造「关」档：需要后端为这些键新增 off 语义（存什么值、消费处怎么判），
  属于契约改动，先写方案再动；本次只把选择讲清楚。
  **当日后续批次已按用户口径补上**：新增清单字段 `offValue`，`MEMORY_EXTRACT` / `PARTNER_LEARNING_FREQUENCY`
  加 `off` 档（真关停），`CHANCELLOR_INTERNAL` / `AGENT_TOOL_POLICY` 用既有档位表示关；
  见 `变更记录/2026-11-18-插件多档开关（开关与档位）.md`。
- 不改 `plugins.json` 的 `summary` 文案：卡面隐藏的是"放不下"的第一句，不是把说明改写短；
  真要缩短文案是内容工作，另批做。
- 弹层不做"上一条 / 下一条"浏览：一次只回答"这张卡是什么"。
