# 2026-11-17 新建对话选目录 + 派活工作目录（变更记录）

> 一句话：会话的 cwd 不再跟着全局「当前项目」漂——新建时自己选目录；总管派活可以按单指定工作目录与工具权限档。

## 结论

| 入口 | 现在怎么定 cwd / 权限 |
|---|---|
| 主人新建 worker 对话 | 输入框左下角、加号旁边多一个「选项目」pill：点开是项目清单，选一个 = 这个对话的工作目录就是该项目主文件夹；不选 = 沿用「当前项目」的主文件夹（pill 上直接写出是哪个）。服务端校验「存在 + 是目录 + 落在已登记根内」后写成会话 cwd。 |
| 总管建 worker | 仍走 `delegate`，只多了两个字段：`workdir`（绝对路径或相对项目主文件夹）、`permission`（read / edit / full）。不新建工具。 |
| 记忆挂载 | 不变，且与目录**无关**：勾选 `projectIds` 只决定记忆召回池，不决定这个会话能去哪个目录。 |

## 回滚

- `CHAT_DIR_PICK=false`：`dirPath` 一律忽略（请求回到旧口径）。
- `DELEGATE_WORKDIR=false`：`workdir` / `permission` 收下但不生效。

两者都是纯增量：不传新参数的行为与改动前逐字节一致。

## 已知边界

- **派活这一条没做端到端**：`workdir` / `permission` 只到了「类型检查 + 合同单测」这一层，没有在真实服务上跑过一次「总管派单 → chancellor 收单落 `ticket.options.workDir`」。chancellor 侧改完 typecheck 通过，但没有起 chancellor 跑真单验证。
- `permission` 只对 Claude / Codex / OpenCode 生效；CodeBuddy / Qoder 仍全权（chancellor 现有口径）。
- `gitIsolated` 派单用 worktree，`workDir` 不生效（行为不变）。
- 验收快照仍按 `project.rootPath` 拍，`workdir` 指到项目子目录时不会收缩——大项目会更慢，这是故意不改的（改了验收口径就变了）。
- 前端「选项目」菜单只列登记项目（不含主工作区、不含子目录）；要选项目里的子目录或主工作区，目前只能走 API 传 `dirPath`。
- 落盘后的会话不再显示 pill（cwd 已定在会话上）；历史会话的「属于哪个项目」没有回显，要看得另做（`/agent/chats` 目前不下发 projectId）。
- 「只选目录、不绑项目」的会话项目记忆是空的（记忆仍按设置里勾选的项目注入），UI 上没有额外提示。
