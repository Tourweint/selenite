# 2026-11-23 「选择会话」从行尾小图标收进总管 / 执事右键菜单

## 用户口径

「右边这个分支会话的图标，也就是选择会话的图标……我感觉这个也没有什么用了，
你就直接把它做在右键的菜单里吧。现在右键总管的菜单还没有，然后右键这个我的不同执事的
这个选择会话，你也把它放在这个右键的菜单里」。

即：行尾小图标不再摆，动作改挂右键；总管行原本没有右键菜单，补一张。

## 改了什么

| 文件 | 改动 |
|---|---|
| `web/partner-roster.js` | 删掉每行尾部的 `.roster-sessions` 按钮；右键菜单在「打开对话」后加「选择会话」（插件关时不加）；摘掉 `CS_ICONS` / `csSvg` 两个只给它用的导入 |
| `web/partners-status.js` | 删掉 `syncChiefSessionsButton()` 及 `loadRoster` 里的调用；给 `#chief-entry` 新挂右键菜单：`打开对话` / `选择会话`（插件关时只留前者） |
| `web/partner-sessions-ui.js` | `onSideSessionsDisabled()` 不再扫 DOM 拆旧按钮——入口已不常驻，后续菜单自然不挂该项 |
| `web/style-02-sidebar.css` | 删掉 `.roster-sessions` / `.chief-sessions` 整套 hover / focus 样式（元素已不存在） |

插件闸仍生效：`state.sideSessionsEnabled` 为假时，两份右键菜单都不出现「选择会话」，
和原来「插件关 → 不渲染按钮」同一口径。

菜单顺序：`打开对话` → `选择会话` → `人设档案` →（分隔）`看「领域」的任务`。
总管行：`打开对话` → `选择会话`。

## 没做 / 边界

- 行尾图标不做「居右」修补——按用户口径直接退役，不在原位置留影子。
- 右键菜单沿用既有口径：只在桌面壳里接管，普通浏览器右键仍是原生菜单
  （2026-11-16 用户拍板）；浏览器里的选择器入口仍在会话顶栏那一枚。
- 收起轨道的执事悬停卡走同一份 `renderRoster`，行尾图标同样消失；卡里右键是否稳定开菜单
  不在本次范围，入口仍以展开态侧栏为准。
