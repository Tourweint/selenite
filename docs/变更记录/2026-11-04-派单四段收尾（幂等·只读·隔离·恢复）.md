## 关键口径

- **租约键与写集**：任务计划 `writes: [相对路径]`；`*` 覆盖整个项目。租约先申请后启动，持不到进 `waiting`；心跳 30s，5 分钟无心跳判 stale 可重申请。
- **worktree**：副本旁边写 `<worktreePath>.json`（`baseRef` + 复制进来的未跟踪文件哈希）；崩溃恢复时可用这份元数据接着用半成品，不再重新检出。
- **终态清标记**：`Store.setTicketStatus` 到 `done / needs_you / idle / failed / aborted` 即删 `inflight.json`，保证标记只代表「还在进行」。
- **恢复策略**：`DELEGATION_RESUME_POLICY=auto-before-merge`（默认）/ `always-ask` / `never`；`merged=true` 的单无论策略都转「待你处理」。
- **回滚**：`CHANCELLOR_TASK_ISOLATION=direct` 回到串行直写；`MANAGER_CONTEXT_ROTATE_RATIO` 可调高；`DELEGATION_RESUME_POLICY=never` 关闭自动续跑。
