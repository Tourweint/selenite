## 改了什么

### E2 后端（三处纯增量，均无 schema 变化）

1. `src/approval-api.ts`：`GET /api/v1/agent/approvals` 的**全局待办**与**按会话**两个投影，行对象从 `ApprovalRecord.origin` 透出可选 `origin`；`undefined` 不带键（老客户端忽略）。这是 E1 前端徽章一直拿不到全局待办 `origin` 的投影修复。
2. `src/companion-api.ts`：`POST /api/v1/partners` 请求体加可选 `soul`（一句话身份）。建档成功后若带 `soul` 则 `bumpSoul` 一次（v2 自定义版本）；400 校验照 PATCH 的 64KB 槽位上限（`PARTNER_SLOT_LIMIT`，与 `atomicWrite` 同一份护栏），在建档前先拦避免留半建档案；不带 `soul` 行为零变化。配套把 E1 新建模态的提交收敛成一段（`openCreatePartnerModal` 把 `soul` 随 POST 带上，删掉补 PATCH 那段与其注释）。
3. `src/index.ts` `/healthz`：加 `autonomy: autonomyEnabled()`。**只露这一个开关布尔，不露任何会话/内容信息**（任务书 E2 #6 选 a）。

### E2 前端（web/ 三文件）

4. **unanswered 渲染**（`send()` 事件分发）：加 `unanswered` 分支 `addError(event.message)`（后端文案「这次没能生成回复，请再试一次。」）；用 `noReplyExplained` 标志压住结尾兜底的「模型没有返回内容。」与 done 的「这一轮出错了。」。后端把 `unanswered` 透成 `error` 帧时（index.ts 收尾兜底），`error` 分支同样置标志，保证只显示那一句具体文案。
5. **任务详情「迟到的回报」**（`renderTicketDetail`）：`data.deadLetters` 非空时照 `reviewRows` 渲染一节，每行 `子单 id · 状态 pill · note · 时间`；空数组整节不渲染；标题 + 副注「父单已终态后子单才回的结果，记账在此，不会自动并入。」。
6. **领域概览 `#/domains`**：点亮 index.html:103 的 disabled 占位为 `rail-domains`；新增 `view-domains` 整页（复用 tasks 布局类），`GET /api/v1/domains` 列 `领域名 · 活跃单数(activeTickets) · 状态`；`error` 行标红 + 错误文案（照「当前项目 pill」降级先例：读不到不白屏，给说明 + 重试）；行点击跳 `#/tasks?domain=<domain>`（任务中心 `openTasks` 从 hash 恢复 `state.domainFilter`，衔接既有筛选）。`currentRoute` / `go` / `applyRoute` / Esc 同步登记。
7. **手动加提醒**：提醒设置区顶部加「加一条」行（text + `datetime-local` + 按钮）→ `POST /api/v1/agent/reminders` body `{text, at}`，`at = new Date(value).getTime()`（epoch 毫秒），成功后 `loadReminders()` 刷新；骨架建一次、填值不重建。
8. **usage 按模型明细**：服务页「累计 token」下加 `<details>` 折叠，展开按模型小表（模型 / input / output / cacheRead / total），取 `GET /api/v1/agent/usage` 的 `models[]`；再点收起。
9. **自主轮开关只读状态**：设置页权限卡加一行 kv「自主轮（观察与审批）· 开/关（环境变量）」，`loadAutonomySwitch()` 读 `/healthz.autonomy` 填值；注释写明只露开关布尔。
10. **【需要你】视觉区分**：`openChat` 渲染 assistant 历史消息时，正文以「【需要你】」开头的行所在块加现有 `.attention` 类，只改渲染判断、不改内容。

style.css 新增类均用 `--*` 令牌 + `td-` / `tk-` 前缀，无硬编码色值。
