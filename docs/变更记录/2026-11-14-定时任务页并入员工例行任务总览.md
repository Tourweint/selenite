# 定时任务并成一张清单

用户原话：

- "我们这个定时任务，就是例行的任务。"
- "我不一定跑任务，反正把他唤醒就行……把随便一个员工唤醒就行。"
- "提醒任务也可以做成例行任务。比如每天提醒我记日记，我给一个员工，他爱执行不执行随便，发一个动，给我发一句话，那也不属于工具调用，但也算一个任务。"
- "定时任务这一页的待触发和员工的例行任务本来是一样的，所以你需要做二级菜单。"
- "你这个长得太丑了，员工类型任务这个容器有点贴边。"
- "合并成一条链就行了……例行任务要能设置，改时间就仿照定时任务。"
- "咱们不是已经弄了整理记忆的几个任务吗？为什么还在这里看不见？应该按每个员工再分类一下。"

## 结论

**「定时任务」页只有一张清单，没有二级页签。**

一条任务 = 三件事：

```text
到点叫谁（总管 / 阅读助手 / 记账助手 / 纪要员）
   送什么提示词（一句文本）
   什么时候（单日 / 区间 / 每天 / 每周 / 每月）
```

- 到点就是把这段提示词发给那个人，让他起一轮、回你。
- 不再分“只发一句 / 自动执行”；页面上也没有这个选择。
- 总管也能收，不再限制“总管只能发一句”。

## 页面

```text
设置 → 定时任务

定时任务
┌──────────────────────────────────────────────┐
│ 到点叫一个人                    [手动设置] [交给 Agent] │
└──────────────────────────────────────────────┘
┌──────────────────────────────────────────────┐
│ 按人筛选                          全部人 (5) ▾ │
├──────────────────────────────────────────────┤
│ 明天 03:30   整理记忆            改时间 暂停 删除 │
│             总管 · 每天 03:30                  │
│ 明天 03:30   整理记忆            改时间 暂停 删除 │
│             阅读助手 · 每天 03:30                  │
│ 明天 03:30   整理记忆            改时间 暂停 删除 │
│             记账助手 · 每天 03:30                  │
│ 明天 03:30   整理记忆            改时间 暂停 删除 │
│             纪要员 · 每天 03:30                │
│ 11月20日     每周五例行盘点      改时间 暂停 删除 │
│ 17:00        纪要员 · 每周五                          │
└──────────────────────────────────────────────┘
```

- 顶部保留原来的「到点叫一个人」卡片和 `手动设置 / 交给 Agent` 两个按钮，不改样式。
- 员工例行任务、每晚记忆整理并成一张清单，按下一次触发时间排。
- 清单顶部有「按人筛选」下拉：`全部人`、`总管`、每个员工；括号里是任务数，选中后只看这个人的任务。
- 每行的操作是真正的按钮（有边框、有内边距），不再是小号灰字：
  - 例行：`改时间` `暂停 / 启用` `删除`
  - 记忆整理：`改时间` `暂停 / 启用` `删除`
- 例行任务不再显示一个看起来能点、实际点不了的「跑一轮」标签；也不再写“自动执行”这种模式说明。
- 暂停后的例行任务沉底，左列显示「已停」，按钮变成「启用」。

## 新建

手动弹窗：

```text
到点做什么  [________________]
到点叫谁    [总管 / 阅读助手 / 记账助手 / 纪要员]
重复        [单日] [区间] [每天] [每周] [每月]
哪一天 / 几点
```

- 新建统一走 `POST /api/v1/routines`：`partnerId` = 选的人（总管是 `chief`），`name` = 文本前 40 字，`prompt` = 全文，`triggers` 由时间规则生成。
- 到点该员工（或总管）起一轮，拿这段提示词执行，再把结果回到会话。
- 实测给 `chief` 建例行任务能成功，不再拦“总管只能发一句”。

## 记忆整理任务

每晚 03:30 的整理不是 `lifediary.routine` 表里的一条记录，而是服务进程内的定时器：对「我的记忆」和每个在职执事各跑一次整理建议，串行、只出建议、不自动应用。

为了让它出现在定时任务页，新增接口：

```text
GET /api/v1/agent/memory/nightly
{
  enabled: true,
  at: "03:30",
  nextAt: "2026-11-14T19:30:00.000Z",
  scopes: [
    { scope: "global", label: "我的记忆", enabled: true },
    { scope: "partner:…", label: "阅读助手", enabled: true },
    { scope: "partner:…", label: "记账助手", enabled: true },
    { scope: "partner:…", label: "纪要员", enabled: true }
  ]
}

PATCH  /api/v1/agent/memory/nightly          { at: "HH:MM" }
PATCH  /api/v1/agent/memory/nightly/:scope   { enabled: true|false }
DELETE /api/v1/agent/memory/nightly/:scope
```

- 页面按 `scopes` 每人一行：标题都是「整理记忆」，meta 是「总管 / 阅读助手 / … · 每天 03:30」。
- 右边是 `改时间 / 暂停 / 删除`；暂停后左列显示「已停」，按钮变「启用」；删除后这一行消失。
- 删除只停这个人的整理调度，不动他的记忆。状态落 `.data/memory-nightly-tasks.json`，跨重启生效。
- 「改时间」和例行任务共用同一个弹窗；改的是整组共用的时刻，保存后四个人的时间一起变（`.data/memory-nightly-at.json`）。

## 改时间

两种任务共用一个弹窗：

- 例行：把简单 cron / once 反解成弹窗里的"单日 / 每天 / 每周 / 每月"，保存时 `PATCH /api/v1/routines/:id { triggers }`。
- 例行规则如果是多个触发器、interval、event，或带复杂 cron，列表里仍能看 / 开关 / 删除，但不显示「改时间」，避免把规则改坏。
- 记忆整理：和例行任务共用同一个“改时间”弹窗（670px），不再单独做窄版；重复方式固定“每天”，其余选项灰掉，时间可改。

## 接口

| 用途 | 接口 |
|---|---|
| 例行任务清单 / 新建 / 改时间 / 开关 / 删除 | `GET/POST /api/v1/routines`，`PATCH/DELETE /api/v1/routines/:id` |
| 每晚整理状态 / 改整组时间 / 按人暂停 / 删除 | `GET /api/v1/agent/memory/nightly`，`PATCH /api/v1/agent/memory/nightly`，`PATCH/DELETE /api/v1/agent/memory/nightly/:scope` |
| 同事名单 | `GET /api/v1/partners` |

`/api/v1/agent/reminders` 保留在后端（旧工具可能还在用），但定时任务页不再读写它，也不再轮询弹通知。

## 验证

- 页面只有一张清单；「每周五例行盘点」显示为：11月20日 17:00 / 纪要员 · 每周五 / 改时间 / 暂停 / 删除。
- 暂停后左列变「已停」，按钮变「启用」；再点恢复。
- 点「改时间」能把 `cron 0 17 * * 5` 反解成「每周 / 周五 / 17:00」；保存后规则不变。
- 新建弹窗只有“到点做什么 / 到点叫谁 / 重复 / 哪一天 / 几点”，没有“只发一句 / 自动执行”。
- 新建「总管 + 每天」成功；列表出现一条任务；删除后消失。
- 每晚整理显示 4 行：总管 / 阅读助手 / 记账助手 / 纪要员，时间都是「明天 03:30」，右侧「改时间 / 暂停 / 删除」。
- 点「改时间」和例行任务同一个 670px 弹窗；把 03:30 改成 03:35 后四行一起变，改回 03:30 后一起恢复。
- 清单顶部「按人筛选」能选「全部人 / 总管 / 阅读助手 / 记账助手 / 纪要员」，选「总管」只剩总管一行，选「纪要员」剩两行（整理记忆 + 例行盘点）。
- 测试数据已清空：例行只剩原来的「每周五例行盘点」。
- 控制台 0 条报错；`tsc --noEmit` 通过；`node --check` 通过三个前端文件。

## 边界

- 例行的月度规则仍是 cron 语义：选 29–31 号时，小月不触发；没有做"月末顺延"。
- 记忆整理的「改时间」是整组共用时刻，不是每人独立时间；按人只能暂停 / 启用 / 删除，删除不动记忆。
- 旧提醒接口仍在，但页面不再展示、也不再发桌面通知；现在一条任务只走例行执行器。
