# 2026-11-23 总管行去掉重复的「总管」胶囊

## 用户口径

「侧边栏总管的胶囊小图标文字无需显示」。

展开态侧栏最上面的总管固定条目原来是：头像 + 行名「总管」+ 一枚 `.pill-tag` 写「总管」。
行名已经把身份说清楚了，胶囊是同一句话的第二遍，去掉。

## 改了什么

| 文件 | 改动 |
|---|---|
| `web/index.html` | 总管行删掉 `<span class="pill-tag">总管</span>`，剩头像 + `.roster-name` + 任务计数 |
| `web/style-02-sidebar.css` | 删掉 `.chief-entry .pill-tag { margin-left: auto; }`；`.chief-count` 从 `margin-left: 0` 改回 `auto` |

`.chief-count` 要跟着改：它原来贴着胶囊右侧（所以不能再抢自动外边距）；胶囊没了，
计数回到 `.side-count` 默认的行尾右对齐，可见时不会贴着名字。

`.pill-tag` 本体保留——执事花名册的领域 / 派发权、审批卡、设置页还在用。

  （`partners-status.js` 按 `.chief-sessions` 查询，不按子节点序号）不受影响
  （该按钮同日稍后已退役、改挂右键菜单，见 `2026-11-23-选择会话收进右键菜单.md`）。
