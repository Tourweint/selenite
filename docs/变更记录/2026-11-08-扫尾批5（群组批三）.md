## 一、复合头像（界面）

- 群列表行 / 侧栏群行 / 群会话头（新增 `#group-head-avatar`）改用成员头像拼图：
  1 人直出、2–4 人 2×2、>4 人取前 3 + 右下角 `+N`（`paintGroupAvatar`，样式 `.gavatar*`）。
- 成员头像来源改为**群详情成员投影**（`member.avatar`），老服务端缺字段时回落花名册缓存。
- 后端：`GroupRow.members` / `membersOf()` 补 join `p.avatar`、`p.domain`；`groupProjection` 透出。

## 二、审批卡标注来源

- 投影：按会话形态的 `GET /agent/approvals` 补 `conversationId`（全局形态本来就有）。
- 前端：`approvalSourceLabel()` 按会话反查——群成员会话（`partner-<pid>-group-<gid>`）→
  `群「名」 · 成员名`；执事专线 → 执事名；主对话 → 总管；`task-` 专线/查不到 → 不显示（不猜）。
  审批卡标题下加一行 `.approval-source`；设置页「待处理审批」行首同源替换 `chatTitle` 兜底。

## 三、成员状态胶囊

- 群会话 composer 上方新增 `#group-pulse`：忙（当前发言成员）+ 等审批（本群成员的 pending 审批）。
- 数据只走既有端点：`GET /groups/:id`（新增 `round` 投影）+ `GET /agent/approvals`；
  群会话打开时 5s 轮询，离开路由即停（不加新端点）。
- 后端 `group-runtime` 记 `activeSpeakers`，`groupRoundStatus()` 供投影读；成员间隙为 null。

## 四、@ 消歧（契约小改）

- `parseMentionedIds` 支持唯一长标签 `@名字·<domain>`：域命中该成员才算点名；
  打错域 → 不命中（按普通文本，不回退短名）；成员无 domain 同理。
- 重名规则收窄为"**正文真的用了那个短名**才 400"（没写这个名字不再拦，照常走值日）；
  400 载荷带 `candidates:[{name, domain}]`。创建/改群时的重名校验不变。
- 前端 @ 菜单：带领域的成员显示「名字（领域）」并插入长标签；400 后出现可点的候选条
  （`#group-at-hint`），点一下插入 `@名字·领域`。时间线 @ 上色同步认长标签。
- 探针补：长标签命中 / 打错域不命中 / 重名 400 带候选 / 重名时长标签仍可点名。

## 五、消息合并与日期分割

- 日期分割改本地日界渲染：今天 / 昨天 / M月D日（跨年带年份），仍按本地时区取日。
- 合并条件补"同一天"（原来跨零点 5 分钟内会把两天并成一条，且日界线已插入）；
  跨天不合并。
- 回读与实时追加收敛到同一份 `groups.lastMeta` 游标与 `appendGroupMessageToThread`：
  实时流开始跨天也会补日界分割；流式气泡头像改为成员真实头像。
