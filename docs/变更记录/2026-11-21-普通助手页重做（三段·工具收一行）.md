# 2026-11-21 普通助手页重做（三段 · 技能可选 · 工具收一行）

> 范围：前端 `ts/apps/server/web/`（`worker-profile.js`、`partner-modals.js`、`style-22-partner-profile.css`）
> + 服务端 `src/skill-state.ts`、`src/skills-api.ts`、`src/agent/lifecycle-injections.ts`、
> `src/agent/lifecycle-harness.ts`、`src/tools.ts`、`src/worker-tools.ts`。
> 新增一个端点（普通助手技能开关）与 worker-tools 的一个只读字段；存储复用 `skills-state.json`。
> 技能选择的取舍见 `docs/设计方案/2026-11-21-普通助手技能选择（worker 独立命名空间）.md`。

## 为什么

用户对「设置 → 注入 → 人设 → 普通助手」提了几轮：

- 列表卡底下那行「所有普通助手会话共用这一份人设，改完下一轮生效」是解释文字，先不要。
- 点进去之后太丑、太空：只有一块正文，长句解释占地方（「Worker 会话与派活工人共用这份人设…」）。
- **间距**：会话卡里「所处项目」离卡片上边、「上下文」离卡片下边都远；工具行上下也松；
  人设正文框到卡片下边留了一大截。根因是卡片内边距 + 行内边距叠了两次，正文框还写死 240px。
- 「负责项目」不用填：普通助手不绑项目，项目是创建会话时确定的。但要在页面上**看得见**这个状态，
  且不可切换。
- 「能用的工具」四行大开关不合理——四件（读 / 写 / 改 / 跑命令）是本机工人干活的全集，
  摊成四个平级功能只是把页面撑开。
- 「上下文」这一行删掉。
- **技能要能选**：像执事个人页一样逐条开关，而不是只看计数。
- 工具太少：工人应该能向派出他的总管 / 执事提交消息。

## 改了什么

### 列表卡（`partner-modals.js`）

- 删掉普通助手卡下的 `pt-meta` 解释行；只留名字 + 「全部 Worker 共用」标签。
- 卡面 aria-label 从「编辑普通助手的人设」改成「打开普通助手设置」（页面已不止人设）。

### 详情页（`worker-profile.js` + `style-22-partner-profile.css`）

1. **人设正文**：头像 + 标题 + 字数；正文 textarea + 撤销 / 恢复默认 / 保存。
   删掉正文卡底部长句解释；只保留只读态 / 保存失败的提示行。
   正文框**按内容长高**（150–560px，超了内部滚），不再写死 240px 留一大截空白。
2. **会话**（只剩两行）：
   - `所处项目`：锁图标 + 「创建时确定」的只读控件（`aria-disabled`，点不动）；
     悬停说清「新会话跟随侧栏当前项目，创建后固定；派活按单子的 project 参数」。
   - `技能`：显示「全局 N · 独开 M」，点击开弹层逐条选（全局已开锁定只读 / 全局未开可只给普通助手开）。
     **不跳全局技能页**；语义见设计方案。
   - **`上下文` 行删除**（连同 `settings-context.js` 的 `?role=` 预选改动一并回退）。
3. **派活**：
   - `工具`：四件工具收成一行小标签（关掉的划线降透明度），逐条开关收进右侧 `⋯` 弹层；
     弹层里四行开关 + 一行只读「上报 · 恒开」，解释全挂 `data-tip`。全关时 toast 明说「下次派活没有任何工具」。
   - `上报` 标签：`escalate` 工具（2026-11-19 批2 已有）本来就随 native 工人上架，只是之前页面上看不见。
     worker-tools payload 新增只读 `escalate`（读 `WORKER_ESCALATE_TOOL`），页面据此画标签。
   - 删掉「派活带项目记忆」行：该回滚开关 2026-11-21 已随 27 项退役，功能恒注入；
     页面残留的开关入口本就不会渲染（flag 已不在清单），这次把死代码一并去掉。
4. **间距修根因**：`.wf-rows` 取消卡片上下内边距（`padding: 0 18px`），行高 48px、行内不再叠
   10px 的上下 padding；会话卡从 98px 起算（两行），工具卡 50px，首行文字距卡片上边约 24px。
5. **离开守卫**：正文有草稿时点「← 总管与执事」先弹「人设还没保存」；技能已是弹层，不再触发导航。

### 普通助手技能独立（`skill-state.ts` / `skills-api.ts` / 注入 / `tools.ts`）

- 复用 `skills-state.json` 的 `partners` 覆盖层，保留键 `worker`；不加新文件。
- 新端点 `PUT /api/v1/agent/worker-skills/:name/enabled`：全局已开 / core / 关闸 → 409，
  不存在 → 404；只写覆盖层。
- `skillPartnerOf`（索引 / 斜杠）与 `skill` 工具的 `skillOwnerOf` 依赖：worker 会话 → `worker`，
  不再回落 chief。
- 回滚：`WORKER_SKILL_SCOPE=false/0/off` → 回到回落 chief、新端点 409；覆盖位保留。
- **行为变化**：升级前 worker 会话会继承总管私开的技能；升级后只看全局开 + 普通助手自己的覆盖。
