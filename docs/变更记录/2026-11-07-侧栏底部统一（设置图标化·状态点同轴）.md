# 2026-11-07 侧栏底部：设置去文字、状态点与齿轮同轴

用户口径：「侧边栏收起的时候，绿色的点点在『设置』底下；但是展开的时候，它俩一个在左，一个在右，
然后『设置』就不用文字了，用图标就可以了。」

## 问题

收起轨道早就是「齿轮 + 正下方一个绿点」，但展开态是另一套：

- 齿轮是一整行导航行，右侧带「设置」二字（`justify-content: flex-start`，按钮宽 212px）；
- 状态是「圆点 + 连接中」一横排文字，靠左对齐。

两行都从左起排、字宽不同，视觉上就是左一块右一块；状态文案还让最后一行比导航行矮一档。

## 改了什么

- `index.html`：删掉「设置」二字（`aria-label` / `title` 已是「设置」）；状态去掉 `status-slot`
  包裹层，只留 `<i>` + 一个视觉隐藏的 `.status-text`（`role="status" aria-live="polite"`，
  读屏仍能播报「连接中 / 已连接 / 连接断开」，只是不占版面）。
- `style.css`：
  - `.side-foot` 由 `align-items: stretch` 改 `center`，两行都居中；底部 padding `8px 0 10px`。
  - `.side-foot .foot-gear` 收成 **40×40 圆形命中区**（同 `.rail-btn`），`display: grid` 居中，
    图标 22px——与收起轨道按钮同尺寸、同轴。
  - `.status` 只剩一颗 7px 的点、10px 行高、居中；三态色与 `.rail-status` 完全一致
    （ok 绿 / off 红 / waiting 呼吸灰）。
  - `.status-text` 用 `clip-path: inset(50%)` 的读屏隐藏法，不做 `display:none`（否则读屏也听不到）。

## 验证（2026-11-07，隔离 faux 服务 127.0.0.1:8232）

量测（Playwright `getBoundingClientRect`）：

| | 齿轮中心 x | 图标 | 状态点中心 x | 垂直间距 |
|---|---|---|---|---|
| 展开态 | 116 | 22px | 116 | 齿轮下 27px |
| 收起态 | 36 | 22px | 36 | 齿轮下 28px |

- 两种状态几何一致；三态颜色实测量到展开/收起**同色**（ok `rgb(31,157,77)`、off `rgb(178,88,79)`）。
- 25 个侧栏控件逐个体检：无浏览器默认边框（防「黑圈」回归）。
- 点击：展开态齿轮 → `#/settings`；收起态（用真实收起按钮切）齿轮 → `#/settings`。
- `node --check` 通过；`pnpm typecheck` 退出 0；`pnpm --filter @lifediary/server test` **264/264 通过**。

## 期间修掉的一个回归（本轮自己造成的）

改 `.side-foot` 那一块时用整段替换，误删了 `.side-item` 基础规则（侧栏所有行的共用样式：
无边框 / 圆角 / 高 38px / hover 底 / `aria-current` 强调 / svg 22px / disabled 透明度）。
后果是齿轮露出浏览器默认的 `2px outset` 黑边——正是用户上一轮嫌弃的那个「黑圈」。
已按 `git show HEAD` 原样恢复，并加了逐控件体检脚本防再犯。

## 已知边界

- 状态文字不再常驻可见，鼠标悬停在点上没有 tooltip（读屏与 `aria-live` 仍在）。
  如果之后想要「悬停看状态」，在 `.status` 上加 `title` 即可，不动布局。
