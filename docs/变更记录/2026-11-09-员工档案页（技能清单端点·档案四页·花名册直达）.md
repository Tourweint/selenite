### 前端四页的数据口径（全部复用既有端点）

| 页面 | 请求 | 呈现 |
|---|---|---|
| 工作履历 `records` | `GET /api/v1/agent/memory?scope=partner:<uuid>&limit=2000` | `kind==="work"` 倒序；content 原样（可换行）+ `createdAt` + `source` 徽章 |
| 记忆 `memories` | 同上（非 `work`） | 按 kind 分组 + 中文标签 + 条数徽章；每条 content + `createdAt` + `source` 徽章（taught / imported / user 原样小字） |
| 例行规则 `routines` | `GET /api/v1/routines?partnerId=<uuid>` | `name` + trigger 表达式原样（`cron` / `interval` / `once` / `event` 不翻译）+ `enabled` 徽章 + `sessionMode` |
| 技能 `skills` | `GET /api/v1/partners/:id/skills` | `name` + `summary`（首行）+ `updatedAt` |

- scope：执事 = `partner:<uuid>`；总管 `chief` 记忆在 `global`（系统架构 D15），故 chief 页走 `global`。
- 记忆与履历**共用一个端点、每次进页拉一次**（`limit=2000` 是服务端上限；`memoryEngine.list` 排序里 `work` 只是排在末位，不排除，所以前端能一次拿全量再按 kind 分拣）。刻意不缓存：抽屉开着期间新落的履历 / 记忆，切页就能看到。
- 四页空态话术逐字按任务书；`MEMORY_ENABLED=false`（404 `memory_disabled`）给「记忆未启用」而不是报错；
  执事能力整体未启用时 routines / skills 的 404 按空列表处理。
- 页面**只读**：没有任何编辑 / 删除 / 整理入口。编辑仍走人设页三卡与例行任务既有编辑面，
  记忆删除 / 整理沿用设置页记忆区。

## 设计上的刻意选择

- **新端点只读、不加开关、不进 shared / WRITE_TOOLS。** 无行为面就没有回滚开关的需求；
  响应形状只服务端与自家 web 页用，手机端不做（任务书登记），参照 9-S 技能管理端点的既有做法，
  不往 `ts/packages/shared/src/index.ts` 塞一个没人消费的 Zod schema。
- **只认 `Dirent.isFile()`。** 家目录里若有指向外部的符号链接，`isFile()` 为 false，顺带不把它端出去；
  不用再单列一套 realpath 复核（那是管理面写 / 读单条时才需要的口径，§2.19）。
- **不新建存储、不加端点给记忆 / 履历 / 例行。** 核对过 `memoryOverview` →
  `memoryEngine.list({scopes:[scope], limit})`（`agent/session.ts:1516`、memory 包 `engine.ts:273`）：
  排序 map 里 `work` 落到 rank 9 但**不被过滤**，所以一个 `scope=partner:<id>` 就能拿全量；
  前端按 `kind` 分拣即可，不需要第二个端点。
- **entity 组的中文标签复用设置页 `MEMORY_KIND_LABEL`（「人事物」）**，没有为档案页另立一套标签。
  任务书括注写的是「实体」，指的是 kind 不是字面文案；一处标签一份真相。
- **档案组只在 `csTarget` 有身份时出现。** 与首页「身份块」「备选模型」同口径：普通助手会话
  （`csResolveTarget()` 返回 null）没有角色可看，摆四行点进去只有说明等于噪声；四页自身仍留了说明兜底。
- **读取态有并发守卫。** `renderCsProfilePage` 拉回来后先复核「抽屉还开着 + 还停在这一页 + 目标没变」
  才重画，晚到的响应不盖掉用户已经切走的页（同 `refreshCsDetail` 口径）。
- **`toggleChatSettings` 只做了一次最小抽取**（打开段 → `openDrawerAt`），行为零变化：常规入口仍传
  `csResolveTarget()` / `home`；没有改它的关闭分支、事件绑定（`() => void toggleChatSettings()` 仍不带参数）。
