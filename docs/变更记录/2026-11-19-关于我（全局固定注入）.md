# 关于我：全局固定注入 + 每 Agent 读取开关（2026-11-19）

## 做了什么

新增设置一级页 **关于我**（`#/settings/about-me`）：一份全局的主人固定背景，每轮作为
**system 段** `user_profile` 紧跟 persona 注入；每个 Agent 一个读取开关；普通 worker 会话与
派活工人**固定不读**。方案见 `docs/设计方案/2026-11-19-关于我（全局固定注入）.md`。

同时把旧的 per-partner `memories/USER.md`（"主人画像"）从执事身份里退役——同一个概念不能
有两处真相。文件与 `readUserMd()` 保留兼容，不再注入。

## 为什么这么切

- **不进记忆**：记忆是打分召回（重要性 0.45 + 新鲜度 0.3 + 关键词 0.2 + 召回次数 0.05，
  16 条 / 2000 字），语音输入错字恰好让查询文本本身带错——"每轮都必须在"的用户习惯不能靠召回。
- **不改人设**：SOUL 是"它是谁"；写进人设会让每个执事各存一份、迟早漂移。
- **每 Agent 开关而不是全局一刀切**：主人大部分时间不和普通 worker 说话，不希望每个会话都背一份；
  默认开（新能力净增类默认开），worker 固定不读（用户明确口径，不为它再开一个开关）。
- **群会话跳过**：多人上下文里不带个人档案，v1 明确不做。
- **系统段而非消息注入**：与 persona 同层，不写进对话历史、不占每轮消息预算的位置。
