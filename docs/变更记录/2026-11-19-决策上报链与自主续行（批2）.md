# 决策上报链（worker→总管→用户）与自主续行（2026-11-19 批2）

方案：`docs/设计方案/2026-11-19-决策上报链（worker→总管→用户）与自主续行.md`（用户拍板：权限不动，做"哪些事需要往上问、需要上级决策"；质检=派 worker+提示词，不写代码）。

## 改了什么

- **契约先行**：`shared` ChatEvent 新增 `escalation` 成员（`ticketId/domain/escalationId/question/context/options?/urgency/seq?`），快照测试同步。SSE 透传白名单 + ChatStreamEvent 成员；openai 兼容层两处跳过（手机不进聊天流）；routines/autonomy 订阅方加中性分支。
- **worker 侧**（chancellor）：工具面加 `escalate`（`WORKER_ESCALATE_TOOL=false` 不注册，回滚形态与改动前逐字节一致）；**上报等待**——escalation 已发出未答时主循环挂起（不续轮、不退场），答复经批1 steer 通道进来即解除；**自主续行**——初始轮收尾后 REPORT 非终态且 `WORKER_TURN_BUDGET`（默认 3，0=关）有余量 → followUp 自动接轮（`[续行]` 标记+上轮汇报锚点）；**无进展保险丝**——连续 3 个续行轮零工具调用 → REPORT blocked 退场；每段续轮前查宿主存活（ppid 轮询）与作废帧（`{"type":"control","action":"abort"}`，复用批1 同一条 stdin）；续行判定全在纯函数 `worker-continue.ts`（8 单测）。
- **宿主路由**：新模块 `escalation.ts` 全局订阅派活事件——注册/限流（每单 1 条活跃；`ESCALATION_MAX_PER_TASK` 默认 5，超限直达用户）/路由（派活方是执事 → 批3 `wakeOnAgentMessage` 信封唤醒其 canonical 会话；是总管 → `continueConversation` 起代答轮）。`respond_escalation` 工具（按需池 8→9）：`action=answer` → 答复经批1 插话通道 steer 投回 worker + 台账署名；`action=escalate` → 现有 ask_user 管线（`approval-api` 加 `onAskAnswered` 钩子，升级答复直投 worker、不给总管续跑）。新端点 `GET /agent/escalations` / `POST /agent/escalations/:ticketId/route`（挂 `/api/v1` 鉴权下）。作废单联动：cancel 成功后对活 worker 推 abort 帧（best-effort）。
- **质检 worker**（0 新逻辑代码）：`.data/executor.json` 加 `qa:"internal"|"qa-worker"`（env 缺省 `CHANCELLOR_QA_MODE`）；`templates/qa.md` 纯提示词模板（结论行 `DONE:/CONTINUE:/BLOCKED:`）；`qa.ts` 注入缝 + 模板替换 + 结论解析（纯函数）；宿主 `qa-bridge.ts` 用既有派单器派质检单。**边界（如实）**：质检 CONTINUE 走既有返工轮——验收时原 worker 进程已退场，批1 steer 通道物理上到不了，不硬造。

## 缓存前缀资产说明（工具描述）

- `respond_escalation` 为**新增**工具、默认按需池成员（不进常驻前缀）；注册顺序在 `ask_user` 之后（`tool-schema-guard.test.ts` 清单已更新）；能力声明 `readOnly=false/destructive=false/needsApproval=never`。
- `escalate`（worker 子进程工具面）不进宿主前缀。

## 边界（刻意没有 / 已知限制）

- 上报等待期**无超时**：靠宿主管道关闭/作废帧/超时顺延兜底；宿主重启丢内存活跃集（worker 等不到随管道关闭退场）——按"不做持久化状态机"拍板点到为止。
- 总管真调 `respond_escalation` 的轮次未 e2e（faux 总管无法按运行时单号调工具；执行逻辑单测覆盖）——真模型链路留给浏览器验收。
- 外部 CLI 无 escalation/续行（进程外，如实不做）。
- 审批代批不做（用户拍板权限不动）；`unattended.ts` 的审批 skip 行为不变。
