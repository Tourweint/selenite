# 2026-11-03 设置页分层重排（对齐 cindy）

## 改了什么

设置页从「一整页所有分区 + 侧栏滚动定位」改成 **cindy 同款分层结构**：左侧分区导航点击后
**真切页**（hash 子路由 `#/settings/<分区>`），一次只渲染当前分区的 DOM。只动
`ts/apps/server/web/`（index.html / style.css / app.js），无契约、无服务端改动。

## 为什么

原设置页 6 个分区全在一页里，侧栏只是 `scrollIntoView`，找设置项靠滚；内容宽 640px 偏窄、
节标题 12px 偏弱、进场动画是 6 组错峰上浮（和分区导航无关）。按用户要求对照参考项目
cindy（`<reference>\cindy`，2026-11-03 读取其
`apps/desktop/src/renderer/components/settings/SettingsView.tsx`、`SettingsSidebarNav.tsx`、
`settingsRowClasses.ts`、`tailwind.config.ts`）重做。

## 从 cindy 学的尺寸（2026-11-03 核对）

- 左栏固定 **260px**（padding 24/16/28）：返回行 = 28px 圆形返回钮 + 24px/500 标题，
  底距 18px；下面是胶囊导航（高 36px、圆角 full、图标 15px、行距 2px）。
- 内容列独立滚动，内容宽 **max-w 920px 居中**，页底留 **128px** 呼吸；
  容器 `scrollbar-gutter: stable`，切页时内容宽度不跳。
- 节律：**标题在卡片外**（16px/500），标题-卡片间距 14px，节距 18px；
  行 `padding 12/16`、min-height 56px，行标签 13.5px/500、说明 12px，分割线左右缩进 16px。
- 导航选中态是**中性灰胶囊**（cindy `sidebar-item-active` ≈ 浅灰；我们用 `--card-high`），
  不用强调色；hover 走 `--card`。

## 从 cindy 学的动效

- **切页 150ms 纯 opacity fade**（cindy fast 档 + `cubic-bezier(0.16,1,0.3,1)`，compositor-only），
  挂在 `.set-page.enter`，每次渲染重放；瞬时回顶不做平滑（cindy review 反馈同款理由）。
- hover / 选中 150ms 过渡；返回钮按下 `scale(0.96)`。
- 原「6 组分组错峰上浮」删除——cindy 切页只淡入整面板，不做逐组错峰。
- 分段滑块（segment-slider）的 plate 滑动是我们已有的，等价 cindy 的 plate，保留。
- `prefers-reduced-motion` 全局既有规则继续覆盖。

## 路由

- `#/settings` → 缺省落「外观」；`#/settings/connect` 等子页可直接深链；
  浏览器前进/后退可用；`?view=settings[/<分区>]` 深链（壳托盘用）透传分区。
- Esc 返回聊天页（原有行为不变）；导航按钮 `role=tab` / `aria-selected`，
  内容容器 `role=tabpanel` + `aria-labelledby`。
- 每个子页只加载自己需要的数据（连接页才拉配对码/设备列表，提醒页才拉提醒，
  服务页才拉用量），配对码定时刷新只在连接页驻留时跑。
- 「权限」从「会话」卡片里拆成独立一节（跨页真分层的第一步，页内也分层）。

## 刻意不做的

- **不做设置内全局搜索**（cindy 有 SettingsSearchBox）：我们 6 个分区体量还小，
  搜索会话保留在「会话」页，等分区多了再立项。
- **不搬 cindy 的 12px 卡片圆角**：本仓库形状 token 是 8/12/16/24、分组卡 16px
  （2026-10-21 手机端口径），只借布局/节律/动效，不破自己的形状语言。
- **侧栏折叠按钮（«/»）删除**：cindy 固定 260px 不折叠；窄窗口（≤800px）降级为
  顶部横向胶囊导航。
- `lifediary.settingsNav`（旧折叠状态）localStorage 键不再读写，留着无害。
