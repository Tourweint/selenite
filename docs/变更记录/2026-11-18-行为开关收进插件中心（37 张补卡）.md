# 行为开关收进插件中心（37 张补卡）

**日期**：2026-11-18  **状态**：已落地（未重启生效——`hot:false` 项与消费代码要重启；清单本身热更新）

## 改了什么

用户口径：「有哪些能够变成插件的，把它变一下，把开关放到插件中心里头」。对全仓 env 开关做了一轮
**代码级清点**（`grep` 全部 `flagEnabled/flagValue` 消费点 + 全量 env 键扫描），把散在裸 env 读取里的
用户行为开关收进 `src/plugins.json` 清单，插件页（设置 → 插件）从 44 项 / 6 组扩到 **81 项 / 7 组**：

- **37 张新卡**：对话基本能力 +6、记忆 +7、自主与派活 +11（含 1 张 core）、普通助手（工人）新组 +4、
  技能与课题 +2、任务与界面 +7。
- **新分组「普通助手（工人）」**：`WORKER_CHAT_ENABLED` / `WORKER_PERSONA_EDIT` /
  `WORKER_PERSONA_DISPATCH`（重启生效）/ `WORKER_TOOLS_DISPATCH`（重启生效）。
- **1 张新 core 卡**：`AGENT_TOOL_POLICY`（工具写权限，full / no-shell / read-only 三档）——工具写权限
  是安全边界，跟记忆 / 执事体系 / 宰相 / 自主轮并列系统核心，core 从 4 项变 5 项。
- **消费点统一改走 `flagEnabled()/flagValue()`**（24 个文件）：此前这批开关全是裸 env 读取，清单卡拨了
  也不会生效；现在 plugin 项读 `.data/agent-flags.json` 覆盖（env 作部署回落），`AGENT_TOOL_POLICY` 作为
  core 保持启动 env 装配。

## 收口判据（哪些不进）

进清单 = **用户认得出的「功能有没有」**：开了是什么样、关了回到什么旧形态，一句话能讲清。
不进、继续走 env：

- 机制参数 / 回滚微开关：`DELEGATION_*` 家族、`ROUTINE_QUIET`、`TOOL_LOOP_GUARD`、`TASK_KEYED_BASELINE`、
  `MINISTER_DIRECT_DISPATCH`、`AGENT_STALL_TIMEOUT_S` 等——它们是批次的逃生门，不是功能。
- 路径与额度：`ATTACHMENTS_DIR` / `ATTACHMENTS_MAX_MB` / `AGENT_SKILLS_DIR` / `PERSONA_MEMORY_ASK` /
  `AGENT_TOOL_POOL_PATH` 等（沿用 flags 层白名单口径：路径 / 令牌类一律不收）。
- 模型行为调优：`AGENT_THINK_*`、`MEMORY_DECAY_DAILY`、`MEMORY_RETRIEVER`、`MEMORY_SESSION_CAP` 等。
- `CHIEF_PARTNER`（总管身份是产品默认形态，不做成可拨卡）。

## 语义变化（两处，都是有意收紧）

1. **布尔判定统一 `false / 0 / off` 算关**。原有两个开关是「只有显式 `false` 才关」：
   `CHAT_CONTEXT_INSPECT`、`CHAT_CONTEXT_LOOKUP`（`0`/`off` 原本算开）。收进清单后走统一的 `flagIsOff`
   口径，`0` / `off` 也算关；两处单测断言同步改。其余转换键的原口径（`false|0|off`、`1|true|on`）
   与清单口径逐值兼容，唯 `DEVICE_MATRIX_ENABLED` / `COMPANION_HOME_ENABLED`（原只认 `1/true/on`）改为
   「非 off 即开」——垃圾值从关变开，方向无害。
2. **requires 刻意从简，不越轴**。只挂「父关时子项本来就不可能生效」的硬依赖
   （如 `DELEGATE_WORKDIR` → `CHANCELLOR_ENABLED`、`PARTNER_LEARNING_FREQUENCY` →
   `MEMORY_ENABLED` + `PARTNER_PERSONA_MODULES`、`MEMORY_NIGHTLY_SPLIT` → `MEMORY_NIGHTLY_REVIEW`、
   项目三卡 → `CURRENT_PROJECT`）。**`PARTNER_PROJECT_MEMORY` / `PROJECT_MEMORY_GATE` /
   `PROJECT_MEMORY_ACTIVE_ONLY` 三键刻意不挂父**：首轮给 `PARTNER_PROJECT_MEMORY` 挂了 `MEMORY_ENABLED`
   父闸，companion-api 测试环境（记忆总闸全局关）立刻投影字段消失——它们的消费点连着文件夹挂载与
   投影，父闸锁会越出这张卡自己的轴，当日摘除并登记。这与「插件中心与父子开关」方案 §2.1
   「不伪装成锁」的口径一致，只是从「不进清单」放宽为「进清单但不挂父」。

## hot 口径

挂载 / 注册期冻结的标 `hot:false`（改完重启生效）：`WORKER_PERSONA_DISPATCH`、`WORKER_TOOLS_DISPATCH`
（启动装配一次）、`AGENT_APPEARANCE_WALLPAPER`（路由挂载）、`AGENT_TOOL_INDEX`（工具注册）、
`SKILL_ADVICE`（路由挂载）、`AGENT_TOOL_POLICY`（core，启动 env 装配）。其余全部 `hot:true` 即时生效。
