# 2026-11-23 上下文页回到浮动卡片（「全部」默认收起）

## 用户口径

> 「系统提示词还是做成浮起来的小窗比较好，不要做成这样……像复习小卡片那样。」

> 「咱们看全部的时候才有这个收起就可以了。不看全部的时候不用收起就行了。」

> 「看全部的时候……按它的时候你默认收起就行了。然后外边这个收起按钮，你随便吧。」

落成三条：

1. 页面不铺正文，四段内容只在浮动小卡里看；
2. 单组卡（点某个图例 / 格子）**没有**「收起」，就是一张普通小卡；
3. 只有点「全部」才出现收起，而且打开就是**全部组都收起**、只列组头，想看哪组点哪组的「展开」。

## 改了什么

| 文件 | 改动 |
|---|---|
| `web/settings-context.js` | 删掉卡片级 `collapsible` / `togglePopFold` / `data-ctx-pop-fold`；`groupSectionMarkup(group, color, { foldable, folded })` 按参数决定组头有没有「收起 / 展开」、body 是否默认隐藏；`openGroup("__all")` 传 `foldable: true, folded: true`；请求详情的两个组不传，保持展开、无按钮 |
| `web/style-24-context.css` | 保留 `.ctx-pop-fold`（现在只用于组头）、`.ctx-pop-group.is-folded` 组头补白；删掉 `.ctx-pop.is-folded` |
| 保留 | `sessionParts` 把 `toolResults` 并进「对话与工具」（4 段，没有单独的「工具结果」图例） |

## 结构

- 页面：标题栏 → 总览卡（格子 + 4 个图例）→ 请求卡，整页 1,850px，请求卡首屏可见。
- 单组卡：`标题 · 数量 · token ×`，没有收起；行默认折叠，点一行看原文。
- 「全部」卡：`全部内容 · 4 组 · ≈20,978 token`，下面四行组头
  `系统提示词 / 工具定义 / 技能 / 对话与工具`，各自右侧一个「展开」，组里的行全部藏着。
  点「展开」才展开那一组；再点「收起」收回去。整张卡收起状态高 250px。
- 请求详情：`固定前缀`、`当时已存档的消息` 两组，保持展开，组头不带收起按钮。

## 验证

- `node --check web/settings-context.js` 通过。
- 本机 39847（真实数据，只读 GET）实测：
  - 单组「系统提示词」：卡片头收起按钮 0 个，8 行在；
  - 「全部」：4 组、4 个「展开」、4 个 body 全隐藏，卡片高 250px；点第一组展开 → 8 行出来，卡高 575px，其余 3 组仍收起；
  - 请求详情：2 组、组头收起按钮 0 个；
  - `pageerror` / console error 为 0。
- 未跑：`pnpm typecheck`、全量单测（只改 web 渲染与样式）。

## 边界

- 「收起」现在只有「全部」里才有；单组卡与请求详情都没有。
- 行本身的折叠（点一行看原文）与组的收起是两层；组收起只影响这一组的行显不显示。
- 默认开销模式仍走单组浮层，同样没有收起。
