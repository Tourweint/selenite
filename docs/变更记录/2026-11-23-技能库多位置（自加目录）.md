# 2026-11-23 技能库多位置（自加目录）

## 用户口径

「现在注入这里头选技能的时候，技能库只能选默认位置，我希望能够添加多个位置……就是选择不同的位置」，
同时「把这个前端的界面再排得整齐一点」。

改动前只有一条写死的读取链（主目录 → `~/.agents/skills` → 内置），
写 / 删都只能落在主目录，页面上只有一行「位置：<主目录>」。

## 为什么这么定

- **主目录永远第一**：自加位置顶到最前会让同名归属不可预测；顺序＝登记顺序，先到先得。
- **默认写主目录**：不选位置的老习惯不变，只有主动选位置才落到别处。
- **移除位置只删登记**：和「项目移除文件夹」同一条纪律，避免在设置页误删一整个目录。
- **不做位置排序 / 设主位置**：换顺序 = 移除后重加，第一版不维护第二套顺序契约。
- **页头只留一行标题**：原来「技能 / 技能库」两行标题重复，计数与动作各占一行；现在标题 + 计数 + 动作同一行。

## 没做 / 边界

- 不做跨位置搬移 / 合并同名技能；不按位置过滤列表。
- 不改执事个人技能的写目标（仍写执事私有目录）；总管私技能目录仍前置在总管会话的链首，不在本页管理。
- 不自动创建自加目录、不自动清理消失的目录（页面上如实标「不存在」，可移除）。
- 服务端改动**要重启 server 才生效**（当前进程非 watch 模式）。

## 回滚

- 界面级：逐个移除自加位置即可（每个位置一次 `DELETE /agent/skill-dirs`）。
- 能力级：`SKILLS_EXTRA_DIRS=false/0/off` → 忽略自加位置、两个位置端点 404；`skills-dirs.json` 原样保留。
- 代码级：revert 本批；旧代码不读 `skills-dirs.json`。
