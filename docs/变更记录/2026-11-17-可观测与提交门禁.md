# 2026-11-17 可观测（一轮时间线）+ 提交前契约体检

## 改了什么、为什么

用户拿一段"企业级 Agent 平台"JD 文案逐条核查后，明确只补两件投入小的工程卫生，
不追多租户 / 真分布式 / 自动自演进（详见 `docs/设计方案/2026-11-17-可观测与提交门禁.md`）。

**一轮对话时间线（串账）**
- 新增 `apps/server/src/turn-timeline.ts`：按 `/chat` 已有的 SSE `start/done.id`（uuid）
  给每轮发单号，把工具调用 / 闸门拦截 / 模型回合 / token 用量 / 收尾追加进
  `.data/turn-timeline.jsonl`。钩子拿不到流 id，用进程内 `internalId → turnId` 小表
  （上限 512）反查，`beginTurn` 在 `/chat` 入口登记。
- `index.ts`：入口 `beginTurn` + start；usage 事件记 token；错误记脱敏类别枚举；
  done 记结束状态 / 字数 / 耗时；新增 `GET /agent/turn-timeline?turnId=<uuid>`（§2.5）。
- `lifecycle-harness.ts`：beforeTool 拦下记 gate、afterTool 记 tool、beforeRequest 记 round。
- 只记枚举 / 计数 / 字数 / 耗时，绝不记工具参数 / 输出 / diff / 对话正文 / 原始错误 /
  内部整数 id（GET 投影）。开关 `TURN_TIMELINE=false` 停记 + 端点 404；测试隔离
  `AGENT_TURN_TIMELINE_PATH`。**不改 shared 契约、不加 SSE 字段、不动手机端**。

**提交前契约体检（pre-commit）**
- 新增版本化 `.githooks/pre-commit`：每次提交只跑契约形状快照
  `packages/shared/src/snapshot.test.ts`（硬阻断），`tsc --noEmit` 仅告警。
  全量单测 / probe / http / memtest 不进钩子（AGENTS.md §验证 留给手动）。
  `--no-verify` 可跳过；依赖未装告警放行。
- 新增 `.gitattributes`（`.githooks/*` 与 `*.sh` 钉 LF，防 Windows `/bin/bash^M`）、
  `scripts/install-hooks.sh`、`ts/package.json` 加 `hooks:install`。已执行安装，
  `core.hooksPath=.githooks` 生效（覆盖所有会话）。
