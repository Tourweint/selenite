# 外部执行三档：CodeBuddy / Qoder 国际版 / Qoder CN

- 日期：2026-11-03
- 范围：`<chancellor>\src\employee\cli.ts`（新）、`external.ts`（新）、
  `qoder.ts`（新）、`mercenary.ts`（改为兼容别名）、`codebuddy.ts`（改用统一底座）、
  `employee/index.ts`、`types.ts`、`config.ts`、`index.ts`、`main.ts`；
  harness `src/qoder.test.ts`（新）、`scripts/qoder-probe.ts`（新）、`package.json`、`.env.example`
- 依据：`docs/设计方案/2026-11-03-宰相层（分管子代理）.md` §5.6

## 做了什么

1. **统一底座** `employee/cli.ts`：三个 CLI 共用
   `parseCliStdout`（数组 / 单对象 / 逐行）、`isCliSuccess`（exit0 + 非空 result +
   非 error + `permission_denials` 为空）、`runCliProcess`（stdin、超时、abort、killTree）。
2. **CodeBuddy** 改用统一底座；npm 的 `.cmd/.ps1` 壳仍解析成 Node 入口再起进程。
3. **Qoder 国际版 / CN** 新增 `employee/qoder.ts`：
   - 写任务 `--permission-mode bypass_permissions`、纯问答 `dont_ask`；
   - `-o json`、`-m <model>`、`--max-turns`（写任务 40，纯问答 6）；
   - 提示 >8K 走 stdin；
   - 0 字节 `qodercli*.exe` 自动回退到同目录最高版本真身。
4. **选择顺序** `employee/external.ts`：`codebuddy → qoder-intl → qoder-cn`，
   `--version` 健康检查带缓存，`selectExternalCli()` 取第一个可用档位；`doctor` 会打印三档状态与当前首选。
5. **雇员类型** 新增 `qoder-intl` / `qoder-cn`；`mercenary` 保留为国际版别名，拆单/验收调用不变。
6. `.env.example` 补 `CHANCELLOR_QODER_CN_BIN` / `CHANCELLOR_QODER_CN_MODEL`。

## 没做的（留在后续阶段）

1. `-r <session_id>` 续接；`session_id` 已解析返回，但执行者还没有"继续改"的任务语义。
2. 负责人按任务改档位、失败/登录过期自动换下一档（同一任务不并行两档）。
3. 外部执行在 worktree 里跑、权限再收紧（等 §5.4 租约与隔离）。
4. 拒绝场景 / 超时 / cancel 只有单测与既有 `killTree` 模式，没有真实构造。
