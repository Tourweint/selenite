# 2026-11-13 侧栏去装饰（状态点·空闲·档案小图标）

## 改了什么

| 文件 | 改动 |
|---|---|
| `ts/apps/server/web/index.html` | 总管条目删掉 `<i id="chief-dot" class="status-dot">` |
| `ts/apps/server/web/app.js` | 花名册行删掉状态点、`空闲` 文案、员工档案小图标（`profileBtn` / `CS_ICONS.idcard`）；`el` 里删掉 `chiefDot` |
| `ts/apps/server/web/app.js` | 行内保留：头像、名字、领域标签、派发权拨杆、在办单数、忙因胶囊（忙时才出现） |

## 为什么

用户原话：「绿色的小点是总管，右边绿色圆点是……执事右边的点点，显示空闲，再显示他的卡片。员工信息先不管，也可以去掉，我觉得这些多余，没必要吧。把这些展示都去掉就行了，不用展示了。」

一行里同时有：状态点、`空闲`、档案图标、领域、派发拨杆、单数——「谁」和「有什么活」被装饰挤掉。现在的口径是侧栏只回答两件事：这是谁、他手上有几单；状态去会话里看。

## 口径

- 总管行不留状态点（总管状态在右侧抽屉/设置里看）。
- 执事行只在 `active > 0` 时给「N 单」；没单就是空的，不再写「空闲」。
- 忙因胶囊保留（只在真忙时出现，是事实不是装饰）。
- 员工档案入口从侧栏撤掉；右侧对话设置 → 档案 → 工作履历仍可进（`openPartnerProfile` 未删）。
- 收起轨道的悬停浮卡与展开花名册同一份 `renderRoster`，一并生效。

## 附带修掉的一处线上故障

`ts/apps/server/web/app.js`：工作树里有一版未完成的 E1「灰块流」重写（`createToolFlow` / `toolFlowFromSteps`），但发送链路仍调用 `createWorkPanel`，历史回读调用 `workPanelFromSteps`——旧函数已被这次重写删掉，于是**打开任何带工具的历史都会抛 `workPanelFromSteps is not defined`，发一轮工具也会抛 `createWorkPanel is not defined`**（产品页面直接挂错误卡）。

处置：按 HEAD 原样恢复 `createWorkPanel` 与 `workPanelFromSteps` 两个函数，历史回读调用改回 `workPanelFromSteps`；E1 两个新函数留在文件里但未接线，等 E1 方案拍板后整体替换，不做半截接线。

## 验证

- 产品浏览器（1280 宽，侧栏展开）：总管行只有头像 + 名字 + `总管` 标签；执事三行（阅读助手 / 记账助手 / 纪要员）只有头像 + 名字，DOM 里该行 `i,button` 子节点为 0；总管会话顶栏仍是「总管」。
- 打开带工具的总管历史：`已工作 7s 2 步` 折叠块正常还原，无 `ReferenceError`，无错误卡。
- 控制台无 error / warning。
- 截图：`.screenshots/gap/roster-clean.png`。
- **没验的**：发送一轮真会调工具的请求没实跑（怕往现有会话里塞测试消息）；`createWorkPanel` 与 HEAD 逐字一致，靠的是代码同源而不是运行验证。设置页、右侧抽屉的状态点/状态文案本次未动。
