# 2026-11-24 工具块分页展开（每页 30 步 · 行尾「+N」）

**改了什么**

1. `ts/apps/server/web/tool-chips.js`：把原型的分页逻辑搬进真实实现。
   - 固定每页 `CHIP_PAGE = 30`（运行中与展开态同一档，不做设置项）。
   - 跑动行：行首「工作 N 步」折叠条 + 一行装得下的块 + 行尾「+N」；「+N」= 这一组
     **当前被收起的块数**（剩余总数，不是页大小）。
   - 展开态只铺前 `revealed` 枚；余下进「+N」。点「+N」：跑动行 → 进展开态第一页；
     已展开 → `revealed += 30`，到顶消失。折叠条从收起 / 一行报数重新展开 → 回到第一页。
   - 每次翻页只给新出现的这 30 枚播 `tchipFanOut`（从点击前「+N」的实际位置飞回各自
     格子，16ms 一枚排队、24 号封顶）；已铺着的块不重播。收起时清掉块上的内联动画。
   - 展开后新到的块一律压进「+N」，不自动铺开——保证每次点「+N」仍是固定 30 步
     （2026-11-24 用户复试口径；初版 `atLiveEdge` 自动跟队尾已删）。运行中的块在跑动
     单行视图仍按原 pinned 规则永远可见。
   - 「+N」数字变化播 180ms 小弹跳（`translateY(-1px) scale(1.14)` 再落回）。
   - **点「+N」时先钉住它再发牌**（用户追加口径）：点击瞬间量旧屏幕坐标，
     `freezePager()` 克隆一枚绝对定位挂在 `.msg` 里、`opacity:0` 隐藏（旧数字不在旧位置
     干等）、真身留在流里占位且 `visibility:hidden`；发牌从克隆位置发出，
     `dealDuration(count) = 240 + min(count-1,24)*16 + 60` 后 `releasePager()` 把新数字
     淡入并 260ms 滑到真身新位置（没有下一批则直接收掉克隆）。
     `releasePager` 另挂 340ms 计时器兜底；`cleanupPagerGhost()` 在收起 / reset /
     再次冻结 / 点折叠条时清克隆与计时器。折叠条展开不克隆（它本身不挪位），但坐标
     同样在点击那一刻先量（`openAnchorRect`）。
   - 头部注释、`planRowChips` JSDoc、`syncFold` 附近的旧口径一并更正。
   - 新增纯函数 `nextRevealCount(revealed, total, page = 30)` 与
     `export function setChipPagingEnabled(value)`。
2. 回滚开关 `TOOL_CHIP_PAGING`（默认开、hot）：
   - `ts/apps/server/src/plugins.json`：`ui` 组 `keys` 加 key，并加定义（label「工具块分页展开」）。
   - `web/state.js`：`toolChipPagingFlag` 投影；`web/app.js`：首屏 `ensureFlag` 后调
     `setChipPagingEnabled`；`web/settings-switches.js`：设置页拨杆改动即时更新。
   - 关掉 = 2026-11-24 之前的旧形态：展开就是全部、跑动行没有「+N」。
3. `web/style-06-tool-blocks.css`：`.tchip-more { font-variant-numeric: tabular-nums; }`
   （9→10 时块宽不跳）；注释里「行尾 +N 已退役」改成准话（2026-11-21 退役的是固定枚数与
   「收起」按钮，2026-11-24 起「+N」以分页形式回归）。
4. `qa/tool-chips.check.mjs`：过期断言「灰块行没有写「几步」」改成现行口径——
   行首折叠条必须报「工作 N 步」、行内不许出现「秒」。另把点详情前的等待从固定 400ms

**为什么**

长轮几十上百步，展开一次全铺会把正文刷掉几屏；用户 2026-11-24 拍板「每次追加 30 步」，
行尾「+N」报剩余总数、点一次再要一批。原型已给用户看过并确认形态，本批只做落地。

**开关**

`TOOL_CHIP_PAGING`：插件页「任务与界面 → 工具块分页展开」，默认开、hot:true；
也认 env（`false` / `0` / `off` = 关）。纯前端开关——值走 `PUT /agent/flags/TOOL_CHIP_PAGING`，
前端排版时读模块变量，下一帧 / 下一次交互生效。**改 `src/plugins.json` 需重启服务**才看得到
插件卡（静态 web 文件每次读盘，不用重启）。

**2026-11-24 复试修正（用户看完真实实现后）**

1. **删掉 `atLiveEdge` 自动跟队尾**：初版在展开态翻到当前队尾后，后续新到的块会继续自动显示，
   用户实测「点第二下之后后面全展开了，再没有 30 步一轮」。现在 push 不再改 `revealed`，
   新块一律压进「+N」，每次点「+N」固定加 30（不足 30 取剩余）。
2. **幽灵发牌期间先隐藏旧数字**：初版克隆带着旧「+N」停在旧位置干等，用户觉得「旧文字留存一小段时间」。
   现在克隆 `opacity:0` 发牌；发完把新数字淡入并 260ms 滑到真身新位置；没有下一批则直接收掉克隆、不做淡出。
3. **复核（headless Edge，真模块）**：演示页 `?real=1` 直接加载 `web/tool-flow.js` + `web/tool-chips.js`：
   - 60 步：跑动行 4 枚 / `+56`；展开 30 / `+30`；翻到 60 / `+N` 消失；
     再追加 20 枚 → **visible 仍 60、`+20`**（不自动铺开）；再点 → 80/80、`+N` 消失。
   - 120 步：30 → 60 → 90 → 120，每页都是 30；点「+N」瞬间克隆 `opacity:0`、真身 `visibility:hidden`，
     1.2s 后克隆收掉、新数字在真身位置可见。
   - `pnpm typecheck` 0；全量 1515/1515。
   - 页面唯一 console error 是 `/favicon.ico` 404（演示静态服务不提供图标），与模块无关。
