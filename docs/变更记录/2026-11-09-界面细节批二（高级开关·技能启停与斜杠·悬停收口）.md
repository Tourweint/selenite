## 改了什么

### 服务端（新开关层 + 技能启停）

1. **flags.ts（新）**：运行时开关层。16 项白名单（FLAG_DEFS，hot/缺省值逐项标注）；
   `loadFlagOverrides()` 启动把 `.data/agent-flags.json` 覆盖写进 process.env（在 loadEnvFile/injectProviderKeys
   之后、路由挂载之前）；`setFlag` 落盘+同步写 env——**既有消费代码零改动即热生效**
   （消费处全是函数内懒读，逐处核对：autonomy/policy/projects/attachments/memory-extract/memory-ingest/
   partners 派发权/relay-config/work-record/routines/skills-api 均懒读；COMPANIONS/GROUPS/CHANCELLOR/
   TOPICS/SKILLS_ADMIN/ROUTINE_SELF_SERVICE 六个是启动期冻结，标 hot=false「重启后生效」）。
   端点：GET /api/v1/agent/flags、PUT /api/v1/agent/flags/:key；`AGENT_FLAGS_UI=false` 整组不挂。
   白名单不收路径/令牌/密钥类。
2. **skill-state.ts（新）**：技能启停位，`.data/skills-state.json` 存 enabled 名单，**名单外一律视为关**
   （默认全关）；`SKILL_STATE=false` 逃生门 = 回到全部进索引。
3. **skills.ts**：`createSkillStore` 加 `visible(name)` 过滤（索引/names/manual 三处同源；
   全关时索引整个省略）；新增 `skillSlashOf` 纯函数（/名字 解析，与 SKILL_NAME 同一条名字规则）。
4. **agent/assist.ts**：skillStore 构建传 `visible`（懒取 getSkillState，.env 就绪后才解析路径）。
5. **skills-api.ts**：GET 列表 items 带 `enabled`；新增 PUT /:name/enabled（存在性按加载器同一条扫描，
   关着的也能重新开）与 PUT /enabled-all 批量；启停只限白名单名（管理面既有规则）。
6. **agent/lifecycle.ts**：beforeRequest 钩子加技能斜杠注入——用户消息以 /技能名 开头且技能开着时，
   手册整份作为本轮 system 注入（D5「正文按需取」的那一次）；不改契约、手机端同享。
7. **index.ts**：loadFlagOverrides() 挂载前调用 + mountFlags(app)。

### 前端（web/ 三件）

8. **高级开关卡**：设置 → 服务 新增「高级开关」区，15 行（开关 14 + 记忆抽取三档分段），
   每行悬停解释写明当前值与即时/重启；改动 toast 如实报「即时生效 / 重启服务后生效」。
   权限页「自主轮」只读行文案改为指向高级开关。
9. **技能页**：卡片加逐条开关；头加「全开/全关」；标题悬停解释更新（默认全关/斜杠调用/下一会话生效）；
   「技能管理未启用」文案维持（等服务重启的提示不变）。
10. **斜杠选择器**：对话输入 `/xxx` 弹开着技能单（30s 缓存、前缀过滤），↑↓/回车/Tab/点击补全成
    `/名字 `，Esc 收起；挂在 document 捕获段，抢在 Enter 发送之前；普通打字零干扰。
11. **悬停收口**：rowMarkup 的 ⓘ 图标退役（data-tip 直接挂标签文字，help 光标）；记忆组头/整理建议标题同改；
    开机自启、提醒「加一条」、扫码配对、已登记项目、总管与执事、技能库六处手写常驻解释转悬停；
    状态/结果类保持常驻（inlineHint：已移除会话计数、搜索变量名）。
12. **状态灯**：展开态顶到侧栏底栏最右（margin-left:auto），点 7→8px。

## 已知边界 / 没跑的验证

- 斜杠注入（lifecycle）有单测覆盖解析、HTTP 面覆盖启停，但「/名字 → 真模型照手册执行」未做真模型手验
  （faux 只回固定帧，注入帧内容不外显）；机制同刀一 beforeRequest 注入通道，风险低。
- 技能索引按会话冻结（D5）：开关对**已在跑的会话**不生效，下一个会话生效——UI 文案与 toast 已如实写。
- flags 文件被手改坏 JSON → 当作没有覆盖（warn 不炸）；界面上没有「恢复默认」按钮（拨回缺省位即等同）。
- 高级开关的值不随 .env 回读对比（env 是缺省、文件是覆盖，界面显示的是**当前生效值**）。
