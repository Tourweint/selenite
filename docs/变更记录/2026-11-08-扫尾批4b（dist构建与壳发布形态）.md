## 一、服务端单文件构建（§三a）

`ts/apps/server/package.json` 新增：

- `build` → `node scripts/build.mjs`
- `dist:probe` → `tsx scripts/dist-probe.ts`
- devDependencies 显式登记 `esbuild`（此前只在传递依赖里，靠 hoist 能解析，但不该依赖这个巧合）

### `scripts/build.mjs`

- esbuild JS API，`bundle: true`、`format: "esm"`、`platform: "node"`、`target: node<当前大版本>`。
- **产物落 `dist/src/index.js`，不是 `dist/index.js`**（与任务书字面不同，理由如下）：
  三处资源读盘都是 `new URL("../web|skills|prompts/", import.meta.url)`。`import.meta.url`
  跟**文件所在目录**走，与文件名无关：`dist/index.js` 的 `../web` 会指到 `<server>/web`
  （源码目录），dist 就不自足了；放 `dist/src/index.js`（与源码 `src/` 同深度）才指向
  `dist/web`。`dist/index.js` 保留为一行入口壳（`import "./src/index.js"`），
  满足 `node dist/index.js` 的口径。
- 资源整份复制到 `dist/web`、`dist/skills`、`dist/prompts`（`node_modules` 不复制，bundle 已含）。
- CJS 依赖（`qrcode` 等）转 ESM 后可能留下 `require`，所以 banner 用 `createRequire(import.meta.url)`
  补一个真 `require`；`node:sqlite` 等内置模块由 `platform: node` 自动外置。
- `.env` / `.data` / `provider-keys.json` 仍按 **cwd** 找，不跟产物走。

### `scripts/dist-probe.ts`

构建 → 在**空临时目录**（cwd 隔离，不读真实 `.env` / `.data`）`node dist/index.js`（独立 `PORT`）→
逐项断言：`/healthz` 200、`/` 200、启动日志技能条数 > 0、faux 一轮 SSE 有 `start` 帧且有文本、
`dist/prompts` 有模板。

## 二、壳构建脚本 + 版本号（§三b）

- `desktop/build.ps1`：`go build -ldflags "-H windowsgui -X main.version=<git describe --tags --always>"`；
  `git describe` 失败/空值退 `dev`；`Push-Location $PSScriptRoot`，从任意目录可跑。
- `desktop/main.go`：新增 `var version = "dev"`，托盘初始 tooltip 与 `tray-features.go`
  的状态 tooltip 都带 `Selenite <version>`。
- 文件存 UTF-8 **带 BOM**：Windows PowerShell 5.1 按 ANSI 读无 BOM 的 .ps1，中文注释会把字符串引号吃掉。
- README 补「出 exe」一节。

## 三、开机自启（§三c）

- `desktop/main.go` 的 `Shell` 组新增 `OpenAtLogin() bool` / `SetOpenAtLogin(bool) (bool, error)`，
  直接包 MyGo 现成 API（HKCU `Run` + `StartupApproved`）；设置失败返回 error，前端不把失败画成已开。
- `web/app.js`：设置 → 服务 → 运行时卡片里加「开机自启」行（默认 `hidden`）。
  `shellCall(method, ...args)` 扩展为可透传绑定参数；读 `OpenAtLogin` 失败（浏览器 / 
  `LIFEDIARY_SHELL_BINDINGS=off` 整组未挂）就**保持不渲染**，与整组同退口径一致。
- 语义：**自启的是壳**，服务仍由壳拉起；这个开关与运行时起停互不影响。
