# 2026-11-04 界面第三轮落地（收起轨道·内嵌发送·运行时切模型）

方案：`docs/设计方案/2026-11-03-界面第三轮（收起轨道·内嵌发送·模型配置）.md`（含分工与取舍）。
前后端两个会话完成后，按该方案一次落地；契约按接口文档 §7 顺序先改文档再改代码。

## 改了什么

### 1. 侧栏收起轨道（web/）

- 收起不再是 0 宽整栏消失：`--rail: 60px`，收起时侧栏保持一条图标轨。
  轨上自上而下：「+ 新对话」（真功能：展开侧栏 + 新建 + 聚焦输入框）→ 分隔线 →
  任务中心 / 领域负责人 / 群组（**禁用占位**，tooltip 写明"还没建好/占位"，不装能点）→
  底部设置（真功能）+ 状态圆点。
- 动画沿用「外层 width 过渡 + 内层定宽原地淡出」：收起 250ms 加速淡出，
  轨道延迟 120ms 淡入（两层不打架）。展开态轨道 `opacity:0 + pointer-events:none` 藏住。
- 侧栏底部设置入口在收起态仍可达（顺带修掉《自绘标题栏与设置整页》记的
  "收起或 ≤800px 时设置入口不可达"的前半条；≤800px 仍整栏隐藏）。
- 持久化键不变：`lifediary.sidebar`，`"closed"` 语义从"0 宽"收窄为"轨道"。
- 覆盖《宰相层》§5.9"折叠态收进顶栏菜单；不额外做图标栏"一项（用户 2026-11-03 指定要做轨道）。

### 2. Composer 内嵌发送（web/）

- 输入框改成**容器卡**（对齐 cindy ComposerCard）：边框/卡底/圆角/阴影从 textarea
  整体上移到 `.composer`，textarea 透明无框；`:focus-within` 时容器边框换 accent。
- 发送钮 48px→32px 圆钮，住进底部工具行右下角；**发送/停止同槽**（cindy SendButton）：
  流式时 `.send.streaming` 换停止方块图标、点击走 `/stop`，顶栏的停止按钮删除——只有一个停止入口。
- 首页态保留：文本区 84px（整卡约 144px）、`--r-xl`、竖屏居中（`bottom: calc(50vh - 72px)`）。
- 对话态整卡 min 高约 86px（同 cindy ComposerCard 的 min-h 86）。
- 底部工具行左半边空着——附件/模型 pill 等 cindy 有而我们没有后端能力的，不做空壳。

### 3. 运行时切模型（契约 + 服务端 + 设置页）

- **契约**（先文档后代码，接口文档 §2.8 + §2.5 + §6）：`GET /healthz` 扩展
  `{ ok, llm, model, models[] }`；新增 `POST /api/v1/agent/model`。
  语义：`LLM_MODEL` env 是出厂默认，切模型 = 写运行时覆盖（`MODEL_RUNTIME_PATH`，
  默认 `.data/runtime.json`，只存模型 id，无密钥），下一轮对话生效。
- **provider.ts**：`buildModel` 提到模块级、目录数组改模块级；新增 `setRuntimeModel` /
  `runtimeModelInfo` / `upstreamModelId` / `modelOverrideEnabled`。切换 = 目录补模型 +
  重发 provider + 改 `cached.model/fastModel` 引用（快/深永远共用当前模型，D1 不变）；
  启动时恢复覆盖值（不在清单内就忽略，env 默认接管）。
- **agent.ts**：`chatStream` 开跑前做**模型漂移对齐**（`syncConversationModel`）——
  durable 会话存的是模型引用，还停在旧模型上的存量会话在这一轮重配过去，思考档保持原样
  （机制同 D3 思考切换）。只挂聊天流；任务会话短命不追。
- **openai-compat.ts**：直通路径的模型跟随运行时覆盖（`upstreamModelId()`）。
- **回滚开关**：`MODEL_RUNTIME_OVERRIDE=false` → 启动忽略覆盖值、接口一律 400、
  前端探测到清单为空退化为只读行。
- **设置页「服务」分区**：模型行升级——`/healthz` 的 `models` 有多项时出下拉
  （原生 select），切换后提示"已切换，下一轮用新模型；首轮会慢一点（上游缓存重建）"；
  faux / mock / 清单单项 / 覆盖被关 → 只读行 + 对应说明。**特性探测**：旧服务端没有
  `models` 字段时行为与改造前一致。密钥与上游地址不进界面（仓库硬约束）。

## 为什么

- 收起轨道：用户 2026-11-03 明确"收起后左边不应全部隐藏，先占上位，留小加号和小图标，
  群组/专家留占位"。当时只做到 0 宽（《首页顶栏与浮层》"明确没做"），本轮补上。
- 内嵌发送：用户要求"发送按钮放在对话框里，自己看别人怎么做"——cindy 的
  ComposerCard/SendButton 是验证过的形态，照抄结构不照抄依赖。
- 切模型：用户要求"切换模型肯定希望支持，在设置里能配置"。单上游架构下能动的只有
  模型名；providers 页那种 baseUrl+key 表单违反"密钥只走环境变量"硬约束，刻意不做。
