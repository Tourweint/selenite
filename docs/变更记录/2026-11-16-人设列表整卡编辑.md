# 2026-11-16 人设列表整卡编辑（卡片可点进档案 + 卡面去状态点）

## 改了什么

设置 → 人设列表（`renderPartnerList`，总管与普通执事同一条路径）：

- **整卡可点**：头像、名字、卡内留白点击都进现有 `#/settings/partners/<encoded id>` 编辑页。
  卡片用 `div.card.pt-card` + `role="button"` + `tabIndex=0`，不再新增按钮，也没有把 ⋯ 按钮包进 button。
- **键盘**：卡片可聚焦，Enter / Space 打开编辑页；Space 调 `preventDefault()`，不滚页。
  只有 `event.target === card` 时才处理这两个键——焦点落在卡内 ⋯ 按钮上按 Space，只开按钮自己的菜单，不跳转。
- **点击防冒泡**：卡内按钮的点击一律不触发跳转（`closest("button")` 兜底），⋯ 自身原有 `stopPropagation` 保留。
- **卡面状态**：`active` 不再显示「运行中」标签；列表卡上的状态圆点（`ptStatusDot`）整列去掉。
  `paused` / `archived` 文字标签照旧。
- **⋯ 菜单**：动作与条件原样（试跑 / 暂停或恢复 / 删除执事；archived 无暂停，总管无删除），
  移除与整卡点击重复的「编辑这个人」。
- **提示与无障碍**：名字 `data-tip` 改为「点击卡片打开这位执事的人设档案」，
  删掉旧的「右侧按钮可编辑、暂停或归档」口径；⋯ 的 `data-tip` 统一「更多操作」，
  并按总管 / 执事给出 `aria-label`（`<名字>的更多操作`）；卡片自身 `aria-label` 为 `编辑「<名字>」的人设`。
- **样式**（`style-16-partner.css`）：`.pt-card` 补 `cursor:pointer` 与 border/background 过渡，
  hover 用 `--outline` / `--card-high`，`focus-visible` 用 `--accent` 2px 外描边；
  `.pt-dots` 补同色 `focus-visible`。只吃现有主题 token，未改全局 `.card`。

## 为什么

用户 2026-11-16 明确要求：人设列表一张卡就是一个人的档案，点哪儿都该进去；
卡面「运行中」和状态圆点是冗余信息。旧记录
`2026-11-15-改人设页二次重构与删除执事入口.md` 的「刻意没做」里写着整卡可点当时因用户没提而没做，
本次是用户批准后补上。
