# 2026-11-04 批次一落地（消息级必备七件）

方案来源：《桌面端必备能力调研与差距清单》批次一（用户拍板"前七个直接可以做，后边的先写方案"）。
批次二方案另落 `docs/设计方案/2026-11-04-批次二方案（通知·上下文·排队·搜索·表格·壳）.md`。

## 改了什么

契约（先文档后代码，接口文档 §2.1 / §2.5 / §5 → `shared` → 两端）：

- SSE 新增 `thinking` 事件（思考正文增量，deep 档才有）；`done` 加可选 `usage` `{input, output, cacheRead}`。
  老客户端按 type/字段忽略，纯增量。`GET /agent/chats` 条目加 `pinned`。
- 新端点 `POST /api/v1/agent/chat/:id/pin`。
- **补了一笔 2026-11-03 的文档欠账**：rename / hide / restore 三个端点当时没登记进接口文档，本次随 pin 一起补进 §2.5。

服务端：

- `agent.ts` chatStream：从 `pi.live` 的 thinking 块抽思考正文，增量透传（守卫同 delta：只认前缀续接）；
  收尾读最后一条 assistant 的 usage 作为**内部事件**吐出（index.ts 捕获后挂 `done.usage`，不单独发帧）。
- `agent.ts` chat-meta：`ChatMeta` 加 `pins[]`，`pinChat()`，`listChats` 条目带 `pinned`。
- `index.ts`：thinking 透传、usage 捕获、done 富化、pin 端点；**mock 流补 thinking + usage + 代码块示例**——
  新 UI 在无 key 环境也有完整链路可验（mock 的职责就是"链路可验"）。
- `openai-compat.ts`：消费端跳过 thinking / usage 两类新事件（OpenAI 协议无对应位）。

界面（web/）：

1. **代码块复制按钮**：块右上角 hover 出现，读 `pre.innerText`（流式中也能复制到最新文本），1.5s 复位；
   事件委托挂 thread 上。
2. **轻量语法高亮**：无依赖一条合并正则（`hlBuild`），挑注释/字符串/数字/关键字/属性名五类，
   规则允许未闭合（流式半截字符串也上色）；支持 js/ts/go/py/bash/json/css/html 系别名；
   >20k 字符或未知语言原样转义。颜色走新 `--code-*` 五个 token（浅/深两套，取自家色板）。
3. **思考折叠卡**：对齐 cindy ThinkingCard——全态默认折叠、流式中 summary 计时跳秒、
   正文开始后定格"已思考 Ns"、thinking 增量都追加进同一张卡；出现后占位的「正在思考」行让位。
4. **会话置顶**：行 hover 出 ★（置顶/取消），置顶的排前面（段内保持原顺序）+ 标题前缀星标；走 chat-meta。
5. **导出对话 Markdown**：顶栏「导出」（仅有会话时出现），正文从 `/messages` 现取，
   下载 `<标题>-<日期>.md`。
6. **错误重试 + 中断标记**：发送链路的错误行带「重试」（重发最后一条 user 文本）；
   点停止后流收尾给一行"已中断生成。"。
7. **消息级 token/耗时**：`done.usage` 挂到 assistant 消息上，hover 显示"N tok · Xs"，
   title 给输入/输出/缓存命中明细；faux 给的 0 值不显示。

顺手修复：**start 事件后 `loadChats()`**——以前新会话要等页面重载才进侧栏，置顶/重命名都够不着
（浏览器实测抓到的既有缺口，非本批引入）。

## 为什么

用户口径"桌面端 Agent 必须有的要做"；这七件是调研判定的小而必备（来源见调研文档 §四）。

- `pnpm typecheck` ✓；`node --check web/app.js` ✓；`pnpm --filter @lifediary/server http` 全绿（含既有 11 节）。
- 浏览器实测（mock 8125 / faux 8126，隔离数据，跑完清理）：
  - mock：思考卡流式中计时→定格"已思考 1s"→展开可见正文；代码块 tok-k/s/c 三色上色；

    "105 tok · 5.8s"+明细 title；导出按钮出现；停止后"已中断生成。"落行。
  - faux：pin 接口 `pinned:true` → 列表字段 ✓；界面 ★ 前缀、取消/再置顶即时生效；
    新会话即时上栏（修复验证）；置顶的压在最上；导出下载事件触发。

  重试按钮未在 UI 上实击（mock 无错误路径），接线已 review。
