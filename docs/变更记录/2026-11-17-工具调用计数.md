# 工具调用计数（含 deferred 与 loads）+ 技能斜杠漏计补齐

**日期**：2026-11-17 当日方案落地。
**方案**：`docs/设计方案/2026-11-17-工具调用计数.md`；结论已下沉系统架构.md
（`tool-usage.ts` 模块行）与接口文档分册2 §2.5（`GET /api/v1/agent/tool-usage`）。

## 背景

工具面 2026-11-16 C 段起有"按需加载"（8 个管理型工具 defer、`tool_index` 一句话清单、
`tool_search` 取完整定义），技能侧批 17 起有用量账，但**工具调用没有任何计数**。
用户目标：按真实使用频率动态调整上下文——"有些工具可能被隐藏了，但可能还用了很多"，
这要有账可查。本批只立数据底座，调整策略本体另立项。

## 改了什么

- **新增 `src/tool-usage.ts`**：`.data/tool-usage.json` 账本（`{count, err, loads, lastUsedAt}`），
  仿 `skill-usage.ts` 全套惯例（tmp+rename 原子写、写前重读、坏账当空、写失败只 warn、
  永不删除）。开关 `TOOL_USAGE`（env-only，缺省开；`false/0/off` = 停记 + 端点 404，
  仿 `SKILL_USAGE`）。
- **挂钩 `agent/lifecycle-harness.ts` afterTool**（`emitTool(end)` 旁）：`call.parent === undefined`
  时 `recordToolUse(call.name, 成败)`。口径=模型发起并真实执行完的调用；内核 bash/read/write/edit、
  deferred 加载后的调用、worker 会话的调用全走这一条，天然覆盖（已核对内核 `tool.js`：
  被拦 / 工具不存在 / 校验失败在 call phase 提前 settle，不经 afterTool，不进账；
  拦下另有 gate-blocks.jsonl 审计，两本账不重复）。
- **`tools.ts` tool_search 命中加载时 `recordToolLoad(name)`**：`loads ≠ count`，搜出来没调用
  也留痕——"被藏起来但老被要用"正是动态调整要的信号。
- **补技能斜杠漏计 `agent/lifecycle-injections.ts` skillSlashProvider**：`/技能名` 取到手册也
  `recordSkillUse(name)`（此前只有 skill 工具计数）；dryRun（injection-preview）不记，审计不污染账本。
- **新端点 `GET /api/v1/agent/tool-usage`**（index.ts，`/agent/usage` 旁）：`{tools:[…]}` 按 count
  降序；`TOOL_USAGE=false` → 404。
- **前端用量页第四张卡「工具调用」**（settings-router.js + settings-usage.js）：工具 / 执行 /
  失败 / 按需加载 / 最近使用；全部累计、不随 7d/30d 区间走；404 / 没记录 / 读取失败 → 整节
  隐藏不出空卡；"N 天前"复用 `skillLastUsedText`。
  **同日调整（2026-11-17 用户拍板）**：这张卡从「用量」页撤掉，工具用量统一放
  **设置 → 工具页的「用量」列**（`settings-tools.js`）；端点与人设页弹层的数字保留，
  用量页只留模型 token 三张卡。
- **http 探针**：spawn env 加 `AGENT_TOOL_USAGE_PATH` 隔离；§10（faux 真执行 recall）后断言
  账有记录、成功无失败、常驻工具 loads=0、端点形状与降序正确。
- **测试**：`src/tool-usage.test.ts` 五组（计数分桶 / loads 不冲执行 / 开关旁路 / 坏账容忍 /
  端点投影排序），登记进 package.json 测试清单。

## 验证

- `pnpm typecheck` 全绿。
- `pnpm --filter @lifediary/server test`：新 5 组全过；**既有失败 1 项与本批无关**——

- `pnpm --filter @lifediary/server http`：全过（含新断言 4 项，见下）。
- 隔离核实：单测无一处真执行工具（`LLM_FAUX_TOOL=""` 显式关），真实
  `.data/tool-usage.json` 不会被测试污染；探针账落 `probe-http-tool-usage.json`。

## 刻意不做

- 不拆人设 / 会话 / 项目维度（全局一本账，动态调整要的是全局频率；账本结构可后扩）。
- 不回填历史（要的话一次性扫 durable `pi.tool-result` 的 `toolName`，模式照 `usage-range.ts`）。
- 不做动态调整本体（提升 / 收敛策略改的是上下文构成，契约级，另立方案）。
- 不动工具描述与注册顺序（prompt-cache 前缀资产）；日志零内容。
