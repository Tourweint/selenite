## 刻意没做

- **按天曲线 / 热力图**（ZCode 与 Cindy 都有）：`pi.usage` 只存"每个会话的累计"，没有逐日流水；
  硬画就得先加一本按天账，那是新机制（存储 + 回填口径），不在"改个页面"里夹带。
- **金额**：服务端 `cost` 固定 0，页面不折算人民币——"不假装知道价格"是既有口径。
- **按会话的用量榜**：要逐会话开 session 读 `pi.usage`，成本与收益不成比例；现在只有按模型。
- **把 faux 藏掉或算成"假账"**：它在总数里占 78%，藏了会让人以为用量真有这么多；页面照实列，
  加「模拟」标签 + 注脚说明"没配真上游时的假回答，那部分不是真实消耗"。
- **服务页留一行「用量 → 查看」**：左侧导航已经有「用量」，再加一行入口是二次复读。
- **823 下把明细表拆成卡片流**（每条模型一张小卡）：8 个数字字段拆卡后每张要重复字段名，反而更难横向比；
  这一轮先保留横向滚动。
- **统计格折成两行**（五格拆 3+2）：折行会让"输入/输出"与"缓存读/缓存写/命中"错位，宁可收字号。
