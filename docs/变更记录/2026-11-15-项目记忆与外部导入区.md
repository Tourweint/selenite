# 项目记忆 + 外部导入区（2026-11-15）

方案：`docs/设计方案/2026-11-15-项目记忆与外部导入区.md`（存哪/怎么匹配/为什么这么定，全在里面）。
契约下沉：`接口-端点6` §2.15 表 + §2.15.5（项目/外部导入条目与 TTL 缓存口径）+ §2.15.6（项目匹配）；
`接口-存储工具与配对.md`（remember/recall 的 project scope）。

## 改了什么

1. **记忆包**：`MemoryScope` 加 `{type:"project", id}`（scopeKey `project:<uuid>`）；
   `ImportEntry` 加可选 `source`（落 `record.source`，缺省 `"imported"` 老调用零变化）。
2. **`agent/project-scope.ts`（新，零依赖）**：会话→项目解析。快照源由 lifecycle-harness
   注入（`setProjectBindingsSource`）；注入侧 TTL 缓存 30s + 后台刷新，工具侧 async 直查。
   **为什么独立成零依赖模块**（两个实测坑）：assist→lifecycle 会成环（lifecycle-injections
   顶层取 assist 的 provider，`memoryRecallProvider` TDZ 炸模块）；tools→assist 静态加载
   会拖垮 partner-work 等**刻意不起全局记忆引擎**的测试（rmSync EPERM——记忆引擎握住临时目录）。
3. **工具**：`remember` 加可选 `scope: "auto"|"project"`（不归属项目时如实回话）；
   `recall` 与每轮注入在会话归属项目时召回键空间加 `project:<uuid>`。
4. **导入适配器升级**：项目级条目带匹配线索（zcode=目录名剥哈希；qoder=路径 slug，
   与 `rootPath` 转 slug 精确对比，dash 歧义不存在），server 端 `matchRegisteredProject`
   统一匹配——命中落 `project:<uuid>`（无前缀），没命中 global+【项目名】前缀；
   条目记 `source=import:<sourceId>`。`importMemory` 放行 `project:<uuid>`（必须是登记项目）。
   手工文件导入保持 `source="imported"`。
5. **端点**：`GET /memory` 加 `veracity=imported`（跨 scope 导入视图，响应带 `bySource`）；
   `GET /memory/scopes` 加 `kind:"project"`（有记忆才列）与 `kind:"external"`（伪 scope
   `__imported__`）。
6. **前端（记忆页 A 版）**：范围 tabs 渲染项目/导入徽章；外部导入 tab 按来源分组渲染
   （不走 kind 分页装载，一次拉全）；整理按钮在伪 scope 上隐藏；`memorySourceLabel`
   认 `import:` 前缀。

## 还有哪些不确定

- http 探针复跑中（本批改动后）；此前唯一红项「系统提示带项目根路径」是 11-13 起的
  既存无关红。
- **没登记的项目**吃不到项目 scope（保持 global+前缀）——这是设计：登记哪几个项目是
  用户的事；登记后**再点一次导入**即可搬进项目 scope（global 里旧的前缀条目手动删）。
- 注入的项目 scope 在**重启后第一轮**可能缺席（TTL 缓存冷启动），30 秒内自愈。
- 手工文件导入（POST /memory/import）API 已放行 project scope，但前端没有项目选择器
  （本批不做，登记边界）。

## 补丁（同日，范围 tabs 溢出）

项目 tab 上了 20 个后一排溢出 ~2000px，而滚动条是刻意隐藏的（A 版口径）——没有任何滚动手段。
`memory-page.js` 给 `.mem-a-people` 补两个交互：滚轮直转横滚（deltaY→scrollLeft，溢出才拦截）、
按住拖拽滑动（拖过 6px 用捕获期 click 吃掉落点，防止拖完误触 tab）；触屏原生滑动不接管。
浏览器验证：溢出 1995px 下滚轮 0→240 ✓、拖后 click 被抑制 ✓。
