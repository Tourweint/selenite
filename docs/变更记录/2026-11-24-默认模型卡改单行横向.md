# 2026-11-24 默认模型卡改单行横向（方案 E）

## 改了什么

1. **`web/settings-router.js`**：「设置 → 模型 → 默认模型」卡从「名字 / 说明 / 思考」三行堆叠改成一条水平带：
   `模型名 · 供应商 | 思考强度 | 更换`。`mdl-think` 从 `.mdl-main` 里挪出来，成为 `.mdl-card` 的行内元素；
   `mdl-current` / `mdl-hint` / `mdl-think` / `mdl-change` 的 id 都没变，`plus-menu.js` 与
   `settings-usage.js` 的引用不受影响。
2. **`web/settings-reminders.js`**：正常态不再拼「· 切换后下一轮对话生效」；思考强度标签从
   「思考强度 · 新会话默认」改成「思考强度」。未配置 / faux / 只有一个模型三种状态的提示文案原样保留——
   只在正常态删字，不顺手丢掉边缘状态的说明。
3. **`web/style-11-composer-tools.css`**：`.mdl-card` 改成 56px 高、`space-between` 的横向 flex；
   新增 `.mdl-model` / `.mdl-prov`（供应商前的 `·`、空串隐藏）；`.mdl-think` 固定 330px；
   「更换」弹层右缘从 wrap 右缘再收 18px 到按钮右缘；新增 `max-width: 1120px` 折行：
   第一行名字 + 更换，第二行思考强度整行。

## 为什么

2026-11-24 用户口径：三行全堆在左栏，「更换」按整卡高度居中，垂直方向谁都不对齐；且
「切换后下一轮对话生效」「新会话默认」两句常驻文案没用。演示页
`.box-agent-scratch/model-card-align-2.html` 出 E / F / G 三版，用户挑中 E（单行横向）。

## 验证

- 真服务 39847 真页面 + headless Chrome 截图：1200px 单行；1100 / 1000px 折成两行；
  模型名、供应商、滑块、更换同一中线；卡高 56px。
- `node --check` 改了的前端 JS；`.mdl-main` / `.mdl-sub` 已无残留引用。
- **没跑**服务端单测 / 探针：改动只在 web 静态层，未动 HTTP 契约或服务端逻辑。
- **没点开**「更换」弹层做交互验证：弹层位置只按 CSS 从 wrap 右缘收到按钮右缘（18px），
  常驻态未覆盖打开态。
