# 2026-11-13 选中态口径：轨道黄圈只表示「你在这里」，总管不亮，群组补上

用户口径：收起轨道的黄色圆圈看不明白；在对话里亮「对话」是对的，但总管会话里也一直亮着；
群组页没有黄圈；总管不要黄块；黄色可以继续用来区分，把 bug 修好即可。纯前端。

## 改了什么

### ① 轨道 / 侧栏的「当前所在」改成一份口径（app.js）
- 新增 `currentRailSection()` / `syncRailCurrent()`：
  - 普通会话（chatKind=worker）→ 轨道「对话」；
  - 执事专线（conversationId=`partner-<id>`）→ 轨道「执事」；
  - 群列表 / 群会话（route=group）→ 轨道「群组」；
  - 总管会话 → 都不亮（用户拍板：选了总管本身就看得出，不再摆黄块）；
  - 任务 / 回顾 / 搜索 / 领域 / 设置没有轨道项，不亮。
- 旧代码只判 `route === "chat"`，而总管 / 执事会话也走 chat 路由，所以「对话」永远亮着——
  这就是用户报的「无论咋着它一直是黄的」。群组则从来没人点亮。
- 同步点：`applyRoute`、`openChat`（切会话开始 + chatKind 回读后）、`startNewChat`。
  会话种类还没回读（chatKind 空、有 conversationId）时先不亮，避免总管会话闪一下「对话」。
- 展开侧栏的行选中：`syncSideRowsCurrent()` 点亮当前执事花名册行、当前群行；
  `renderRoster` / `renderGroupRows` 重建时也按当前路由落位。
- 「所有群聊」仍只在群列表页高亮（原逻辑不动）；进具体群后熄灭，改由那条群行亮。

### ② 选中与悬停分开（style.css）
- 轨道选中钮加 1px 内描边（`--accent-line`）；hover 仍是浅底、不描边。
  暖金 / 琥珀主题下选中圈和 hover 圈色系接近时，靠描边 + 图标强调色也能一眼分开。
- 侧栏行选中样式不变（accent-soft + accent 字 + 内描边），hover 不变。

## 明确不做
- 总管条目任何选中块（用户拍板）。
- 项目 / 课题的「当前」态：两者是卡片 / 侧栏分区，没有页面路由，不亮。
- 手机端抽屉不动。

## 验证
- `node --check web/app.js` 过。
- 浏览器实测（真实会话数据）：
  - 普通会话「你好，先起个头」→ 轨道仅「对话」黄圈 + 该会话行黄块；
  - 总管会话 → 轨道、展开侧栏都没有黄块（旧行为是「对话」一直亮）；
