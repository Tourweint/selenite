# 2026-11-21 表格 C 卡片版与 html 交互卡

## 改了什么

**表格渲染换 C 圆角卡片版**（用户从对比页五版里拍板）：

- `web/style-05-message-extras.css`：`.table-wrap` 从「光秃秃的横滚容器」升级成卡片——hairline 外框 + `--r-md` 圆角 + 卡底色 + `width: fit-content`（窄表随内容收、宽表卡内横滚，圆角裁切靠 overflow-x:auto 自带 clipping）；行间发丝线、表头 `--card-high` 浅底小字 nowrap、行 hover 微墨；新增 `.nw`（不折行）/ `.num`（tabular-nums）两个类。
- `web/markdown.js` `tableHtml()`：短单元格挂 `nw`（≤8 字符，或无空格且 ≤26 字符的非 CJK token，长中文说明照旧折行）；全数字列自动右对齐（只在分隔行没写冒号=没表态的列生效）。

**顺手修了两个既有 GFM 兼容 bug**（表格样例实测时抓到）：

1. `isTableDelim` 的 `-{2,}` 不认单横线分隔行 `:-:`，整张表塌成段落（GFM 合法写法，模型输出里真实存在）→ 改 `-+`。
2. 对齐解析把 `:---`（GFM 左对齐）落到 `/-+:$/` 判成右对齐 → 改判据顺序：先两头冒号（center）、再尾冒号（right）、其余 left；并把「带过冒号 = 表过态」传进 `tableHtml`，显式左对齐不被自动右对齐盖掉。

**新增交互卡（html 卡）**：助手回复里**闭合**的 ` ```html ` 围栏渲染成内联沙箱卡（形态 1：无工具条、无标题、无源码按钮，直勾勾渲染——用户拍板；三形态里源码按钮经否决全删）。机制与安全边界见 `docs/设计方案/2026-11-21-表格渲染与交互消息/方案.md`，要点：

- `web/markdown.js`：html 围栏（仅闭合的、仅助手消息走 markdown 这一路）→ `<div class="html-card" data-srcdoc="…">` 占位符；`setHtmlCardsEnabled` 模块内开关，缺省开。
- `web/html-cards.js`（新）：全局 MutationObserver 发现占位符 → 挂 `sandbox="allow-scripts"` + `referrerPolicy="no-referrer"` 的 iframe（无 same-origin、不开表单/弹窗）；srcdoc 缺 doctype 补 `<!DOCTYPE html>`（quirks 模式量高失真，实测首报偏高）；注入报高脚本 postMessage 上报，高度自适应到 72% 视口上限、超出内部滚，按 srcdoc 内容缓存（重建免闪）。
- `web/stream-reveal.js`：reconciler 加一个跳过分支——同 `data-srcdoc` 的 `.html-card` 原地保留（iframe 是挂载层塞的，换节点=重载；内容变了才走 replaceItem）。流式里模型在卡后面继续写字不再让 iframe 刷新。
- `web/app.js`：`ensureFlag("CHAT_HTML_CARDS", true)` → `setHtmlCardsEnabled`；`initHtmlCards()` 全局一次。
- `web/style-05` / `web/style-21`：`.html-card` 卡体（圆角边界 + 卡底，非气泡=整行宽）；气泡模式 480px 定宽（% 宽在 fit-content 气泡里是循环尺寸，不给定值会塌成 iframe 默认 300px）。
- `src/plugins.json`：新增 `CHAT_HTML_CARDS`（ui 组，默认开）——**回滚开关**，关=新渲染退回普通代码块。

## 为什么这么做

- 表格选 C 而不是推荐的 B：用户拍板「圆角比较美观」，B 的书页感是模型口味不是用户口味。
- 交互卡不搬形态 2/3：用户原话「直勾勾地渲染」「连上边的标题都不需要」「看源代码根本也没啥用」；动画能力取决于模型写什么代码（用户原话「跟模型他怎么写代码有关系」），渲染层不掺和。
- 占位符与挂载分两层：stream-reveal 的 reconciler 按「元素+属性一致」保节点，挂载阶段加的任何属性（高度、data-mounted）都会让下一轮增量把卡换掉、iframe 反复重载——所以 renderMarkdown 只产与源文本一一对应的占位符，挂载收在观察器层。

## 还不确定 / 边界

- 手机端不渲染卡（显示代码块），要了再立项。
- 开关是渲染期读的：关掉后已挂出的卡到刷新为止；插件页 summary 里写明了。
- 工具灰块 / 会话地图里的 html 围栏走同一渲染（不区分来源）；工具块自身限高滚动兜住，未专门设计。
- 卡内报高在字体晚到/动画展开时靠 ResizeObserver 跟随；极端情况（模型 JS 自己改高度）按 RO 兜底，没做防抖压测。
