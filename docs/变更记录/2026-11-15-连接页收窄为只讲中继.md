# 变更记录 · 连接页收窄成「只讲中继」（2026-11-15）

> 用户原话：「把本地连接也改成和远程连接一样的那一行，既然技术上做不到，就算了吧。」「上面的图片也可以改一改，只保留和中继连接的内容。」「下面解释性文字『一台设备经中继接入』也删除吧。」「那就不做了，这个全互联，那就只靠这个中继全互联就行了。」

## 改了什么

| 位置 | 改动 | 为什么 |
|---|---|---|
| `web/settings-router.js` | 「本地连接」由一张大卡片（左文字右二维码）改成**和「远程添加手机」一样的一行**：左边 `扫码连接手机`，右边一个主按钮 `显示二维码`；二维码收进 `#pair-qr-box`，点了才展开 | 用户要两节长得一样；二维码常驻等于半屏空白 |
| `web/settings-connection.js` · `loadPair()` | 取码成功才展示二维码，按钮文案从 `显示二维码` 换成 `换一个码` | 曾跟随页面加载就取码——每取一次都作废上一枚 |
| `web/settings-router.js` · 定时器 | 进页面不再 `loadPair()`；每 100 秒自动换码只在**二维码展开时**跑 | 收起来的时候悄悄换码，会把用户正举着给人扫的那枚作废 |
| `web/style-08-search-gate.css` | 新增 `.pair-qr-box`（居中竖排、`[hidden]` 真隐藏），`.pair` / `.pair-info` 不再被这一节使用 | 一行式布局 |
| `web/settings-connection.js` · `paintConnStar()` | **图只画「经中继的连接」**：节点只剩「本机」+ 名册里经中继的设备，线只剩 本机↔中继、中继↔设备。本地直连设备、没登记而直连的凭据不再进图（也不再有「到本机」那条虚线/曲线） | 用户："只保留和中继连接的内容"。他同时放弃了跨机全互联，图就不再承担"两条通路都画清楚"的职责 |
| 同上 · 角度方案 | 去掉"按通路分两簇"，经中继的设备在右侧自上而下排成一把扇（`1.5π → 2.5π`） | 图里已无直连节点，分簇没有意义 |
| 同上 · `tipParts` | 不再拼"本地 / 直连本机 / 走公网直连" | 图里已没有这类节点 |
| `web/settings-connection.js` · `updateConnectionHint()` | 中继已连上时**不再输出任何文字**（`"N 台设备经中继接入（M 台在线）"` / `"中继已连上，还没有手机加入"` 一起删），元素 `hidden`。断点类文案（被 pid 占用 / 未接入 / 重连中）保留 | 用户点名删掉那句解释；但断点是必须看见的信息，不能一起删 |
| `src/index.ts` · `onAuthFail` | **没带任何凭据的请求不再记成活口**（无 `Authorization` 时直接返回） | 真实 bug：页面自己那次不带令牌的请求会被记成一台"3 分钟前回话的未知凭据"，列表里凭空长出一行幽灵设备，还点不出「认领」（没有哈希可认） |

## 与上一版的关系

2026-11-14 五次打磨的做法是"直连也必须画到本机、名册外的凭据也要连线"。2026-11-15 用户改成"只靠中继"，所以图中的直连分支撤掉——**不是回滚 bug 修复**：`live` 剪枝、幽灵节点过滤、`unclaimed`、认领/删除端点全部保留，只是不再画进这张图；那台平板仍然在「已连接的设备」里以一行「未知凭据 + 认领」出现。

## 没做 / 没验证

- **真平板点「认领」没代做**：需要它此刻在发请求，页面上才会出现那一行。当前 `live` / `unclaimed` 都是空——它没在说话，页面就没有可认领的对象。
- `PAIR_ADOPT=false` 的回滚路径仍未实跑。
- 中继脱机时星形的实际观感（灰虚线）本轮没看。
- 手机端没改。
