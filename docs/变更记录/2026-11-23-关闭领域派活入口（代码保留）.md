## 开关语义

- **关（默认 `CHANCELLOR_DOMAIN_DISPATCH=false` / 未设）**：`delegate` 的 schema 里没有 `domain`，描述
  不再说「领域负责人」；总管 / 主人会话一律无领域直派 worker —— 请求不带 `domain`、显式 `managers:false`，
  chancellor 不会建分管宰相。旧调用 / 旧会话硬带的 `domain` 在路由前就被丢弃，不会报 `invalid_domain`。
- **开（`true` / `1` / `on`，或任何不是 `false` / `0` / `off` 的值）**：恢复改动前完整行为——`domain`
  参数、领域名清单、领域负责人 / 分管路径、`partner_manage` 原文案。判据沿用 `flags.ts` 的
  `flagEnabled`（`false` / `0` / `off` 算关）。
- **执事路由不动**：执事（partner）在自己领域内仍直派（`managers:false`），跨领域拒绝仍按
  `callerDomainOf` 判定，不依赖 `delegate.domain`。关闭时模型拿不到 `domain` 参数，旧调用硬带的跨领域
  值会被忽略、按自己领域直派。

## 提示词 / 缓存前缀资产

`delegate` 的工具描述与参数表是提示词前缀的一部分。本批在默认形态下**删除了一段参数与一处描述词**
（「领域负责人/执行者」→「执行者」），属有意的缓存前缀变更：上线后第一次请求上游缓存会重算一次。
`partner_manage` 的 tool description 同样改动。变更仅此两处，其余工具描述与注册顺序未动。
