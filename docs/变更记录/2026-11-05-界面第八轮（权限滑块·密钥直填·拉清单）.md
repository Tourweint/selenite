## 2. H2 后端（provider-secrets.ts 新建）

- 密钥文件 `.data/provider-keys.json`（0600、原子写、启动全量注入 env 且已有 env 值优先）；`PUT /providers/:id/secret`：生成 `LIFEDIARY_KEY_<ID大写>`（id 规则保证天然合法，未放宽 KEY_ENV_PATTERN）→ 写文件 → 热注入 `process.env` → 同步 providers.json keyEnv；响应不回显密钥；DELETE 联动清条目；回滚开关 `PROVIDER_SECRETS=false`。
- CORS 补 `PUT`（既有 `/workspaces/current-project` 也受益）。
- 探针 §16（22 断言）：secret 无回显、hasKey 布尔、假上游收到 `Bearer <刚填key>`（热注入→modelsUrl 立即可用）、providers.json 无明文、DELETE 清条目、重启后文件 key 仍生效。
- H2.1：`modelsUrl` 在手时允许空清单建档（"先存 Key 再自动拉取"的前提）；无 modelsUrl 空清单仍 400；上游返回空清单明确报"上游清单为空"，不静默沿用旧清单。

## 3. H1 界面

- **权限分段滑动高亮（抄 CINDY segmented-control）**：共享胶囊 `.segmented-plate`（absolute），`syncSegmented()` 实测矩形写 transform（减 border 1px 校正），200ms `cubic-bezier(.4,0,.2,1)`，首帧防"从 (0,0) 滑入"，ResizeObserver 复量，reduced-motion 直切；写成通用 `.segmented.slide` 修饰类。**实机 MutationObserver 抓证**：点击只改 `aria-checked`（3 条属性记录、0 个子节点变动），plate 常驻不重建——动画由 CSS 过渡真实播放。
- **切供应商不闪**：右栏常驻骨架 + `fillProviderForm()` 只改字段值，160ms opacity 微动画；加载中 `.is-loading` 半透明不白块。
- **密钥直填 UI**：「API Key」password + 眼睛；keyEnv 输入行删除（前端自动生成）；旁注"Key 只存在你这台电脑的服务端…"；保存编排 = POST providers → PUT secret →（自动拉取勾选）POST modelsUrl 回填清单并自动取消勾选；编辑时留空 = 不改密钥；后端未上线/关闭时降级回手输 env 形态。

## 5. 事故与修复（测试操作失误，非产品缺陷）

总管实机测试时行点击未生效（选择器命中隐藏按钮），在**百炼**表单上误存了 magpie 的 Key 并触发拉取失败。修复：密钥文件清除误写条目、providers.json 百炼 keyEnv 恢复 `LLM_API_KEY`、重启服务核实。教训：脚本化 UI 测试必须"先断言表单已切到目标供应商再操作"。
