# 2026-11-23 设置默认模型思考强度换滑块

**改了什么**

设置 → 模型 → 默认模型卡里的「思考强度 · 新会话默认」从一排分段按钮（关/低/中/高）换成与对话页
模型菜单底栏同一件**填充滑块**，并带滑动动画（点按 / 拖动 / 方向键都动）。

- 滑块本体从 `web/hover-tip.js` 的 `thinkingFoot` 抽到新文件 `web/thinking-slider.js`
  （`createThinkingSlider`），两处摆位共用；对话页行为不变。
- 动画：单击轨道不再按下就抢跳，松手后带 160ms 过渡滑到目标档；真拖动仍关过渡跟手
  （`.is-dragging`）；键盘方向键同样带过渡。行出现时沿用轻落淡入（`thinkingRowIn`），
  `prefers-reduced-motion` 下过渡与入场动画都关。
- 设置页改档只发 `{ thinking }`（服务端「只改档」分支），不再顺手把模型重设一遍；
  服务端按支持域 clamp 回实际档时滑块带过渡跟回；保存失败回到上一档。
- 顺手修：原分段点击回调 `setGlobalThinking(current, item)` 多传一个参数，`thinking` 实际收到
  的是 current 对象——分段时代这一行本身就是坏的；换滑块后改为只传档位。
- 删掉已无用户的 `.think-seg / .think-opt` 样式，`thinkSegIn` 改名 `thinkingRowIn` 给设置行用。

**为什么**：用户口径「设置里默认模型这页调思考强度的，也变成对话框里那个滑动的块，把这动画也做出来；
没动画还是不太好看了」。2026-11-21 的记录里「设置页默认模型卡的分段行保持不变」是当时用户没点名，
本次翻案（见 `2026-11-21-思考强度换填充滑块.md` 追记）。

**验证**（2026-11-23，隔离实例 :39848 + IAB 真浏览器）

- 设置页渲染出滑块（当前模型四档，初值「关」）；`web-imports` 导入护栏绿、`pnpm typecheck` 0。
- 单击轨道 78% → 中，落盘 `.data/runtime.json` `thinking=medium`；单击 99% → 高，抓帧确认旋钮
  在途（inline 目标 714px，抓时 computed 478px）说明过渡真在跑，随后落盘 `high`。
- 拖拽从右到左 → 关，落盘 `off`。
- 回归对话页：模型菜单底栏滑块正常渲染，单击 → 低，`localStorage` 同步
  `lifediary.thinking=low` / `thinkingTouched=1`，动画在途（7px → 73px）。
- 行入场动画 computed `animationName=thinkingRowIn`。

**回滚**：revert 本批；设置页恢复分段按钮（`.think-seg / .think-opt` 样式需一并恢复）。

**明确不做**：手机端（无此界面）；拖动过程实时发包（拖一发一，避免请求风暴）。
