# 会话地图切换：顶栏「切换」+ 选择器双落点

**日期**：2026-11-18。
**范围**：纯前端（`web/index.html`、`web/chat-map.js`、`web/partner-sessions-ui.js`、`web/style-02-sidebar.css`）；不碰契约与服务端。

## 问题（用户反馈）

- 地图页只能看当前这条会话的家族图；想换一条会话的地图得先回对话、再从侧栏/标题进另一条，很绕。
- 「选择会话」弹层只能去对话（点一条 = 打开聊天），没法直接落到那条会话的地图。
- 用户口径："地图不能没有……尽量保留一点，能切换不同的会话。"

## 设计

1. **地图顶栏加「切换」**（`整理 / 定位` 左边）：点开当前执事/总管的会话选择器，选一条直接换地图。
   - 执事地图 → 该执事的 canonical + 副会话；总管地图 → 总管会话清单。
   - 普通 worker / 群 / 任务会话没有对应选择器 → 按钮隐藏（保持现状：从侧栏进另一条再点地图）。
2. **选择器加「打开到」双落点**：`打开到 [去对话] [看地图]`。
   - 点一条已有会话：`去对话` = 旧行为（打开聊天）；`看地图` = 关弹层后切 `#/map/<id>`；
   - 默认跟随当前页面：**地图页**打开的选择器默认「看地图」，**对话页**默认「去对话」；
   - 两个位置**固定**：永远是 `去对话` 在前、`看地图` 在后，不随当前档位换顺序（人的肌肉记忆；
     焦点在打开时放到真正生效的那一档，切换档位后同样）；
   - 弹层里原有的解释性文字（"人设、记忆与项目照旧共用……"）删除：选择器只留控件、列表与新建按钮；
   - 当前正在看的那条（对话页的当前会话 / 地图页的当前地图）高亮并禁用；换档后按新落点重新判断。
3. **跨执事切换**：地图页左侧花名册每个执事旁的「选择会话」也遵循“当前页面在地图 → 默认看地图”，
   所以在地图上换另一个执事的地图 = 点那个执事的会话按钮 → 选一条（不用先回对话）。
4. **删除当前地图的兜底**：在「看地图」档删掉当前地图的那条会话时，落到剩余的第一条无来源会话的
   地图（主对话优先）；没有剩余就回对话/新开。避免留在 404 地图上。
5. **新建会话**：两个档位下都先进对话（新会话没有内容，地图要等第一句话）；弹层说明里写清楚。

## 交互示意

```text
地图顶栏：  ← 会话地图                          [切换] [整理] [定位] 100%

点「切换」→ 小记的会话
            打开到  去对话  (看地图)
            主对话                    3 轮 · 1 小时前
            第一句测前缀              1 轮 · 1 天前   ← 当前地图，高亮禁用
            副会话验收：收到请回一句    2 轮 · 1 天前
            新建会话
```

## 验证

- `node --check` 通过（`chat-map.js` / `partner-sessions-ui.js`）；`web-imports.test.mjs` 通过。
- 浏览器实测（本地 39847，真数据）：
  - 地图顶栏出现「切换」；点开默认「看地图」，当前地图那条高亮禁用；
  - 选「副会话验收」→ hash 切到 `#/map/...side-e548a242`，地图换成那条会话的两轮；
  - 回对话 → 标题打开选择器（默认「去对话」）→ 切「看地图」→ 选「主对话」→ 落到 canonical 的地图（4 轮）；
  - 地图页点花名册「小记」的会话按钮 → 选择器默认「看地图」（跨执事直接换图）；
  - 普通 worker 会话的地图：顶栏「切换」隐藏（无对应选择器）。
- 本次只改前端静态文件，刷新页面生效；未重启服务。

## 明确不做

- 不做全局地图索引 / 地图画廊：切换入口按执事/总管分组，走现有选择器。
- 不改「一条会话 + 分支 = 一张家族图」的画板结构。
- 普通 worker / 群 / 任务会话不加地图切换器（没有会话选择器；从侧栏换一条再看地图）。
