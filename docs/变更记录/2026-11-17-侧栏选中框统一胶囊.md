# 侧栏选中框统一为胶囊

**日期**：2026-11-17。
**范围**：纯样式，一行圆角；不碰契约、不碰 JS。

## 问题

用户指出：在侧栏选中一条对话，选中框是方角矩形；选中一位执事，选中框是胶囊。
同一个侧栏里两种形状，看起来像两套东西。

## 缘由

选中态的底纹、内描边、字重本来就完全一样（`.chat[aria-current="true"]` 与
`.side-item[aria-current="true"]` 都是 `--accent-soft` + `inset 1px --accent-line`），
只有圆角不同：`.chat` 用了 `--r-md`（12px），`.side-item` 用 `--r-full`（胶囊）。
侧栏里执事 / 群组 / 项目 / 任务行都走 `.side-item`，对话行是唯一的方角。

## 改了什么

- **`web/style-02-sidebar.css`**：`.chat` 的 `border-radius` 从 `--r-md` 改为 `--r-full`，
  与侧栏其余可点行同一形状。hover 底纹也跟着变成胶囊（同一行，不该只改选中态）。

## 验证

- 浏览器实测（Playwright，本机 39847）：给一条 `.chat` 与一位执事行同时置
  `aria-current="true"`，读计算样式——两边 `border-radius` 均为 `9999px`，
  背景与 `inset 0 0 0 1px` 内描边完全一致；页面无脚本错误。
- 会话行高 36px、执事行 38px，高度差来自各自内容密度，本次不动（形状已一致）。
- 样式改动无需 typecheck。

## 刻意不做

- 没有改成"双方都方角"：侧栏六类可点行里五类是胶囊，把多数派改方角动的地方更多，
  也更不像这套侧栏原本的语言。若哪天要方角，改 `.side-item` 一处即可整体翻过去。
- 不统一行高：对话行与执事行内容密度不同，强行同高只会打乱列表节奏。
