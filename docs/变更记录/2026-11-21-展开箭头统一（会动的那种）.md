# 2026-11-21 展开箭头统一（会动的那种）

**改了什么**

全站可展开区块的指示箭头收敛成一套：形状、旋转角度、时长、状态载体各只有一个出处。

1. **公共层（新增）**
   - `web/icons.js`：加 `chevSvg()` / `chevDownSvg()` 两个 helper——折叠族指右 chevron
     （`m9 18 6-6-6-6`），下拉族指下（`m6 9 6 6 6-6`）。此前 9 个文件各内联一份 SVG path、
     文字箭头有 `▸ ▾ › ＋ － + −` 五种体系，全部换掉。
   - `web/style-27-chevron.css`（新文件，`style.css` 末尾追加 @import）：旋转行为唯一出处——
     `.chev` 收起指右、`[aria-expanded="true"]` / `details[open]` 时转 90° 指下；
     `.chev-ud`（下拉族）展开翻 180° 指上；过渡统一 `transform .18s var(--ease-standard)`；
     `prefers-reduced-motion` 下关动画。各页本地 rotate/transition 规则删除，只留尺寸颜色。
   - 原生 `<select>` 换皮：`appearance:none` + data-URI chevron（中灰 #82828c，四主题通用），
     覆盖 set-input / modal-input / font-select / map-window / rm-filter-select / archive-select /
     ctx-select，约 15 处，模板零改动。**这批箭头刻意不转**：原生下拉拿不到可靠的开合事件，
     要动画得整套换自绘面板（另批）。

2. **改出动画（此前 8 处静态）**
   - 审批弹层汇总条（`approval-pop.js`）：`▾/▸` 换字符 → chevSvg，展开改**原地切换**
     （翻 aria-expanded + 列表 hidden + 同步签名），不再整卡重画——重画会重建 DOM，
     transition 永远播不出来；列表改为常驻 DOM 只翻 hidden。
   - `::before` 换字符族 → 真箭头：单详情「现在到哪一步」（tasks-detail）、记忆导入弹窗两处
     （memory-page）、人设「＋/－」六处 details（partner-modals / partner-profile）、
     连接页 relay-adv（顺手藏掉全站最后一个浏览器原生 marker）。
   - 会话地图（chat-map）：节点收起 `+/−` → chevron + aria-expanded；因整图重画，
     `toggleCollapsed` 在重画后用 WAAPI 给那颗箭头补播一次旋转（照 tool-chips animateRow 思路）；
     折叠卡「往前放 N 轮」的 + 换指右 chevron（动作钮，静态）。
   - 任务中心「更早的 / 打手手风琴」（tasks-redesign）：同款 WAAPI 补播（这两处点击走整页重绘）；
     子单开关本来就原地改，transition 直接生效。
   - 技能页筛选/排序下拉（skills-list）、输入框模型 pill（index.html）：挂 `.chev-ud` 翻 180°。
   - 项目行文件夹清单 caret（project-switch）：aria-expanded 已有，挂 `.chev-ud`。
   - 「工作 N 步」折叠条（tool-chips）**判定保持静态**：它展开后整条消失，箭头没有可见的第二态。

3. **修齐已有动画（11 处形态各异）**
   - 指下/180°、指下/-90° 全部改指右/90°（视觉终态不变）：上下文页行、侧栏对话文件夹。
   - `▸` 文字 → chevSvg：任务子单、tk2-more、tk2-caret、工具池 `›`、归档分组。
   - **修真 bug**：style-21 的 `.mem-a-chev` 写了 `var(--ease)`——这个变量全站不存在，
     整条 transition 按规范失效，记忆页两个箭头的动画**从来没播过**；统一后归 style-27 顺带修掉。
   - style-22 的 `.pf-fold` 孤儿死代码删除（岗位契约早已搬进弹窗，JS 只剩 `.pf-fold-tools` 在用）。
   - style-25 的 `tool-pool-caret` 要颜色+transform 复合过渡，选择器加重一级压住通用规则，值取同一组。

4. **派活页专项（用户点名）**
   - `.executor-model-toggle`（每张 CLI 卡的模型箭头）：`openModelMenu/closeModelMenu` 同步
     触发钮的 `aria-expanded`，箭头挂 `.chev-ud` 开面板翻 180°（rotate 只落在 svg 上，
     不碰按钮自己的 `translateY(-50%)` 定位）。
   - **「默认派给谁」原生 select → 自绘面板**：原生箭头是 OS 灰三角（和同页自绘模型面板两套语言）
     且永远转不了。换成 set-input 样式按钮（文字 + chev-ud）+ 挂 body 的 fixed 菜单——复用模型
     清单那套 `placeMenu`（从 openModelMenu 抽出共用）/ 关闭手势（外点 / Escape / 滚动）/
     `.model-row/.model-item` 行样式；面板加 opacity 淡入（不用 transform，避免和朝上开的
     `translateY(-100%)` 内联样式打架）。selectable 的 kind 可点，phone/mcp 锁定项摆进来但禁用
     （同旧 disabled option 语义）；当前值落按钮 dataset，save 时读它；锁定态照旧禁用。
   - 面板是常驻节点：paint 时从 body 收回盒子里，进页时清掉上次关在 body 下的孤儿。

**为什么**

用户口径：展开的小箭头要统一成「会动的那种」，要好看；派活页箭头「对但不是特别对，也不会动」，
最上面的「默认派给谁」也要调。普查（两路 Explore 扫 web/ 全量）发现 11 处有动画但五套字符、
两种 SVG 方向、三种角度、五种缓动并存，还有 8 处完全静态、1 处假动画（var(--ease) 不存在）。

动/不动的判据（已与用户对齐）：**有第二态的箭头才动**——真正切换展开/收起的（分组、下拉、汇总条）
给旋转反馈；导航型箭头（抽屉行、群列表、供应商模板卡、头像角标——点开新页/弹层，没有展开态）保持
不动，动了是假动画；侧栏分区头「刻意无箭头」是既有设计（index.html 有注释），不碰。

**验证**（2026-11-21，IAB 真机）

- `node --check` 全部改动 JS 通过；`pnpm typecheck` 绿。
- 浏览器逐页验：派活页（面板开合、9 行、选中态、phone 锁定禁用、淡入、双箭头 180° 翻转、
  Esc 关回位、重载后无孤儿 DOM）；模型 pill / 技能下拉（matrix(-1,0,-1) = 180° 跨帧实锤）；
  记忆页分组与工作履历（matrix(0,1,-1,0) = 90°，视觉指下）；上下文浮层行（视觉指下 + 规则实锤）；
  原生 select 换皮（appearance:none + chevron 底图）。
- 排查中确认的测试方法学：IAB 里 evaluate 挂起期间合成器帧不走——**同一 eval 里点完立即读
  computed transform 会读到过渡第 0 帧（identity/none）**，跨 cell 读或看截图才是终态；
  隐藏（display:none）子树的 computed transform 也一律 none。读数"异常"均为伪影，视觉与
  getAnimations 为准。
- 未真验：会话地图 WAAPI 补播（当前打开的会话没有带分支/折叠卡的地图）、归档分组与打手手风琴
  （当页无数据）——三处同族模式已被其它页面实锤，代码路径一致。

**回滚**：纯前端样式批，无 env 开关（沿「前端细节五件」先例），回滚 = revert 本批；
`style-27-chevron.css` 删除即可回到各页自管形态。

**明确不做**：原生 select 升级自绘面板（除「默认派给谁」外，另批）；导航箭头动画化；
无箭头文字钮加箭头；侧栏分区头加箭头；手机端与 Go 壳。
