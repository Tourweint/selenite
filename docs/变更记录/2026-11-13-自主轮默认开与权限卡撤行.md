# 自主轮默认开 + 权限卡撤行（2026-11-13）

## 改了什么、为什么

用户在 设置→权限 看到「自主轮（观察与审批）」一行不知道是什么，问清后拍板两件：

1. **撤行**：这行从 权限 卡撤掉，入口只在 设置→服务→高级开关（`AUTONOMY_ENABLED` 一直在那，hot:true）。原来那行只是只读镜子，留着反而让人以为是权限项。
2. **默认开**：`AUTONOMY_ENABLED` 缺省从 off 翻成 on——"没人盯着跑的轮要有人兜底提醒"（观察层把卡住/等你批/出错/用量受限写进会话）+ 自主轮审批收紧（写文件/跑命令/派活一律弹卡、禁"记住"；建执事/建群/自建巡逻/递话结构性拒绝）。想关仍是一行 env 或高级开关切「关」，回滚开关没动。

## 落点

- `src/autonomy-mode.ts`：`autonomyMode()` 缺省→`on`；只有显式 `false / 0` 才 `off`（空白等价未设）。
- `src/autonomy-state.ts`：`autonomyGate()` 同口径翻默认（两处解析器保持一致，见文件注释）。
- `src/flags.ts`：FLAG_DEFS 的 `AUTONOMY_ENABLED` defaultValue `false`→`true`（高级开关页缺省显示开）。
- `src/autonomy.ts`：头注释同步。
- `web/app.js`：权限卡撤行 + 撤 `loadAutonomySwitch()`（唯一消费 `policy-autonomy` 节点）+ 高级开关 tip 补大白话解释（定时/事件唤醒、没人盯着跑的一轮叫自主轮）。
- `ts/apps/server/.data/agent-flags.json`：清掉存量 `"AUTONOMY_ENABLED": "false"` 覆盖，让默认接管（本机数据文件，不入 git）。

## 探针隔离（防默认外溢）

22 处起服务的探针显式补 `AUTONOMY_ENABLED: "false"`，行为与翻默认前逐字节一致：
http / settings / skills / sidebar（原有）+ 脚本批量补 18 处（approval、chief、companion、d2、d3、delegate-chain、delegate-wake、group-manage、groups、home、matrix、mobile-proxy、partner-relay、providers、relay、thinking、topic 等）+ 手工 4 处（diary、files、task、dist）。
http-probe 原 `AUTONOMY_ENABLED: ""` 改 `"false"`（新解析下空串=开，探针意图是关）。
没补的：harness-resume-busy / context-ratio / worktree-cleanup / pid-liveness（起的是探针自身或 chancellor worker，不读这个 env）；进程内探针（durable、delegate-gate/resume/concurrent 等）不 bootstrap index.ts，观察层不订阅、wake 走不到 runPartnerTurn（无执事配置），够不着自主轮。

## 生效时机

flags 文件是启动装载（loadFlagOverrides），本机**下次重启服务生效**，不用改任何设置。前端撤行是 web/ 直发，刷新页面即生效。

## 刻意不做

- 不把自主轮做成权限卡三档按钮（用户拍板：属高级设置，以后再说移动的事）。
- 权限卡不新增任何可调项；`/healthz.autonomy` 字段保留不退役（手机端/诊断可能用）。
