# 2026-11-21 灰块入场动画（生长）

**改了什么**

对话流工具灰块 / 思考块的入场从「升 3px + 淡入 0.22s（tchipIn）」换成用户从五版对比页里挑的
**「丙 · 生长」**（`web/style-06-tool-blocks.css`，纯 CSS，`tool-chips.js` 零改动）：

- 图标先弹到位（scale .4→1.18→1，0.2s emphasized），块体用 clip-path 从图标处向右长出来
  （inset(0 100% 0 0)→inset(0)，0.3s decelerate），文字随后浮现（0.22s，延迟 0.12s）——
  「这一步正在发生」。
- **勾号落定弹跳随批带上**（checkPop 0.18s，settle 那一刻从 .4 弹到 1）：限定
  `.tchips-wrap.is-live`——历史回读的块生来就是 ok，不播，开旧会话满屏跳勾。
- **思考块的转圈环不被顶掉**：spinner 规则在文件里更晚出现、同特异性取替图标弹入——
  环从起跑就转，运行中的样子不动（用户口径「运行中就不用改了」）。工具块图标照常弹入。
- `prefers-reduced-motion` 下入场 / 弹入 / 勾号全部关掉，块直接到位。
- 历史回读不播：入场仍挂在 `is-live`（只有现场这一轮有），打开旧会话块不齐动——机制沿用原状。
