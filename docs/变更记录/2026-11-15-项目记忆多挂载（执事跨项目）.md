# 项目记忆多挂载（执事跨项目）· 2026-11-15

**方案**：`docs/设计方案/2026-11-15-项目记忆多挂载（执事跨项目）.md`（前案 `2026-11-15-项目记忆挂载跟人走.md` 文首已补指向）。
**回写落点**：D23（多挂载 + 闸门 + 挂载=可达性）、`接口-端点4`（`projectIds` 契约与 PATCH 语义）、`接口-端点6`（记忆页项目分组段补多挂载）、`接口-存储工具与配对`（remember/recall/gatedScopes）、`接口文档.md` §6（`PROJECT_MEMORY_GATE`）。

## 改了什么

1. **挂载单选 → 多选**：shared `PartnerProfileSchema` `projectId: uuid|null` → `projectIds: uuid[]`（字段上线半天、手机端未消费，直接换名）。`partners.sqlite` 加 `project_ids TEXT`（JSON 数组），migrate 一次性搬旧单值（单值 → `[旧值]`），旧列 `project_id` 保留不读不写。PATCH：数组 = 整体替换（去重、每个须命中登记项目含归档）、空数组 = 清空、省略 = 不改、未知 uuid 400 整批不写。`detachProject`（项目删除连带解除）改为 JS 端过滤数组后写回。
2. **注入闸门**：memory 包 `RecallQuery` 加 `gatedScopes`（字面命中才进候选、不吃最近窗口、空 text 不贡献、与 scopes 重复 key 从严；FTS 不可用回落窗口时由引擎侧 `directlyRelevant` 过滤兜住，闸门不留缝）。`recallContext` 组装收纯函数 `composeProjectRecallScopes`：绑定项目全权进池、其余挂载项目 gated；`PROJECT_MEMORY_GATE=false`（新回滚开关，默认开）退回全权进池（跟人走当日形态）。
3. **注入行带项目归属**：`InjectOptions.scopeLabel`，project 来源行渲染 `- [项目名 · kind] …`；不传 resolver / 解析不出名字逐字节回旧格式。项目名解析器 `setProjectLabelResolver` 由 lifecycle-harness 接线（含归档项目），`agent/project-scope.ts` 保持零重依赖。
4. **`project_index` 注入**（`INJECTION_ORDER.project_index: 95`，memory_recall 之前）：非群、开关开、挂载 ≥1 时一行负责项目清单 + 用法提示（多挂载才提 remember 指名）。登记进 `injection-registry.ts`。
5. **remember 指名写入**：加可选参数 `project`（项目名）；解析阶梯收纯函数 `resolveProjectWriteTarget`：指名（须在负责清单，先精确后忽略大小写唯一命中）→ 会话绑定 → 唯一挂载 → 报错引导（`no_project_scope` / `project_ambiguous` / `project_not_mounted`）。**工具描述与参数有改 = 缓存前缀资产**（上游 prompt cache 打掉一次，随本批语义变更属预期）。`recall` 工具 scopes 并入全部挂载项目（主动查不受闸门），描述刻意不动（少打一次缓存）。
6. **人设页多选**：负责项目弹层单选 `<select>` → 勾选清单（复用 `export-part` 样式）；`"projectIds" in partner` 判定显隐；已移除项目的挂载渲染勾死占位、保存时不送（服务端对登记外 uuid 一律 400）。

## 顺手修的存量缺陷（非本批引入）

- **`partner-profile.js` 缺 `setModalHint` 导入**：工作树在途的改人设页重构用了 14 处 `setModalHint`（来自 `project-modal.js`）却没 import——调用即 ReferenceError，弹层保存 handler 死在禁用按钮之后（hint 空、PATCH 发不出、按钮永久禁用）。本批的负责项目弹层同款写法同踩，浏览器验收时插桩定位后补了 `import { setModalHint } from "./project-modal.js"`，修复全文件所有弹层。**该文件有并行会话在途改动（工作树 vs HEAD 差 1180 行），只补了一行导入，未动其它**。
- **http 探针 §14.4「系统提示带项目根路径」存量红**：2026-11-13 项目容器重构后 current_project 节改说「主文件夹：」，探针断言还在找旧字符串「根路径：」（11-13 起就红，与本批无关）。断言对齐现状并改名「系统提示带项目主文件夹路径」。
