# 2026-11-17 定时主动轮（到点跑模型 + 触发消息隐藏）

## 改了什么

用户拍板：删掉"不调模型、到点写一句写死文本"的旧闹钟形态；定时到点改为**让目标执事真跑一轮模型、主动说一句**。触发那一轮的指令带专用隐藏标记，回读历史时跳过，界面上只看到对面自己冒出的一句。两条定时路并存——例行任务（触发可见，不动）与定时主动轮（触发隐藏）。派活唤醒不碰。

- `packages/shared/src/index.ts`：新增常量 `PROACTIVE_HIDDEN_MARKER = "[lifediary.proactive]"`（服务端内部常量，非契约字段；固定字节勿改）。
- `scheduled-run-deliverer.ts`（新）：无依赖回调槽，供 reminder 到点调用；解 `reminder → agent → lifecycle-harness → reminder` 的循环依赖。
- `scheduled-run-handler.ts`（新）：到点实现——目标执事取值顺序（显式 partnerId → 会话反查 → chief 兜底），拼 `marker + 正文` 走 `runPartnerTurn(authority:"autonomous", sessionMode:"persistent")`。
- `reminder.ts`：`deliver` 按 `SCHEDULED_TASK_MODEL_RUN` 分流——默认跑模型（回调）、false 逐字节回旧闹钟（写 `lifediary.reminder` entry + deliverer 写死消息）；周期续排两种形态都保留。
- `index.ts`：装配 `installScheduledRunHandler()`；保留旧 deliverer 注册作回滚形态。
- `agent/session-transcript.ts`：fold 的 pi.user 分支读 `raw` 后判隐藏标记，只在 `messages.push` 处跳过；`turnStartAt` 保留，回答的步骤/workMs 照常挂载。
- `agent/session-search.ts`：全局搜索绕过 fold 直读 entries，补同一隐藏判据，避免"看不见的消息被搜出来"。
- `plugins.json`：新增 `SCHEDULED_TASK_MODEL_RUN`（autonomy 组，默认 true，hot，requires COMPANIONS）。
- `tools.ts`：`set_reminder` 工具描述改口径（到点跑模型、触发指令隐藏）。**此改动打掉上游 prompt cache 前缀，按规矩登记在此。**
- `agent/proactive-hidden.test.ts`（新）：5 条用例——隐藏生效、autonomous 头在标记前仍隐藏（真实提交形态）、普通消息不受影响、回答步骤/workMs 仍挂载、标记必须独立成行；已加进 `package.json` test 列表。
- **实施中发现并修正的关键点**：`runPartnerTurn` 会在正文前拼 autonomous 透明头，若按"整条文本以标记开头"判定则隐藏永远不生效；已改为"标记独立成行即可"（fold 与全局搜索两处同判据），并补真实形态测试用例。

## 行为变化（需知晓）

- 回复**落在目标执事的主会话**（与例行任务一致），不再是建提醒的原会话。
- 挂念（nudge，`partner-proactive.ts` 动态 import ReminderTask）跟着走"跑模型 + 隐藏触发"——从此调模型，成本上升，但更符合"对面主动找你"。
- 回滚：`SCHEDULED_TASK_MODEL_RUN=false` → 旧闹钟行为（写死消息、不调模型）；这是逐字节回退，不是删代码。
- 手机端无需改：只读 transcript，隐藏自动生效。

## 明确不做
- 不改例行任务、不碰 `delegation-wake.ts`（派活唤醒）。
- 不加 `ChatEvent` 事件、不改 `TranscriptMessageSchema`（隐藏在折叠层完成，契约零字段改动）。
- 不把 routine 也改成隐藏——两条路并存是需求本身。

### 实施中修正的两处（探针驱动）
1. **隐藏判据不能认"整条文本行首"**：`runPartnerTurn` 会在正文前拼 autonomous 透明头，触发标记落在头之后的独立行。fold 与全局搜索都改成"标记独立成行即隐藏"，并补真实形态测试。
2. **自主轮默认带安静契约，短回复会被判 quiet 剔除**，界面只剩空 assistant：`scheduled-run-handler` 显式 `quiet:false`（同派活唤醒口径），"到点必说一句"。
