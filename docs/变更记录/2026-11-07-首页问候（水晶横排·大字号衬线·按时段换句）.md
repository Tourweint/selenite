# 2026-11-07 首页问候：水晶横排 + 大字号衬线 + 按时段换句

## 为什么

用户三点要求，都在首页空态（还没开口时的那一屏）：

1. **水晶和文字改成左右排列。** 原来是 88px 水晶竖着压在 17px 文字上方，一竖一横的重量不对等：图标占掉三分之一屏高，句子缩在下面像图注。
2. **中间那句要调大，字体也要设。** 17px 无衬线在这屏里读起来是「按钮文案」量级——它是首页唯一一句人话，却比输入框里的字更小。
3. **考虑按时间换语句。** 同一句话天天见就是墙纸，早晚各一句能把"现在是什么时候"这层意思带进来。

顺带修掉一个既有缺陷：空态与输入框重叠。`2026-11-06-项目文件入口修复与回答脚注` 的「发现但没改的」里登记过，`#empty` 底部压在 `#composer` 顶部约 32px（本次实测 -32px）。改竖排为横排后这一组变矮，不处理就会直接钻进卡片里。

## 改了什么

### `web/index.html`

- 问候语 `<p>` 加类 `empty-greet` 和 id `empty-greet`（换句要拿到它）。
- 水晶图从 `crystal.png` 换成 `crystal-mark.png`（下条解释为什么另存一份）。

### `web/crystal-mark.png`（新增）

原图 512×512，但水晶只占中间 278×460 一条，四周全是透明。88px 的框里真正画出来的石头只有 48px。竖排时这点空白不显眼，横排就变成图标与文字之间一段莫名其妙的距离。新图按 alpha 包围盒裁掉透明边（278×460），CSS 用 `height` + `width:auto` 定高，尺寸从此是"石头的尺寸"而不是"画布的尺寸"。原图保留，favicon 与别处引用不动。

### `web/style.css`

- `:root` 新增 `--font-display`：`Songti SC → Noto Serif SC → Source Han Serif SC → STSong → SimSun → serif`。只给首页这一句用，正文与控件仍是 `--font`。Windows 实测落到 **Noto Serif SC**（`CSS.getPlatformFontsForNode` 回读 familyName = `Noto Serif SC`、postScriptName = `Noto-Serif-SC-Medium`），机内自带，不引外链字体（离线可用、无 FOUT）。
- `.empty` 改横排：`inline-flex` + `align-items:center` + `gap:16px`，`text-align:left`。
- 首页定位重做（**这是本次最实质的一处**）：删掉 `margin-top: calc(22vh - var(--titlebar-h))`，改为
  - `.main[data-home="1"] { grid-template-rows: 1fr; }` —— 首页 `.top` 是 `display:none`，但栅格仍是 `auto 1fr`，`.scroll` 落在 auto 行只拿到内容高（实测主区 709px，滚动盒只有 392px），空态被裁在这个矮框里；改单行后滚动盒铺满主区。
  - `.main[data-home="1"] .thread { min-height:100%; justify-content:flex-end; padding-bottom: calc(50vh + var(--composer-home-offset) + 42px); }`
  - `.main[data-home="1"] .empty { align-self:center; margin:0; }`

  口径推导：卡片底边距主区底 = `50vh - offset`，而 JS 写入的 `offset = 卡高/2 - 12`，所以卡片顶边距主区底 = `50vh + offset + 24`；再留 18px 呼吸即 `+42`。**卡高由 `ResizeObserver` 实测**，字号变大、占位文案换行、卡片长高，这一组都跟着上移，不会压上去。
- `.main[data-home="1"] .empty-mark { height: 1.8em; }` / `.empty-mark { height: 1.8em }`：水晶宽高比 0.6 偏瘦，46px 时在 30px 宋体旁边像一道竖线，抬到 54px（= 1.8em @ 30px）才有"一枚石头"的分量。
  - **用 em 不用 px**：整组的字号是 `clamp(22px → 30px)`，窄窗收到 22px 时 54px 的石头会头重。绑成 `1.8em` 后它跟着缩到 40px，比例在各档窗口都是同一个。
- `.empty` 承接字号 `clamp(22px, 2.2vw + 6px, 30px)`，`.empty-greet` 用 `font-size: inherit`：图标与文字必须读同一个值，各写一份 clamp 迟早不同步。
- `.empty p.empty-greet`：`--font-display`、`font-size: inherit`（吃 `.empty` 的 clamp）、`font-weight:500`、`line-height:1.25`、`letter-spacing:.03em`。
  - 选择器必须带 `.empty` 前缀：既有 `.empty p { font-size:14px }` 的优先级是 (0,1,1)，单个 `.empty-greet` (0,1,0) 会被它盖掉（第一版犯过，实测 computed 仍是 14px）。
  - 用 `clamp` 而不是写死 30px：最长的一句「早，今天想从哪儿开始？」在 600px 宽的窗口里会折成两行；480px 宽实测仍是单行。

### `web/app.js`

- `el.emptyGreet` 取 `#empty-greet`。
- 新增 `GREETING_SLOTS` / `greetingSlot()` / `greetingLine()` / `syncGreeting()`，`updateHomeMode()` 在首页态调用 `syncGreeting()`。
- 启动尾部加 60s 轮询：只在 `data-home === "1"` 时 `syncGreeting()`。窗口常开过夜不能一直挂着「晚安」。轮询只改 `textContent`，不重建 DOM，不打断 `rise` 动画，也不闪。

**换句规则**（四段，边界按作息不按整点）：

| 时段 | 起点 | 两句 |
|---|---|---|
| 早 | 05:00 | 早，今天想从哪儿开始？ / 醒得早，想法大概也清楚。 |
| 白天 | 10:00 | 说吧，我在。 / 手上的事，说来听听。 |
| 晚 | 18:00 | 忙完了？慢慢说。 / 天黑了，正好收个尾。 |
| 夜 | 23:00 | 这么晚还没睡。 / 夜里的想法，往往更要紧。 |

- 23:00–05:00 归"夜"，凌晨不叫"早上"。
- **轮换不随机**：随机会让刷新时跳到另一句，看起来像出错。取 `(本地日期序号 + 段序号) % 2`——同一天同一段里刷新、重开、切主题都是同一句，跨段或跨天才换。
- 文案口径与原来那句一致：短、第一人称、不催不迎，不提模型和功能。"说吧，我在。"保留在白天段，它是这屏的定调句。

## 验证

真浏览器（headless Chrome + CDP，隔离服务 8199 / faux 模型 / 独立数据目录），1440×900 与 1100×700、900×620、1440×1000、480×760 四档：

| 项 | 结果 |
|---|---|
| 横排几何 | 1440 宽下水晶 33×54、文字 371×38，图标与文字间距 16px，垂直居中（中线误差 < 1.5px） |
| 居中 | 五档窗口下整组中心 = 输入卡中心 = 滚动盒中心（480 宽实测均为 264，误差 0） |
| 整组与卡片间距 | 18px，五档窗口恒定 |
| 字号缩放 | 1440/1280 → 30px，1024 → 28.5px，820 → 24px，480 → 22px；五档下文字都是单行（`getClientRects().length === 1`），无溢出 |
| 图标随字缩放 | 54 → 51 → 43 → 40（= 1.8em），与文字比例恒定 |
| 卡片长高跟随 | 把卡 `min-height` 从 141 推到 200 / 260，`offset` 由 58.5 → 88 → 118，整组同步上移，间距仍 18px |
| 竖排重叠（既有缺陷） | 修复前 `#empty` 底部 324 vs 卡片顶 292（重叠 32px）；修复后 350 vs 368（留 18px） |
| 滚动条 | 五档窗口 `scrollHeight == clientHeight`，首页不多出滚动条 |
| 字体真实落点 | `CSS.getPlatformFontsForNode` → `Noto Serif SC`（12 字形），不是回退的 serif |
| 换句 | 00/04 夜、05/09 早、10/17 白天、18/22 晚、23 夜；同段同句、跨日换句、连续 8 天轮换正确 |
| 四主题 | paper / white / indigo / black 各截一张，均无漏色、图标无白底、深色下文字对比正常 |
| 发消息后 | `data-home=0`、`#empty` 已移出 DOM、卡片回到底部（bottom 886 / vh 900）、脚注正常 |
| console | 全流程零 error、零 warning、零未捕获异常 |

## 明确不做

- 不做问候语的设置项（用户没要求，也别把一句招呼做成配置项）。
- 不引外链字体、不做字体子集化：这一句的字形都在系统字体里，加载一个 woff2 只为一句问候不值当，也破坏离线可用。
- 不改输入框自身的字号（首页 16px 是 2026-11-04 定的，跟这次的"问候语要大"是两件事）。
- 不动 `crystal.png` 原文件与 favicon，避免影响别处引用。
- 不做问候语的每日一词/随机池：两句一轮已经能消除墙纸感，池子越大越容易撞上不合时宜的句子。
