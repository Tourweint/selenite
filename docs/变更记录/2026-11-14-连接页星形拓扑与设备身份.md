## 没做 / 没验证（首轮）

- **没有浏览器实机点验**：星形的实际观感（字号、椭圆是否挤、长名截断）只做了 SVG 结构与数值校验，没人眼看过。
- **没有撤销过一台真实设备**：唯一在线之外的中继设备 `vivo手机`（`#b9dc98bc`）是用户当前要用的，撤销它等于作废凭据，所以只用未知 id 验了通路。
- 手机端没改：它不需要知道自己的 ID。
- 两套名册的主键不合并（`pair` id 与 relay `deviceId` 各自保留），只合并展示行。
- 拓扑不做动画；不做设备间真网状。
- 当前名册实况（2026-11-14）：本地配对两条都已是 `revoked`（`平板自检 #110636c9`、`vivo手机 #f8260fba`），中继名册是 `书房主机 #d72f1d5d`（在线）与 `vivo手机 #b9dc98bc`（离线）。也就是说**本地配对的凭据现在全失效了，手机/平板若走本地配对要重新扫码**；页面会把它们显示成活动行的「另有 N 条旧凭据已移除」或独立「已移除」行。
