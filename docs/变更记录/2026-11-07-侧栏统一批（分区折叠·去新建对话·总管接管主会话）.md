# 2026-11-07 侧栏统一批（分区折叠 · 去新建对话 · 总管接管主会话）

## 需求（用户原话，六条）

1. 侧边栏收起时，设置按钮和服务已连接的小绿点，**绿点要在设置按钮底下**；展开之后不要变，
   「服务在线」几个字也弄大一点，跟上面的字体对齐。
2. 群组要能收起；"知识这方面也都是加号，有一个收起按钮"。
3. 项目也做成「点击能展开 + 小加号添加」，**把这几个栏统一一下**。
4. 最上面的「新建对话」没用了，去掉。
5. **主会话不要了**——总管跟主会话是一个效果，把它从界面上删掉（它不能删、不能改名、
   不能置顶、不能星标），以后用总管。
6. 「全部会话」导向设置也不需要了。任务中心也做成「加号 + 小箭头」那种可展开形态，
   展开后像里面那个对话一样，点进去要有它的界面。

## 判定

免写方案类（AGENTS.md：文案 / 样式 / 同契约下补校验）。UI 结构重排，**后端零改动、无新端点、
无新 env、无契约变化**；数据仍全部来自既有 `GET /api/v1/agent/chats`、`/api/v1/tickets`、
`/api/v1/partners`、`/api/v1/projects`、`/api/v1/groups`。

## 做了什么

### 1. 底部：齿轮在上、状态在下（展开态与收起态同构）

- 收起轨道 `.rail-foot` 从「齿轮居中 + 状态点绝对定位在右侧」改为**竖排**：齿轮在上、
  绿点在正下方同一竖轴（实测两条中线都在 36px）。底部内边距 12px → 18px，
  绿点不再贴着窗口下沿。
- 展开态 `.side-foot` 同样改为竖排：齿轮一行、状态一行。齿轮从「36px 裸图标」改成
  **整行导航行并带「设置」二字**；状态文字 11.5px → **12.5px**，与导航行/分区名同一档，
  左缘与上面各行对齐（绿色圆点外套 22px 槽位 + 3px 内衬，和 22px 图标同轴）。

### 2. 分区统一（会话 / 任务中心 / 项目 / 执事 / 群组）

五个分区共用一套 `.side-sec` 形态，**分区头 = 折叠箭头 + 名称 (+计数) + 行尾 ＋**：

| 分区 | 折叠 | 行尾 ＋ 的动作 | 展开后 |
|---|---|---|---|
| 最近会话 | ✔ | 新建一轮普通会话 | 会话列表（置顶优先，最多 5 条） |
| 任务中心 | ✔ | 打开任务中心整页 | 最近在跑的对话卡（灯 + 标题 + 时间） |
| 项目 | ✔ | 添加子项目（既有弹窗） | 主项目 + 子项目内联行（行尾仍有文件入口） |
| 执事 | ✔ | 新建执事（既有弹窗） | 花名册 |
| 群组 | ✔ | 新建群组（既有弹窗） | 群列表 |

- 折叠态各存一份 `lifediary.side.<sec>`（`open` / `closed`），刷新后保持。
  旧键 `lifediary.chief.recents` 只作为「最近会话」的初始值读一次，之后不再写。
- **任务中心展开后"像里面那个对话"**：侧栏列的是对话卡（标题 + 聚合灯 + 时间），
  不是任务单行；点一行直接进任务中心那张卡（`#/tasks?ticket=<首张父单>`）。
  完整三列看板/筛选/打手卡仍只在整页——侧栏是入口，不做第二块看板（用户担心的
  "点一下变成展开了，那它的界面从哪里找"就是这个取舍：分区头里留「打开任务中心 →」）。

### 3. 去掉的入口

- **顶部「新建对话」大按钮**（`.new` / `#new-chat`）与**收起轨道顶部 ＋**（`#rail-new`）：
  新建入口收敛到「最近会话」分区头的 ＋。快捷键 Ctrl+K 不变。
- **「全部会话 →」**（跳设置→会话搜索）：按用户口径下线；设置页「会话」分区仍在，
  侧栏只列最近 5 条。
- **项目 pill**（`#proj-pill` / `#side-proj`）：换成内联行，不再"点开一个小窗再看"。
  收起轨道仍是 `.rail-proj` 圆钮 + 同一份弹层（72px 放不下内联列表）。
- 「新对话」顶部菜单项（`#menu-pop`）保留（Ctrl+K 之外的备用入口）。

### 4. 主会话从侧栏退场

- `renderChats()` 增加 `chatKind !== "chief"` 过滤：**总管会话不再作为一行混在「最近会话」里**。
  它仍是一条真会话、历史可回读，仍能从顶部「总管」条目打开（`openChiefChat` 读 `state.chats`
  全量，不受这条过滤影响）。
- 这样处理的原因：总管会话本来就**没有置顶/改名/删除/星标的完整语义**（用户明确点名这四点），
  摆在普通会话列表里只会让人以为"这行坏了"；而它的入口（总管条目）一直在最上面。
- 没有删任何数据、没有加删除接口、没有改 `chatKind` 判定（缺字段的旧会话仍按 `chief`）。

## 刻意没有

- **不删总管会话本身**：它是总管人格（SOUL）与会话历史的承载，删了要重新播种；
  本次只撤掉列表里的那一行。
- **不给分区做拖拽排序 / 自定义分组**：用户要的是形态统一，不是布局编辑器。
- **不在侧栏放第二块任务看板**：三列 + 筛选 + 打手卡留在整页，侧栏只列对话卡。
- **不改轨道顺序**（总管 → 任务中心 → 项目 → 执事 → 群组 → 设置）：E5 定的一一对应仍成立，
  只是两端各少了一个"新建"。
- **不碰后端**：所有数据面沿用既有五个 GET。
