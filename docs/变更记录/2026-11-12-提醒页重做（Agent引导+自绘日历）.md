# 提醒页重做：Agent 引导 + 自绘日历

日期：2026-11-12
状态：已落地（纯 web 前端，零契约、零服务端改动）

## 起因

用户口径（2026-11-12，桌面端设置 → 提醒，两轮）：

1. 第一轮：这一页「做得太差，彻底不合格」，定提醒应该直接让 Agent 建；
   原生 `datetime-local` 在中文界面里显示 `MM/DD/YY`，不能接受。
2. 第二轮：解释性文字太多，要照别的页面的字号/密度收；「手动指定时间」不要用文字链接，
   做成额外的小按钮；弹窗和选时间仍不好看，再调。

## 改了什么

- **`web/app.js`**
  - 主路径「让 Agent 帮你记」：一句自然语言输入框 + `交给 Agent`。点后跳到总管对话，
    预填「帮我定个提醒：<原话>」并聚焦，人看过再发送（沿用技能评估那套
    「跳总管 + 预填、不自动发」的既有模式）。空着点也给一句模板。
  - 手动入口收成输入框右侧的方形日历图标按钮（`title` / `aria-label` 都是「手动指定时间」），
    不再占一行文字。
  - 弹窗重排成两栏：左边日历、右边时段；顶部只留「提醒什么」，删掉说明段与重复的状态文案。
    时段分「上午 / 下午 / 晚上」三组、每组三个常用时间，外加「其他时间」输入
    （认 `9:30` / `09:30`，失焦补零）。底部一行短状态：`明天 09:00 · 11 小时后`；
    过去时间禁用「添加」。默认明天 09:00。
  - 自绘日历：周一打头、翻月、今天描边、选中实心、过去日期禁用。
  - `openModal` 的宽度重置补上 `modal-reminder`（原先只重置 `modal-wide`），
    避免提醒弹窗的 620px 档漏给下一个弹窗。
  - 待触发列表减字：左列中文日期（今天/明天/11月20日）+ 时间，右列内容 + 相对时间；
    去掉星期与裸英文状态；已结束沉底灰显；空态只留一句「还没有提醒」。
  - 删掉旧的 `whenText`、`.tk-remind-*` 与旧内联表单。
- **`web/style.css`**
  - 提醒页改为 `.rm-hero* / .rm-say* / .rm-icon-btn / .rm-row* / .rm-cal* / .rm-time*`；
    日历去掉米色底卡、改成裸日历 + 32px 圆角日格；时段按钮改三列小方块。
  - 新档 `.modal-panel.modal-reminder`（620px），窄屏两栏自动叠成一栏。
  - 颜色只吃现有 token，不新造色值。

## 刻意没做

- **没加「删除 / 取消提醒」**：服务端没有单条提醒的取消接口（`POST /chat/:id/stop`
  会中止整个会话，不是提醒级操作）。要做得单独立项。
- **没改 POST /agent/reminders 契约**：请求体仍是 `{ text, at }`。
- 没在提醒页做「常用语模板 / 语音」等额外入口。
- 没动手机端：手机端没有这个设置页。
