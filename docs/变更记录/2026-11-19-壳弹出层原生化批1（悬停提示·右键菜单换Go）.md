# 2026-11-19 壳弹出层原生化批1（悬停提示·右键菜单换 Go）

用户目标「把前端部分组件换成 go，一些比较核心对性能要求比较高的，可以自己上网找资料 mygo」——
即 2026-11-10 记忆里"壳原生化立项时再拿出来用"的那笔账正式立项。方案、取舍、备选、明确不做、
真机验收记录全在 `docs/设计方案/2026-11-19-壳弹出层原生化（mygo ui 接管悬停提示与右键菜单）.md`；
长期口径已下沉 `系统架构.md` §6.3 与 `desktop/README.md`。本文只记改了什么、验了什么。

## 改了什么

**壳（desktop/）**

- 新增 `popovers.go`：`Shell.Capabilities / ShowTip / HideTip / ShowMenu` 四个绑定 +
  flyout 视图（tipView / menuView）+ 纯函数（拆行/摆位白名单/键盘导航/五套主题色板）。
  线程模型按 mygo 规矩走 atomic 快照（视图在主线程跑、不拿锁，防建窗死锁）；
  `ShowMenu` 阻塞返回所选序号（-1 = 按掉），业务闭包不过桥。
- `theme.go`：主题识别四套 → 五套，**补 celadon（青瓷）**——此前壳不认识页面侧 2026-11-14
  加的第五套，`Shell.SetTheme` 存不了、弹出层取不到色只能落 paper 兜底；`splashBackground`
  给 celadon 配了 `#f1f5f1`。
- `go.mod`：mygo **v0.7.3 → v0.10.0**。翻案原因：v0.7.3 的 FitContent 明文不支持原生
  Content（`Native UI (Content) does not fit`），flyout 定不了尺寸 = 批1 硬前提缺失；
  升级零代码改动，`go.sum` 净增两个 indirect（`go-text/typesetting` / `golang.org/x/image`，
  壳首次直接 import `ui` 包带出）。教训：立项时应把依赖特性核对进方案，不该留给实现期翻案。
- 新增 `popovers_test.go`：开关解析、摆位白名单、拆行（CRLF）、键盘导航（跳过禁用/分隔线、
  回绕）、五套色板齐全哨兵、矩形直通，以及 **`ui.NewTester` 无窗口真渲染**两例（菜单行 +
  键盘 Enter 回执、提示多行）。

**页面（ts/apps/server/web/）**

- `ui-atoms.js`：新增 `nativePopupsReady()`（启动探一次 `Shell.Capabilities` 缓存，模块加载即预热）
  与 `markNativePopupsBroken()`（调用失败粘性关原生，本会话全走 DOM）；无 `window.mygo` /
  老壳 / 开关 off 三种情形都落 false。
- `hover-tip.js`：`showHoverTip` / `hideHoverTip` 加原生分叉——有鼠标落点贴光标（零尺寸锚点）、
  键盘聚焦贴元素矩形，与 web 定位算法同口径；触发/收口时机（450ms、focus 守卫、scroll/resize/
  click 收）全部不变，不依赖 `el.hoverTip` 存在。
- `sec-menu.js`：`openMenuAt`（贴光标 bottom-start）与 `openSecMenu`（锚按钮矩形 bottom-end）
  两处咽喉加分叉，闭包留页面侧、桥上只过显示字段；aria-expanded 在原生路径也维护；
  兜底 = 原生调用 reject 时当次走 DOM 并粘性关原生。`context-menu.js` 零改动（它走
  `openMenuAt` 自动原生化）。

## 验了什么

- `go vet` / `go build` / `go test ./...` 全绿（既有 6 个测试文件 + 新增全部）。
- `node --check` 改动的四个 JS 全过；`pnpm typecheck` 两红在 `openai-compat-agent-chat.ts` /
  `routines.ts`——并行会话在途改动的文件，本批不碰 TS，无关。
- **真机 e2e**（验证壳连真实服务 + PowerShell 驱动鼠标 + 截图）：悬停出原生黑签（贴光标、
  320 折行、Win11 圆角）；右键输入框出原生菜单（无选中时「复制」正确置灰）；**点「粘贴」
  整链路闭环**（剪贴板文字真进了输入框、input 事件触发、输入框长高）；⋯ 菜单 bottom-end
  右缘对齐；`LIFEDIARY_NATIVE_POPOVERS=off` 时悬停/右键零 flyout 窗口（EnumWindows 验证）、
  DOM 旧路正常渲染。
- **真机踩出并修掉的两个坑**：① 背景画在 Column 上会露 Win11 系统底板 → 改画 `c.Root()`；
  ② flyout 开阴影时 Windows 阴影辅助窗在窗口下方露一条内衬 → 两个弹出层都 `Shadow: false`
  （v0.10.0 渲染怪癖，克隆 v0.10.0-30 亦无修复；框架修了再开回来）。

## 没验 / 不确定的

- 方向键 / Enter 的真机手感（逻辑已由无窗口测试覆盖）、Esc 关菜单、跨屏翻转——需日常使用观察。
- 非 Windows 平台未验（壳只在 Windows 出包）。
- lobe-mygo（组件库）本批未引入：设计语言与"纸感宋体"体系不一致，组件膨胀后再评估；
  skill-picker / plus-menu / 执行器模型下拉 / approval-pop 走同一条通道，列为批2 候选。
