# 2026-11-23 任务行悬停「一整条」：把行尾三点收进悬停块，并取消它自带的小浮块

## 用户口径

「鼠标放在任务上时，会有淡淡变亮的背景……不会包括右边的那三个点」；
「把这一整条做出来，应该包括右边的小三个点。包括之后，三个点也应该显示」；
「鼠标放在三个小点上时，那个浮起的块到底要不要显示？你看看吧」。

## 问题定位

代码里行底本来就是整行一层（`.chat:hover { background: var(--card) }`，行 10→222px），
怪的是别处：

| 现象 | 成因 |
|---|---|
| 悬停块看起来到 ⋯ 前就断了 | `.chat` 右内边距只有 6px，而行是 36px 高的胶囊（两端各 18px 圆弧）。⋯ 的 20px 命中区落在 196→216，右半截正好压进圆弧收窄的那一段，视觉上就「掉出」了块 |
| ⋯ 像一块「浮起来的小方块」 | `.chat-act:hover { background: var(--card-high) }` 自己画了一层底。行底一层 + 按钮一层，同一条被切成两截；指到点上时尤其明显 |
| 行悬停时 ⋯ 出现，但仍发灰 | 按钮平时 `color: var(--text-3)`，行悬停没有提亮它 |

## 改了什么

只动 `ts/apps/server/web/style-02-sidebar.css`，无 JS：

| 位置 | 改动 |
|---|---|
| `.chat` | `padding: 8px 6px 8px 12px` → `8px 12px`。右留 12px，⋯ 整个落进胶囊直边段 |
| `.chat-act` | 补 `cursor: pointer` |
| `.chat:hover .chat-act / :focus-within` | 新增：行悬停时 ⋯ 由 `text-3` 提亮到 `text-2` |
| `.chat:hover .chat-act:hover` | 删掉 `background: var(--card-high)`，只把颜色提到 `text` |
| `.chat-act:focus-visible` | 新增内描边（`outline-offset: -2px`）。去掉底之后键盘焦点不能丢位置 |

判断：**那个浮块不再显示**。整条悬停块本身就是「你在这条上」的状态，
⋯ 再叠一层小底等于在同一个状态里画两个块，还会卡在胶囊圆弧上把人带偏；
点它有没有反应由「颜色提亮 + 菜单弹出」交代，不靠一块底。

## 验证

- 本机 39847 拉真实页面（`http://127.0.0.1:39847/`，`Cache-Control: no-store`），实测几何：
  行 `10→222`、⋯ `190→210`、`padding: 8px 12px`；行底铺满整行，⋯ 距右端 12px。
- 截图核对：白 / 黑两套主题下，行悬停都是一整条胶囊，⋯ 落在块内；
  指到 ⋯ 上时行底仍是 `--card`、按钮底为透明，只有图标变深（`rgb(46,43,58)`）。
- 行为没变：行悬停 / 键盘 focus-within 时 ⋯ 照常出现；点 ⋯ 仍弹出「重命名 / 置顶 / 归档」。
- 本次纯 CSS，未跑 `pnpm typecheck`（无 TS 改动）。
