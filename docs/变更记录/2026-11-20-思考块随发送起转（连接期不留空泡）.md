# 2026-11-20 思考块随发送起转：连接期也不留空泡

> 纯前端。发消息那一刻就把「思考」灰块立起来转圈，真实思考到了继承同一枚块，
> 不再让助手气泡先空着（/ 只留一枚光标点）等人点。

## 为什么改

用户反馈：消息发出去、上游还没连上时，助手那一侧只有一个空泡/小圆点，
着急的人会以为没发出去而乱点。

这条等待期（`POST /agent/chat` 还没回、`start` / 第一个 `thinking` 帧还没到）
本来就是"在想"的一部分，只是过去没有任何可见表达：思考块要等第一个
`thinking` 事件才创建；如果模型不吐思考正文（思考关着 / 上游不流 reasoning），
等待期就完全没有反馈。

## 改了什么

- `ts/apps/server/web/composer-send.js`
  - `send()` 建好本轮 DOM 后、发请求前调用 `beginThink()`：助手气泡里立刻出现
    一枚运行中的「思考」灰块（连接上游也算在想）。
  - 新增 `thinkHasText`：只有真收到 `thinking` 正文才在 `endThink()` 里 `finish()`
    定格；一路没有正文的，进入正文 / 工具 / 收尾时 `drop()` 撤掉——
    思考关着的轮次不会在历史里多出一枚空的「思考」。
  - 真思考帧到来时 `beginThink()` 已存在块就返回，**继承同一枚**，不重复创建。
  - 新增 `insertAboveAnswer(card)`：思考块在发送时就撤掉了空 `.body`，
    审批 / attention / escalation 卡不能再假设 `body.isConnected`；
    脱链时退回插在整个 `.flow` 前面，避免卡片静默丢失。
- `ts/apps/server/web/tool-flow.js`：`think()` 句柄增加 `drop()`（撤掉这块占位）。
- `ts/apps/server/web/tool-chips.js`
  - `createChip` 把 `spec.kind` 落到 `data-kind`（CSS 只给思考块加转圈，工具块不变）。
  - 新增 `remove(id)`：撤块并从组里摘账；组空了把整条块行 `hidden`，
    正文前不留空行；`push()` 时把容器重新放出来。
- `ts/apps/server/web/style-06-tool-blocks.css`：思考块 `run` 态图标位换成
  1.5px 转圈环（`tchipSpin`，0.8s linear），跑完换回 sparkles；
  `prefers-reduced-motion` 下停转。

## 验证

- 浏览器（ego-browser，真页面 + 截获 `/agent/chat` 的假 SSE 流，隔离台，服务端真起在 39847）：
  - **连接挂起时**：`chatCalls=1`（请求未回）时 `.tchip[data-kind="think"]` 已在，
    文案「思考」、`data-state="run"`、`animationName=tchipSpin`、两帧 transform 不同
    （确实在转）、`.caret=false`、`.body` 为空。截图 `pending.png`。
  - **真思考到达**：`thinking` 两帧 → `delta` 两帧后仍只有 1 枚思考块（继承，不重复），
    `data-state="ok"`，正文「这是测试回答。」，点开详情「先想一想，再回答。」。截图 `after-think.png`/`detail-check.png`。
  - **无思考正文**：连接期仍有转圈块；`delta` 到达后该块数量为 0、空块行不可见
    （`offsetHeight=0`），正文「直接回答，没有思考。」。截图 `after-no-think.png`。
  - **审批帧先于正文**：带 `callId/tool/args` 的 approval 帧到达时，卡片可见且高度 >0
    （旧写法 `body.before(card)` 在空 body 脱链时会静默丢掉）。截图 `approval-before-text.png`。
- `node --check`（composer-send / tool-flow / tool-chips）通过。
- `npx tsx --test src/tool-chips-row.test.mjs src/web-imports.test.mjs` 7/7 通过。
- `pnpm typecheck` 通过。

## 刻意没做

- **没改群聊**：群聊有自己的 `正在思考…` 流式气泡（`groups-composer.js`），
  本轮只说单聊的助手气泡。
- **没改手机端**：移动端没有这枚思考灰块；本次只动桌面 web。
- **没改服务端事件时序**：`start` / `thinking` / `progress` 契约原样，前端只是把
  "还没连上"这段也用同一枚块表达。
- **没有给连接期换「连接中」文案**：用户口径是一开始就显示「思考」，
  并且真思考到了继承同一枚块；多造一个中间态会把一块拆成两块。
