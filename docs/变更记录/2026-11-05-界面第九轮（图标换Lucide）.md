# 2026-11-05 界面第九轮（图标系统重做：手画 SVG 全量换 Lucide 官方版）

用户第九轮需求（"ui 太丑了，找组件库或重画，设置图标非常差"）。总管派 CodeBuddy 一批（I1），交工后总管实机截图验收 + 补修一处。

## 1. 根因与方案

- 现状：37 处内联 SVG（index.html 25 + app.js 12）全是手画 16 视框随手坐标——设置=圆圈+八根短线假齿轮、加号/文件夹/星芒同类。
- CINDY 好看的底层原因：全部图标来自 **Lucide**（`lucide-react 0.468`，510 处引用）。
- 方案（零依赖）：Lucide 官方 path 数据**内联**进三件套（unpkg lucide-static 拉取比对），不装 npm 包、不引构建链，仓库"三文件刷新即见"架构不动。

## 2. I1 实施

- 37 处一一对应替换：settings/plus/clipboard-list/folder/users/message-circle-more/arrow-up/chevron-down/eye/eye-off/x/arrow-left/panel-left/menu/minus/square/copy/palette/message-square/bell/link/server/info/triangle-alert/file-text/chevron-right；设置导航由单 path 改为多图元 icon 字符串（Bell/Server 等拼不成单 path）。
- stroke 统一 2.0（24 视框官方默认）：照抄旧 1.4–1.8 在 24 框会压到 0.9–1.1px 偏细；2.0 折算后与旧视觉对齐，且把原先混杂的粗细统一了。CSS 尺寸规则零改动。
- 官方性核验：88 个图元与 lucide-static@0.468 官方 SVG「标签+属性」全等比对，85 完全一致；3 个例外均为刻意保留（.ctx-ring 两圆 + ico-stop 实心 fill 语义）。

## 3. 总管补修

- **ico-stop 尺寸**：官方 `square` 占视框 75%（旧手画只占 42.5%），14px 槽里会从 6px 涨到 10.5px——按 CINDY SendButton 规格（10×10 圆角 1.5）改为 rect 9×9@7.5,7.5 rx1.5，附注释说明为何偏离官方比例。

## 4. 实机验收（39847 截图）

- 首页：侧栏新对话/任务/文件夹/齿轮、composer 加号/发送/chevron 全部 Lucide 风格；水晶与上下文环未动。
- 设置页：调色盘/气泡/文件夹/铃铛/链环/服务器/双人/信息 八项导航图标成形，观感与 CINDY 同源。

## 5. 刻意不做 / 遗留

- 按钮不重画（用户"按钮其实还好"）；布局重排、颜色改动不做。
- 导出（纯文字钮）、搜索（原生 input）无 svg 载体，未新增图标（避免破坏一一对应）。
- 15px 小尺寸下齿轮与 message-circle-more 的三点偏密——用户若嫌弃，单独微调该两颗的 stroke 或尺寸。
