# 会话地图：收起分支 + 隐藏空/归档节点 + 卡片去文字

**日期**：2026-11-18。
**范围**：纯前端（`web/chat-map.js`、`web/style-26-chat-map.css`）；不碰契约与服务端。

## 问题（用户反馈）

1. 地图里还能看见已经删掉/归档的会话（幽灵「新分支」卡）。
2. 看不懂「新分支」是什么；希望它只在点新建后出现，空分支不占画板。
3. 副本需要收起按钮；展开 / 收起用 `+` / `−` 表示。
4. 卡片底下的「第一句测前缀」「进入」「分支」这些文字没必要；保留主体，能图形化就图形化。

## 改了什么

- **隐藏不该占画板的节点**（`buildModel`）：
  - 非根的 `archived` / `missing` / `turns` 为空的节点整支不画（连同后代）；
  - 因此已归档的老分支、刚建还没说话的空分支、已删来源的幽灵节点都不再出现；
  - 根节点即使归档/为空仍显示（空根走「这条会话还没有回合」空态）。
- **收起 / 展开副本**：
  - 每条非根分支的第一张问卡右上角有 `−`；收起后只留这张问卡，答卡与整条后代不画；
  - 收起后按钮变 `+`，头部加「已收起」小标；点 `+` 恢复；
  - 状态存 `localStorage: lifediary.chatmap.collapsed.v1`；打开某条会话的地图时自动展开它和祖先，
    否则「定位」找不到当前会话；顶栏「整理」同时清位置与收起状态。
  - 车道按可见节点重新分配，收起的后代不留空车道。
- **卡片去掉文字**：
  - 删除卡片底部整行（重复的会话标题、`进入`、`分支` 文字按钮）；
  - 答卡的「从这里另开一支」改成右上角小图标（悬停出现，`data-tip` 说明）；
  - 正文从 2 行放宽到 3 行（`-webkit-line-clamp: 3`），卡片高度不变；
  - 正文不再挂 `title` 悬停全文（黑签会盖住右上角图标；全文看详情抽屉）；
  - 双击卡片 / 详情抽屉仍可进入会话；详情抽屉的「进入会话 / 从这里分支」保留。
- **其它**：可见节点数参与顶栏提示的「N 轮 / M 条分支」，与画面一致。

## 验证

- `node --check web/chat-map.js` 通过；本次只改前端静态文件，无需 typecheck / 服务端重启（刷新页面生效）。
- 浏览器实测（本地 39847，真数据）：
  - 归档子分支 `084ee23d` 不再出现在地图；卡片底部标题与「进入 / 分支」文字消失；
  - 该归档老分支（0 条新回合，只有复制前缀）随后从归档页永久删除成功（归档页已放行 side），
    地图 / 归档清单 / 选择器三处都不再出现；
  - 用 `/branches` 建了一条一次性分支并给它发一句话 → 地图出现该分支（第一张问卡右上角 `−`）；
  - 点 `−` → 只剩问卡 + 「已收起」+ `+`；点 `+` → 答卡与分支恢复（4 张卡）；
  - 删除这条一次性分支后重载：地图只剩根会话两张卡，无幽灵、无空分支、无残留收起项。
  - 验收用的一次性分支已删除；用户指出的归档空分支 `084ee23d`（0 条新回合、只有复制前缀）也已从归档页清掉。

## 刻意不做

- 不在画板里新建分支：新建仍走答卡上的分支图标（`POST /branches`）。
- 不显示空分支占位卡：空分支只在选择器里出现，有了第一句话才进地图。
- 不改「一条会话一张地图」：地图仍是根 + 分支的家族视图。
