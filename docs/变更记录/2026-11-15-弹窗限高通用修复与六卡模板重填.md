# 2026-11-15 弹窗限高通用修复 + 六卡模板重填（区域领导式）

## 改了什么

### 一、弹窗展开顶出按钮——通用修复（style-13-projects-modal.css）

用户口径："展开一个就把底下的拉开，保存/取消顶出屏幕外，很多框都可能有这个问题。"

根因（老坑，modal-import 2026-11-15 注释里就写过）：`.modal` 是 grid 容器，`.modal-panel`
的 `max-height: calc(100% - 2rem)` 在 grid auto 行里**不解析**——内容一多面板就撑出视口，
底部按钮落在屏幕外。只有 modal-import 一家用了视口单位，其余弹窗全带病。

修复（两条，全站弹窗受益）：
- `.modal-panel` 限高改视口单位（`100vh/100dvh - 2rem`）——`.modal-body` 本就有
  `min-height:0 + overflow-y:auto`，面板限高后内容区自己滚；
- `.modal-actions` sticky 贴底（`bottom:0` + 面板色背景 + padding-top）——保存/取消永远可见，
  长内容从按钮底下穿过不透字。

### 二、六张模板重填（区域领导式，partner-templates.js PARTNER_TEMPLATES 整段重写）

用户口径：Grok 小镇的 bot prompt "说的都太细节了"——细节应该下沉为**派活时注入给打手的
提示词**（打手生命周期短，细则跟单走）；执事模板只要"区域领导"式的简洁定义。

参考素材：Grok 小镇 112 张卡的一句话定位（fiber 反查 `window bots` 数据）+ 登录后领取的
8 张完整 prompt（M01/G03/G11/L06/L19/L26/L24/L05，2026-11-15 用户登录后抓取）。**取其写法
（具体职责+节奏+边界），不抄其动作序列**。六卡新文案示例：

- 大管家：查整写盯 + "答应我的事，到点就报，没办完也要报一声进度"；契约验收"说做完了必须带证据"；
- 监工：自己不动手干重活，拆好派给工人、盯到验收，只回一行结论；工人卡住换思路或换人；
- 巡官：盯梢清单随时加，30 天内和 7 天内各提醒一次，之后每周跟一次；没变化不发"一切正常"；
- 日记官：每晚问三个问题（今天做了什么/有什么没做完/明天最要紧的是什么），原话一字不改归档，
  主人没答的日子记"今天没聊"不编；
- 书童：读书出笔记+按章节答问题；说明书/保修卡/发票存档，坏了答怎么修、保修到哪天、找谁；
- 知心：我随口提过的人和事她记下来，下次自然接着问。
