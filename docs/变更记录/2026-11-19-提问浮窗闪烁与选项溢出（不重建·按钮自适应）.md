# 2026-11-19 提问浮窗闪烁与选项溢出

用户口径：「右下角弹出的提问浮窗闪烁，超出行高会溢出」。
属于样式 / 单模块内修正，按 AGENTS.md 免写方案，直接改、这里交代。

## 闪烁的成因（代码级）

`approval-pop.js` 的全局待办轮询每 `APPROVAL_POP_POLL_MS`（5 秒）调一次
`refreshApprovalPopups()` → `renderApprovalPopups()`，而后者每次都：

1. `host.replaceChildren()` 把整叠卡拆掉重建；
2. 新节点继承 `.approval-pop` 的 `animation: hoverTipIn .15s ease-out`，而该动画是
   `from { opacity: 0 }`——**等于每 5 秒让所有卡从全透明淡入一次**，就是肉眼看到的闪；
3. 顺带把用户正在浮窗里打的草稿、光标、选区一起冲掉。

## 改了什么

**`ts/apps/server/web/approval-pop.js`**

- 新增内容指纹 `approvalPopFingerprint()`（callId / tool / kind / origin / deadlineAt /
  conversationId / args）。指纹与上一帧相同且已画过（`host.dataset.painted === "1"`）时
  **只走表针、不动 DOM**——不重建就既不闪也不丢草稿。
- 真要重画时：草稿按 callId 存进 `approvalPopDrafts`（textarea 的 `input` 事件写入，
  `bindApprovalPopDraft()` 挂回），焦点/选区由 `approvalPopFocusSnapshot()` 记录、
  `restoreApprovalPopFocus()` 复原；答复成功或点「忽略」时清掉该条草稿。
- 卡片加 `data-call-id`；上一帧已在的卡补 `is-static`，**只有真正新来的那张播入场动画**。
- 内层 `refreshApprovalPopups()` 的"runtime 已停"分支照旧清空，只是现在也走同一套重画路径。

**`ts/apps/server/web/style-06-tool-blocks.css`**

- `.approval-pop.is-static { animation: none; }`。
- `#approval-popups` 封顶 `max-height: calc(100vh - 32px)` + `overflow-y: auto`：屏幕矮或一次
  来三四张时整叠往上长会顶出可视区，现在封在视口内、需要时滚动。
- `.approval-actions .ghost`：`.ghost` 是固定 28px 高、`padding: 0 12px`，长选项折行后
  文字会顶出按钮边框（这就是"超出行高"那条）。提问卡的选项改成 `height: auto` +
  `min-height: 28px` + `line-height: 1.45` + `white-space: normal` + 左对齐 + 任意断词。
  规则挂在 `.approval-actions` 上，对话流里的同款提问卡一起受益；其它地方的 `.ghost` 不动。

## 追加（同日）：多待办收成一行

用户口径：「右下角只显示有 n 个问题等你就行了……如果有一个问题就直接展示，如果有多个问题再显示这个有 n 个问题等你，
然后点开是列表」。原来的上限是「同屏最多 3 张 + 余下一行计数」，现在改成：

| 待办数 | 浮窗形态 |
|---|---|
| 0 | 不显示 |
| 1 | 直接摊开那张卡（可选项即答、可写字答复，同旧行为） |
| ≥2 | 只留一行 `有 N 个问题等你 ▸`（全为 ask_user 才这么说，混有写操作审批则写「有 N 件事等你处理」）；点一行展开列表；列表每行 = 来源 + 问题摘要（两行截断），点一行就地摊成卡，卡头多一个 `‹ 列表（N）` |

实现要点（`approval-pop.js`）：

- 新增 `approvalPopExpanded` / `approvalPopActiveCallId` 两个 UI 态，并拼进内容指纹——
  点开、收起、切条目也会走同一条重画路径，不会和轮询打架。
- 摊开的那条若已答完 / 被忽略 / 服务端已决，下一次重画自动退回列表；待办掉到 1 件或清零时
  把展开态收起来，下一批新问题从折叠态开始。
- `APPROVAL_POP_MAX` 随之退役（声明、切片、"还有 N 条"分支、导出、`.approval-pop-more` 样式全删）。
- 样式新增 `.approval-pop-summary` / `.approval-pop-caret` / `.approval-pop-list` /
  `.approval-pop-item*` / `.approval-pop-back`，仍走 `is-static` 不重播淡入。
