# 全局工具池：设置 → 工具页（统一改）

**日期**：2026-11-17 当日方案落地。
**方案**：`docs/设计方案/2026-11-17-全局工具池（设置·工具页）.md`；结论已下沉
`接口-端点7-权限技能与开关.md` §2.22 / §2.22.1 与 `系统架构.md`（`tool-pool.ts` / `tool-index.ts`）。

## 背景

工具面缺一个统一界面：按需名单是代码常量，人设页只能给个人"提升"，想把某个工具
在全局从常驻改成按需只能改代码。用户要的是项目统一模式：**全局默认 + 按人覆盖，新人跟随全局**。

## 改了什么

- **新增 `src/tool-pool.ts`**：`.data/tool-pool.json`（`{deferred:[…]}`，按需例外名单；
  `AGENT_TOOL_POOL_PATH` 可换；缺失/坏 JSON 回落代码默认 8 个；空数组 = 全部常驻）。
  读写带 mtime+size 缓存、tmp+rename 原子写；记 `applied`（本次 Harness 装配用的名单）
  供 `restartPending` 判定；`sanitizeDeferredList` 校验（未知名 / 非字符串 / >64 400，
  **`tool_search` 禁入**）；`mountToolPoolRoutes` 挂 GET/PUT，catalog / 分组 / 摘要由 index.ts 注入。
- **`src/tool-index.ts`**：默认名单迁到 tool-pool；`isDeferredTool` / `markDeferred` 改读配置
  （可选 env 参数，测试可钉临时路径）；`markDeferred` 装配完记 applied。
- **`src/partner-tools.ts`**：apply 里判断"已加载的 deferred"改用注册对象的 `tool.deferred`
  （配置文件可能已改、Harness 未重开，读文件会口径漂移）；去掉 `isDeferredTool` import。
- **`src/index.ts`**：挂 `/api/v1/agent/tool-pool`（紧跟在 `/agent/tool-usage` 后）。
- **前端**：新增 `web/settings-tools.js`（`toolPoolMarkup` / `wireToolPool`），
  侧栏「上下文」后加「工具」分区（`settings-base.js`），`settings-router.js` 加分支；
  表格复用 `.use-*` 样式，只加 `style-25-tools.css`（两条小样式 + style.css import）。
  页面列：工具 / 分组 / 摘要 / 定义 token / 用量（用过·搜出）/ 池切换；标题右侧「恢复默认 / 保存」；
  `restartPending` 时常显「已保存，待重启生效」。
- **测试**：新增 `src/tool-pool.test.ts`（默认回落 / 往返 / 坏配置 / 校验与 tool_search 守卫 /
  restartPending / applied / 端点）；`tool-index.test.ts` 钉临时路径并补"配置驱动 markDeferred"；
  登记进 package.json 测试清单。

## 版式调整（2026-11-17 用户反馈）

- 解释性文字收进「工具池」标题与表头的悬停（`data-tip`），页面上不再常驻；
- 每行可点开，展开**完整工具定义**：说明原文（接口补 `description`）+ 参数 JSON Schema（接口补 `parameters`）；小箭头 + 引用块，展开状态重画后保持；
- **去掉这一页的分组标签**（硬编码 `toolGroupOf` 映射不再用于本页；接口也不再回 `group`，分组仍只服务人设页勾选目录）；
- 「定义 / 用量 / 池」三列居中；页脚只留「共 N 个工具，按需 M 个」。

## 行为与边界

- 全局改完**必须重启服务**才生效（`deferred` 是工具注册期属性，只在 `openHarness` 里打）。
  页面只写文件并提示，不自动重开 Harness（重开会中断正在跑的轮次）。
- **按人只能提升**（写 `modelTools.add`，下一轮生效）；按人降级内核做不到，
  人设页的"取消勾选"（= 不可用）是唯一替代。新人 `promotedTools` 为空 → 跟随全局。
- `tool_search` 不允许进按需名单（否则所有按需工具永久不可达）。
- `AGENT_TOOL_INDEX=false`（`AGENT_TOOL_INDEX` 回滚关）：GET 仍可读但标 `enabled:false`，PUT 400。

## 刻意不做

- 页面内重启按钮 / 自动重开 Harness（用户拍板）。
- 按人降级（内核限制，理由见方案）。
- worker 工具面（`worker-tools.json` 已有自己的开关，语义不同）。
- 不动工具描述 / 注册顺序 / 内核。
