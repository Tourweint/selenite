# 2026-11-04 — 透石膏图标接入（托盘 / EXE / favicon）

## 改了什么

把占位图标换成正式的透石膏（selenite）晶体图标，覆盖三个位置：

- **托盘图标**：`desktop/main.go` 里 `trayIcon()` 原来是代码画的 32×32 蓝圆（占位），
  改成 `//go:embed assets/icon-tray.png`（64×64 透明底）。顺带删掉了不再使用的
  `bytes` / `image` / `image/color` / `image/png` import。
- **EXE 资源图标**：`desktop/assets/icon.ico`（16/32/48/64/128/256 多尺寸）经
  `rsrc` 生成 `desktop/rsrc.syso`，编译时自动链进 `lifediary-shell.exe`，
  资源管理器 / 任务栏 / Alt-Tab 都用这枚图标。
- **Web favicon**：`ts/apps/server/web/favicon.png`（48×48），`index.html` 加
  `<link rel="icon" href="/assets/favicon.png">`。

## 为什么动了 web.ts

`/assets/:file` 原来只允许文本 MIME（`.html/.js/.css/.svg`），且用 `readFile(..., "utf8")`
读——PNG 是二进制，utf8 解码会坏。所以：

- `CONTENT_TYPES` 加 `".png": "image/png"`；
- 路由改成 `readFile(url)` 不带 encoding，统一按字节发（文本资源发原始 UTF-8
  字节，浏览器按 content-type 解析，无行为变化）。

## 资源来源

源图是 2048×2048 白底 PNG（用户定稿）。处理脚本：从四角 flood-fill 把近白背景
抠成透明，按晶体 bbox 居中、四周留 8% padding，再 LANCZOS 缩到各尺寸。

## 文件清单

- 新增：`desktop/assets/icon.png`（512 主图存档）、`icon-tray.png`（64）、`icon.ico`（多尺寸）
- 新增：`desktop/rsrc.syso`（编译产物，随 exe 一起走）
- 新增：`ts/apps/server/web/favicon.png`（48）
- 修改：`desktop/main.go`、`ts/apps/server/web/index.html`、`ts/apps/server/src/web.ts`

## 验证

- `go vet` / `go build -ldflags="-H windowsgui"` 通过；exe 从 13.57 MB → 13.64 MB
  （图标资源 ~65 KB）；用 `ExtractAssociatedIcon` 从 exe 里提出 32×32 图标，肉眼
  确认是透石膏晶体，不是默认 Go 图标。
- `pnpm typecheck` 通过。
- 起 Hono 单测：`GET /` 200 text/html、`GET /assets/favicon.png` 200 image/png 2892 B
  （与磁盘字节数一致，二进制没坏）、`GET /assets/style.css` 200 text/css 60925 B。

## 没做的

- 没改窗口标题栏里的 brand 文案（已经是 Selenite）。
- 没做安装器图标 / 开始菜单快捷方式图标——这两个走 exe 资源自动生效，不需要
  单独文件。

## 二次定稿（同日）

第一版直接用了抠底后的晶体，浅色背景下对比度偏低。做了描边版（晶体轮廓外
扩 6px `#222226` 深色细描边），用户试过后认为暗色底板版效果不好，最终**全
部位置统一用描边版**：

- `assets/icon-tray.png`（托盘 64×64）
- `web/favicon.png`（浏览器标签页 48×48）
- `assets/icon.ico`（16/32/48/64/128/256 全尺寸，EXE 资源）

rsrc.syso 与 lifediary-shell.exe 已用描边版图标重编译。从 exe 提取 32×32 资源
确认是描边版晶体。
