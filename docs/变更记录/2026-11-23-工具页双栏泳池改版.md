# 2026-11-23 设置 → 工具页改双栏泳池（方案 A）

## 用户口径

- 工具页用表格 + 行尾小胶囊不够美观，而且「它在哪个池子里」看不出来：到底是按需池（工具索引），
  还是常驻池，需要一眼能判断。
- 三个预览方案（双栏泳池 / 分组清单 + 预算条 / 池标签页）里用户选定 **A 双栏泳池**。

## 改了什么

| 文件 | 改动 |
|---|---|
| `web/settings-tools.js` | 版式重写为两栏泳池：左常驻、右按需；栏头报个数与该池 token（`N token / 轮` / `工具索引 N token`）；卡片带名字、定义大小、用量与「移到按需 / 移到常驻」；点卡片展开说明原文与参数 JSON；`tool_search` 不给移动动作（显示「加载入口」，服务端本来也会 400） |
| 同上 | 索引段 token 由前端按服务端同一口径估算（`tool-index.ts` 的文本 + payload 里的 summary + CJK 1/字、其它 1/4 字符），只用于栏头展示，不改注入 |
| 同上 | 修复「恢复默认」：旧标记把 `disabled` 写死在按钮上，`syncDirty()` 里拿了元素却从没启用过，按钮一直是死的。现在 `state.enabled` 即可用；提示里的「8 个」改成实际的 9 个 |
| `web/style-25-tools.css` | 删掉表格版样式，换成双栏 / 栏头 / 卡片 / 详情样式；窄窗（≤900px）收成一栏；不做 sticky 栏头（设置页是壁纸上的半透明纸，sticky 的不透明底会压出一条色带） |
| `docs/基线文档/系统架构.md`、`docs/基线文档/接口-端点7-权限技能与开关.md` | `DEFAULT_DEFERRED_TOOL_NAMES` / `defaults` 的「代码默认 8 个」改成 9 个（现状漂移，迁移 save_reminder_advice 时漏改） |
| `src/tool-pool.ts`、`src/tool-index.ts` | 同上，两处注释的「默认 8 个」改成 9 个（纯注释） |

契约、后端、存储结构一律没动；保存仍然只写 `.data/tool-pool.json`，仍需重启服务生效。

## 验证

- `node --check web/settings-tools.js` 通过；`web/` 不在 tsconfig 范围内，本批无 TS 逻辑改动。
- 真页面（本机 39847，`#/settings/tools`，IAB）核对：
  - 两栏 25 张卡；栏头 `常驻池 16 · 5,141 token / 轮`、`按需池 9 · 工具索引 438 token`（438 与服务端索引口径一致）；
  - 点 `read` 的「移到按需」→ 15 / 10、`4,979 token / 轮`、`工具索引 461 token`，「有改动」出现、保存可点；
  - 点「恢复默认」→ 回到 16 / 9、`5,141` / `438`，有改动消失、保存退回禁用；
  - 点开 `write`：`aria-expanded=true`，出现「说明原文」与「参数（JSON Schema）」；再点收起；
  - `tool_search` 卡片显示「加载入口」，没有移动按钮；
  - 视口 860px：两栏收成一栏；切 indigo 主题看了一遍，栏头成本色从 `--text-3` 提到 `--text-2`（壁纸底上更可读）。
- **没点保存**：避免写真实 `.data/tool-pool.json`；PUT 处理逻辑本批未改，未重测。

## 没做 / 边界

- 不搜索、不排序、不按用途分组（方案 A 没有这些；要加另立）。
- 不做 sticky 栏头（理由见上）。
- 索引 token 是前端展示估算，不参与任何注入或保存；真实注入仍由服务端 `tool-index.ts` 决定。
- 保存后待重启提示、按人提升/取消勾选、`tool_search` 自锁语义全部沿用原口径。
