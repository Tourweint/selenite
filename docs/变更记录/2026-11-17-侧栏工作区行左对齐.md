# 侧栏展开态「工作区」行改左对齐

**日期**：2026-11-17。
**范围**：纯样式，一行规则；不碰契约、不碰 JS 结构。

## 问题

展开侧栏的项目区里，「工作区」那一行的名字看起来是居中的，而下面每个项目行
都是左对齐（2026-11-17 用户指出）。

## 缘由

工作区行是 `<button>`（点它 = 回默认对话落点），项目行是 `<div>`。
浏览器给 `<button>` 的 UA 默认样式带 `text-align: center`；`.side-item-label`
是 `flex: 1` 的块，文字对齐跟着继承下来，于是名字在本行剩余宽度里居中。
同一套 `.side-item` 里，`.sec-menu-item` / `.sec-foot-link` / `.proj-item`
都显式写了 `text-align: left`，只有 `.side-item` 漏了。

## 改了什么

- **`web/style-02-sidebar.css`**：`.side-item` 补 `text-align: left`，
  兜住所有「行是 button」的侧栏行（工作区行、无工作区时的「设置工作区根目录」行、
  接口不可用的重试行）。

## 验证

- 服务直发 `web/`，`curl /assets/style-02-sidebar.css` 已看到新规则（无需重启，刷新页面生效）。
- 样式改动无需 typecheck；未跑浏览器截图。

## 刻意不做

- 不加 `!important`、不逐行覆盖：根因在共用类，修一处比给每行打补丁可靠。
