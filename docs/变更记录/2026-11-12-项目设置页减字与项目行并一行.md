# 项目设置页：说明收进悬停、项目卡信息并一行

日期：2026-11-12
状态：已落地（纯 web 前端，零契约、零服务端改动）

## 起因

用户口径（2026-11-12，桌面端设置 → 项目）：

1. 主项目（工作区根目录）解释性文字太多；解释应放标题悬停里，只有必须当面说的才常驻。
2. 子项目名字显示两遍；名字、路径、有没有版本控制最好并成一行。
3. 绿色小圆点圈着「在」、左侧小绿点都没必要。
4. 待确认的请求不用改；空态时解释文字放前头没问题。

## 改了什么

- **`web/app.js`**
  - `renderWorkspaceCard`：删掉标题下的常驻说明；两段解释（作用范围 + 更换根目录会清空
    当前项目选择 + 拒绝盘符根/主目录/系统目录）合并进标题 `data-tip`（悬停 450ms 出，
    同其他设置页）。底部提示行改为默认 `hidden`，只在两种时候出现：编辑根目录时提示
    「更换根目录会清空当前项目选择（回到主工作区）」；保存失败时显示错误。
  - `projectCardMarkup`：去掉左侧 `status-dot` 和「在」标签；名字、相对路径、版本控制
    并进同一行（`·` 分隔）。相对路径与项目名相同（忽略大小写/斜杠）或就是工作区根时
    不再重复显示路径。异常标签保留：目录丢失（黄）、工作区外、已归档。
- **`web/style.css`**：`.proj-card` 改单行居中；新增 `.proj-card-line` / `.proj-card-vcs`，
  路径单行省略；删掉 `.proj-card .status-dot` 与卡片内多行间距规则。`.status-dot` 本身保留
  （服务页、侧栏仍在用）。`.proj-card-path` 基础样式保留原换行行为，待确认请求卡不受影响。

## 刻意没做

- 待确认的请求空态与有内容时的文案、按钮都没动（用户明确说不用改）。
- 没把「子项目」节标题与卡内「已登记的项目」合并——本轮只处理用户点名的重复与噪声。
- 没动「添加子项目」弹层、别名/归档/删除流程。
