# native 执行器模型口径修正

**日期**：2026-11-16
**范围**：ts/apps/server（executor-config.ts / executor-probe.ts / web/settings-executor.js / executor-config.test.ts），纯文案与注释，零行为改动。

## 改了什么

设置→派活的 native（本机内核）卡片原来写「模型由设置 → 模型的主选决定」，**这句不实**（2026-11-16 核实）：

- native worker 子进程（chancellor `worker-main.ts`）只读启动 env：`CHANCELLOR_LLM_MODEL` → `LLM_MODEL` → 默认 `deepseek-v4.1-flash`（百炼 OpenAI 兼容端点）；
- 设置→模型切主选写的是 `.data/runtime.json`，只影响主对话与内部质检（拆单/验收，`internal-model.ts`），**不影响 native worker**。

修正共 7 处：`EXECUTOR_KIND_INFO` 的 modelHint/note、`executorForDelegation` 注释、probe 两处提示、web 卡 tip 与保存注释、测试用例名。全部改为如实口径：「模型由启动 env 决定（默认 deepseek-v4.1-flash），设置→模型的主选不影响它」。

## 为什么只改文案不改行为

让 native 真正可调（走 `EmployeeProfile.model` + spawn env 覆盖）与"人设共享"是同一批产品问题，已立项 `docs/设计方案/2026-11-16-通用worker配置统一.md`，批 1 落地。先修口径避免界面继续说谎。
