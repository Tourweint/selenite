# 2026-11-23 上下文页收口：工具栏靠左、会话框缩短、请求卡去掉提示

## 用户口径

1. 上下文页的会话选择框太长，左右留白太大；
2. 「当前会话 / 默认开销」与「占比 / 窗口」一个在框左边、一个在框右边，不好看，放到一边；
3. 底下「请求与缓存」的提示不要，像「发现一次命中率骤降」那种红光提示也不要；
4. 上边的 prompt / 命中 / 输出不用介绍，把「前缀变化」「骤降」「完全未命中」放到上面，
   和「多少次请求 · 第几页」放在一起。

（原话里「选择绘画」指「选择会话」，「周降四次」指「骤降 4 次」。）

## 改了什么

| 文件 | 改动 |
|---|---|
| `web/settings-context.js` | 工具栏顺序改为 `当前会话/默认开销` → `占比/窗口` → 会话/角色下拉 → 刷新；`ctx-scale` 从行尾挪到模式开关右侧；删掉卡头 `<b>请求与缓存</b>`、`ctx-cache-summary` 与 `ctx-cache-alarm`；卡头只留一行账（请求数 / 页码 / 前缀变化 / 骤降 / 完全未命中）+ 右侧命中率 |
| `web/style-24-context.css` | `.ctx-select` 从 `flex:1 1 240px / max 320px` 收到固定 200px、左对齐；新增 `.ctx-cache-meta` / `.ctx-cache-sep`（点数用 7px 间距串成一行）；删掉 `.ctx-cache-copy` / `.ctx-cache-sub` / `.ctx-cache-summary` / `.ctx-cache-alarm` 整套样式；前缀变化与骤降的强调从 danger 红改为 warning 琥珀 |

## 保留

- 右侧大号「命中率」仍在（用户没要求去掉，和「命中次数」不是一回事）。
- 请求行尾的 `↑ / ! / · / C` 小标记保留：点开单条仍能看出前缀为什么变，且只占一个字符，不构成提示条。
