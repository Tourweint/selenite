# 2026-11-07 对话右上角快捷设置（模型切换 + 一行一个批量加模型）

## 需求

用户原话：每个对话的右上角都应该有设置入口，可以就地调一些东西（仿 cindy，比如选模型）；另外"现在不能一行填一个模型，还是得自己去挑"——要能按行批量填模型。

## 判定

免写方案类（AGENTS.md）：UI 重排 + 复用既有端点，不动契约、不动存储、无新 env。

## 做了什么

1. **对话顶栏右上角齿轮**（`#chat-settings-btn` + `#chat-settings-menu`）：每个对话（非首页）顶栏右侧常驻，下弹面板（复用 composer-pop 弹层语言，方向改为向下落，入场动画反向）。
   - **上半：模型切换** —— 复用 composer 模型菜单的同一份渲染（`renderModelMenu` 泛化出容器参数）与同一套逻辑（`chooseModel` / 思考档分段），数据源同为 `GET /api/v1/agent/model`，每次打开现拉。供应商分段点击会 dispatch `providerchange` 事件，面板用来同步批量区的「加到：某家」标签。
   - **下半：一行一个模型批量添加** —— textarea 逐行填/粘贴模型 ID，加到模型区当前选中的供应商。**不走新端点**：先 `GET /api/v1/agent/providers` 拿全量记录（模型菜单的投影不含 baseUrl/keyEnv/元数据，回写必须原样带上），把新 id 合并进既有清单后走既有 `POST /api/v1/agent/providers` 回写，既有模型的元数据/思考档原样保留，不删任何模型（避开 `selected_model_missing`）。
2. **校验口径**（批量区）：超长行（>200 字符，同服务端上限）→ **整批拦下**并逐行报行号，不静默丢弃；空行忽略；同次输入重复行只取一个；与清单重复的模型跳过并在结果里明说；成功提示 N 个已加入、下一轮生效。

## 刻意没有

- 批量区只加不改不删：编辑/删除模型、上下文/思考档配置仍在设置 → 服务的供应商表单里（那里有检测和逐模型弹窗）。
- 不做「每个对话独立的模型」：切模型仍是全局默认（下一轮生效），既有语义不变——本需求的"每个对话右上角"指**入口位置**，不是会话粒度的配置。
- 新建供应商仍走设置页：面板里没有供应商时批量区提示去设置 → 服务添加。

## 验证（2026-11-07 浏览器实测，本机 39847 实例）

- 齿轮只在对话视图出现（首页 `.top` 隐藏，符合"每个对话"口径）；点开现拉目录，供应商分段/模型行/思考档分段与 composer 菜单一致。
