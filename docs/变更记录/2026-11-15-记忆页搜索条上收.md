# 记忆页搜索条上收

## 改了什么

设置→记忆页（A 版）搜索条与上方内容的间距收近：

- `.mem-a-people`（一排人）`margin: 0 0 14px` → `margin: 0`
- `.mem-a-toolbar`（搜索条）`margin: 20px 0 10px` → `margin: 0 0 10px`

两者与上方分类片之间的间距交给 `.set-sec` 区块自带的 14px flex gap，不再叠加自己的边距。

## 为什么

用户反馈搜索记忆与上面的分类隔得有点远。根因是 flex 容器 gap 14px 之上又叠了
people 的 14px 下边距 + toolbar 的 20px 上边距（flex 里边距不塌缩），实际空隙 48px，
是区块统一节奏的三倍多。

改后一排人→搜索条实测 14px（与区块其他间隔一致）；搜索条→分组列表 24px 不变。

## 验了什么

纯 CSS（style-21-answer-memory.css），无 TS 改动。浏览器实测（127.0.0.1:39847/#/settings/memory）
getBoundingClientRect 复核：people_to_search 14 / search_to_groups 24 / overview_to_people 33（卡内边距，未动），
截图目测搜索条不再悬空。
