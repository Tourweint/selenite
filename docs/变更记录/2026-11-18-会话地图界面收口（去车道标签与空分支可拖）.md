# 会话地图界面收口（去车道标签、顶栏副行、空分支可拖）

**日期**：2026-11-18。
**范围**：纯前端（`web/index.html`、`web/chat-map.js`、`web/style-26-chat-map.css`）；不碰契约、不碰服务端。

## 问题（2026-11-18 用户反馈四条）

1. 地图里的「空分支」卡看不懂是什么；分叉出来的两个分支不知道为什么存在；虚线卡还拖不动。
2. 地图上的胶囊型小提示词句（车道标签）多余，页面留卡片就行。
3. 顶栏的 `MAP` 三个字多余。
4. 标题下的会话副行（`标题 · N 轮 · M 条分支`）不该常驻，改成鼠标停在地图上时由黑底悬浮小签显示。

## 改了什么

- **去掉车道标签**：删 `renderLaneLabels` / `.map-lane-label` 样式与相关选中态同步。
  车道仍然按深度优先分配（`assignLanes`），只是不再在车道起点画胶囊；卡片脚注本身带会话标题。
- **顶栏收口**：删 `MAP` 徽标与 `.map-sub` 常驻副行；`#map-title` 仍为「会话地图」。
  副行文字（标题 · 轮数 · 分支数 · 截断标记）改写到 `#map-viewport` 的 `data-tip`，
  悬停画布时走全局黑底小签（与站内其它 `data-tip` 同一套）。
- **新分支占位卡**（原「空分支」）：
  - 文案改名 `新分支`，正文说清「分叉出来的新会话，还没有新消息。点开说第一句。」
  - 卡片 `data-tip` 解释来源：分叉点之前的对话已复制过来，之后还没有新回合。
  - 脚注从重复标题改成「分叉自第 N 轮 · 母会话标题」。
  - **可拖动**：占位卡不再在 `pointerdown` 时直接跳会话，改为和普通卡一样拖动并保存位置；
    未拖动（指针位移 < 4px）才进会话。
- **操作按钮补提示**：答卡「分支」的 `data-tip` 说明「从这条回答另开一支：新会话带走这之前的对话」；
  「进入」也补 `data-tip`。

## 验证

- `node --check web/chat-map.js` 通过。
- 浏览器实测（本地 39847，真数据）：
  - 地图顶栏只剩「会话地图」，`MAP` 与副行消失；画布上无车道胶囊。
  - 鼠标停在画布空白处，黑底小签显示「第一句测前缀 · 1 轮 · 2 条分支」。
  - 新分支卡拖动后 `style.transform` 变化并写入 localStorage；不拖动点击仍进入该分支会话（标题回读为「小记 · 第一句测前缀」）。
  - 普通问/答卡拖动与连线刷新不受影响。
- 未跑 `pnpm typecheck`：本次只改 `web/` 静态 JS/HTML/CSS，不在 TS 编译范围。

## 刻意不做

- 不隐藏「空分支」这个数据结构：它仍是一条真实会话的入口，只是改叫「新分支」并把含义写在卡上。
- 不改分叉动作的流程（仍是点「分支」立即建副本并跳进去）；只是把按钮说明补到悬停里。
- 不把会话副行搬到别处常驻：按用户口径只留悬停提示。
