# 2026-11-21 全局默认思考档与新会话继承

**改了什么**

思考档新增"全局默认"一层，新会话不再默认落 off。用户报障「右下角思考明明开着，新会话发『你好』
跑的却是 `#think-off`」，真实库（conversation 3442）+ 代码定位出**两处脱节**：

1. **全局层根本没有思考档字段**——思考档一直是会话级（会话模型引用的 `#think-<档>` 后缀 +
   进程内粘性表），全局换模型端点只存裸 modelId；
2. **新会话首轮的档位只在屏选模型时才随 start 带上**（`composer-send.js` 的
   `model.thinking` 挂在 `state.pendingModel` 分支里）——不选模型直接发，档位整个丢失，
   `ensureConversationModel` 兜底到 off。

**修法（契约先行）**：

1. **shared `ChatRequestSchema` 加顶层可选 `thinking`**（快照测试同步更新——契约变更显形）：
   新会话档位优先级 = 顶层 `thinking`（composer 拨盘）> `model.thinking`（屏选模型带的档）>
   **全局默认思考档** > off；已有会话忽略（改档走 `/mode`）。
2. **provider.ts**：`runtime.json` 加 `thinking` 字段（与运行时模型选择同文件、同缓存纪律）；
   `runtimeThinking()`（读，null = 没设过）与 `setRuntimeThinking()`（写，按当前全局模型支持域
   clamp off 兜底，`MODEL_RUNTIME_OVERRIDE=false` 与 faux 同门拒绝）；换模型时档位原值保留、
   消费方按新模型支持域再 clamp。
3. **session-open.ts**：`ensureConversationModel` 与 `sessionModelInfo` 的兜底链统一插入全局层——
   **会话引用后缀 > 进程内粘性 > 全局默认档 > off**（显示与建档同一条链，pill 显示的档不再
   与第一轮实际跑的档脱节）。
4. **index.ts**：GET `/agent/model`（无 chat 的全局投影）带 `thinking` + `thinkingLevels`；
   POST `/agent/model` 收可选 `thinking`（只带 thinking = 只改档不换模型；带模型则换完再设档）；
   `/chat` 创建按上面的优先级落 initialModel（只带 thinking 没带 model 也按全局模型建档）。
5. **web**：设置页默认模型卡加「思考强度 · 新会话默认」分段行（按全局模型支持域画，
   点一档只改档不换模型，服务端 clamp 后按回值标选中）；composer 新会话 start 始终带顶层
   `thinking`，但**只在拨盘被用户真碰过时**（`lifediary.thinkingTouched`，旧 mode 迁移也算碰过）
   ——缺省 off 不冒充用户的选择，没碰过就让服务端全局档说话。
6. **接口文档**：`接口-端点3` 的 GET/POST /agent/model 与「新建会话带初始模型」段已回写
   （全局档字段、只改档用法、档位优先级、兜底链）。

**为什么**：用户口径——三层兜底（会话档位 / 进程内粘性 / 默认关）保留，但"新建会话模型继承了
全局默认，思考档位没有夺取到"；要在设置里能设全局默认档，新会话读取它，没设过才落 off。
附带的 composer 侧发现一并修：拨盘档位只在屏选模型时随 start 下发是同族脱节。

**验证**（2026-11-21）：`pnpm typecheck` 绿；全套 **1253/1253** 绿——契约快照按新字段更新
（`thinking` 进 ChatRequestSchema 形状，显形留痕）；transcript-page 一条按新 steps 口径的更新
（上一批）；provider.test 补一条 faux 门 parity 测试。**真机验收悬挂**：全局档写入/继承与
设置卡控件需要真实供应商（faux 下该端点按设计拒绝），等服务重启后在真机上点一遍
（设置→默认模型卡设档 → 新建对话 → 首轮 meta 看 `#think-<档>`）。

**回滚**：shared 的 `thinking` 字段为纯增量可保留；行为回滚 = revert 本批（runtime.json 里多出的
thinking 字段被旧代码忽略，无迁移负担）。

**明确不做**：`MODEL_RUNTIME_PATH` 之外的第二落点；全局档按"每供应商"分别记（跟随当前选择整档）；
手机端档位 UI（手机不消费 steps/thinking 选择）；composer 思考强度控件换滑动块——**另批进行中**
（对比页已出，用户挑选后落地）。
