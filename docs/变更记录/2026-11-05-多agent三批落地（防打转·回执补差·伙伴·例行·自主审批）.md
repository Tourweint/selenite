## 做了什么

**批次A（通用加固）**
- A1 防打转守卫：`loop-guard.ts` 纯类（阈值照 cindy：30 连同指纹 / 同指纹 60min / 读窗 128 内 distinct≤32 且重复≥4 → 铁证拦；4 连 / 12 窗 distinct≤2 / 16 窗 distinct≤4 → 疑似告警只进日志），挂 `beforeTool`/`afterTool`，只统计顶层调用，≥30s 节奏轮询豁免；`TOOL_LOOP_GUARD=false` 回滚。
- A2 回执补差：`delegations.sqlite` 加 `boot_id` 列（跨进程的 accepting 一律 uncertain，不自动重派）+ `delegation_dead_letters` 死信表（父单 aborted/终态后迟到子单记账；启动恢复扫描，`GET /api/v1/tickets/:id` 只读投影 `deadLetters`）。

**批次B（伙伴最小可用，`COMPANIONS_ENABLED`）**
- B1 记忆隔离：`MemoryScope` 加 `partner` 型（`partner:<uuid>`），extract 的私有 scopeToKey 复制版收口成单处。
- B2 伙伴：`partners.sqlite`（档案/版本快照/会话链接/routine 定义四表）+ `partner-homes/<uuid>/` 家目录（SOUL.md 双层：磁盘=当前值、版本行=冻结快照，改完下一轮生效；64KB 槽位；原子写；播种幂等 SOUL 最后写）+ `companion-api`（CRUD/跑一轮）+ `partner_skill_write` 工具（进 `WRITE_TOOLS`）。**伙伴 = 普通会话 + 版本冻结身份提示词，没有第二套权限系统**（闸门/审批/pathGuard 指向 workspace/ 原样生效）。
- B3 例行任务引擎：`routines.ts` 纯逻辑内核（24h 回执去重 / 单规则串行 lane / deferred 30s / 终态落盘失败只排队不执行 / 重启 running→interrupted 不重放）+ **触发层是 durable `RoutineTask`（sleepUntil 落库），不是扫描循环**（守住"定时扫描型 cron 刻意没有"口径）；revision 作废机制替代"取消任务"；事件触发走新增的全局事件口（`watchAllEvents`/`watchAllDelegationEvents`），伙伴自己会话的事件不触发（防自环）。
- B4 模型候选链：`model-chain.ts`（unanswered 原因归类 + 只切用户配的链、跨供应商所以 429/配额可切、aborted/上下文/参数不切）+ runPartnerTurn 的 unanswered 重跑 + PATCH 端点（keyEnv 只存名，值形状 400）。

**批次C（主动性，`AUTONOMY_ENABLED` 默认关，关 = 零行为）**
- C1 观察层：`autonomy.ts` 订阅全局事件口 + 轮次结算 + 审批 pending，五类事件（stuck/waiting/errored/usage-limit/sweep；**没有 finished**——本仓无"模型报交付"机制）；防风暴账本 `autonomy-core.ts`（事件 id 带状态锚跨重启稳定 + 24h 6 次上限 + sweep 2h 桶）；提醒=写会话行（`【需要你】…` ≤140 字枚举化，不经模型）；伙伴会话一律不是观察对象（防自叫醒）；sweep 定时器按需启停。
- C2 自主轮高危审批：`autonomyTurns` 进程内 Set 为事实源（`autonomy-state.ts`），beforeTool 对自主轮的 RISK_TOOLS（set_reminder/delegate/propose_project/write/edit/bash/powershell/partner_skill_write）**强制 ask 且禁"记住"**；审批记录/事件/对外帧带 `origin:"autonomous"`（纯增量）。普通轮行为完全不变。

## 没验什么（如实登记）

- 定时链的"跨重启醒来"（RoutineTask sleepUntil）没在探针里跨进程验——revision 作废与状态机有单测，跨重启语义依赖 durable 自身的睡眠落库（reminder 同款范式）。
- 自主轮强制审批的端到端（例行轮里写工具弹卡 → 手机批）没起服务验：C2 判定有单测，端到端留给 `AUTONOMY_ENABLED=true` 的手机联调。
- 候选链重试的真实切换没跑（faux 只有一个模型）：纯函数 4 条单测覆盖判定，真切换要两家供应商的探针。
