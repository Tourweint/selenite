# 2026-11-03 首页顶栏、设置入口与浮层

## 改了什么

- 首页重新对齐 cindy：顶部左上角常驻「侧栏开关 + 功能菜单」，菜单里的「设置」
  走独立 hash 路由 `#/settings`，不是弹层。
- 首页恢复「问候 + 大输入框」层级，输入框从 660×64 调到 820×128（桌面端）。
- 主对话区改为浮在侧栏之上的圆角卡片：四周留 8px 背景、圆角 28px、柔和投影；
  侧栏 `z-index` 在下，主区在上。
- 侧栏收起动画沿用「定宽内容 + 原地淡出」：开 360ms 减速曲线，关 250ms 加速曲线，
  不收窄内层，避免文字重排（对齐 deepseek-harness 的做法）。
- 圆角与投影取值参考手机端 `lifediary` 的首页卡片观感（28dp 圆角 + 软阴影）。

## 为什么

用户明确要求首页向 cindy 对齐、恢复顶部侧栏按钮、设置进独立页面、放大输入区；
随后追加要求侧栏动画与「侧栏在下、对话在上」的浮层关系。
本次显式覆盖了《2026-11-03-界面第二轮》里「首页只留一个输入框」的旧决定。

## 验证

- `node --check ts/apps/server/web/app.js`
- `pnpm typecheck`（`ts/` 下，通过）
- 起服务 `PORT=8099 pnpm --filter @lifediary/server start`，用浏览器实测：
  顶部按钮、菜单进 `#/settings`、侧栏收起/恢复、问候语在输入框上方均通过。

## 明确没做

- 没动托盘、桌面壳 Go 文件。
- 没新增前端依赖。
- 侧栏只收起到 0 宽，没有做 deepseek 的图标 rail（当前产品侧栏没有图标导航）。
