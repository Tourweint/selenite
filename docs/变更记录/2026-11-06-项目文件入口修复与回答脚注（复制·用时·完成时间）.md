> 范围：`ts/apps/server/web/`（`app.js` / `style.css` 为主）。不动后端、不动契约。
> 交付口径按用户原话拆成三件：①侧栏项目两个入口「没用」；②复制按钮挪到回复正文下方，

## 一、侧栏两个入口「都没用」——根因不是接口

用户说的是展开侧栏项目区里那两个按钮（行尾「浏览文件」/「在资源管理器里打开」）。
排查下来是**两层原因叠在一起**：

### 1. 整页脚本在启动前就挂了（决定性）

侧栏统一批把 `#rail-new`（收起轨道顶部的「新建对话」）从 `index.html` 删了，
但 `app.js` 里还留着：

```js
el.railNew.addEventListener("click", ...)   // el.railNew === null → TypeError
```

这一行位于文件中部、**在启动 IIFE 之前**。它一抛错，后面所有顶层监听注册
（项目区渲染、模型 pill、设置页、路由）全部不执行 —— 表现就是"点什么都没反应"，
不只是项目那两个按钮。`node --check` 查不出来（语法没错），只有真跑页面才现形。

处置：轨道入口一律改可选链（`el.railNew?.addEventListener`），并在 `el` 表里
注明该 id 已退役。同时全量扫了一遍 `el.X` 与 HTML id 的对应关系，确认没有第二处
裸调用：现在 `el` 表 121 项里只剩 3 个已移除的 id（`rail-new` / `side-group` /
`open-tasks`），且全部是可选链调用或无调用点。

### 2. 旧进程没有文件端点

39847 上那个进程是 14:17 起的，而 `files.ts`（18:39 合入）里的
`POST /workspaces/open-explorer` / `GET /files` / `GET /files/content` 都在它之后 ——
旧进程对这三个路径一律 404。用最新代码起隔离服务实测三个端点都是 200，与代码无关。

处置：前端把 404 与业务失败分开说。404 时明确提示
「服务还是旧版本（没有文件/资源管理器接口），重启服务后再点」，
而不是笼统的"打不开资源管理器"——后者会让人以为是路径或权限问题，白折腾。

### 3. 顺带修掉的两个真 bug（都在入口自身）

- **面包屑重复项目名**：文件浏览器的 `startRel` 是"工作区内相对路径"，
  子项目进来本来就是 `tmp-ws-test`，原来又拿项目名当根 → 显示
  `tmp-ws-test/tmp-ws-test`。改为 `openFileBrowser(项目名, 相对路径, 工作区根名)`，
  面包屑恒以工作区根名打头（`Workspace/tmp-ws-test`）。
- **入口默认不可见**：`.proj-row .proj-act` 原来是 `opacity: 0`，只在行 hover 时出现。
  看不见的按钮等于没有 —— 改成常态 `.55` 淡显，hover / 键盘聚焦提亮。

## 二、回答脚注：复制 · 用时 · 完成时间

原来是两个各自绝对定位的浮层：`.copy-btn` 贴右上角（`top:-2px; right:-4px`），
`.msg-usage` 贴右侧（`top:24px; right:-4px`）。两者都脱离正文流，永远和正文右边缘对不齐，
而且"复制"在右上、"用时"在右侧中部，看起来像两件不相干的东西。

改成正文下方一条正常流的脚注 `.msg-foot`：

```
[复制]  2,034 tok · 12.4s │ 完成于 14:03
```

- 复制按钮挪进脚注（`.msg-foot .copy-btn`，`position: static`），不再是浮层；
- 用时：现场那一轮用 `done.usage` + 墙钟；**历史回读补上 `workMs`**
  （服务端 `readTranscript` 早已下发，前端一直没用），所以切回旧会话也看得到用时；
- 完成时间：现场那一轮以"拿到 `done` 的时刻"为准；历史消息用该条 assistant 的
  `at`。`clockOf` 当天只给 `HH:MM`，跨天补 `M/D`；
- 历史消息只显示时长、不显示 token —— 历史里没有可读的 usage，不编 `0 tok`；
- `.msg-foot` 留 20px 高 + `margin-top:-6px`：不留高度的话 hover 一出现就把下面的
  消息顶下去，长对话里鼠标来回划会一直抖。

## 三、"子项目是什么"的说明

侧栏项目区尾部一行小字：`主项目=打杂空间，子项目=登记的仓库`，
完整解释挂 `title`（主项目 = 最大工作区根，打杂/临时文件；子项目 = 登记进来的
独立目录，通常是代码仓库；非完全访问档下助手只能在这两个空间里动手）。

一开始写成三行小字，实测把 232px 的侧栏撑出横向滚动条（`.sidebar-inner` 是定宽 +
`overflow-y:auto`，任何横向溢出都会长出一条滚动条）。改一行 + `text-overflow` 收住。

同时：分区头恒为「项目」（原来塞 workspace 名，和下面主项目行一模一样，
两行都叫 `Workspace` 时分不清谁是主项目）；主项目行补「主项目」标注；
行内边距与间隙收紧（12px→8px / 6px→4px，按钮 24→20px），否则主项目名被截成 `Wor…`。
