# 外观页响应式统一（单行横滚）与窄屏侧栏覆盖层

> 记录一次响应式细节收口：外观页主题卡与壁纸格统一成同一套"单行 + 横向滚动"布局，窄屏（≤800px）侧栏从"强制轨道、展开无效"改成覆盖层展开。

## 用户原话

> 「切换主题的布局和切换壁纸的布局不一样。缩得特别小的话，壁纸永远在 1 行，但主题会在两行，它们都是 5 个呀。」
> 「如果缩得特别窄，左右距离特别小，这不都到上头了吗？到上面就没有办法左右滚动了。你把这个左右滚动做一下，不仅是鼠标滚轮可以滚动，长按鼠标模拟手指也可以滚动。」
> 「特别窄的情况下，侧边栏展不开。可以有个提示，比如'太窄了，无法展开这个侧边栏'。或者你也可以做展开这一块。你考虑一下吧。」

## 结论

1. **主题卡与壁纸格统一单行横滚**：`.theme-cards` / `.wallpapers` 从 grid 换 flex（基宽 160px，`flex: 1 0 160px`）——宽屏 grow 摊满一行，观感与原 5 等分一致；窄屏 shrink 0 兜住基宽出横向滚动。旧的三档折行媒体查询（≤1020 折 3 列 / ≤760 折 2 列 / ≤560 壁纸折 1 列）整段退役——两排卡曾经一边折行一边不折，用户点名不一致。
2. **滚轮 + 拖拽横滚（`web/scroll-x.js` 新建）**：全站滚动条只留主对话（既有口径），横排溢出没有条子可拖，所以滚轮纵向分量直转 `scrollLeft`、按住拖拽滑动（触屏走原生）。拖过 6px 就吃掉落点 click，防拖完误触卡；没溢出就不拦滚轮不抢按住。做法与记忆页 people tabs 那份内联实现同一条路（那边先做的，等下次动到它再收编，本批不动）。两排卡（`settings-router.js` 外观分支 + `appearance-wallpaper.js` 的 `wireSection`）都挂了这个辅助；壁纸自定义图补 `-webkit-user-drag: none`，按住拖动不再被原生图片拖拽抢走。
3. **窄屏侧栏改覆盖层展开**（用户二选一里选了"做展开"，提示就不需要了）：≤800px 时收起 = 48px 轨（旧口径保留），展开 = 264px（`min(264px, 78vw)`）面板浮在主区上，不挤占主区宽度；配 `.sidebar-scrim` 遮罩（z-29，面板 z-30，标题栏 z-40 仍在顶），点遮罩收起。旧做法是把整栏强制钉 48px 且与 data-sidebar 无关，窄屏点展开静默无效。宽屏侧栏常驻口径不变（点外不收，遮罩永远 hidden）。
4. **inert 口径归一**：窄屏 CSS 现在尊重 data-sidebar，`applySidebarA11y` 不再分窄宽两套——轨道 = 收起态可见、inner = 展开态可见；遮罩只在「窄屏 + 展开」出现，随 `NARROW_SIDEBAR` change **和 window resize** 同步（见第 5 条）。设置路由整页无侧栏，`html[data-route="settings"] .sidebar-scrim` 直接 display:none。
5. **resize 兜底**：IAB/模拟视口改尺寸不派 matchMedia `change`（2026-11-15 实测：`matches` 会更新、CSS 媒体查询也跟着走，事件就是不来），补 `window.addEventListener("resize", applySidebarA11y)`——同步是幂等的，多调不伤。真窗口 resize 本来就两路都通。
6. **收起轨窄屏仍钉 48px**：改写窄屏块时展开态选择器（带 html 属性权重）会盖过收起态的 48px，closed 必须显式再钉一次——浏览器验收抓到过这处回弹成 72px，已修。
7. **覆盖层动画定宽冻结**：`.sidebar-inner` 在覆盖层里也用定宽 `min(264px, 78vw)`（与面板同式），展开动画期间由 overflow:hidden 裁着露出来，不跟面板宽度重排折行——与宽屏开合"定宽冻结"同一套做法（浏览器验收第一帧抓到过文字跟着折行，已修）。

## 验证（2026-11-15，IAB 浏览器实测；locator/cua 真实点击在该环境不达页面，按既往口径用合成事件驱动真实监听器）

- 宽 1280：主题卡 / 壁纸格各 5 张等分单行（scrollWidth == clientWidth，无滚动）；侧栏开 232 / 关 72 往返，遮罩全程不出现。
- 窄 420：两排卡单行、内容 840 > 可视 358 溢出、每张保 160px；滚轮 deltaY 200 → scrollLeft 200；按住拖 120px → +120；拖后落点 click 被吃（主题未变），再点正常选中；壁纸排滚轮同通。
- 窄屏侧栏：收起 48px 轨；展开 264px 覆盖层（absolute / z-30 / 实底 / 右缘描边阴影）+ 遮罩可见（z-29）；点遮罩收起、点展开钮再开；inert 随开合归一；设置路由侧栏与遮罩都 display:none。
- 缩放联动：420→1280 遮罩自动藏、1280→420 自动出（resize 兜底路）。
- 测试期间切走过的主题已还原（paper），侧栏状态还原 open。

## 刻意不做

- 记忆页 people tabs 的内联横滚实现不收编（本批不动那个文件，等下次动到它再合并成同一个辅助）。
- 主题色圆点排不加横滚：它本来就 `flex-wrap`，窄屏换行两排圆点可接受。
- 窄屏展开不加"太窄了"提示：展开已经可用，提示反而多余。
- 横排不显滚动条：全站"滚动条只留主对话"口径不动，隐条 ≠ 不能滚（滚轮 / 拖拽 / 触控板横向分量照走）。
