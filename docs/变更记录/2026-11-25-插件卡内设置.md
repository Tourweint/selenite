# 2026-11-25 插件卡内设置（设置收到插件卡附近）

审计与设计：`docs/设计方案/2026-11-25-插件设置就近呈现.md`；取证：`.box-agent-scratch/reports/2026-11-25-plugin-settings-audit.md`。

## 改了什么

1. **新增 `web/plugin-settings.js`**：一张声明式登记表 `PLUGIN_SETTINGS[插件 key] = { hint, render?, links? }`。
   - `render` = 卡内内联控件，只调既有函数 / 既有端点 / 既有存储键：
     - `MEMORY_NIGHTLY_REVIEW`：时间输入，`GET/PATCH /api/v1/agent/memory/nightly`；
     - `CHAT_MAP_ENABLED`：下拉（最近 5/10/15/20/30 轮），走 `chat-map.js` 的 `setChatMapWindow`；
     - `AGENT_APPEARANCE_WALLPAPER`：可见度 / 模糊两条滑杆，走 `appearance-wallpaper.js` 的读写；
     - `TOOL_TIMEOUT_POLICY`：原样复用详情浮层那张内嵌面板（`renderInlinePolicyPanel`）；
     - `AGENT_TOOL_POLICY`：**只读**回显 `GET /api/v1/agent/policy` 的实际权限与审批档。
   - `links` = 「去 XX」页内链接（按人 / 项目 / 设备 / 复杂流程一律走链接，不复制流程）。
2. **`web/settings-switches.js`**：`flagCardMarkup` 在卡尾最左挂「设置」按钮 + 面板外壳（只有登记了的插件才画）；
   `renderFlagRows` 里调一次 `wirePluginSettings(card)`（事件委托，挂一次）。点按钮 `stopPropagation`，不连带打开详情。
3. **`web/chat-map.js`**：顶栏「最近 N 轮」下拉的处理体抽成 `setChatMapWindow`，与插件卡共用；多导出
   `getChatMapWindow`、`CHAT_MAP_WINDOW_OPTIONS`。
4. **`web/appearance-wallpaper.js`**：多导出 `saveWallpaperState`（原模块内 `saveState`）。
5. **`web/style-14-settings-pages.css`**：`.flag-grid` 加 `align-items:start`；新增 `.flag-settings*` 一段。
   展开时该卡 `height:auto`，面板 `grid-template-rows 0fr → 1fr`；收起后 `visibility:hidden`，不进 Tab 序。

## 为什么

2026-11-25 用户口径：逐个插件检查，有更详细设置的，把设置放到插件卡附近的小卡片里，方便调插件配置。
审计 89 条清单（任务书写 87，实际 `plugins.json` 是 89：多出 `GOAL_MODE` / `GOAL_MAX_ROUNDS` 两条）：
A 纯开关 33、B 有全局设置 21、C 按人 / 项目 / 设备 20、D 只有 env / 常量 14、E 已退役 1。
本轮只做 B（卡内内联或链接）与 C（入口）；D / E 只登记，不新增契约、不改开关语义。

## 回滚

纯前端能力，env 到不了浏览器，本轮不加投影（加了就是改契约）。两层本地回滚，都不用动别的文件：

- `web/plugin-settings.js` 顶部 `INLINE_SETTINGS = false`；
- 控制台 `localStorage.setItem("lifediary.pluginInlineSettings", "0")` 后刷新。

env 形态（`PLUGIN_INLINE_SETTINGS=false` 经 `/agent/policy` 投影）列在方案 §5.1 待立项。

## 发现但没动（要先写方案）

`AGENT_TOOL_POLICY`（工具权限限制）卡上的档位**不驱动真实闸门**：闸门是 `agent/policy.ts:101` 的模块级 `policy`，
import 期就定了；插件存储在 `index.ts:331` 才写进 env，之后没有任何地方再从 env 回灌。运行期能改它的只有
`POST /api/v1/agent/policy`（会话页权限卡）。所以这张卡的面板只回显实际生效值并指路，不给第二个可写控件。
**这是代码走查结论，没有起服务实测。**
