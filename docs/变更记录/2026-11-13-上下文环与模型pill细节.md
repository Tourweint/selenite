# 上下文环隐藏数字 + 模型名/思考档对齐 + 上下文窗口按会话模型取

日期：2026-11-13
状态：已落地（typecheck ✅ / 793 单测 ✅ / http 探针 325 项 ✅ / IAB 实机三场景 ✅；纯 web 三件 + 服务端一处只读语义，契约形状不变）

## 起因（用户口径，2026-11-13）

1. 上下文环旁边的「4K / 多少 K」不要常驻，只在鼠标悬停时显示。
2. 模型没问题，但思考强度和模型名字的位置对不上，要对齐。
3. 怀疑会话上下文不是按当前会话加载的，要求调整。

## 改了什么

### 1. 上下文环只留环，数字全部收进悬停

- `index.html`：删掉 `<span class="ctx-pct" id="ctx-pct">`；`#ctx-ring` 里只剩 20×20 的 SVG。
- `app.js`：`el.ctxPct` 映射与 `textContent = formatTokenCount(data.used)` 删除；
  悬停 `title` 不变，仍是 `用了 4K · 顶了 3% · 最多 128K`。
- `style.css`：`.ctx-ring` 去掉 `gap` 与文字用的 `font-size / font-variant-numeric`。
- 环弧仍按 `used / window` 画，warn/danger 阈值不动；数字读不到时整块隐藏的口径不变。

### 2. 模型名与思考档对齐

- 根因：`#model-pill-label` 是 flex item，里面又套了一个 `inline-block` 的
  `.pill-label-text`；inline-block 的 baseline 落在盒底，把外包的行盒撑到 22.4px
  （正常 18.2px），`align-items: center` 一居中，模型名就比右边 `·高` 高约 3px。
- `style.css`：`#model-pill-label { display: flex; align-items: center; min-width: 0; }`，
  `.pill-label-text` 补 `min-width: 0`。两者行盒现在同为 18.2px，在 30px 的 pill 里同心；
  窄窗口下省略号照旧（IAB 2 倍缩放实测 `magpie 本地网关 · auto/glm-…`）。
- 文字滚动动画（`pill-label-enter/exit`）结构不动，`position: relative` 仍在。

### 3. 上下文窗口按「这个会话自己的模型」取

- `agent/session.ts` 的 `contextUsageOf()`：原来 `window` 读全局默认模型
  （`readLlmConfig()`），会话在 pill 里切过模型、或旧会话还停在别的模型上时，
  环会按错的窗口算占比。现在先读 `conversation.agent(CTX)` 的模型引用
  （剥掉 `#think-*` / `#t…` 派生后缀查基座模型），查不到 / 模型已被删才回退全局默认。
- 契约形状不变，仍是 `{used, window}`；`接口文档.md` §2.2 的描述补一句
  「该会话当前绑定模型的 contextWindow」。
- `app.js` 的 `openChat()` 在切到不同会话时先把环藏起来，等 `/context` 回来再画：
  加载期间旧会话的数字不会停在新会话的角落，避免再被看成「没按会话加载」。
  同一会话重开不闪（按 `dataset.conv` 判断）。
