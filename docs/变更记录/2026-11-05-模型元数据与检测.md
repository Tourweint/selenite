# 模型元数据与单模型检测（逐模型上下文 · 思考档 · 添加模型弹窗）

日期：2026-11-05
类型：契约 + 存储 + 设置页改造
方案：`docs/设计方案/2026-11-05-模型元数据与检测方案（逐模型上下文·思考档）.md`

## 缘起

供应商页还是「一行填一个模型」的 textarea，上下文窗口 / 最大输出对所有模型硬编码
`131072 / 4096`，思考档只能靠后台探活或手改 JSON。用户要求：

1. 选模型页能看见每个模型的上下文与思考强度（从服务端下发）；
2. 供应商页像 ZCode 一样，右上「添加模型」+ 模型列表；
3. 填模型 ID 后点「检测」，真测连通并自动回填上下文 / 思考档，用户确认后保存。

## 改动

### 存储（`providers.json`，纯增量）

- `ProviderEntry` 增加可选 `modelMeta: Record<modelId, {contextWindow?, maxTokens?}>`。
- 校验：键只保留仍在 `models[]` 里的模型；值只收正整数（`1..10_000_000`），
  非法数值丢弃、空对象不落盘；`modelMeta` 整体不是对象 / 值是标量 → `400 bad_model_meta`。
- 缺省不变：没配元数据的模型仍用 `131072 / 4096`，默认值不写进文件。
- `POST /agent/providers` 增加 `modelMeta` / `modelThinkingLevels` / `allowEmptyModels`：
  不传元数据 = 保留旧值并按 `models[]` 裁剪；`allowEmptyModels: true` 才允许空清单建档
  （默认仍 `400 bad_models`，老语义与探针断言不变）。空清单供应商不会成为 `defaultSelection`。

### 投影

- `GET /agent/model` 的 `models[]` 每行增加 `contextWindow` / `maxTokens`（已解析的生效值）。
- `GET /agent/providers` 每项增加 `modelMeta`（稀疏）与 `modelThinkingLevels`（每模型生效档位）。

### 新端点 `POST /api/v1/agent/providers/:id/models/detect`

body `{modelId}`，只读、不写配置，允许检测尚未加入 `models[]` 的 id。三路并行：

- `POST /chat/completions`（`max_tokens=8`）判连通与耗时；
- `GET /models`（退 `/models/{id}`）抽上下文 / 输出上限，认
  `context_length` / `context_window` / `max_model_len` / `max_input_tokens` /
  `max_output_tokens` / `max_completion_tokens` 等常见字段（大小写不敏感，扫一层嵌套）；
- 复用 `probeLevel` 探 `low/medium/high` 思考档，`off` 始终视为基线。

返回 `reachable / status / latencyMs / contextWindow / maxTokens / thinkingLevels / levels / message`。
上游没给上下文时返回 `null`，不用默认值冒充。错误：`404 unknown_provider`、`400 bad_request`、
`400 providers_disabled`。日志只记枚举与耗时，不记上游正文与密钥。

### 前端（`ts/apps/server/web/`）

- 供应商表单删掉「模型清单」textarea 与「自动拉取清单」勾选，换成模型卡片列表：
  每行 `模型 ID` + `上下文 / 输出 / 思考档` 摘要 + 编辑 / 移除；区块右上「添加模型」。
- 添加 / 编辑模型弹窗：模型 ID + 「检测」按钮 + 上下文 / 最大输出 + 思考档复选；
  检测回填后用户确认才进草稿，供应商再点「保存」才落盘。未保存的新供应商检测按钮禁用。
- 保存流程收敛成一次 `POST /agent/providers`（带 `models` / `modelMeta` /
  `modelThinkingLevels` / `allowEmptyModels: true`）+ 可选密钥；删掉原「保存并拉取清单」的第二段请求。
- 模型菜单当前行的模型名右侧显示上下文（`128K` / `1M` 短写）。

## 刻意不改

- 不做全量模型目录自动导入（`modelsUrl` 后端能力保留，新 UI 不用）。
- 不做已知模型名的内置上下文表，不做主动二分探测真实上下文上限。
- 手机端不读新字段。
- 检测结果不自动落盘（必须用户确认）。
