# 分支会话删除与选择器二级缩进

**日期**：2026-11-18。
**范围**：服务端（`companion-api.ts` / `agent/partner-session-delete.ts` / `partner-store.ts` / `agent/durable-delete-plan-chat-deletion.ts` / `partner-session-role.ts` / `plugins.json` / `.env.example`）+ 前端（`web/partner-sessions-ui.js` / `web/partner-sessions.js` / `web/style-02-sidebar.css`）。先落设计方案 `docs/设计方案/2026-11-18-分支会话删除与选择器二级菜单.md`。

## 问题

- 选择器里的分支 / 副会话删不掉：普通归档可以，但归档页的永久删除按 `kind` 挡掉所有 `partner` 会话；分支越攒越多没法清。
- 主对话和副本在选择器里平级显示，看起来像两条无关会话；画板却是"一条会话 + 全部分支"的家族图，用户对不上。
- 用户要求：选择器里直接删；副本缩进挂在母会话下面（二级菜单）；画板不用改。

## 改了什么

### 服务端

- **新端点** `POST /api/v1/partners/:id/sessions/:conversationId/delete`（`companion-api.ts`）：
  - 只允许执事 `role='side'` 与总管带 `ChatOrigins` 的分支副本；canonical / 总管无来源的主对话 / 普通 worker 拒绝。
  - 有**未归档**子分支 → `400 has_branches`（带数量，不级联）；忙 → `400 conversation_busy`。
  - 删除走 `runExclusiveMaintenance` + `deleteSubtreeRows`，清 `Chats` / `ChatKinds` / `ChatProjects` / `ChatOrigins` / chat-meta / `partner_session_links(role='side')`；记忆、附件、磁盘不动。
  - 实现独立成 `src/agent/partner-session-delete.ts`，复用 durable-delete 的维护闸与清理函数。
- **归档页永久删除同步放行 side 副会话**（`durable-delete-plan-chat-deletion.ts`）：`kind` 门槛放行 `role='side'`（canonical / chief / 群 / 任务仍拒绝）；新增 `has-branches` 拦截未归档子分支；删除后清 `role='side'` 链接。这样之前归档掉的老副会话（空分支）也能从归档页清掉。
- **`purgeChatMappings` 补清 `ChatOrigins`**（`durable-delete-plan-chat-deletion.ts`）：否则画板会留指向已删会话的幽灵节点；现有 worker 永久删除也顺带受益。
- **`PartnersStore.deleteSideLinkBySessionId`**（`partner-store.ts`）：只删 `role='side'`，删除幂等。
- **`GET /partners/:id/sessions` 补字段**：`sessionManage`、每条 `origin?` / `deletable`；并沿 `ChatOrigins` 补可达后代（老分支缺 side 链接时也能在选择器里看到）。已归档子分支不挡删除。
- **新开关 `PARTNER_SESSION_MANAGE`**（`plugins.json`，group `autonomy`，`requires: PARTNER_SIDE_SESSIONS`，默认开/hot）；`.env.example` 同步；读取助手 `partnerSessionManageEnabled()` 放 `partner-session-role.ts`。

### 前端

- 选择器用 `buildSessionTree()`（`web/partner-sessions.js`，纯函数）按 `origin.source` 建树：副本缩进挂在母会话下面，母会话不在列表 / 有环时退回顶层。
- 每个 `deletable` 行悬停出垃圾桶；点击把弹层 body 换成确认视图（不叠加 `openModal`），取消回列表。
- 删除成功：非当前会话 → 原地重拉列表重绘；当前会话 → 关弹层回主对话（执事走 `/open`，总管打开剩余第一条）。
- `PARTNER_SESSION_MANAGE=false`：回到平铺列表、无垃圾桶、端点 400。

## 刻意不做

- 不做「一个会话一张地图」：画板仍是家族视图（D30）。
- 不级联删子分支；已归档子分支不挡删除（恢复后成为独立副会话）。
- 归档页永久删除不扩到 canonical / chief / 群 / 任务；side 副会话 2026-11-18 起同步放行（有未归档子分支先拦 `has-branches`），这样之前归档掉的老空分支也能清。
- 不加归档按钮、不做批量删除、不做手机端。
- 不清理孤儿 `ChatOrigins`（子分支的 origin 指向已删母会话）——按"恢复后当独立会话"处理。
