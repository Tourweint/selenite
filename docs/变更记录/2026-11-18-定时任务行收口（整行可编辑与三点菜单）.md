# 定时任务行收口（整行可编辑、动作进 ⋯）

**日期**：2026-11-18。
**范围**：纯前端（`web/settings-reminders.js`、`web/settings-router.js`、`web/partner-profile.js`、
`web/memory-page.js`、`web/style-14-settings-pages.css`、`web/style-22-partner-profile.css`）；
不碰契约、不碰服务端。

## 问题（2026-11-18 用户反馈）

1. 设置 → 定时任务每行右边一排文字按钮（编辑 / 暂停 / 立即跑 / 历史 / 删除，整理记忆是改时间 / 暂停 / 删除），
   太挤、不好看；希望收成右边一颗 ⋯。
2. 行里的「每晚整理 / 触发可见 / 触发隐藏」徽章、以及「指令：……」的预览是解释性噪声，不该常驻。
3. 整理记忆那一行只写「改时间」，看不出整行可编辑，也看不懂「整理建议」是什么。
4. 人设页的例行任务与设置页是同一张清单，两边都要能改。

## 改了什么

- **共享行渲染 `renderScheduledTaskList`（设置页与人设页共用）**：
  - 整行变成编辑入口：点时间 / 标题 / 空白都打开同一个编辑器；行可 Tab 聚焦，Enter / Space 打开。
    键盘事件只认行自己，行内按钮的 Enter / Space 归按钮。
  - 右侧只留一颗裸态 ⋯（复用 `sec-menu`，挂 body + fixed，不吃卡片裁切）；
    菜单按 kind 给项：例行/提醒 = 编辑 / 暂停或启用 / 立即跑 / 历史 / 删除（删除前加分隔线）；
    整理记忆 = 改时间 / 暂停或启用 / 删除。
  - 「历史」改从菜单开合：展开后就地显示执行记录，菜单项随之变成「收起历史」。
  - 删掉行内徽章（每晚整理 / 触发可见 / 触发隐藏）与「指令：……」预览；
    触发消息可见性仍在编辑器里改，指令正文点开就能看到。
- **设置页顶部说明**：`到点让 TA 自己跑一轮` 下面那段长说明收进标题 `data-tip`，
  并补一句「点一行就能改；暂停、立即跑、历史、删除在右边的 ⋯ 里」。
- **人设页每晚整理块**：原来并排的「改时间 / 暂停」文字按钮收成一颗 ⋯；
  那段「拆分 + 对账、只出建议」的长解释收进标题 `data-tip`，块头只剩标题 + 时刻 + ⋯。
- **记忆页「整理建议」**：标题补 `data-tip`，解释「只给建议、逐条点应用才改、不会自动改」。

## 验证

- `node --check` 四个改动的浏览器模块通过；`pnpm typecheck` 全绿。
- 浏览器实测（本地 39847，真数据）：
  - 设置 → 定时任务：行内只剩标题、人、时间；无徽章、无指令预览；右边一颗 ⋯。
  - 点行 → 整理记忆打开「改时间」，例行任务打开「编辑定时任务」；取消后弹层正常收起。
  - ⋯ 菜单：整理记忆为「改时间 / 暂停 / 删除」，例行任务为「编辑 / 暂停 / 立即跑 / 历史 / 删除」；
    点「历史」就地展开执行记录，菜单再开显示「收起历史」。
  - 人设页 → 定时任务弹层：每晚整理块只剩标题 + 时刻 + ⋯，菜单「改时间 / 暂停」；
    下面例行任务清单同样整行可编辑、右侧 ⋯。
- 备注：本机 IAB 的 Playwright locator 点击在本会话里连普通按钮也超时（环境问题），
  交互用页面 DOM 点击验证，鼠标可达性用 `elementFromPoint` 确认。

## 刻意不做

- 整理记忆仍然只能改时间（服务端 `PATCH /agent/memory/nightly` 只接受 `at`），
  没有借这次收口扩成「改内容」。
- 触发消息可见性保留原有编辑器语义，不在行里新增只读标记。
- 不改设置页其它区块；`settings-router.js` / `style-14` 里同文件的其他在途改动不属于本次。
