# 2026-11-14 VPS 中继安全加固（owner 令牌 · 受限用户 · 防火墙）

> 「中继搭好了，公网上谁都管，这事儿得处理」——把中继从「公网裸跑的 root 进程」改成
> 「必配 owner 令牌 + 专用低权限用户 + 只放行 22/8084」的部署形态。

## 结论

- 修复后的 `server.ts` 已部署到 `<VPS_IP>:/opt/lifediary-relay/src/server.ts`（13709 字节，sha256 前 16 位 `44434299c8f52949`，与仓库一致）。改动只有 `isOwner` 一处：不再读 `x-forwarded-for`、只用真实对端地址，拿不到对端即 fail-closed。
- **公网裸签已关死**：无令牌 `403`、伪造 `x-forwarded-for: 127.0.0.1` 也 `403`、带令牌 `200`（三例实测）。
- 中继以专用用户 `relay`（uid 997、nologin）运行，systemd 单元带一套 hardening，内存上限 256M，`NRestarts=0`，常驻约 50MB。
- `ufw` 已启用（默认拒绝入站，放行 22/8084），`fail2ban` 已装 sshd jail。启用后开新连接验证 SSH 正常，没锁死。
- 本机 `ts/apps/server/.env` 补上同一枚 `RELAY_OWNER_TOKEN`（64 位 hex，文件被 `ts/.gitignore` 覆盖），重启后
  `POST /api/v1/relay/join-code` 从 502 变 **200**——页面「添加手机」这条终于通了。

## 改了什么

| 位置 | 改动 | 为什么 |
|---|---|---|
| `/opt/lifediary-relay/src/server.ts` | 镜像本地修复版（唯一差异就是 `isOwner`） | 旧代码把缺头的公网请求兜底成 loopback，未配令牌 = 全网可签发加入码/撤销设备 |
| `/etc/lifediary-relay.env`（600 root） | `RELAY_OWNER_TOKEN=<64 位 hex，随机生成>` | owner 口必配钥匙；令牌不进仓库、不进日志 |
| `/etc/systemd/system/lifediary-relay.service` | `User=relay`；`EnvironmentFile=-`；`ExecStart=/usr/bin/node --import tsx src/index.ts`；`NoNewPrivileges` / `PrivateTmp` / `ProtectSystem=full` / `ProtectHome` / `ReadWritePaths=.data .home` / `RestrictAddressFamilies=AF_INET AF_INET6 AF_UNIX` / `MemoryMax=256M` | 被拿下也拿不到 root；不必为启动去 /root 写文件；npx 换 node 去掉每次解析 |
| 系统用户 `relay` | `useradd --system --nologin`，只 chown `.data` 与 `.home`，代码目录仍 root 所有 | 服务能写状态文件，改不了自己的代码 |
| `ufw` | `allow 22/tcp`、`allow 8084/tcp`，默认 deny incoming，`--force enable` | 原来 `ufw` 服务 active 但 status inactive，等于没开 |
| `fail2ban` + `/etc/fail2ban/jail.local` | sshd jail：10 分钟内错 5 次禁 1 小时 | root 口令弱且 22 口对公网，爆破是必然 |

## 没做 / 残留风险（明说）

1. **root 仍开密码登录**（`permitrootlogin yes` + `passwordauthentication yes` + 弱口令）。现在只靠 fail2ban 挡爆破。
   改法两条都要求用户先备好后路：换强口令，或装公钥后关口令登录——任一改错就远程再也进不来，本轮没动。
2. **中继仍是明文 HTTP**（`http://<VPS_IP>:8084`）。设备令牌与消息内容在公网上可被中间人看到。
   需要 TLS 才有质变：域名 + Caddy/NGINX 证书，或 Cloudflare Tunnel，或 WireGuard 隧道。没有域名之前做不了。
3. **端口 22 仍用默认 22**。改端口能少掉大半扫描噪音，但要同步改本机脚本，属于「用户要我就做」。
4. 中继根路径 `/` 返回 500（`www/` 静态两件套没跟着部署到 VPS），是不可用的控制台页，和安全无关，
   本次没补——需要的话把 `www/` 一起上传即可。
5. 后端 `MemoryMax=256M` 是按当前 50MB 常驻给的余量，多台手机同时反代大响应时是否够没压过。
