# 2026-11-07 头像并入「人设」：加宽编辑弹窗 + 预设/本地二选一

用户口径（原话要点）：

1. 「头像应该合并到指示里。编辑指示的弹窗做得稍微宽一点」；
2. 「选图片可以下拉选择系统预设图片，也可以从本地选文件」；
3. 「页面比较丑，需要调一个比较好看的方式展示。至少先变宽点，方框什么的做得正常一点，风格统一就行」。

## 口径澄清（动手前先对齐的地方）

用户在需求里说的「人设」，在仓库里原本**没有**对应的界面文案（界面现称「人设」）。最接近的两处是：设置 →「执事」里编辑弹窗的 **SOUL · 身份**，
以及设置 →「头像」这个独立分区。按用户三句话（头像要并进人设、弹窗要加宽、列表要好看）判断，
指的正是这条链路：**给一个角色写"它是谁"的地方**。因此本轮把两处合成一处，界面统一用「人设」（用户口语里的"指示"就是它；存储字段仍是 `soul`）。
`soul` 字段名、`PATCH` 契约、存储列全部不动——这是界面归并，不是数据模型变更。

## 改了什么

### 1. 头像并入人设（一个弹窗、一次保存）

- 设置分区「头像」删除；「执事」分区改名为 **「人设」**，图标换成「人形 + 笔」。
- 编辑弹窗标题改为 `人设 · <名字>`，第一段即「人设」：头像在左、正文在右，
  底部只有一颗 **「保存人设」**（旁边是「撤销改动」，干净态禁用）。
- 保存时把 `avatar` 与 `soul` 放进**同一个 PATCH**：服务端本来就支持一次带多个槽位，
  且全量校验通过才写，因此不会出现「头像进去了、正文没进去」的半写。
- 名字/领域挪到独立一段（两列）；模型候选链、例行任务原样保留在后面。
- 详情页文案、卡片按钮（`编辑` → `改人设`）、版本号标签（`SOUL vN` → `人设 vN`）一并统一。

### 2. 选图片：下拉面板里同时给预设与本地

- 点头像不再直接弹系统文件框，而是浮出一个选择面板：
  - **30 张预设**（10 男 / 20 女，`/assets/preset/<m|f><NN>.png`，2026-11-06 已有白名单路由），
    按性别分组、圆形网格铺开；点一张即进草稿；
  - **「从本地选一张…」** 走系统文件框，仍复用 `fileToAvatarPng`（解码 → 最长边 ≤256 → PNG → ≤128KiB），
    与服务端复核同口径；
  - **「不使用」** 清空头像，回落名字首字。
- 面板用 `position: fixed` 挂 body、坐标按头像按钮实测写入：弹窗正文是 `overflow:auto` 的滚动容器，
  绝对定位塞在里面会被裁掉下半截。右侧放不下自动翻到左边，下方放不下贴底。
- Esc 两级：先关面板、再关弹窗（输入法组合中的 Esc 豁免，沿用既有 `isComposing || keyCode === 229`）。

### 3. 弹窗加宽 + 方框形状统一

- `openModal(title, build, { className })` 新增宽度档：`.modal-panel.modal-wide` = `min(760px, 100% - 2rem)`。
  只由调用方显式传入，其它模态仍是 420px——宽度不该由内容猜出来。每次打开会重置，不会泄漏到下一个模态。
- 弹窗内部：**头像行 + 全宽正文**。先试过"104px 头像列 + 1fr 正文列"两列，实际渲染里左侧会空出一大条、正文被挤到 600px 出头；改成头像 64px 与说明同一行、正文吃满宽度，760px 弹窗里一行能放 50+ 字。正文最小高 220px、行高 1.75。
- 设置内容列 `920px → 1000px`：原来 1440 宽窗口里右侧空一大条，卡片只有两行控件就撑满。

### 4. 列表重排（"方框做得正常一点"）

- 执事/人设卡片从「三行堆叠」（头像+名字+标签+状态点挤一行 / 元信息一行 / 按钮一行）
  改成 **`40px 头像 | 名字+元信息 | 操作`** 三列网格，一张卡一行读完；`≤720px` 落成两列、操作换行。
- 状态点从名字行首挪到名字行尾，与状态徽章同一侧；总管条目的「总管」标签在名字本身就叫"总管"时不再重复渲染。

## 明确不做

- 不改 `partners` 存储、不改 `PATCH` 字段语义、不新增端点（纯前端归并）。
- 不做图片裁剪（cindy 有 `AvatarCropEditor`，我们在客户端已缩到 256px，圆形展示用 `border-radius` 即可）。
- 不做"生成头像"（需要模型出图链路，不在本轮范围）。
- 不动侧栏头像点击行为（仍打开这个同一个弹窗，只是标题与内容变了）。

## 兼容

- 旧路由 `#/settings/avatars` 由 `currentSettingsPage()` 别名落到 `partners`：老书签不会掉回「外观」成一页空白。
- 旧的 `.av-*` 样式族已无引用，整块删除；30 张预设 PNG 与 `/assets/preset/:file` 路由不变。
- 手机端不加载这套 web 文件，零影响。
