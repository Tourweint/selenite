# 2026-11-25 主题收口（保留燕麦，删米黄与奶油）

前情：同日先加了三套暖色纸（见 `2026-11-25-新增三套暖色主题.md`）。用户看完后拍板三套里只留一套，米黄不要。
本文是收口这一步的记录，**主题口径以本文为准**。

## 结果

- 最终 **6 套**：`white`（暖白）/ `celadon`（青瓷）/ `devin`（燕麦）/ `antigravity`（陶白）/ `indigo`（靛蓝夜）/ `black`（炭黑）。4 浅 + 2 深。
- 删 `paper`（米黄）与 `codex`（奶油）。
- **默认主题从 `paper` 改成 `devin`**：默认主题被删，这是无法避免的默认变更。
- 强调色机制不动（`data-accent`、十档预设、自定义取色），手机端不动。

## 为什么留燕麦

- 推文里燕麦给得最完整：主背景 / 侧边栏 / 文字 / 强调色四项都有原值。
- 青强调色 `#1E8294` 在燕麦底上的对比度是 4.17；奶油的暖黄 `#C08A00` 在奶油底上只有 2.78（那还是配平值，推文只写了 "Yellow"）。
- 米黄与燕麦同为暖纸、区分度低，按用户口径删米黄。

对比度（WCAG 相对亮度，对各自 `--bg`，代码算的）：燕麦正文 13.99、次级 6.19、弱字 3.08；
米黄原值是 13.14 / 4.92 / 2.72。正文和次级字比原默认更清楚，弱字同档（本来就不到 4.5）。

## 迁移规则

页面侧（`index.html` 防闪脚本与 `theme.js` 的 `currentThemeChoice`，两处同口径）：

| localStorage 里存的 | 落到 | 是否写回 |
|---|---|---|
| 六套之一的 id | 原样 | 否 |
| `dark` | `indigo` | 是 |
| 其余：`light` / `system` / 没存 / **`paper` / `codex`** | `devin` | 是 |

壳侧：`savedTheme()` 读不到、记的是 `paper` / `codex` 等认不出的名字、`LIFEDIARY_THEME` 认不出，一律回 `devin`；
`SetTheme("paper")` 现在会被拒（旧缓存页面若回写旧名，只是记不上，不影响使用）。

## 与任务单写的不一样的两处

都在 `popoverPalette` 的燕麦色板里，我按代码里既有的对齐规则取了值，没有照抄任务单的数：

1. **`border` 用 `rgba(44, 37, 32, 0.14)`，任务单写 0.16。** `popovers.go` 自己的注释是"对齐 web `.sec-menu` 的 1px `var(--composer-border)`"，
   燕麦的 `--composer-border` 是 0.14。其余几套也都是照各自 token 取的（暖白 0.14、青瓷 0.16）。

   按公式算是 `#eddfd5`（脚本算过，见前一份变更记录）。
