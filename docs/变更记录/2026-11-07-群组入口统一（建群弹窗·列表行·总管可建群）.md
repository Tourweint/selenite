# 群组入口统一（建群弹窗并入设置语言 · 列表一行一群 · 总管可建群）

> 2026-11-07。方案与取舍：`docs/设计方案/2026-11-07-群组入口统一（建群弹窗·列表行·总管可建群）.md`。
> 契约下沉：`接口文档.md` §2.14（`group_manage`）+ §4（工具清单口径）；模块与 D16 →
> `系统架构.md`。

## 改了什么

### 1. 建群弹窗：从"另一个产品"回到模态的既有语言

- **根因**：群名/公告两个输入框挂的是 `text-input` —— 这个类在 `style.css` 里**根本不存在**
  （全仓唯一两处引用就是它俩），于是退化成浏览器默认控件：2px 直角灰框、14px；
  成员勾选是原生 13px 复选框（Windows 蓝勾）。
- 结构改成 `.modal-field` + `.modal-input` + `.modal-desc` + `.modal-actions`，与「新建执事」同拍。
- 成员从"勾选胶囊"改成**一行一人**（头像 + 名字 + 右侧动作），值日不再单开一块空区——
  原来是「输入框 + 提示 + 勾选块 + 值日块 + 公告 + 按钮」六段，现在三段。
- 三个控件态各给固定形状：`加入`=描边按钮（唯一主操作）／`×`=移出（图标，占固定 24px 槽）／
  `设为值日`=描边，当前值日=`值日` 淡底标记（**不可点掉**——群建出来必须有人接不 @ 的话）。
- 值日随成员移动而传递：移走值日 → 自动交给还在群里的第一位，避免"提交时默默补第一位"。

### 2. 顺手修掉一个跨模态的老毛病

`.modal-input` 上写着 `flex: 1`，而 `.modal-field` 是 **column** 弹性容器 → `flex-basis: 0`
把显式 `height: 36px` 在主轴上压掉，输入框实际只有 **19px**（一行文字高）。
「新建执事」与「新建群组」两个模态实测都是这样。补 `.modal-field > .modal-input { flex: 0 0 auto; }`
（只对纵向字段复位；`.modal-row` 里的横向输入框仍要 `flex:1` 吃满剩余宽）。

### 3. 群组列表：卡片网格 → 一行一群

`minmax(240px,1fr)` 自适应网格在只有 1–2 个群时把卡片撑到 300px+，右侧一片空白，像一张被
拉宽的孤卡。现在整块一个描边容器（`.group-list`，640px 上限）里一行一群：
`首字圆钮 | 群名 + 副行 | 人数 | ›`。副行复用 `gsResponderShort()`（同一概念不再两套措辞——
原来列表写「不 @ 阅读助手 回」，断句会读成"不要 @ 阅读助手"）。

### 4. 总管可建群：新增模型侧工具 `group_manage`

- 之前只有界面按钮能建群，模型侧没有对应的手；`partner_manage` 却能建/停执事，能力面不对称。
- 动作只开 `create` / `list`；改群、删群、按 uuid 指定成员**不做**（见方案 §明确不做）。
- **核心实现抽到 `group-manage.ts`**：`createGroupChecked()` 是建群校验与落库的唯一一份，
  `POST /api/v1/groups` 改为调它（400 文案逐字未变，groups 探针 21 项回归全绿）。
  `GROUPS_ENABLED` / `groupsAvailable()` 从 `group-api.ts`（HTTP 装配层）下沉到这里并 re-export，
  工具装配按同一开关决定注不注册——工具不该反向 import HTTP 层。
- 权限与 `partner_manage` 逐字一致（只有总管 / 主对话）。
- `WRITE_TOOLS` + 自主轮风险表 `new_task` 同步登记（D14 备忘）。
- 模型侧只收**名字**：`members: ["阅读助手","记账助手"]`、`responder?: "阅读助手"`，值日缺省取第一位；
  重名 / 查无此人拒绝并列出可选执事。

## 实测中修的自身 bug

1. `.text-input` 不存在 → 输入框退化成浏览器默认框（本次主因）。
2. `.modal-input` 被 `flex:1` 压成 19px（老问题，影响两个模态）。
3. 列表副行「不 @ 阅读助手 回」断句歧义 → 复用 `gsResponderShort()`。
4. 群名与副行两个 `span` 并排成一行（`display:flex` 漏在父级）。
5. 值日可被点掉 → 出现"谁都不值日"的假状态，而提交会默默补第一位：改成不可点标记。
6. `×` 被动作按钮宽度推着跑（两行差 34px）→ 动作槽与移出槽分开，`×` 固定 24px。
7. 行高在 34–37 之间跳（标记 24 / 按钮 26）→ 统一 26 + `min-height:37`。
8. 加了 `gcf-tag` 又在改版里删掉「总管」重复标签 → 死样式一并清掉。

## 刻意没有

改群/删群/按 uuid 指定成员的模型工具；共 2 人以下或 7 人以上建群；群名唯一性约束
（同名群允许，仍在界面里靠人分辨）；群组列表的排序/搜索（v1 仍按 `updated_at`）。
