## 做了什么

### 服务端

- **删除**：`src/topics.ts` / `src/topic-runtime.ts` / `src/topic-api.ts` / `src/topics.test.ts` / `scripts/topic-probe.ts`。
- **摘线**：`index.ts` 不再挂 `/api/v1/topics*`；`agent/lifecycle-harness.ts` 删 `topics` section、`TopicTask` 注册、`researchExt` 安装与 `deps.topics`；`lifecycle-injections.ts` / `injection-registry.ts` / `context-defaults.ts` / `context-inspect.ts` 删两段课题注入与字段名；`agent/session-open.ts` 删 `configureResearchChat`。
- **工具**：删 `propose_topic`（`tools.ts` / `tool-pool.ts` / `tool-capability.ts` / `partner-tools.ts`）；`web_search` **解耦**——从「`TOPICS_ENABLED && deps.search`」改为「有 `deps.search` 就注册」，描述去掉“课题研究”措辞。
- **其余**：导出包不再收集 `library/topics.json`；`plugins.json` 删「长期课题」卡与分组 key；`package.json` 删 `topic` 探针脚本与 `topics.test.ts` 测试项；`http-probe` / `partner-relay-probe` 去掉课题期望与 `TOPICS_STATE_PATH`。
- **兼容保留**：`partner-session-role` / `partner-types` 的 `role="topic"` 枚举值不删（历史会话可能带），只是不再有新写入方。

### 前端

- **删除**：侧栏课题分区 / 轨道钮 / 悬停卡 / 提议卡 / 课题详情与时间线；`groups-topics.js` 拆出群组部分为 `groups-list.js` 后删除；`topic-proposal.js` 中与课题无关的插话 / 轮末回读 / 待审批补挂迁到 `turn-reconcile.js` 后删除；`style-19-topics-review.css` 只删课题侧栏 / 时间线 / 提议卡区段，搜索源与任务中心样式保留。
- **新增**：`research-tag.js` —— 项目「研究」标记，纯 `localStorage`（`lifediary.researchProjects`），侧栏项目行 / 设置项目卡 / 轨道项目菜单显示小标签；右键或 ⋯ 菜单可开/关。不写服务端、不进契约、模型不可见、不同步手机。
- 同日补：侧栏项目行右键菜单三项（查看此项目 / 研究标记 / 项目设置）去掉解释行 `hint`，并去掉「研究标记」与「项目设置」之间的分隔条——只有三项，隔开显得断档。
- 侧栏 `SIDE_SECTIONS`、`dom.js` 引用、`index.html` 轨道/分区/浮层、`rail-card.js` 课题卡、`tool-meta.js` 的 `propose_topic` 全部清掉。

### 文档

- `接口文档.md`：目录去掉长期课题、`PROMPT_TAIL_INJECTION` 去课题简报、env 表删 `TOPICS_ENABLED` / `TOPICS_STATE_PATH`。
