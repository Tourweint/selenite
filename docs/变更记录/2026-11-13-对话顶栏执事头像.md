# 2026-11-13 对话顶栏执事头像

## 改了什么

| 文件 | 改动 |
|---|---|
| `ts/apps/server/web/index.html` | `.top` 里把标题包进 `.top-id`，前面加一个 `#chat-head-avatar`（`.pt-avatar chat-head-avatar`，默认 `hidden`） |
| `ts/apps/server/web/style.css` | 新增 `.top-id`（横排、gap 8px）与 `.chat-head-avatar`（26px）；`.top h1` 原规则不动 |
| `ts/apps/server/web/app.js` | `el` 增加 `chatHeadAvatar`；新增 `syncChatHeadAvatar()`；在 `openChat` 起手、`startNewChat`、`loadRoster` 三处调用 |

## 为什么

用户要求：「这个框应该显示我跟谁聊天就是谁的信息……执事的这个名字是对的，但是没有头像，加一下头像吧；总管就不用了。」

改造前主对话顶栏只有一个 `#title`：执事专线能把名字显示对（`partnerDisplayName`），但没有任何身份标记；
群组顶栏早有复合头像（`#group-head-avatar`），两边不对称。现在执事专线补一张跟侧栏花名册同源的脸。

## 口径

- 头像只属于「某个人」。`partner-<id>` / `partner-<id>-group-<gid>` → 该执事头像 + 名字。
- 总管不摆头像：他不是「某个人」，他的名字在这条会话里就是会话自己的标题（现名「我的主对话」）。
- 普通 worker 会话同样不摆头像。两种情况整块收起，标题仍顶在最左，与改造前一致。
- 头像数据取 `state.partners`（与花名册同一份），花名册晚到或改完头像重拉时由 `loadRoster` 补同步；换会话时先按新 id 重摆，避免上一位的脸挂在新会话标题旁。
- 顶栏头像只做展示，不可点（点头像进编辑仍是侧栏花名册那只按钮的行为，本批不改）。

## 验证

  - 总管会话（「我的主对话」）：无头像，标题位置与改造前一致。
  - 群会话「书房小事」：仍是原复合头像（2×2 成员拼图）+ 群名，无回归。
  - 前端控制台无报错。
- 截图（临时留存，`.screenshots/` 不进 git）：`.screenshots/gap/head-partner-after.png`、`head-partner-crop.png`、`head-chief-after.png`、`head-group-chat.png`。
- **没验的**：手机端（lifediary，Kotlin/Compose）顶栏是另一套布局，本批不动；执事头像在 26px 下的多套主题对比度只看了当前主题。

## 已知边界

- 花名册没拿到（首帧失败 / 403）时执事专线只有名字没有头像，等 `loadRoster` 回来自动补上；不拿首字兜底成一张假脸。
- 群组顶栏的复合头像逻辑另有一套（`paintGroupAvatar`），本次不合并、不改尺寸。

## 追加（同日第二改）：总管顶栏回到「总管」，侧栏不再是编辑面

### 改了什么

| 文件 | 改动 |
|---|---|
| `app.js` | 新增 `chiefDisplayName()`；`openChat` / `startNewChat` / 首帧 / 就地改名四处统一：`chatKind=chief` 的顶栏写总管的名字，不再拿会话标题 |
| `index.html` | 总管条目头像由 `<button>` 改成 `<span>`，删掉「编辑总管头像」语义；静态标题 `新对话` → `总管` |
| `app.js` | 删掉总管头像的编辑监听；花名册行头像由 `<button class="avatar-edit">` 改成纯 `<span>`（连带收起轨道浮卡，同一份 `renderRoster`） |
| `app.js` | `syncChiefAvatar` 不再往头像写「编辑 X 头像」的 aria/title |

### 为什么

1. 用户报：「总管的名字应该改回总管」。原来顶栏优先显示会话存储标题，那条总管会话叫「我的主对话」，于是顶栏跟着显示会话名。现在顶栏只回答「我在跟谁说话」：总管会话一律「总管」，改名只影响侧栏清单那一行。
2. 用户报：「侧栏里也能改头像，跟设置里是一样的，别这样；只能从右边改，改字去设置」。原来侧栏每行头像都是编辑按钮，点开的是同一个「改人设」弹窗（头像 / 名字 / SOUL / 模型链），与设置→执事完全重合。现在侧栏只负责「打开会话」：点头像跟点名字一样都是开会话。改头像 / 改名字去**右侧对话设置的人设页**或**设置→执事**。

### 口径

- 顶栏 = 身份，不是会话名。执事 → 执事名；总管 → 总管名（人设里改过名则跟随）；普通 worker → 会话标题。
- 侧栏三条路径（总管条目、执事花名册、收起轨道的浮卡）头像都只画不改；`openEditPartnerModal` 只剩设置页「改人设」和右侧人设页两个入口。

### 验证

- 产品浏览器（632×665，侧栏窄屏收轨）：总管会话顶栏 `#title` = 「总管」；点轨道浮卡里阅读助手的头像 → 打开阅读助手会话（顶栏「阅读助手」+ 头像），没有弹编辑框；`#partner-roster` 三个头像与总管头像都是 `SPAN.pt-avatar`；右侧对话设置抽屉里「阅读助手 · 人设 v12 · 点头像或名字改」仍在；控制台无报错。
- 截图：`.screenshots/gap/chief-title-now.png`、`side-no-edit.png`。
- **没验的**：宽屏展开侧栏下逐行点头像的手感没实拍（逻辑同一份 `renderRoster`，与浮卡同源）；设置页「改人设」弹窗本次未动，未回归测试。
