# 2026-11-24 任务中心补「豆包 CLI」打手卡

## 用户口径

任务中心没显示派给豆包 CLI 的任务。豆包 2026-11-23 已作为第六档外部执行器接入
（见 `2026-11-23-豆包CLI执行器（第六档外接CLI）.md`），但任务中心的前端固定表没跟着补。

## 改了什么

| 文件 | 改动 |
|---|---|
| `web/tasks-model.js` | `EMPLOYEE_LABEL` 加 `doubao: "豆包 CLI"`（否则列表 / 详情原样显示 `doubao`）；`TASK_HITTERS` 加 `{ id: "doubao", label: "豆包 CLI" }` |

豆包单的 `employee` 就是 `"doubao"`；缺的只是任务中心「打手」区按固定 id 渲染的那张卡。
