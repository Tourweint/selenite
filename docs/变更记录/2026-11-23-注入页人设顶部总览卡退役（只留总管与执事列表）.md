## 为什么删

用户口径：这一页「上边新加的不太对，只保留底下那些」。

- 卡里的总管 / 执事 / 普通助手和底下 `partner-list` 是同一批对象：底部列表本来就
  「普通助手置顶 + 每个执事一行」，等于同一份东西列了两遍。
- 卡多出来的只有「派活工人（池）」一行；池工人不是可点进去改档案的角色，它的
  人设就是普通助手那一份，想看它的九段走 `#/settings/context?role=dispatch-worker`
  （上下文 tab 已经能选到这一档）。
- 所以删除不丢入口：总管 / 执事 / 普通助手仍从底部列表进；池工人的上下文仍从
  上下文 tab 的「派活工人（池）」角色进。
