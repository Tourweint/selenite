# 变更记录：2026-11-18 Agent 设置页四分区改版 + 工具池动效

> 范围：纯前端 `ts/apps/server/web/`（settings-base / settings-router / settings-context / settings-executor / settings-tools / style-14 / style-16 / style-25）。零契约、零服务端改动、零 env。

## 为什么

用户 2026-11-18 口径：设置 → Agent 这一页"太丑了"。具体三条：

1. 顶部四个子菜单（人设 / 上下文 / 工具 / 派活）只是挤在一起的小文字按钮，想要更像样的版式；
2. 工具页鼠标移到行上会盖一块**灰色方框**，不要；
3. 工具行点开的详情是硬切出来的，想加一个渐显/撑开的动画。

这是"主要调整的设置页"，值得按页面级版式改，而不是只补两个 hover。

## 改了什么

### 1. 四分区导航改成四张卡（`settings-base.js` + `style-14`）

- 每个 tab = 图标 + 名称 + 两三个字的注脚，四张并排：
  **人设（是谁）/ 上下文（看到什么）/ 工具（能做什么）/ 派活（谁去干）**。
- 图标沿用 Lucide 口径：user / layers / wrench / send。
- 选中卡：`--accent-soft` 底 + `--accent-line` 描边，图标底换成 `--accent-container`；
  未选中卡与页面其他卡同底（`--card`），只弱化文字。
- 悬停**不铺灰底**，只提亮字与描边；窄窗 ≤800px 收成两列（≤460px 再压小图标与内距）。
- 切 tab 仍走四条旧 hash（`#/settings/partners|context|tools|executor`），路由与老书签零改动。

### 2. 子页标题去重（`settings-router.js` / `settings-context.js` / `settings-executor.js`）

导航卡已经写着分区名，内容里不再重复：

- 人设：去掉外层「人设」标题，直接用 **「总管与执事」+ 新建执事**（动作并进 `.set-sec-head`）；`.pt-head` 退役。
- 上下文：去掉「上下文」标题，工具栏（当前会话 / 默认开销 / 会话选择 / 占比 / 窗口 / 刷新）直接作为页入口。
- 派活：标题从「派活」改成 **「执行器」**（这一页真正的对象），保存按钮仍在标题右侧。
- 工具：保留「工具池」（不是 tab 名的重复，是具体对象）。

### 3. 工具池 hover 与展开动画（`settings-tools.js` + `style-25`）

- 行悬停不再给 `td` 铺 `--card-high`：只把工具名提到 `--text`、箭头提亮，保留"可点"的暗示。
- 池胶囊（常驻/按需）在本页悬停也不铺底，只把字色换成强调色（`.tool-pool-table .pf-tool-mode:hover`）。
  人设页的同款胶囊行为不动。
- 详情内容包进 `.tool-pool-detail-inner`；展开/收起走 220ms 的 **height + opacity** 过渡
  （`cubic-bezier(.2,.8,.2,1)`）。动画只负责过程，终态交回 CSS：
  - 不写内联终态，`fill: "forwards"` 保住终态，`onfinish` 里再 `cancel()` 交回自然高度；
  - 收起时先 `hidden = true` 再取消，避免闪回完整高度；
  - 连点先取消上一段，不叠动画；
  - `prefers-reduced-motion` 下直接开关，不做动画。

## 刻意不做

- 没改四个页面的内容结构、数据与交互（上下文棋盘、工具池保存、派活检测都原样）。
- 没给导航加常驻说明段：四个注脚已经承担"这个 tab 是干嘛的"，再解释就违反页面密度口径。
- 没动人设列表卡的悬停底色：用户这次只点名工具页的灰块；列表卡是"整卡可点"的另一套语言。
- 没加 env 开关：纯样式/版式改动，无行为分叉可切；回滚 = revert 本批文件。
