# 对话工作归属常显（worker 只读项目标签）

日期：2026-11-18
状态：已落地（服务端 + 桌面端 web；手机端不涉及）
方案：`docs/设计方案/2026-11-18-对话工作归属常显（worker只读标签）.md`

## 起因

普通对话（`chatKind=worker`）创建时把「当前项目主文件夹」钉进 `pi.agent.cwd`，没选项目才落主工作区；
但输入框左下角的项目 pill 只在**还没落盘**的新会话显示，发出第一条消息后就永久消失，首屏空会话
那条启动路径甚至从来没画过 pill（`web/app.js` 的启动段只改标题，没有调 `syncChatProjectPill()`）。
用户看不到一条已有 worker 对话到底在哪个项目/工作区干活。

用户口径：左侧侧栏选中什么，新对话就落在什么；把归属**常显在输入框里、只读、不可改**。
任务专线仍在侧栏按「总管 / 各执事」分组（`chats-groups.js`），本次不动。

## 改了什么

### 服务端

- 新增 `agent/chat-workdir.ts`：纯投影 `resolveChatWorkdir`（project / workspace / dir），
  不读库、不抛错，单测不启 durable。
- `agent/session-index.ts` 新增 `chatWorkdirOf(chat)`：读 `conversation.agent(CTX)` 的 `cwd` +
  `ChatProjects.byInternal` + 项目库；项目已删 → 目录名兜底；有项目绑定但无 cwd → 项目主文件夹。
- `GET /api/v1/agent/chat/:id/messages`：仅 `chatKind === "worker"` 且开关开时，两个响应分支
  （普通 / `sinceSeq` 补帧）都 spread `chatWorkdir`。
- `CHAT_PROJECT_LABEL`（默认开、hot）：`flags.ts` wrapper + `plugins.json`「对话基本能力」条目 +
  `.env.example` 注释；`/agent/policy` 投影 `chatProjectLabel`。

契约（纯增量）：

```json
"chatWorkdir": { "kind": "project | workspace | dir", "name": "…", "path": "…", "projectId": "…（仅 project）" }
```

### 前端

- `web/chat-project.js` 重写为只读展示：新建态读 `state.switcher`（当前项目 / 工作区），落盘后读
  服务端 `chatWorkdir`；首条消息 `start` 帧时冻结当前侧栏选择。删掉 `picked`、菜单、`chatProjectPayload`。
- `web/index.html`：`#chat-project-pill` 由 `<button>` 改静态 `<span>`，删 `#chat-project-menu` 与 chevron；
  `dom.js` 删 `chatProjectMenu`；`style-11` 去掉旧菜单样式，加 `.project-pill.is-static` 只读态。
- `web/chat-open.js`：打开会话先收起旧标签，回读后 `setChatWorkdir(data.chatWorkdir ?? null)`。
- `web/composer-send.js`：`start` 帧只在**新会话**冻结归属（续话不拿当前侧栏选择顶替），不再发 `dirPath`。
- `web/project-switch.js`：`applyProjectData` / `selectProject` 末尾 `syncChatProjectPill()`；
  修正“普通对话固定落主工作区”的过期注释。首屏空会话的显示由 `applyProjectData → sync` 自然补上。
- `web/plus-menu.js` + `web/state.js`：`capabilities.chatProjectLabel` 默认 true、从 `/agent/policy` 赋值。

### 契约 / 文档

- `接口-端点1` §2.2：响应示例 + `chatWorkdir` 字段说明。
- `接口文档` §6：新增 `CHAT_PROJECT_LABEL` 行；`CHAT_DIR_PICK` 行补“桌面端选择器退役、契约保留”。
- `系统架构`：修正“普通对话固定落主工作区”的过期口径，补输入框常显只读归属。
- `2026-11-17-新建对话选目录…` 设计文档文首补 11-18 更新说明（选择器退役，契约保留）。

## 明确不做

- 不允许改已落盘会话的项目 / cwd（仍是创建时快照）。
- 不给总管 / 执事 / task 专线加这个标签；侧栏按派活人分组不动。
- 不把 task 会话绑到票的 project（另立项）。
- 不恢复输入框里的选项目菜单；`dirPath` / `CHAT_DIR_PICK` 契约保留给 API / 手机。
