## 改了什么（按契约顺序）

**1. 契约（`ts/packages/shared/src/index.ts` + `docs/基线文档/接口-端点4-执事例行与自主轮.md`）**

- 新增 `PARTNER_VOICE_LIMITS`、`PartnerVoiceRuleKindSchema`、`PartnerVoiceRuleSchema`、
  `PartnerVoiceView`：学习只落规则 + ≤40 字短例句；`jargonCount` 单独给。
- 新增 `PartnerPersonaContentsSchema`（人设库整份快照用的运行时形状）与
  `PARTNER_PROFILE_LIMITS`、`PartnerPersonaProfileSnapshotSchema`、
  `PartnerPersonaProfileSummary`、`PartnerPersonaProfilesView`。
- 新增 `PartnerProactivityView`、`PartnerProfilesActionSchema`（`save` / `apply` / `remove`
  一次只做一件）。
- `PartnerPersonaSwitchesSchema` 增 `nudgeEnabled`（挂念提醒子开关，默认关）。
- `PartnerPersonaView` 增 `voice` / `proactivity` / `profiles`（`enabled=false` 时都为 `null`）与
  `limits.voice` / `limits.profiles`；`switches` 增 `nudgeEnabled`。
- `PartnerPersonaPatchSchema` 增 `profiles`（`.strict()` + refine：一次只能做一个动作）。

**2. 学习（新文件 `ts/apps/server/src/partner-learning.ts`，默认关）**

- 结算钩子（`agent/settled.ts`，只认执事 canonical 主会话、只读最后一条用户消息）做确定性统计：
  句长倾向、称呼习惯、常用语气词、引号里的黑话候选；短例句滚动保留最多 8 条（每条 ≤40 字）。
- 落伙伴家目录 `persona/voice.json`：`{version, updatedAt, samples, stats, rules}`；
  规则 `kind` = `sentenceLength` / `address` / `interjection` / `jargon`。
- **反思频率** env `PARTNER_LEARNING_FREQUENCY`：
  - `weekly`（缺省）：既有周盘点例行跑完后，用执事自己的模型链（候选链第一个可用项，缺省当前模型）
    把统计 + 短例句提炼一次；
  - `settle`：每 5 次结算抽查一次。
  模型不可用 / faux / 失败 → 保留确定性规则，不编造；不新造调度。
- 注入：`learning` 开且规则非空时，`buildPartnerTurnContext` 在在办段之后加 `【表达习惯】`
  （id `partner_learning`，order 305）；模块关 / 总开关 false / `MEMORY_ENABLED=false` 整段不出现。
- **红线**：只落规则与 ≤40 字短例句，不存整段对话原文；日志只记条数 / 枚举；
  样本与规则不进日志、不进 export-bundle、不进团队包。

**3. 主动性（新文件 `ts/apps/server/src/partner-proactive.ts`，默认关）**

- 追问建议：纯提示词 `【主动一点】`（id `partner_proactivity`，order 306），模块关不注入。
- 挂念提醒：子开关 `nudgeEnabled`（默认关）。从主人 `kind=intention` 记忆里只挑**今天相关**的一条
  （正文含 今天 / 今日 / 今天的 `M月D日`，或 `expiresAt` 落在今天），引 ≤40 字；
  **正文必须带 `【执事名】` 身份前缀**；经既有提醒链（`ReminderTask` → `setReminderDeliverer` →
  `sayInConversation`）下发；**一天最多一条**（本地日期落 `persona/nudge.json`）；
  排提醒前查 `conversationIsBusy`，不打扰正在跑的会话。
- **主动开口时机不新造调度**：只挂两处既有唤醒——
  ① 派活完成即唤醒（`delegation-wake.ts`）成功一轮后；
  ② 既有周盘点例行（`routines.ts` 的 `runOnce`）成功后。
  没有这两类事件的执事不会自己找上门（已知边界，不是保证每天一条）。
- 装配：投递器在真正发提醒时**动态 import** `partner-runtime` / `agent/session` / `reminder` / `agent/shared`
  （`partner-context` 会 import 本模块，静态 import 会成环；动态 import 在调用时才求值，依赖方向仍单向）。

**4. 人设库（新文件 `ts/apps/server/src/partner-profiles.ts`，默认关）**

- `persona/profiles.json`：命名快照，`{version, items:[{id,name,createdAt,preset,modules,contents}]}`；
  **上限 5 份**，名称 ≤24 字，同名拒绝（不静默覆盖）。
- `save` 拍当前整套 contents + **完整有效开关表** + preset；`apply` **整份写回**
  （`replacePersonaContents`，不是字段合并）+ `setPersona`，**SOUL.md 一个字节都不动**；
  `remove` 删一份。
- 模块关：GET 仍回列表（内容保留），存 / 应用 / 删一律 400 带说明；总开关 false：端点字段为 null、动作全拒。

**5. 端点（`companion-api.ts`）**

- GET 增 `voice` / `proactivity` / `profiles` / `limits.voice` / `limits.profiles` / `switches.nudgeEnabled`；
  `enabled=false` 时 `voice` / `proactivity` / `profiles` / `living` 全为 null。
- PUT 增 `profiles` 动作；**必须单独提交**（不能和 preset / modules / switches / contents / living 混批，
  否则 400 且一个字节都不写）。`save` 拍当前整套；`apply` 整份写回并刷新开关 / 预设；`remove` 删一份。
  动作失败 400，不静默半写。

**6. 注入顺序（缓存前缀资产，有意变更）**

`INJECTION_ORDER` 新增两个 id：`partner_learning: 305`、`partner_proactivity: 306`，
位置在 `partner_status`（300）之后、`partner_impression`（310）之前。
顺序快照测试已同步；工具描述与注册顺序**未动**。

**7. 前端（`web/partner-profile.js` + `style-22-partner-profile.css`）**

- 人格模块区补三行：学习（已学规则条数 + 查看）、主动性（挂念开关 + 行内「挂念」子开关）、
  人设库（`N/5 份` + 查看）。
- 学习弹层：只读展示规则 / 短例句 / 黑话。
- 人设库弹层：存当前整套 / 应用 / 删除；应用后页面内容与开关一起刷新；应用不改 SOUL。
- 开关 / 预设 / 子开关仍即时 PUT；总开关关着整块隐藏。

## 开关名

| `PARTNER_PERSONA_MODULES` | env（批1 已有） | 总开关；false = 三块全停（字段 null、动作 400、钩子短路） |

## 与任务书 / 方案的偏差（如实列出）

- **主动开口时机**：任务书允许"做不动就标本批不做"。本批**没有新造调度器**，只挂两处既有唤醒
  （派活完成唤醒、周盘点例行）。因此没有这两类事件的执事不会主动开口；通用定时开口留到以后单独立项。
- **手机端**：只做"看 + 切预设 / 开关 + 活状态条数 / 预览"，字段级编辑不做（任务书允许）。
  手机端契约零新增，直接消费批1/批2/批3 已有的 persona 端点。
- 学习模型的提炼频率默认 `weekly`（周盘点后一次）；`settle` 档才每 5 次结算抽查。
  没有模型时只保留确定性统计，不编黑话解释。

## 已知边界（未做 / 未验证，2026-11-15）

- 学习样本与规则不进团队包 / export-bundle；团队包导入的执事从空 `voice.json` 开始。
- 人设库应用是整份覆盖，不提供逐字段 diff / 撤销 / 导入导出。
- 挂念只从 `kind=intention` 的**主人 global 记忆**里挑，且只认"今天"；没有今天相关意图就不发。
- 主动开口不覆盖"主人正在干活"的会话（排提醒前查忙闲）。
- 手机端不改人格内容、不建人设库、不写学习样本。
