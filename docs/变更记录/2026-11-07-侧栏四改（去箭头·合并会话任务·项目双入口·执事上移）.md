# 2026-11-07 侧栏四改（去箭头·点整行折叠·合并会话与任务·项目双入口·执事上移）

用户原话（四条）：

> 1. 「箭头别要了，点击这个框相当于收起或展开，在右边留个加号。」
> 2. 「项目的加号：用于创建新项目或添加子项目。」
> 3. 「任务中心与最近会话：任务中心的加号是加一个普通的对话；"最近会话"其实没啥用了，
>    它和任务中心的效果是一样的，这两个可以合并一下，就用一个加号。」
> 4. 「把"执事"往上放一点，应该排在偏上面的位置。」

## 一、去箭头：整行就是折叠把手

- 删掉 `.sec-chev-btn` / `.sec-chev`（JS 与 CSS 一并清空，`grep sec-chev` 现在 0 命中）。
- 分区头改成**一个 `<button class="side-sec-head">`**：图标 + 名称 + 计数，点它 = 收起/展开。
  行尾只留一个 ＋。
- 布局改成两行网格（`grid-template-columns: 1fr auto`）：第一行 = [整行按钮][＋]，
  第二行 = 分区体（`grid-column: 1 / -1`）。收起时只 `display:none` 分区体。
- 折叠状态不再有箭头指示，靠"展开时有内容 / 收起时只剩一行"直接可见；hover 给一层底，
  表明这一行是可点的。

## 二、项目的 ＋ 变成双入口

点 ＋ 弹一个小菜单（挂 body 下，坐标按按钮实测，右侧放不下自动翻边、点外面关）：

| 入口 | 语义 | 走什么 |
|---|---|---|
| **新建项目** | 目录还不存在 | `POST /projects` 提交待确认 → 立即 `confirm`（服务端 `mkdirSync` 建目录后登记） |
| **添加已有子项目** | 目录已在硬盘上（多是已有仓库） | 沿用原 `openAddSubprojectModal`：绝对路径 + 立即 confirm，**不建目录** |

两行都带一句解释——「新建项目 / 添加子项目」这两个词本身看不出差别，
所以把"要不要建目录"写在行里。新建项目要求填**相对主工作区**的路径，填绝对路径会被拦下
并提示改走「添加已有子项目」。

## 三、会话与任务中心合并成一块「对话」

理由（用户口径）：这两块的实际效果一样——都是"我有哪些对话"。

- 分区从 5 块变 4 块：**执事 / 对话 / 项目 / 群组**。
- 「对话」分区只有一个 ＋ = 新建一条普通对话（原「任务中心的加号是加一个普通的对话」）。
- 列表里同时出现两类行：
  - **会话行**（`.chat`）：普通对话，点进对话，带置顶/改名/移除；
  - **任务行**（`.task-row`）：有派活的对话，前面是聚合灯，点进任务中心那张卡。
- **去重**：已经在会话列表里出现的对话，任务行不再重复渲染（同一对话不能两行）。
  为此会话行加了 `data-conv`，任务行渲染前按它过滤。
- **空态统一**：两处各写一句会冒出两条互相矛盾的提示，改成 `renderSideListEmpty()` 一处判定——
  会话行与任务行都没有内容时，才显示「还没有对话。用 ＋ 新建一条。」
- 分区底部的「打开任务中心 →」保留（完整看板仍在那页）。

## 五、五改（同日）：展开/收起动画

用户原话：「需要把这个展开的动画做出来，就是点击这个栏目，然后它这个动画」。

### 之前是什么样

`.side-sec.is-collapsed .side-sec-body { display: none }` —— 点一下瞬间开合，没有过渡。

### 现在怎么做的

三层结构 + 高度轨道过渡：

```
.side-sec-body   grid，grid-template-rows: 1fr → 0fr（只负责轨道过渡）
  .side-sec-clip  overflow: hidden + min-height: 0（把内容裁掉）
    .side-sec-inner  真正的内容（展开时淡入 + 下落 4px）
```

- **为什么用 `grid-template-rows: 0fr → 1fr`**：内容高度是变的（会话多了、任务行多了都会长），
  写死 `max-height` 要么裁掉最后几行、要么留一段空白；fr 轨道按内容算，不需要知道真实高度。
- **时长**：展开 240ms 减速曲线（内容"落下来"）；收起 160ms 加速曲线（手指离开后不该再等）。
  内容侧：展开 `opacity 180ms + translateY(-4px → 0)`，延迟 30ms 跟高度错开一帧。
- **收起时不提前淡出**：一开始给内容加了 110ms 的 opacity 过渡，70ms 时内容已经看不见、
  只剩一截空壳在收缩，观感像"先隐身再收框"（中间帧截图核对过）。现在 opacity 归零推迟到
  160ms 之后（= 收起结束），全程可见地被裁切卷走；归零只是防止 0 高时残留描边。
- **减少动态效果**：`prefers-reduced-motion: reduce` 下 `transition: none`，直接切。
- **折叠状态仍存 localStorage**，刷新后保持。

### 顺带修掉一个真 bug：群组点了没反应

四个分区的折叠绑在一个循环里（`SIDE_SECTIONS`），但群组**另外又单独绑了一次**
`toggleSection("groups")`。同一元素两次 toggle 互相抵消：点一下先收起、紧接着又展开，
表现成"群组点了没反应，也没有动画"。已删掉重复绑定，并留注释说明为什么不要再绑。
