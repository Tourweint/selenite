## 权限档口径（2026-11-23）

| 执行器 | 界面档位 | 映射 |
|---|---|---|
| Claude Code | 只读 / 可改 / 全权 | `plan` / `acceptEdits` / `dangerously-skip` |
| Codex | 只读 / 可改 / 全权 | `read-only` / `workspace-write` / `danger-full-access` |
| OpenCode | 只读 / 全权 | `--agent plan` / `--auto`（edit 与 full 同档，不再画第三段） |
| 豆包 | 风险确认 / 全部允许 | `ask_risky` / `always_allow`（不画「只读」） |
| CodeBuddy / Qoder / pool | 固定（`permissions:null`） | 不变 |

内部契约不动：`EmployeePermission`、`.data/executor.json`、ticket 快照仍是 `read / edit / full`；
旧配置里豆包 `permission:"read"` 仍按 `ask_risky` 执行。

## isolation 口径（2026-11-23）

- `auto` / 不传 = 跟随 `CHANCELLOR_TASK_ISOLATION`（且仅 git 项目开 worktree），**不写 ticket 快照**；
- `worktree` = 这张单强制隔离；非 git 项目回落 direct（`isGitProject=false`），不报错；
- `direct` = 直接在项目目录干；
- 续跑 / 崩溃恢复按 `ticket.options.isolation` 原单快照走，新参数不生效；
- 回滚：不传即 auto，行为与改动前一致，全局 env 仍是缺省。
