# 前端细节五件：滚动、纪律红线、禁用模块弹窗、悬停提示（2026-11-16）

> 用户口径：继续挑前端小细节。五件事全是界面行为，不动接口、不动提示词、不动存储。

## 改了什么

### 1) 设置 → 上下文：展开原文不再套内层滚动

文件：`ts/apps/server/web/style-24-context.css`

- `.ctx-text` 去掉 `max-height: 440px; overflow: auto; overscroll-behavior: contain`。
- 展开后的系统段 / 工具 Schema / 技能索引 / 记忆原文都随设置页整页滚动。

原因：原来鼠标停在「技能索引」里时，滚轮被困在内层 440px 的框里，外面的设置页怎么滚都不动；
`overscroll-behavior: contain` 又把到达边界的滚动链也掐断了。用户要的是「外面继续滚」。

### 2) 人设 → 纪律弹层：红线并入同一列卡片，底部改「保存」

文件：`ts/apps/server/web/partner-profile.js`、`ts/apps/server/web/style-22-partner-profile.css`

- 去掉 `.pf-disc-list` 的 `max-height: 58vh; overflow: auto`：七个纪律节 + 红线共用弹层这一条滚动轴，
  不再出现「上面一节自己滚、红线钉在弹层底下」的两层结构。
- 主人数据红线从弹层底部的裸 `<pre>` 改成与七节同款的 `.pf-disc-section` 卡：
  卡头「主人数据红线 · 固定 · N 字」+ 只读正文（`.pf-disc-red`，等宽、保留换行、无内滚）。
- 弹层底部按钮由「关闭 / 去岗位契约」改为「关闭 / 保存」；「去岗位契约」入口移除。
- 新「保存」= 把所有改过的节合并成一次 PUT（单节「保存这一节」仍保留，二者不冲突）；
  没有改动时按钮禁用，保存失败保留草稿。

原因：用户原话「主人的数据红线固定在地下了……做成和上头一样的风格」「底下这个改成保存」
「岗位契约也别去岗位契约了……不要这个就行了」。

### 3) 没开的人格模块：点卡弹小窗，不再只在页脚留一行字

文件：`ts/apps/server/web/partner-profile.js`

- 点击 `persona.modules[id] !== true` 的模块卡，改为 `openConfirm` 小弹窗：
  标题「「口吻」还关着」，正文「打开之后才能改内容；关着改了也不进提示词。」，
  按钮「先不 / 打开并编辑」。
- 点「打开并编辑」会先 PUT 打开该模块，成功后再进入原来的编辑弹层；失败则停在页面提示，不硬开。
- 父闸锁住的场景（学习模块 ← 记忆总闸、结果整理 ← 工具结果整理）保持原样：显示关且不能打开，
  仍在页脚说明父闸名字。

原因：用户原话「我改动一个没开的那个，想往里改，它就底下先让打开，再改内容——把这个做成小弹窗吧」。

### 4) 全员悬停提示：贴鼠标落点，不再飘到屏幕角

文件：`ts/apps/server/web/hover-tip.js`

- `hoverTipState` 增加鼠标坐标；`mouseover` 时持续更新（同一元素里换一段文字也跟着更新）。
- `showHoverTip` 有鼠标坐标时以落点为锚：提示左缘贴光标，默认在光标上方 10px，顶上放不下翻到下方，
  右侧/左侧越界时向视口内收；键盘聚焦没有鼠标坐标时仍退回元素矩形。
- 定时器等待的 450ms 里锚点节点若被重渲染摘掉（`isConnected === false`），直接不弹，
  避免用脱链节点量出 `0,0` 把提示放到屏幕左上角。

原因：用户反馈「有时候鼠标放在文字上，解释性文字离这个文字非常远」。旧实现以元素左缘/上缘为锚，
宽行或整卡的左缘可能离鼠标停的字隔半屏；节点被重绘时还会量到零矩形。

### 5) 弹层按钮条统一（顺手）

文件：`ts/apps/server/web/partner-profile.js`

- 「岗位契约」「当前目标」两个弹层原先在正文里塞一条 `.pf-foot`（撤销 / 保存）再在底部另放「关闭」，
  现在把「撤销 / 保存」并进标准 `.modal-actions` 底栏（sticky），与纪律、口吻等编辑弹层同一形状。
- 无改动时「撤销 / 保存」禁用；有改动才可用。逻辑不变，只是位置与样式统一。

  - 悬停「口吻」标题：提示框 `left=378, bottom=370`，鼠标落点 `(380, 380)`——贴光标上方 10px；
  - 岗位契约弹层底栏为「关闭 / 撤销 / 保存」，无正文内 `.pf-foot`。
- 未跑：`pnpm typecheck`（本次只改 `web/` 下的 JS/CSS，未动 TS）；手机端不涉及。

## 刻意不做

- 不重排设置页 / 人设页的信息架构；本次只动展开框的滚动归属、弹层底栏与提示定位。
- 不把「未开启模块」的开关直接改成常开或自动保存；仍要用户在小窗里点一次「打开并编辑」。
- 父闸锁住的两个模块不做可点提示：它们是「总闸关着、单个改不了」，不是「打开就能改」。
