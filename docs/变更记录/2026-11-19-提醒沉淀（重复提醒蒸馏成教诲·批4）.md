# 提醒沉淀：重复提醒蒸馏成教诲（2026-11-19 批4）

方案：`docs/设计方案/2026-11-19-提醒沉淀（重复提醒蒸馏成教诲）.md`（用户口径：用 Agent 时经常要反复提醒，把提醒总结注入提示词，让它能多往下走——与批2 上报链配套：少犯错 + 犯了能自己上报继续跑）。

## 改了什么

- **收集端（0 token，纯代码）**：新模块 `src/reminder-distill.ts`——近 30 天三路候选：①用户消息含提醒模式词（以后/记住/下次/别再/不要再/每次都）的句子（切句→同句聚合次数/首末时间，`redactSecrets` 打码，超 200 字整句丢）；②`source="taught"` 既有偏好（主人侧键空间，排 partner:/project:）；③`verified_answer` fact。三段合计上限 40，日志只记条数。端点 `GET /api/v1/agent/reminder-candidates`（候选+预填提示词）。复用会话考古的 durable 读取（`readTranscriptSources` 改导出，跳隐藏轮/剥定时头/脱敏同一份逻辑，不另抄）。
- **落盘与采纳（D18：只建议、人采纳）**：新模块 `src/reminder-advice.ts`——建议快照 `.data/reminder-advice.json`（整份替换、原子写）；`PUT /api/v1/agent/reminder-advice` 采纳（`engine.remember` 写 `kind=preference/scope=global/source=taught/importance 0.7`，偏好永不删）/忽略（只摘除）。**采纳闸门**照 `illegalAdviceActions`：采纳原文必须来自当前快照，伪造 400；库里已有同句不重复落。
- **工具**：`save_reminder_advice {items}`（总管蒸馏后一次性落建议清单）——按需池第 10 个成员（注册顺序在 `tool_search` 前，schema-guard 快照同步）、能力声明表登记（workspace/low/never，同 save_skill_advice 口径）、`REMINDER_DISTILL_ENABLED=false` 不上架。
- **前端**：新 `web/reminder-distill.js` 共享流（拉候选→确认弹窗→跳总管+预填，不代发）；记忆页头部小按钮「沉淀提醒」+「沉淀建议」卡（逐条采纳/忽略，悬停 data-tip 解释）；设置抽屉人设二级页同款入口。404=入口与卡都不出现。
- **开关**：`REMINDER_DISTILL_ENABLED` 进插件中心（memory 组，hot:false）。

## 缓存前缀资产说明（工具描述）

`save_reminder_advice` 为新增按需池成员：初始不进请求、不打上游 prompt cache；描述写明"它不写记忆库：采纳是主人在记忆页上的动作"。

## 边界（刻意没有 / 已知限制）

- v1 只做 global：不分会话类型（群会话/任务专线的提醒也算用户说过的话）、不分执事/项目域。
- 不自动聚合：必须用户点入口才收集；聚合计数即时算、不留表。
- `verified_answer` 段探针未端到端覆盖（需 ask_user 全链路），单测覆盖 source 过滤。
- 人设页入口落在设置抽屉人设二级页（`settings-persona.js`）——全仓"教诲/偏好"区块只在记忆页，若要迁执事档案页（`partner-profile.js`）迁一行即可。
