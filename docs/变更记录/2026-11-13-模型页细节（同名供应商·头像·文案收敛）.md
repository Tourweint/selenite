# 变更记录：2026-11-13 模型页细节（同名供应商 / 头像 / 文案收敛）

> 上位口径：用户当日「继续调模型页小细节」六条 —— 同模板要能建第二家、第二家要认得出头像、
> id 别露给用户、解释性文字再砍、删除挪到保存/取消那一行。
> 范围：`web/app.js` + `web/style.css`。**零契约改动**（shared / 接口文档 / 服务端路由一律不动）。

## 改了什么

| # | 落点 | 改动 |
|---|---|---|
| 1 | `nextProviderName()` + `fillProviderForm()` | 同一模板可再建一家。模板名已被占用时预填「magpie 本地网关 2」这样的编号后缀（2/3… 逐个试），而不是让左栏出现两行一模一样的名字；id 仍按既有规则查重（`magpie-2`），不撞现有供应商 |
| 2 | `providerBrandIcon()` + `renderProviderNav()` | 左栏头像先按 id 认模板；认不到再按 Base URL 回认（`templatePlanByBaseUrl`），最后按去掉编号后缀的名字回认。第二家的 id 是 `magpie-2`，原来看不到品牌图标，只剩首字母 |
| 3 | `providerFormMarkup()` / `fillProviderForm()` | 表单头那行 `id: xxx（不能改）` 整行删掉。id 是内部标识（keyEnv 命名、查重、接口主键），用户既改不了也无从使用；`#pv-id` 与 `.svc-form-id` 样式一并移除 |
| 4 | 模型区表头 | 删掉「每个模型可单独配置，随供应商一起保存」；「模型」字段名与「添加模型」并进同一行（`.field-head`），不再是"标签一行、按钮掉下一行" |
| 5 | `.svc-form-actions` | 「删除」从底部 `.svc-danger-zone` 挪进保存/取消同一行（序：删除 · 取消 · 保存），危险区与 `.svc-danger-zone` 样式删除。默认供应商不可删：按钮不再 `disabled`（禁用钮的 tooltip 不可靠），点它走行内提示「默认供应商不能删；先把默认模型切到别家。」。删除确认文案收成「删除「X」之后不能撤销。」——「已有会话下一轮回退到默认供应商」这句按用户要求去掉 |
| 6 | 供应商区页头 | 删掉「Key 只留在本机服务端，不进 git、不进日志、不下发手机。」（`#svc-provider-hint` 与 `applyProviderSecretMode` 里同步换文案的那段一起删）。「新建供应商」从独占一行上移到**分节标题行**（`sectionMarkup` 新增 action 槽），标题与动作同一行；`.svc-head` 删除。自建供应商表单里「填好后保存；Key 只进本机服务端」同理不再显示（`#pv-new-hint` 只留给模板） |

## 第二轮（同日追加）：撤掉文字后，动作回到该在的那一行

用户口径：「去掉解释性文字后，占位不是就空了吗？比如模型和右边添加模型就不在同一行了，
上面供应商右边新建供应商也不在一行了……每次改变后，视觉效果是不是统一了？不只是去掉不需要的东西。」

| # | 落点 | 改动 |
|---|---|---|
| 7 | `sectionMarkup()` | 新增第 4 个参数 `action`：给了就渲染 `.set-sec-head`（标题 + 右侧钮同一行），没给仍是裸标题。调用方只有供应商这一节，其余分节签名不变 |
| 8 | `.set-sec-head` | 标题 19px、按钮 32px，行高会被按钮顶成 32px，标题到内容的间距就从 14px 变成 21px。按钮加 `margin-block: -6px` 把这 6.5px 收回去——实测三个分节的「标题底 → 内容顶」都是 **14px**（默认模型 / 供应商 / 搜索） |
| 9 | 供应商表单「模型」 | `.field-head` 包住「模型」+「添加模型」，按钮贴回字段名那一行；按钮 28px 用 `margin-block: -5px` 收掉多出的行高——实测四个字段名（名称 / Base URL / API Key / 模型）的顶边间距都是 **75px**，和其他字段的节律一致。`.svc-models` / `.svc-models-head` 删除 |
| 10 | 左栏列头 | 删掉面板里重复的「供应商」小标题（分节标题已经写着，两处相隔 30px 是同一句话）；`.svc-nav-title` 样式与窄屏规则里的对应项一并删 |
| 11 | `.svc-tpl-grid` 折列阈值 | 模板选择原来是「视口 ≥560 就两列」，但两列判的是视口、真正装卡的是右栏（≈280px）：823 窗口下每张卡只剩 112px，名字被挤成一列一个字、右卡还被面板裁掉。改成 ≥1080 才两列（该视口下右栏 ≈540，每卡 266），窄窗口一列——实测 823 下网格 231px、卡片 231px，名称与副标题都回到一行 |

## 刻意没做

- **给 id 换个说法留在界面上**：用户的问题是"不知道能干什么"，答案就是"不用知道"——它是内部标识，留着只是噪音。
- **模板卡片标「已有」**：同一家建两家是正当需求（比如网关的另一个端口/套餐），标"已有"会让人以为不能建。
- **把「默认供应商不能删」做成禁用钮**：见上，禁用态在部分浏览器不弹 tooltip，反而更不容易解释清楚。
- **品牌图标进表单头**：这次只修左栏认不出头像的问题，表单头加图标是另一件事。
- **`providerSlug()` 对纯数字 slug 的兜底**（如名称「本地网关 2」会 slug 成 `2`，服务端 `PROVIDER_ID_PATTERN` 允许但难看）：属 id 生成规则，改动会影响 keyEnv 命名，另立项。
