# 2026-11-15 行为开关页收拢与中文化

> 2026-11-16 后续：这一页已从「服务」拆出，独立成「设置 → 插件」；本文记录的是拆分前的形态，
> 拆分见 `2026-11-16-行为开关拆成独立插件页.md`。

## 改了什么

用户口径（2026-11-15）：看不懂「高级开关」是啥、工具活动和底下那堆开关不在一个界面、解释只有悬停太薄、
`MEMORY_EXTRACT` 这类裸 key 看不懂，要求**并到一张卡、全中文、解释写详细、默认尽量都开**。

1. **并卡**（`web/settings-router.js`）：服务页「高级开关」改名「行为开关」；「工具活动」从独立卡
   并入 `#flags-card`，与全部开关同屏同卡。同日第二轮按用户「这一条目可以删」的口径，又把工具活动
   从卡内一行降到**卡尾一句只读说明**（常开、不可配置）；它仍是事后复核的凭据，只是不再占一行。
2. **中文化与常驻说明**（`web/settings-switches.js`）：
   - `FLAG_LABELS` 全量改写：`tip`（悬停）→ `summary`（行内常驻），每行写清「是什么 / 开与关差在哪 /
     默认值 / 何时生效」；补上此前没有中文名的 4 个键：`MEMORY_EXTRACT`（记忆提取方式）、
     `TOOL_PROJECTION`（工具结果整理）、`AGENT_ASK_USER`（结构化提问）、`PARTNER_TEMPLATES`（执事招聘模板）。
   - `MEMORY_EXTRACT` 三档 `auto/llm/rule` → **自动 / 模型 / 规则**；`AUTONOMY_ENABLED` 保持 关 / 只观察 / 开。
   - 按「对话基本能力 / 记忆 / 一生记忆库（对外）/ 自主与派活 / 技能与课题 / 任务与界面」六组渲染，
     组头带一句「这组管什么」；`flags.ts` 以后新加的键落进兜底组「其他」，不会从界面消失。
   - 每行标签尾加徽标：`默认开 / 默认关`（直接读 `defaultValue`）、`已改`（`overridden`）；`需重启`
     （`hot:false`）按用户口径在同日晚些时候去掉，理由见第三轮第 3 条。
   - 卡首说明写清 29 个常驻开关里 27 个默认开、2 个默认关，以及「归档天数 / 上下文压缩」仍在会话页专属卡。
     第二轮把两个默认关的布尔开关翻成默认开后，页首变成 **28 默认开 / 1 默认关**；另一条并行改动新增
     `TOOL_PROJECTION_WORKER`（2026-11-16）后，页面最终为 **30 项 / 29 默认开 / 1 默认关**。
3. **样式**（`style-14-settings-pages.css`）：`.flag-intro` / `.flag-group-head` / `.flag-tag` / `.flag-foot`；
   并给 `#flags-card .row-control` 加 `flex:0 0 auto`，防止三档分段控件被长说明挤成竖排。

## 追加（同日第二轮）

用户口径（2026-11-15）：工具活动「这一条目可以删除」；「没开的对话归档先不开，剩下的全开——这些就是我们
做出来的功能」；「平时正常用不会去动这个」。

1. **删掉工具活动行**（`web/settings-switches.js`）：不再渲染 `flag-acts-row`，卡尾 `.flag-foot` 用一句话
   说明「工具活动常开：对话里始终显示读了哪个文件、跑了什么命令、花了多久；不提供关闭，用来事后复核」。
2. **默认值翻案**（`src/flags.ts` + `src/agent/auto-archive.ts`）：
   - `MINISTER_DISPATCH_AUTHORITY`：`defaultValue` `false` → `true`。这是**修元数据**——消费处
     `ministerDispatchMasterEnabled()` 本来就缺省开（只有明确 `false`/`0` 才关），旧值会让界面把
     "实际开着"的开关标成「默认关」。
   - `ARCHIVE_AUTO_ENABLED`：`defaultValue` `false` → `true`，`archiveAutoEnabled()` 从「显式 true/1/on
     才开」改成「显式 false/0/off 才关」。这是**真的翻默认**：新装 / 删 `agent-flags.json` 后自动归档默认开。
     会话页的 `AUTO_ARCHIVE_DEFAULTS` 与开关占位态同步改 `true`，避免首次进入先画成关、再翻成开。
   - `PERSONA_EXPORT_ENABLED` 保持默认关（用户明确「先不开」，它会把对话原文往外部记忆库送）。
3. **测试同步**：`src/flags.test.ts` 自动归档默认值断言改 `true`；`src/agent/auto-archive.test.ts`
   的默认开 / 显式关用例同步改写。`src/index.ts` 两处注释改口径。
4. **本机运行时不变**：`.data/agent-flags.json` 里这两项本来就是 `true`，所以 39847 上「当前开关状态」
   仍是 **29 项开 / 1 项关**（只剩对话归档；并行新增 `TOOL_PROJECTION_WORKER` 默认开，页面从 29 项变 30 项）；
   变的只是新装默认、删覆盖后的默认，以及重启后页首的「默认开 / 默认关」统计与徽标。

## 追加（同日第三轮：插件中心卡片墙 + 解释收进悬停）

用户口径（2026-11-15）：常驻长解释"太丑"，要和别处一样鼠标放上去弹一个小黑块；开关本身做成
类似「插件中心」的东西。

1. **卡片墙**（`web/settings-switches.js` + `web/settings-router.js`）：`#flags-card` 去掉外层
   `.card`，改成六组 `.flag-section` + `.flag-grid`；每项是一张 `.card.flag-item`，卡面只有
   中文名、一句简介、例外徽标和控件。`rowMarkup` 的常驻 `inlineHint` 不再用于开关卡。
2. **解释收进悬停**：完整 `summary` 挂到卡片正文区（名字 + 简介）的 `data-tip`（复用全局
   `.hover-tip` 黑底浮签，`max-width:320px`）；卡面简介由 `flagBrief()` 取 `summary` 第一句。
   分组说明也挂组头的 `data-tip`。
3. **徽标只留例外**：`flagTags()` 只在「默认关 / 待重启 / 已改」时出标签；默认开是多数派，不再
   每张卡挂一枚，靠页首统计看总量。旧版对所有 `hot:false` 开关常驻「需重启」，跟"这次改动有没有
   生效"无关，重启后也不会消失；现在服务端 `listFlags()` 多给一个 `pendingRestart`（`hot:false`
   且文件值与启动装载值不同），界面只在改动还没被进程装载时标「待重启」，重启服务后自动消失。
   「已改」也改成看当前值是否真的和默认不同，不看历史覆盖行（测试留下的覆盖行不再冒充改动）。
   确实要重启的也写在悬停说明与保存 toast 里。
4. **样式**（`style-14-settings-pages.css`）：新增 `.flag-item` / `.flag-item-head/name/brief/foot` /
   `.flag-grid` / `.flag-group-count`；删掉旧的 `.flag-group-desc` 与 `#flags-card .row-control` 规则。
   三档控件在卡底占满整行（`flex:1` + `nowrap`）。
5. **计数**：并行改动 `TOOL_PROJECTION_WORKER`（2026-11-16）自动落进「任务与界面」组，页面从
   29 项变 30 项（36 总 − 6 专属卡），页首统计与分组计数都由数据算，不写死。
6. **页首去长文**：同日用户又要求「解释性文字去掉」，`flag-intro` 只剩一行计数（30 个开关 ·
   29 默认开 / 1 默认关 · 当前 29 开 / 1 关），「这一页管什么」段落与「归档天数 / 压缩在会话页」
   的注释都删掉；这一页干什么由分组标题和卡片简介表达，完整解释仍悬停看。

## 为什么

- 原名「高级开关」是行话：用户不知道"高级"高级在哪，也不知道这一页和「会话」页的归档 / 压缩是什么关系。
- 一屏平铺 + 长解释常驻，怎么摆都像说明书；插件中心式卡片墙 + 悬停详情，才能既扫得快、又查得到。
- 裸 env key（`MEMORY_EXTRACT` / `TOOL_PROJECTION` / `AGENT_ASK_USER` / `PARTNER_TEMPLATES`）在中文界面里
  是硬伤；`auto/llm/rule` 对非开发者同样不可读。
- 用户把开关当**产品功能清单**：做出来就该开，默认关等于功能白做；而且"平时不会逐个拨"，所以默认值
  比界面提示更重要。工具活动不是配置项，留在设置里只会多一行噪音。

## 坑

- `rowMarkup` 的 `inlineHint: true` 本次不再用于开关卡；卡片的 `data-tip` 挂在卡名上，全局
  `.hover-tip` 负责定位和避让视口，别自己再做一套浮层。
- 标签位是 HTML，`esc(meta.label)` 之后才能拼徽标；`attr()` 只用于属性位（`esc` 不转义引号）。
- 卡片定高 132px、简介两行；三档控件在卡底占满整行（`flex:1` + `nowrap`），否则「自动 / 模型 / 规则」
  会被挤成竖排。
- 浏览器自动化截图为空白是 `viewIn` / `set-fade` 动画在无头环境不推进（`opacity:0`），不是页面没渲染；
  验收时临时把 `animation` 置 `none` 再截图，不改代码。
