# 任务中心看板 + 对话派单提示（2026-11-04）

## 做了什么

### 1. 后端补了一个只读列表接口

`GET /api/v1/tickets?domain=&limit=`（[delegation-api.ts](../../ts/apps/server/src/delegation-api.ts)）。

为什么补：原 §2.9 只有 `domains` 与 `tickets/:id`。`domains` 只给计数、不给 id，
看板首屏没法枚举任务单；只靠 SSE 的话刷新一次就空了。新接口跨顶层 `workRoot/`
与各领域 `runs/` 扫 `ticket.json`，按 `updated_at` 倒序，只吐界面需要的字段
（不带绝对路径）。契约已回写 `docs/基线文档/接口文档.md` §2.9。

### 2. 任务中心页（`ts/apps/server/web/`）

- 入口：侧栏底部「任务中心」（与「设置」同一区、同一 `.side-item` 样式，带进行中数量徽标）；
  侧栏收起或窗口 ≤800px 时走 `.side-rail` 的 `rail-tasks`，两种形态都能点到。
- 路由：`#/tasks` 看板，`#/tasks?ticket=<id>` 详情；Esc 先退回看板、再退回对话。
  任务中心**保留侧栏**（入口和回对话都在那儿）；设置页仍隐藏侧栏，行为没改。
- 看板：四列 = 排队/等文件、执行中、待你处理（含失败待看）、已完成；
  `needs_you` 卡片整卡琥珀描边；顶部五格统计（进行中/待你处理/失败待看/已完成/领域）。
  可用宽度不够时四列横向滚动，卡片不被挤扁。
- 详情：状态、领域/项目、任务进度、任务列表、子任务单（可点进子单详情）、最近 6 条验收记录；
  失败原因与「等你」原因用琥珀/红条单独标出。
- 三态：加载（首次扫描）、空（引导回对话派活）、失败（404 提示版本旧 / 500 给重试），都不白屏。
- 视觉全部复用现有 token：`--accent` / `--c-tertiary` / `--c-error` / `--card` / `--divider` /
  `--r-*`，没有新增调色板；卡片、统计格、状态小片都挂了 `.18s ease` 颜色过渡。
- 用词只用：助理 / 负责人 / 执行者 / 任务单 / 待你处理（雇员类型作后缀，如「本机执行者」）。
- 只读：没有改派、没有手动停止、没有悬浮面板、没有头像。

### 3. 对话里的派单提示

- 收到 `delegate` 事件（带 `ticketId`）后，在该轮回复下方挂一条胶囊链接：
  受理阶段「任务已派发，可在任务中心查看。」，后续按 `phase` 更新为
  「已完成 / 需要你处理 / 没做成 / 已中止」，同一任务单只保留一句。
- `attention` 卡片加上「去任务中心处理」链接，不再只有一句纯文本。
- 历史消息里的任务单号（`t-202608…-xxxx`）在 markdown 渲染时自动变成 `.ticket-link`，
  刷新后点「【任务 t-…】已完成」也能直接进详情。

## 验证

真起服务（`pnpm --filter @lifediary/server dev`，127.0.0.1:8082）+ headless Chrome 1520×899。

真数据链路：
- `/api/v1/tickets` 读到本机 `runs/` 里 36 张真实历史任务单（16 进行中 / 9 待你处理 / 7 失败 / 13 已完成）；
- 看板四列计数 5/2/16/13 与列表一致；点第一张卡进详情，读到真实任务列表与验收记录；
- 详情 404（不存在的 id）落到「找不到这张任务单」并给返回按钮。

造数据（已说明）：
- 失败态：CDP 拦截列表接口返回 500；
- 空态：CDP 拦截返回 `tickets: []`；
- 对话提示：CDP 拦截 `/api/v1/agent/chat`，回放一条合成 SSE（`delegate` accepted→needs_you +
  `attention`），走页面真实的事件处理与渲染代码，`ticketId` 用真实任务单，点链接后确实进了真实详情页。
- 没有跑真实模型派单（会起真执行者、跑真命令），所以「模型自己决定派活」这一段未实测。

数值：
- 看板四列在 1520 宽、侧栏 232 时铺满；760 宽时侧栏降为 48px 轨道、看板横向滚动（1044 > 712）。
- 深色主题下 `tk-chip` 过渡 = `background-color, border-color, color 0.18s`；
  卡片颜色从 `rgb(246,241,231)` 过渡到深色档，无硬切。
- 回到对话页：主区 `top=40 / bottom=899`、左上圆角 16px、文档无溢出（上一轮的 40px 问题没回归）。

命令：`node --check ts/apps/server/web/app.js`、`pnpm typecheck` 均通过。

## 没做 / 未验证

- 项目筛选、排序控件没做（顶栏只有「全部领域」过滤；接口也只支持 `domain`）。
- `lastAction` / `lastHeartbeat` / `waitingOn` 只存在于 SSE 运行时事件，`ticket.json` 不落盘，
  所以看板与详情不展示这几项；等/失败原因用 `error` 字段代替。
- 自动刷新没做：只有进入页面、点「刷新」时拉列表；对话里派单时若正开着任务中心，需要手动刷新。
- 真实模型驱动的「派单 → 看板出现新单」未跑。
