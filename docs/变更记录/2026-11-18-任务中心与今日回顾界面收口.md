# 变更记录：任务中心与今日回顾界面收口（去底部链接 · 回顾页重做）

**日期**：2026-11-18。**实施 / 验收**：ZCode。
**性质**：纯界面（文案 / 版式 / 样式），零契约、零新接口、零新开关。

## 用户口径

1. 任务中心底部的「今日回顾：今天都干了啥 →」按钮位置难看，"肯定不能放这里"。
2. 今日回顾页太丑，重新设计；两个入口（底部链接 + 右列卡片）只留右下角那张卡，
   把底部链接去掉。

- `ts/apps/server/web/index.html`：删掉 `.tk2-foot` 底部链接；`#/review` 容器换成
  `rv-daynav`（日期头）/ `rv-sum`（当日概览）/ `rv-tl`（流水），删掉页脚句子。
  同步更新侧栏「任务中心 / 今日回顾入口」与回顾页的注释。
- `ts/apps/server/web/tasks-review.js`：
  - 日期头：大号「11月18日」+「周三 · 今天 / 昨天」+ 「回到今天」+ 前后一天箭头；
    跨年补年份；后一天只挡未来，能翻到没有记录的日子（空态已可看）。
  - 当日概览：左侧主数字「今天派出 N 单」，右侧三个结果数字（收尾 / 等你回话 / 出错），

  数字区加上分隔线；入口只剩这一张卡。切日点击时滚动归零。

- `ts/apps/server/web/style-20-tasks-redesign.css`：重写 `rv-*` 段；回顾卡补箭头、
  日期行与三栏分隔。颜色仍只取现有 token，媒体查询放在本体之后（沿用历史教训）。
- 文档：`系统架构.md` 侧栏入口口径、`2026-11-13-任务中心重做…` 方案的状态与入口表
  同步改成「右列卡片唯一入口」；本记录。

## 为什么这么做

- 底部居中链接悬在两列之外，和任何一列都不对齐，也抢右列卡片的入口——删掉。
- 旧回顾页是「摘要数字 + 左侧时间轴」，空数据时几乎全白；重做成日报版式：
  日期头承担切日，概览承担一眼看懂，流水承担逐条回看。
- 数据仍是 `GET /api/v1/tickets` 按 `updated_at` 分日现算；回执没有 `changedPaths`，
  因此**不写「改了 N 个文件」**（沿用 2026-11-13 方案的口径）。

## 怎么验的

- `node --check`（两个改动 JS）、`pnpm typecheck` 全过。
- `tsx --test` 跑 web 五个测试文件（web-imports / web-stream-reveal / web-msg-clock /
  web-partner-sessions / web-branch）：18 项全过。
- **全套单测没跑完**：`pnpm --filter @lifediary/server test` 在
  `src/partner-work.test.ts` 的 `after` 钩子里栽在
  `EPERM: rmSync C:\Users\...\Temp\lifediary-partner-work-*`（Windows 临时目录删不掉，
  同目录已堆了多天残留），与本批 web 改动无关，后续文件被中断；单跑该文件仍复现。
- 浏览器（本机 39847）实测：
  - 空态（今天无单）：日期头 / 空态卡 / 去任务中心入口 / 无页脚。
  - 假数据注入 9 张单（done×5、failed、needs_you、dispatching、reviewing）：
    概览 9 / 4 / 1 / 1、上午 3 行 + 下午 5 行、完结对话合并为一行、直派单只读。
  - 切到昨天：空态「这天没有记录」、出现「回到今天」、后一天恢复可用、滚动归零。
  - 760px / 480px 窄屏（侧栏收起）：概览换行、行内箭头隐藏、不横向溢出。
  - 任务中心：底部链接已无、右列卡片日期与箭头正确、点击进 `#/review`。
- 本机 ticket store 当前为空，所以带数据的截图是**浏览器内 fetch 假数据**，
  不是真实历史；真实数据下的排版待有单时再看一眼。
- 静态资源由服务端每次读盘（`src/web.ts`），改完刷新即生效、不用重启；但浏览器会缓存
  `/assets/*.js`，验收时用 `?v=<时间戳>` 破缓存，否则看到的是旧模块。

## 已知边界 / 没做的

- 数据源仍是 `/tickets?limit=200`，更早的日子可能被截断（无分页接口，沿用旧边界）。
- 回顾页不做导出 / 分享 / 按类型筛选（用户没提，沿用 2026-11-13 方案的"刻意没有"）。
- web 层没有单测基建，`dayTitle` / `daySubtitle` / 分组纯函数未挂单测。
- 这次没有新增回滚开关：版式改动全部在 `web/` 内，`git revert` 即回退，无需运行时开关。
