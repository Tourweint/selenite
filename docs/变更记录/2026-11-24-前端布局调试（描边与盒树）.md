# 2026-11-24 前端布局调试（描边与盒树）

**改了什么**

1. `ts/apps/server/src/plugins.json`：`ui` 组 `keys` 末尾加 `DEV_LAYOUT_INSPECT`；`flags` 末尾加定义
   （label「布局调试描边」，`type:boolean`，默认 `false`，`hot:true`）。
2. 新建 `ts/apps/server/web/dev-inspect.js`（ES module，无依赖）：
   - `initDevInspect({ outline: true })` 给 `<html>` 加 `dev-box` class；同时无条件把
     `window.__boxTree` 挂上（探针只读、不渲染，所以不跟开关走）。
   - `window.__boxTree({ selector = "body", maxDepth = 8, maxLines = 400 })` 返回文本盒树表：
     每行 `缩进 + tag#id.cls[.cls…] [x,y w×h] p:… m:… gap:… ov:…`；padding / margin 按 CSS 简写
     压成 1 / 2 / 4 个值且全零不输出，gap 只在非零时输出，overflow 只在非 `visible` 时输出；
     class 最多列 3 个、多出的记 `+N`；坐标尺寸取一次 `getBoundingClientRect()` 后取整。
   - 跳过 `SCRIPT/STYLE/LINK/META/TEMPLATE/NOSCRIPT`、`display:none`、`visibility:hidden`、
     宽或高 `< 0.5` 的节点（只跳该节点这一行，子节点仍下钻：`display:contents` / 零高容器里的
     可见子节点不能丢）；深度超过 `maxDepth` 只输出该行并在行尾加 `…`；行数超过 `maxLines`
     停止并追加 `…（已截断，已输出 N 行；调大 __boxTree({maxLines: 2000})）`；选择器找不到返回
     `未找到：<selector>`。
3. 新建 `ts/apps/server/web/style-29-dev-inspect.css`：`html.dev-box *` 画 1px 半透明红线
   （`outline` 不占布局，`offset:-1px` 避免相邻盒子叠成 2px），`:hover` 换 2px 蓝线。
   只描元素、不描 `::before/::after`：那层多数是图标 / 箭头 / 圆点，一起描会在内容上叠一堆
   小方框，反而看不清真正的容器（2026-11-24 判断）。
4. `ts/apps/server/web/style.css`：末尾 `@import` 新分部，默认无视觉。
5. `ts/apps/server/web/app.js`：首屏无条件 `import("./dev-inspect.js")` 并 `initDevInspect()`
   挂盒树；另一条 `ensureFlag("DEV_LAYOUT_INSPECT", false)` 回来再决定加不加 `dev-box`
   class——flag 晚到也能补上；关掉刷新页面即完全恢复。
6. 文档：`docs/基线文档/接口文档.md` §6 补 `DEV_LAYOUT_INSPECT` 行；本记录。

**为什么**

2026-11-24：前端容器层数多，agent 隔着屏幕调布局只能靠量测，看截图分不清内边距属于哪一层。
盒树表是纯文本，可以直接贴进对话；描边开关给人工肉眼核对嵌套与内边距用。都是开发期工具，
不改后端逻辑、不进契约、不引依赖。

**怎么用**

- 描边：设置 → 插件 →「任务与界面」→「布局调试描边」，打开后**刷新页面**生效（flag 首屏读一次）。
- 盒树：浏览器控制台随时可调，无需开关：
  - `__boxTree()` —— 从 `body` 起，深度 8、最多 400 行；
  - `__boxTree({ selector: "#settings-inner", maxDepth: 12, maxLines: 1000 })`。
- 样例（headless Chrome 打开临时测试页，加载真实模块后的输出）：

```text
body [8,8 748×58] m:8
  div#outer.outer [8,8 748×58] p:12 16 m:4 0 8 0
    div#inner.inner [25,21 714×32] p:6 gap:10
      div.cell.a.b+2 [31,27 40×20] ov:hidden
      div.cell [81,27 40×20] ov:hidden
```

**明确不做**

- 不给盒子编号：DOM 是 JS 动态拼的，编号刷新就漂；
- 不做点击拾取器：要挂全局事件、和页面既有交互打架；
- 不做 URL 参数开关：入口只留插件中心，开关口径与回滚走同一处；
- 不写任何 DOM / 不改布局，探针纯只读。
