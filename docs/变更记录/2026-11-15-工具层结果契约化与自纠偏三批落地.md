## 改了什么

### 批次一：bash/powershell 结果投影 + 外挂式挂载（commit a249c2f）

- `src/tool-projection.ts`（新）：三个纯函数（`projectShellResult` 语义退出码豁免 + 失败落盘 hint、
  `projectShellError` 中断稳定标记、`semanticExitReason`/`firstCommandWord` 命令首词解析）+
  挂载判定（`projectionDecision` 纯函数；env/执事三态/会话 kind 三层）+ `wrapShellTool` 包装器。
- `agent/lifecycle-harness.ts`：注册表只装一份——`CodingTools` 里 bash/powershell 换包装版，
  工具清单与顺序不变（保 prompt cache 前缀稳定）；挂载判定依赖经 `setProjectionDeps` 注入
  （同 `setChatKindsSource` 惯例）。**powershell 在本仓库装配里本就没上架**，包装函数就绪、注册不变。
- 挂载点（§5 定稿）：`partners.tool_projection INTEGER` 三态列（NULL=跟随默认 / 1=强制开 / 0=强制关，
  缺列迁移照 dispatch_authority 先例）；`setToolProjection`；`PATCH /companions/:id` 收
  `tool_projection`（null 恢复跟随默认，只收 0/1/null）；执事投影透出 `toolProjection`；
  执事管理界面（partner-profile）加三态开关行（点按循环 跟随→开→关）。
- 默认值（§5.3）：worker/子单/验收子会话与带 domain 执事会话默认开；主人会话与聊天型伙伴默认不开。
- 回滚（§5.4）：执事三态 → `TOOL_PROJECTION=false`（flags 页已登记，hot:true）→ git revert。
- 与 recall 同款的注入纪律：判定只看命令首词（含 `command -v`/`builtin` 后首词、跳过 env 前缀），
  解析不准当普通失败，宁可保守。

### 批次二：delegation 失败回执带可续接信息（commit c39715b）

- `DelegationReport` 失败/中断分支新增 `resume: { id, conversationId, partialReport }`：
  id=子单号 uuid（`GET /api/v1/tickets/:id` 可查）、conversationId=`task-<id>` 专线会话对外 id
  （确定性，未建过时读详情自然 404，不拉 harness）、partialReport=失败前最后一行结论（截 160 字）。
  成功与 needs_you 不带；旧字段只增不改，手机端零改动。
- `delegation-wake` 唤醒提示词给失败单追加一行「续接」指针（不强迫，只给抓手）。

### 批次三：自纠偏对齐 + ToolResult 收尾（commit f4b1ed9）

- **撞上限前提示**：`turn-gate.ts` 新增 `TURN_LIMIT_APPROACHING_INSTRUCTION` / `TURN_LIMIT_WARN_ROUNDS=5`；
  `lifecycle-injections.ts` 登记 `turnLimitApproachingProvider`（剩最后 5 轮，turn ∈ [MAX_TURNS-4, MAX_TURNS]，
  注一行收尾提示；MAX_TURNS ≤ 5 永不注，与硬上限不重叠）。
- **审计「前序失败即跳过」**：核对 durable executor 与宿主 turn-gate——内核每个工具调用是独立
  ToolTask，失败只落 isError 结果、同轮后续调用照跑；宿主 `beforeTool` 只在闸门理由
  （轮次上限/防打转/审批/只读）才拦，没有任何「某工具失败后跳过后续」的分支。
  **没查出问题，不改代码**（2026-11-15 审计，对照 pi-durable 1.4.0 实读）。
- **ToolResult 收尾**：最后 4 个工具（`remember` / `set_reminder` / `persona_recall` / `send_to_agent`）
  迁 `ToolResult` 形状——成功 `ok({message})` 人读文案逐字不变；失败 `err({code,message,hint})`
  不再抛栈（set_reminder 的 6 类参数错误、递话的 7 类拒绝都有了稳定枚举与下一步 hint）。
  `tools.ts` 与 `partner-relay.ts` 各自收掉了已无引用的本地 `text()` 助手。
