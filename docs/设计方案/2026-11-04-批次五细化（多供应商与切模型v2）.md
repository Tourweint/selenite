## 〇、一句话

供应商配置落 `.data/providers.json`（无密钥结构），`Models` 单例**原子换装**（CRUD 后按版本号重建 diff 应用，`models()` 永远返回当前实例且现查版本——不缓存陈旧目录）；模型身份全链路升级为 `providerId+modelId`（**变体键、会话对齐、思考档切换全部带供应商比较**——否则同名模型跨供应商是空操作，审查 S1）；web composer 快捷切换 + 设置页供应商管理（key 只见变量名）。

## 一、数据与迁移

1. `.data/providers.json`（env `PROVIDERS_PATH` 可覆盖）：
   ```json
   { "schemaVersion": 1, "providers": [
       { "id": "bailian", "name": "百炼", "baseUrl": "https://…", "keyEnv": "LLM_API_KEY",
         "models": ["qwen3-max"], "createdAt": "…" } ],
     "defaultSelection": { "providerId": "bailian", "modelId": "qwen3-max" } }
   ```
   - 校验：zod **`.strict()`** + 显式拒收 `apiKey`/`key`/`headers` 字段（strip ≠ 拒收，审查 S6）；`id` 小写 slug 且**保留字排除**（`faux`/`mock`，写明"provider id 是用户可读配置键，不是安全边界，不适用 uuid 口径"）；`keyEnv` 匹配 `/^[A-Z_][A-Z0-9_]*$/`。
   - **播种迁移（B1/B2）**：文件不存在 && `PROVIDERS_CONFIG!=false` 时首启播种——`LLM_BASE_URL`/`LLM_API_KEY`/`LLM_MODEL`/`LLM_MODELS`（逗号分隔全量归入默认供应商）→ 写成默认条目 + `defaultSelection`。**启动日志明确"env 仅播种，此后以文件为准"**。`LLM_MODEL_FAST` 不入文件、行为原样保留（快档仍走 env，接口文档标注）。faux/无 key 不播种。文件损坏/目录只读 → **fail-closed**：启动报错并回退 env-only 行为 + 日志告警（不静默换端点）。写入 = 临时文件 + rename。
   - **回滚开关（S3）**：env `PROVIDERS_CONFIG=false` → 忽略文件、不播种、纯 env 旧行为（与 `MODEL_RUNTIME_OVERRIDE=false` 正交：后者只关切换端点）。
2. 模型身份：`ModelRef = { providerId, modelId }`。`runtime.json` 存 `{"model":{"providerId","modelId"}}`（B3）；**读旧裸 id 兼容**（→默认供应商）；接口文档"只存模型 id"句改口径 + 写明"降级回旧代码会丢选择"。`defaultSelection` 与 `runtime.json` 优先级：**runtime.json（用户显式切换）> defaultSelection > 第一个供应商**。
3. 每模型元数据（B5）：自定义模型一律按 `contextWindow:131072 / maxTokens:4096`（现状硬编码值，接口文档写明"自定义供应商暂不区分窗口"）；`models[]` 元数据留待真需求。

## 二、服务端

1. **Models 生命周期（S2，定死）**：保留**单例 `Models` 实例**；`rebuildProviders()` = 从 providers.json + 选择确定性算出目标 provider 集 → 与当前实例 diff → `deleteProvider`/`setProvider` 原子应用 → 清掉基座已消失的 taskVariants；`models()`（传给 Harness 的函数）**先查 providers.json 的内部版本号**（载入时缓存 + fs.watch 或每次 CRUD 时 bump 内存计数），版本没变直接返回单例——**不每请求重建、不缓存陈旧目录**（ZCode 教训的两头都占）。全局 `declaredModels`/`taskVariants`/`publishProvider` 的旧假设按此重写：变体键一律 **`${providerId}|${modelId}#…`**（S1）。
2. **身份比较全链路（S1）**：`chatModelRef`/`applyChatMode`/`syncConversationModel`（实际 agent.ts:760-780）/`switchThinkingOnTool` 全部改成 `providerId+modelId` 成对比较——**同名模型跨供应商切换必须触发重配**。`readLlmConfig()` 的 `cached.models` 改为 `currentModels()` 访问器（拿单例），所有取目录处（agent.ts:1640、openai-compat.ts:349/355）跟着换。
3. 端点（两个投影，S6）：
   - **`GET /api/v1/agent/model`**（新增，composer 用）：`{ current:{providerId,modelId}, providers:[{id,name,models[],hasKey}] }`——**不含 baseUrl/keyEnv**。
   - **`POST /api/v1/agent/model`**（扩展）：接受 `{providerId, modelId}`；兼容旧 `{model}`（→默认供应商）；**响应保留旧 `model`/`models` 字段**（现有 web 依赖，index.ts:340）+ 新增 `provider` 字段（B8）。错误：unknown_provider/unknown_model 细分；faux/无 key/override_disabled 沿用 §2.8。
   - **`GET /api/v1/agent/providers`**（设置页用）：在 composer 投影之上**加 `baseUrl`/`keyEnv`/`isDefault`**——设置页回填编辑需要它们（S6）；仍无任何密钥值。
   - **`POST /api/v1/agent/providers`**：新增/更新（带 id 即更新）。`modelsUrl` **仅请求参数不持久**（B4）：服务端代拉 `{baseUrl}/models`（key 从 env 取，三种响应形状兼容，超时 5s、响应 ≤1MB，失败返回错误由用户手填）。`test:true` 不写文件，语义 = keyEnv 变量存在非空 + GET baseUrl/models 2xx（**措辞"钥匙已就位"，不叫"连接成功"**）。
   - **`DELETE /api/v1/agent/providers/:id`**。
4. **CRUD 不变量（S4）**：删除默认供应商或当前选中供应商 → 400；**编辑**导致当前选中的 modelId 不在该供应商 `models[]`、或改 id → 400（提示先切走）；keyEnv 指向缺失变量 → **允许保存**（投影 `hasKey:false`，选中时请求报正常错误事件不崩，探针断言）；删除被旧会话引用的供应商（非当前选中）→ 允许，`syncConversationModel` 对齐失败时**真正回退默认供应商**（现状是 catch 后继续用旧引用打 404，agent.ts:776-780——改为回退），**"usage 徽标注明"不做了**（usage 桶 durable 本就按 `provider/modelId` 分，O3）。
5. **/healthz 兼容（S5）**：`models` 保持扁平、语义收窄为"默认供应商的清单"（接口文档注明）；web 服务页迁移到新 `GET /agent/model`+`GET /providers`；http-probe 旧断言不破。
6. 顺手删 `upstreamConfig()` 死代码（openai-compat.ts:121-135，O4）。

## 五、验证（按审查十断言重写）

探针 `scripts/providers-probe.ts`（**必须设 `PROVIDERS_PATH` 隔离**，faux 不播种污染真 .data）+ **两个不同端口/路径的本地假上游**：
1. 启动只有 A → 一轮 → A 收到且 `Authorization: keyA`；
2. 不重启 POST /providers 加 B（第二假上游、`keyEnv=B_KEY`）→ GET /model 立即可见 → POST {B,model} → 下一轮打 B、`Authorization: keyB`；

4. 改 B 的 baseUrl 到第三假上游 → 同进程下一轮即新地址；
5. 改 B 的 keyEnv B_KEY→B_KEY2（都设）→ 下一轮 Authorization 变 keyB2（证明请求前一刻取 env）；
6. hasKey:false 的 C：投影正确；选中后请求报正常错误事件不崩；
7. 删除保护：默认/当前选中 400；删非默认后消失；旧会话引用被删供应商 → 回退默认供应商（按 §二.4 口径断言）；

9. 播种：env-only→文件；重启改 env→文件为准；删文件→env 为准；`PROVIDERS_CONFIG=false`→env 为准且不读文件；
10. faux：CRUD 可用、POST /model 400、不污染真实 .data。
