## 一、工具返回统一契约（五 §八#1）

1.1 新增 `ts/apps/server/src/tool-result.ts`：定义统一返回形状
```ts
export type ToolOk<T> = { ok: true; data: T };
export type ToolErr = { ok: false; error: { code: string; message: string; hint?: string } };
export type ToolResult<T> = ToolOk<T> | ToolErr;
export function ok<T>(data: T): ToolOk<T>;
export function err(code: string, message: string, hint?: string): ToolErr;
```
1.2 **先只给新工具用**（`ask_user` / `report_progress` / `recall_sessions` 这三个是最近加的），
**旧工具一个都不动**——迁移是长期活，本批不碰（避免一次性改 20 个工具的返回形状）。
1.3 在文件头注释里写清"为什么只给新工具用"和"旧工具怎么逐步迁移"（下一批做哪个）。
1.4 单测：`ok` / `err` 形状正确、`hint` 可选。

## 三、审批级别"作用半径"分层（七 #46）

3.1 在 `approval-policy.ts` 文件头注释补一节，写清三类作用半径：
   - **即时生效**：API 引擎（`AGENT_APPROVAL_*` 环境变量/界面开关）——改完下一轮就生效；
