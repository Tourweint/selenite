## 契约变化（先行）

1. `shared` `PartnerPersonaPresetSchema` 枚举扩 `"allrounder" | "apprentice"`（全才/学徒；手机端未引用该枚举，零波及）。
2. **预设语义变化**：`PUT /persona` 保存后服务端按最终开关表推导 `preset`（比较只看 12 个可配置 id；`workHistory`/`currentWork` 固定开、不参与比较）。显式 `preset` 与 `modules` 混批时以推导结果为准（预设名永远与开关表一致）。
3. **履历/在办语义变化**：`workHistory` / `currentWork` 两个模块 id 停止作为注入闸（固定注入；内容为空时本来整段不出现）。存储兼容：旧行上的 `false` 值保留但不再生效；`PARTNER_PERSONA_MODULES=false` 时行为不变（谁也不裁=全注入，与常注入一致）。
4. 新端点 `GET /api/v1/partners/:id/injection-preview`：`{ok, discipline, currentWork, workHistory}`，服务端用与注入**同一装配函数**现拼现给（纪律关→`null`；「等你批的」按会话算，预览不含，弹层里说明）。只读、不进 shared（电脑端 web 专用）。

## 明确不做

- 派活/领域机制不拆（只撤 UI 入口）；`dispatchAuthority` PATCH 端点保留。
- 纪律内容不做可编辑（固定字节是刻意的缓存前缀资产）。
- 主动性模块不删（追问是纯提示词、挂念默认关，零成本）。
- 「等你批的」不做进预览（按会话算，预览无会话上下文）。
- 手机端不动（persona 端点手机未引用）。

## 第二轮补记（同日，用户看完第一版后追加）

- **挂念从主动性里拆出来**：两个开关并排是明确否决项；挂念独立成卡，依赖主动性（点它时若
  主动性关着自动一起开）。服务端语义不变。
- **「记忆」纳入注入区**，并给它一个真开关 `memoryRecallEnabled`（默认开）：关 = 这一位不再
  自动带记忆，`recall` 工具照旧。落点选 `persona_switches` JSON（零迁移、零新表）；闸门在
  `assistant` 的记忆 provider 前置判断，读不到 / 非执事会话一律不拦（宁可按旧行为）。
- **纪律不做可编辑**（本轮给了明确理由并写进弹层）：它是安全边界 + 缓存前缀资产 + 跨执事
  底线，改它等于把"什么能做什么不能做"交给模型自己裁；要自定义规矩走「岗位契约」。
- **高级开关**去掉"默认全开"措辞：结果整理是跟随全局（开），日记执事是唯一位指派。

## 第三轮命名定稿（同日，用户纠正）

两个机制必须分开叫，别再混：

| 区块 | 语义 | 内容 | 谁决定 |
|---|---|---|---|
| **每轮固定注入** | 100%，每句话都带 | 纪律 / 在办状态 / 履历摘要 / 负责项目（索引行） | 宿主固定拼 |
| **按相关度召回** | 先打分，够线才浮出 | 记忆四类（经历/事实/偏好/人和物）+ 挂载项目的记忆 | 召回器按本轮 userText 打分 |

「负责项目」归注入区：挂载同时产生两件事——那一行索引是 100% 注入；项目记忆进召回池算分。

## 第四轮：父子关系定稿（2026-11-16）

**规则**：执事级开关 = 插件在某个执事身上的挂载；它的总闸一律在「设置 → 插件」（2026-11-16 由「服务 → 行为开关」拆出独立页）。
界面表述上，个人页那张卡是"子开关"，tip 里点出父闸位置。

| 子开关（个人页） | 父闸（插件页 / 部署配置） |
|---|---|
| 人格模块 14 个 | `PARTNER_PERSONA_MODULES`（部署配置，不在插件页；false = 回到全开旧行为，不是级联关） |
| 结果整理 | `TOOL_PROJECTION` |
| 负责项目 | `PARTNER_PROJECT_MEMORY`（部署配置，不在插件页） |
| 记忆 + 项目记忆 | `PARTNER_MEMORY_RECALL`（本轮新增） |
| 接派单（UI 已退役，机制在） | `MINISTER_DISPATCH_AUTHORITY` |

日记执事不设父闸（唯一位指派，默认无人）。加新开关时的顺序：先加 flags 行（父）→ 再加
`persona_switches` / `modules` 字段（子）→ 消费处父子都判 → 界面 tip 写父闸位置。

**2026-11-16 锁态落地**：`MEMORY_ENABLED` 关 → 「学习」与「记忆 + 项目记忆」显示关、禁用；
`TOOL_PROJECTION` 关 → 「结果整理」显示关、禁用；父开恢复子项存储值。14 个人格模块与「负责项目」
仍按部署配置处理，不套「随总闸关闭」。
