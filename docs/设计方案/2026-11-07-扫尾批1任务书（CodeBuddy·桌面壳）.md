## 逐项

### 1. 托盘「设置」菜单项

在「重新连接」下加一项「设置」：点击后把**现有窗口**导航到设置页（`#/settings`）。实现取 mygo 窗口执行 JS 的能力（自己查 mygo Window API，类似 `Eval()`）；若窗口未显示，先显示再导航。与 `LIFEDIARY_VIEW=settings` 同一落点，别造第二套路由机制。

### 2. 托盘图标随服务状态变灰

- 用 Go 标准库（image/png + image）写一次性生成：读 `assets/icon-tray.png` 去饱和度（灰度化，保留 alpha），产出 `assets/icon-tray-idle.png` 提交进库；生成脚本放 `desktop/gen-gray-icon/main.go`（一次性工具，注释写明用途与用法），生成产物入库。
- 新 goroutine（服务启动时起）：每 5s `runtime.Status()`，**状态变化才**动作——`running/starting` 用原彩色图标，`stopped/failed` 用灰色图标；`SetToolTip` 同步带状态（如 `Selenite — 服务已停止`）。退出时停掉该 goroutine。
- 回滚开关：`LIFEDIARY_TRAY_STATE=off` 时不起轮询、不换图标（菜单「设置」保留，无害）。

### 3. 退出前查在飞任务

改造 `OnBeforeQuit`（现在是同步置 flag）：
1. `e.PreventDefault()` 挂起退出，`go func()` 异步处理；
2. `GET http://127.0.0.1:<port>/api/v1/tickets`（1.5s 超时），数非终态单（status ∈ received/planning/planned/dispatching/reviewing/idle；解析失败按 0 处理）；
3. 无在飞 / 查询失败（服务没跑）→ 直接 `app.Quit()`，不烦人；
4. 有在飞 → 弹确认框「还有 N 个任务在跑，退出后它们继续执行但窗口关闭。确定退出？」——用 mygo 现成的对话框 API（自己查 mygo 是否有 confirm/messagebox；**如果没有**，改用窗口执行 JS `window.confirm`（WebView2 支持则用），两条路都不通才允许降级为"托盘气泡提示后仍退出"，并在汇报里明说用了哪条、为什么）；
5. 确认 → `app.Quit()`；取消 → 什么都不做（退出被拦下，应用继续活着）。
注意别把原有 `quitting=true` 语义弄丢（`OnClose` 关窗放行依赖它）——在真正决定退出时再置。
