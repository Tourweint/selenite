## 一句话

派活到终态、汇报写回会话之后，把**派活的会话**叫起来跑一轮接住结果（"唤醒轮"）。
规则只有一条：**汇报写了就唤醒，没写就不唤醒。** 开关 `DELEGATION_WAKE_ENABLED` 默认开；
关掉 = 行为与改动前逐字节一致。

---

## 三、新文件 `src/delegation-wake.ts`

3.1 导出 `wakeOnDelegationReport(conversationId: number, report: DelegationReport): void`——
    fire-and-forget，内部全部兜异常，**绝不抛**（调用方在汇报回调里，唤醒出错不能拖累汇报）。

3.2 守卫链（顺序即语义，任一不过 → 静默返回；**每次 flush 都重新过一遍**）：
    1) `delegationWakeEnabled()`：懒读 `process.env.DELEGATION_WAKE_ENABLED`，解析口径照
       `partners.ts:40` 的写法（`(env?.trim() || "true").toLowerCase() !== "false"`）——
       默认开，显式 false 才关；写成**函数**不是模块常量（flags 是 hot:true，切了立即生效）；
    2) `COMPANIONS_ENABLED` 关 → 返回；
    3) `partnersStore().partnerIdOfSession(conversationId)` 为 null → 返回（群会话 / task- 专线 / 未知会话不唤醒）；
    4) partner 不存在或 `status !== "active"` → 返回。

3.3 合并与防抖：`pending = Map<conversationId, DelegationReport[]>`；同会话已有定时器则只追加；
    防抖 **2 秒**后 flush。延时调度做成可注入的内部参数（默认 setTimeout），单测用假时钟。

3.4 flush 流程（每轮）：
    a. 忙退避：`ensurePartnerSession(partnerId)` 拿 chat，`conversationIsBusy(chat.conversation)`
       为真 → 2 秒后重查（期间新汇报照常追加进 pending）；上限 **150 次**，超限
       `console.warn("[wake] 会话 X 忙超 5 分钟，本次唤醒放弃 tickets=N")` 并清 pending；
    b. `collectPending(conversationId)` 取走即清空（**导出**，纯函数，单测直接调）；
    c. `buildWakePrompt(reports)`：模板见下，固定字节；
    d. `runPartnerTurn(partnerId, prompt, { authority: "autonomous", quiet: false, sessionMode: "persistent" })`；
    e. 跑完若 pending 又有新货 → 循环 flush；**单会话单次触发链连续 flush 上限 5 轮**，
       超限 warn 并清（防 while 缺陷死循环的保险丝；方案 §2.2 只写了 while，这条是实现层保险，验收时说明）。

3.5 提示词模板（逐字实现；单号 `ticketId.slice(0, 6)`，`phase` 与 `text` 直用）：

```
[Delegation wake context]
turnAuthority: autonomous

以下后台任务刚到终态，执行端汇报已写进本会话。逐条接住：
- 完成了：一两句向主人转述结果与落点，不复读执行端原文；
- 失败了：说清原因与下一步建议；
- 需要主人拿主意的：把问题明确提出来。
不要重新派同样的活。没有要补充的就一句话收尾。

本批终态：
- 单 3f2a91（done）：示例汇报一
- 单 8c04d2（failed）：示例汇报二
```

（"本批终态"下面的行按实际单数生成；固定头与纪律段一字不改。）

3.6 日志纪律：只记条数 / 枚举 / 耗时 / 会话 id——
    成功 `[wake] 会话 12 唤醒轮 ok tickets=2 耗时4.1s`；
    失败 `[wake] 会话 12 唤醒轮失败: <错误一行>`。
    **不记汇报正文、不记对话内容。**

3.7 导出 `resetDelegationWakeState()`（清 pending / 定时器 / 计数，测试用）。
    依赖方向：只 import `partner-runtime` / `partners` / `delegation`（类型）/ `agent/session`，
    **不 import `agent/lifecycle`**（防循环）。
