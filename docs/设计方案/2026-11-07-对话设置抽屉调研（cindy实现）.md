# 对话设置抽屉调研：cindy 的实现

> 2026-11-07。用户口径：现在右上角快捷设置——齿轮画了个黑圈不好看、点开是下弹面板但应该是右边一个抽屉、
> 且里面只调了模型太单薄——要求参照 cindy 重做。本文核实 cindy 仓库（`<reference>\cindy`，
> 最后提交 2026-11-04）的同类实现，给出现成形状。核实方式：按组件名逐文件实读（cindy 行号会漂移，
> 本文引用按"文件 + 组件/类名"定位，行号为 2026-11-06 克隆版本参考）。冲突以 `docs/基线文档/` 为准。

## 〇、人话版结论（先看这里）

**一句话：cindy 的答案就是"裸图标 + 右侧滑入抽屉 + 首页是一列带图标的设置行"——三件全可以照抄。**

1. **图标：不要圆底、不要描边圈。** cindy 用的就是 lucide 的 `Settings2`（15px），按钮裸的——
   只有 hover 才出现浅底色，平时就是一颗安静的图标。我们那个"黑色圈"应该去掉；
   cindy 的注释里甚至写着"用户明确这个开关不要圆底"（RightSidebarToggle 的圆底按钮是特例，
   设置入口不是）。
2. **点击后：右侧抽屉，不是下弹面板。** 从右边滑入、占满全高、最大宽 448px（`max-w-md`）、
   左缘一条 1px 分割线、无独立圆角（贴边板式，不是悬浮卡片）、背后压暗遮罩。
3. **内容：首页是设置行清单，模型只是其中一行。** cindy 伙伴设置首页列出
   资料卡 / 性格 / 记忆 / 项目 / 模型 / 语音 / 能力 / 消息渠道 / 例行任务 / 历史搜索 / 高级（家目录）
   共 11 行，点行进二级页，抽屉不关。我们至少应该放：**模型、思考档（快/深）、权限档、
   通知时机**四行起步，每行右侧 chevron 进二级页——比把所有控件塞一层强。
4. **深链与关闭：** 打开/关闭走 URL 参数（`?settings=1`），刷新和前进后退天然保持状态；
   Esc 关闭（带中文输入法组合键豁免）、点关闭按钮、点遮罩关闭。关闭前有未保存草稿要拦截确认。

## 一、入口图标：怎么画（核实 2026-11-06）

来源 `apps/desktop/src/renderer/features/bots/BotGroupChatView.tsx`，组件 `SessionContentHeader` 注入的群头部右端：

```tsx
import { Settings2 } from 'lucide-react';
<button type="button" aria-label={settingsLabel}
  className="flex h-7 w-7 shrink-0 items-center justify-center rounded-full
             text-[var(--text-tertiary)] hover:bg-[var(--surface-hover)]
             hover:text-[var(--text-primary)]">
  <Settings2 size={15} />
</button>
```

要点：

| 细节 | cindy 的做法 | 对照我们 |
|---|---|---|
| 图标 | lucide `Settings2`（齿轮+滑杆的混合体），15px | 我们自画齿轮+黑圈 → 直接换 `Settings2` 或同族线性图标，**去圈** |
| 底色 | 平时**无底无边**（`text-tertiary` 三级字色），仅 hover 出现 `--surface-hover` 浅底 | 去掉常驻黑圈；圈是"选中态"语言，不该常驻 |
| 尺寸 | 按钮 28×28（`h-7 w-7`），图标 15 | 对齐 28px 命中区 |
| 色彩 | 全部走主题变量（tertiary → hover primary），明暗主题自动跟随 | 我们已有主题三态，同套变量即可 |
| 无障碍 | `aria-label` + `Tip` tooltip | 补 aria-label |
| 反例注记 | `RightSidebarToggle.tsx` 注释原文："resting 无底无边、仅 hover 底色（**用户明确这个开关不要圆底**）" | cindy 自己的用户也提过同样的意见——圈不要 |

## 二、抽屉：形态与工程（核实 2026-11-06）

来源 `apps/desktop/src/renderer/features/bots/BotSettingsDrawer.tsx`（伙伴设置）与
`BotGroupSettingsDrawer.tsx`（群设置），两者同构。

### 2.1 几何与材质

```tsx
<Dialog.Portal>
  <Dialog.Overlay className="modal-scrim fixed inset-0 z-50">
    <Dialog.Content
      className="fixed inset-y-0 right-0 z-50 flex w-full max-w-md flex-col
                 border-l border-[var(--border-default)] bg-[var(--surface)] outline-none">
      <header className="flex h-14 shrink-0 items-center justify-between border-b …px-5">
        <Dialog.Title>…</Dialog.Title>
        <Dialog.Close …><X size={17} /></Dialog.Close>
      </header>
      …内容…
    </Dialog.Content>
  </Dialog.Overlay>
</Dialog.Portal>
```

| 细节 | 做法 |
|---|---|
| 定位 | `fixed inset-y-0 right-0`：右侧、全高、贴边，**不是居中弹窗也不是下拉** |
| 宽度 | `max-w-md`（448px），窄屏 `w-full` 兜底 |
| 分割 | 左缘 `border-l` 1px 与聊天区分界；无圆角、无悬浮阴影——它是"板"不是"卡" |
| 遮罩 | `modal-scrim`：压暗 + 4px 背景模糊（Windows 下关闭模糊防渲染黑块，globals.css §modal-scrim 注释） |
| 头部 | 56px 高，标题左、X 关闭右（`X` 17px，40px 圆形命中区） |
| 结构 | `flex-col`：header 固定，内容区 `overflow-y-auto` 独立滚动 |

### 2.2 动画

- 遮罩淡入 + 关闭淡出（`globals.css` `modal-scrim-in` / `modal-fade-out`，走 `--motion-enter/exit` token）；
- **抽屉本体 cindy 没有做滑入动画**（Content 只有 fade），滑入感来自遮罩的衬托。我们 WebView2 + 原生 JS
  可以做得更顺：用 Web Animations API 给 `transform: translateX(100%) → 0` 加 250ms ease-out
  （参照 `BotGroupChatView.tsx` 里 thread 面板的 `animateThreadPanelWidth` 做法：开面板播宽度动画、
  关面板播完动画再卸载）。
- `motion-reduce`（减弱动效）时动画归零——照抄这条。

### 2.3 打开 / 关闭语义（值得整段照抄）

- **打开/关闭状态在 URL 上**（`?settings=1` + `settingsPage` 深链）：
  `openSettings()` 把参数写进 `location.search`，抽屉是"路由拥有的"（route-owned），
  聊天视图**保持挂载在下面不被卸载**。好处：刷新不丢状态、可深链直达某个设置页（模型/语音等）。
- **Esc 关闭**：Radix 自带 + `onEscapeKeyDown` 里对 `isComposing || keyCode === 229` 豁免
  （中文输入法组合中按 Esc 只取消候选词，不关抽屉）——中文产品必抄。
- **点遮罩关闭**：伙伴设置走 Radix 默认（点外即关）；群设置反而 `onPointerDownOutside preventDefault`
  不关——因为群设置有未保存草稿。结论：**有草稿保存_guard 的抽屉不该被一次误点外清空**。
- **关闭前守卫**：`beforeCloseRef` + `useBlocker` 把"标题栏关闭 / Esc / 遮罩 / 返回 / 侧栏导航"
  统一走同一个"有未保存修改就先确认"的闸（`BotSettingsDrawer` 注释原话）。
- **关掉抽屉聊天不重挂**：这是选抽屉而不是弹页面的核心理由，注释原话
  "Route-owned compact drawer that keeps the current teammate chat mounted below it"。

## 三、抽屉里放什么：cindy 的设置首页清单（核实 2026-11-06）

来源 `apps/desktop/src/renderer/features/bots/BotsHomeView.tsx`，`settingsRows`（:421-434）。
首页 = 头像+名字居中，下面一列分组卡片行；每行 = 图标(18px) + 标题 + 右侧 `ChevronRight`(14px)，
行高 ≥48px，`hover:bg-[var(--surface-hover)]`，行间 1px 分割：

| # | 设置项 | 说明 |
|---|---|---|
| 1 | 资料卡 profile | 名字/描述/头像 |
| 2 | 性格 personality | SOUL 文本，自动保存 |
| 3 | 记忆 memory | 记忆管理 |
| 4 | 项目 projects | 工作目录 |
| 5 | **模型 model** | 模型/供应商配置（还有二级"高级"抽屉 ModelAdvancedDrawer） |
| 6 | 语音 voice | 语音模式设置 |
| 7 | 能力 capabilities | 技能/插件开关 |
| 8 | 消息渠道 channels | IM 平台连接 |
| 9 | 例行任务 routines | 定时任务 |
| 10 | 历史搜索 history | 会话历史检索 |
| 11 | 高级 advanced | 家目录路径等 |

页内二级导航全部在抽屉内完成（返回按钮回首页），抽屉不关不换页。

**对我们的落点建议**（对话级快捷设置，不是伙伴全套）：

- 第一版四行起步：**模型**（现已有）、**思考档**（快/深，现已有逻辑）、**权限档**、**通知**（批次二的时机开关）；
- 形态照抄：28px 图标入口 → 右侧 448px 抽屉 → 48px 设置行 → chevron 进二级；
- 模型行可以再带一行副文本显示当前模型名（cindy 行组件模式：`text-14` 主文本 + 次级说明）。

## 四、值不值得抄 / 反模式清单

| 判断 | 项 |
|---|---|
| ✅ 抄 | 裸图标入口（无圈）、右侧贴边全高抽屉、max-w-md、遮罩压暗、Esc（IME 豁免）+ 遮罩 + X 三种关闭、URL 状态、设置行清单 + chevron 二级页、关闭前草稿守卫、motion-reduce |
| ✅ 借鉴 | 抽屉内做滑入/滑出动画（cindy 没做但 thread 面板做了宽度动画，WebView2 手写成本 ~30 行） |
| ⚠️ 不抄 | cindy 抽屉用 Radix Dialog（我们无依赖无构建，用 `<dialog>` 元素或手写 overlay 即可，材质与几何照抄 CSS）；窗口拖拽洞（`WINDOW_NO_DRAG_STYLE`）是 Electron 标题栏特有，我们 Go+WebView2 自绘标题栏另有机制 |
| ⚠️ 反模式登记 | ① 设置入口画常驻圈/底色（选中态语言被误用）；② 下拉面板塞多个控件导致又长又挤；③ 点外直接丢弃未保存草稿；④ 抽屉打开时卸载底下的聊天视图 |

## 五、这条会怎么错

1. **抽屉做成居中弹窗**：`max-w-md` 是"贴右边的板"，不是居中卡片；加了圆角+阴影就会变成第二种下拉面板。
2. **URL 状态半吊子**：只在打开时写参数、关闭时忘了清 → 刷新又弹抽屉。cindy 关闭时 `clearSettingsParams()`
   用 `replace: true`，照做。
3. **行组件塞满控件**：首页每行只是"入口"，控件在二级页；别把模型下拉直接嵌进行里。
4. **遮罩模糊在低端集显掉帧**：cindy Windows 侧明确关闭 backdrop-filter（透明窗口黑块教训），
   我们 WebView2 同理，先实色压暗、模糊后置。
