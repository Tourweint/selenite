## 三、外部 id 解析与续话决策（纯函数，可单测）

`ts/apps/server/src/partner-session-role.ts`：

```ts
export interface ParsedPartnerSessionId {
  partnerId: string;
  role: "canonical" | "side" | "group";
}

/**
 * 解析 partner- 前缀的对外会话 id。顺序很重要：
 * 1) /^partner-(.+)-side-[0-9a-f]{8}$/  → side
 * 2) /^partner-(.+)-group-(.+)$/        → group
 * 3) /^partner-(.+)$/                   → canonical
 * 不是 partner- 开头 → null。
 * partnerId 本身可能含 "-"，禁止 split("-") 猜。
 */
export function parsePartnerExternalId(externalId: string | null | undefined): ParsedPartnerSessionId | null;

/** /agent/chat 续话按链接角色分流：canonical 折回主会话；side 放行；side 开关关 → reject；
 *  group / routine / topic / null 保持旧行为（折回 canonical）。 */
export function partnerContinuePlan(
  role: "canonical" | "routine" | "topic" | "delegation" | "group" | "side" | null,
  sideEnabled: boolean,
): "canonical" | "side" | "reject";
```

`task-chat-owner.ts` 的 `dispatchOwnerOf` 改成用 `parsePartnerExternalId`：
`partner-<id>` / `partner-<id>-side-<hex>` / `partner-<id>-group-<gid>` 都返回真正的
`partnerId`（顺手修掉群会话被当成 `<id>-group-<gid>` 的旧 bug）。
拿不到 partnerId 或非 partner 前缀 → `"chief"`，返回结构保持不变。

## 五、两个新端点

`ts/apps/server/src/companion-api.ts`，接在 `/partners/:id/open` 附近：

### 5.1 `GET /api/v1/partners/:id/sessions`

- 开关关 → `400 { error: "side_sessions_disabled" }`。
- `id === "chief"`：
  - 用 `listChats(...)` 取最近会话，过滤 `chatKind === "chief"` 且不以 `partner-` 开头；
  - 按 `lastAt` 倒序；每条 `role: "chief"`；
  - 返回 `{ ok: true, partnerId: "chief", kind: "chief", sessions: [...] }`。
- 其他执事：
  - 不存在 → `404 { error: "not_found" }`；非 active → `409 { error: "partner_inactive" }`；
  - 会话 = canonical（`sessionIdOfPartner` 换成对外 id）+ `sideLinksOf(id)` 的每个 `routeKey`；
  - 用新增的 `chatIndexEntriesOf(ids)`（见 §六）取标题/时间/轮数；
  - canonical 排第一，其余按 `lastAt` 倒序；已归档的不返回（`chat-meta` 过滤）；
  - 每条：`{ conversationId, role, title?, firstText, lastAt, turns, pinned? }`。
- 返回 `{ ok: true, partnerId, kind: "partner", sessions }`。

### 5.2 `POST /api/v1/partners/:id/sessions`

- 开关关 → 400；body 可选 `{ title?: string }`（≤80 字，超了 400 `bad_title`）。
- `id === "chief"`：`openChat(undefined, undefined, "chief")`；`role: "chief"`。
- 其他执事：`createPartnerSideSession(id)`；失败按情况 404 / 409 / 503；`role: "side"`。
- 有 `title` 时用 `renameChat(conversationId, title)`（`agent/session-meta.ts:125`）。
- **不发送问候语、不写任何消息。**
- 返回 `{ ok: true, conversationId, role }`。
