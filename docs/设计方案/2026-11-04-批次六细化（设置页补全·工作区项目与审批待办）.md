## 一、web 设置页「项目」分区（新一级分区，照 SETTINGS_SECTIONS/sectionMarkup/rowMarkup）

1. **工作区**：当前 rootPath（GET /api/v1/workspaces，未设时引导语）+「设定/更换」行（POST，失败按 ProjectError code 显示原因）。
2. **项目列表**：GET /api/v1/projects（名称 / **相对路径=前端用 workspace.rootPath 算**（B7：接口无 relativePath 字段，服务端零改动）/ vcs / `exists`、`insideWorkspace` 异常态徽标）。
3. **新建项目（手动）**：名称 + 相对路径 → POST /api/v1/projects（202 提案）→ 进待确认。
4. **待确认提案**：GET /api/v1/projects/proposals?status=pending → 卡片「确认 / 拒绝」→ POST /api/v1/projects/**:id**/confirm | reject。**路由以代码为准（S7）：确认/拒绝挂在 `/projects/:id/*`，接口文档 §2.7 的 `/projects/proposals/:id/confirm` 是写错的——改文档对齐代码（当前无调用方，最省事且零服务端改动）**；`tools.ts:225-227` 话术"工作区设置"→"项目设置"对齐。
5. `renderSettings` 加 `projects` 分支（B7：不加分支会落到默认"关于"）。

## 二、审批待办区（不进聊天流）
