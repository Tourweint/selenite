一屏看清

版一句话适合代价
A 信封条带底色的卡片，左侧一条金线，抬头写"谁 · 域 发来"。来信是偶发插曲，主人扫一眼就过。最小：只改样式与折叠阈值。
B 引文带不要卡片，一条竖线加小字署名，正文可到 720。信常两三行、要读完。低；但这条不能折叠，且无底色容易混进对方的话。
C 回执行流里只留一行"信使甲 → 14:32"，右侧箭头一转就展开正文。一个会话里连着好几封，只想扫一眼。中：要内联展开器；默认看不见正文。
D 信箱档会话顶部一条"来信 N"，点开抽屉按时间列全部。一天好几封，要抽查而不是逐条读。最大：先得回答"未读算不算状态"。

推送那档是另一件事：关掉推送时，来信只在"回读"（刷新、切走再切回）时出现——左栏那个开关演示的就是这个差别。已定 C 版 + 推送开：流里留一行，点开才见正文。
