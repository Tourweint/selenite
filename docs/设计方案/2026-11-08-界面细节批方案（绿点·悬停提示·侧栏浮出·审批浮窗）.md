## 背景与调查结论（2026-11-08 核对）

用户在刀二运行期间提出一批界面与交互要求，先调查后落本方案。核对结论：

1. **设置旁的绿点** = `/healthz` 每 8 秒轮询的"服务在线"灯（app.js:2394-2417），页面一连上就变绿，与 agent 是否在跑无关；收起轨道与展开侧栏各一颗（index.html:124-132 / 266-276），都竖排在齿轮**正下方**（style.css:418-435 / 594-624）。另有一颗语义不同的点：侧栏总管行尾 `#chief-dot`（档案+服务双条件，app.js:2727-2735），本批不动它。
2. **对话内审批卡已存在**（app.js:4613-4730，插在回答气泡上方，含倒计时/记住本会话/批准拒绝），缺的是"人在别的会话或别的页面时没有东西弹出来"，只能去设置→权限区翻全局待办（app.js:9441-9479、11003-11102）。全局待审批已有 5 秒轮询（app.js:14807-14860），但目前只在群组场景跑。
3. **抽屉模型页**（对话右上角齿轮 → 模型）：主选模型已是 `<select>` 下拉（app.js:6828-6905），但其弹开列表是操作系统样式（无圆角可调）；下方「清单里没有这个模型？」卡片是**手动输入模型 ID 的兜底**（csBatchCard，app.js:7145-7187）。备选链编辑器（app.js:6919-7116）只在执事身上出现，供试跑与例行任务轮次使用。
4. **默认工作区**：现状既无引导也无默认值；后端明确拒绝用户主目录本身及系统目录（projects.ts:153-172），首次使用靠侧栏"设置主项目"行（app.js:7558-7567）。
5. **消息脚注**：助手消息下方 hover 出现「复制（文字按钮）· 用时/tok · 完成于 HH:MM」（app.js:3275-3300、3549-3573；style.css:1128-1156）。
6. **记忆页**：`#mem-list-card` 一张卡里按 kind 分组，组头「经历/偏好/事实/人事物」排在**卡片内**（app.js:10514-10555），与节标题"记忆"（卡外，sectionMarkup）节律不一致；无分页（limit=300，注释明确"真上千再加"）。
7. **主题**：四套色板 token 在 style.css（paper/white/indigo/black，119-166 与 220-267 为 white/black 块），white 底纯 `#ffffff`、black 底纯 `#000000`，观感偏硬；色值源头注释写明搬自手机端 Theme.kt。
8. **抄写对象已核对**（<reference>\cindy）：peek 侧栏 = hover 触发钮 120ms 意图延迟 → 浮层滑入 200ms `cubic-bezier(0.22,1,0.36,1)`，离开 160ms 宽限；tooltip = 12px 圆角 / 13px 字 / 500ms 延迟 / 无箭头 / 纯 opacity 进场；圆角语言 = 容器 12px / 行 8px / 控件胶囊。

## 改动项

### 1. 设置绿点（index.html 266-276；style.css 418-450、594-624；app.js 2388-2417）
- 收起态：删 `.rail-status`，轨道底只留齿轮；`setStatus` 对空元素容错；`#rail-settings` 的 data-tip 改为随状态更新（「服务在线/离线/连接中」）。
- 展开态：`.side-foot` 改横排，齿轮在左、状态点同行右侧；title 保留文字说明。

### 2. 默认工作区（ts/apps/server/src/projects.ts + 启动装配）
- 服务端启动时若无工作区记录：自动设 root = `<用户主目录>/lifediary`，目录不存在则创建。选主目录**子目录**，绕开"拒绝主目录本身"的既有防线（防线原样保留，用户之后改路径仍受 `assertSelectableWorkspace` 约束）。
- 前端不加引导；侧栏"设置主项目"行在无工作区时仍作兜底入口。同步改 app.js:8551"首次使用的唯一入口"注释；系统架构"已知边界"补一条（首次使用改为静默默认+可改）。

### 3. 主题柔化（style.css white 块 119-166、black 块 220-267；app.js THEMES 预览色 164-170）
- white：`--bg/--surface` `#ffffff`→`#fafaf8`；`--surface-low`→`#f3f3f0`；`--card`→`#f4f4f1`；`--card-high`→`#ededea`；`--backdrop`→`#f1f1ee`；`--outline`→`#d7d7d3`；文字 `#1a1a1e` 不动。
- black：`--bg/--surface` `#000000`→`#17171a`；`--surface-low`→`#121215`；`--card`→`#1d1d21`；`--card-high`→`#242429`；`--backdrop`→`#101013`；`--outline`→`#3a3a44`；`--text` `#ededf0`→`#e6e6ea`。
- 预览方块色值同步。**只动 token**，实机看完不满意改色值即可。手机端 Theme.kt 是否跟随，等效果拍板（跨仓库，另派）。

### 4. 悬停提示系统（app.js 5759-5775 泛化；style.css .rail-tip 438-450）
- 现有 rail-tip 泛化为全局 `data-tip` 悬停提示：挂 body、fixed 定位、~450ms 延迟、12px 圆角、反色底、纯 opacity 进场、边缘翻转；rail 按钮并入同一套（删旧 showRailTip）。
- 设置页 rowMarkup（app.js:9235）加 hintMode：描述性解释 → 标签旁小 ⓘ 悬停显示，不再常驻；状态/反馈类（保存中、错误、结果行）保持 inline。逐条审 49 处 `set-hint`：描述性转 hover，没用的直接删（外观描述、抽屉 cs-note 等先出清单再动手）。
- 侧栏展开态：项目区「主项目=打杂空间…」图例移入分区头悬停提示；各分区头 title 转 data-tip。
- 记忆四类组头各配一句悬停解释（经历 = "聊过、经历过的事的记录，帮你想起『上次……』"）。

### 5. 侧栏悬停浮出（app.js 加 ~40 行；style.css）

> **2026-11-09 追记：本项落地当天经用户拍板退役**——扫过左上角就弹面板压内容、"悬停预览/点击固定"两套逻辑叠着难受。
> 已连根移除，回到点按钮展开/收起的单一形态；见变更记录追记与系统架构 §7。
- 抄 Cindy peek：侧栏收起时，悬停收起/展开按钮 120ms → 侧栏面板 fixed 浮层出现在轨道右侧（盖内容，shadow+描边，200ms `cubic-bezier(0.22,1,0.36,1)` 滑入）；移开 160ms 宽限后滑出；浮出时点按钮 = 正式展开（pin）。
- 面板内可正常点选，选中即收浮层；reduced-motion 与窄屏（≤800px）不启用；侧栏已展开时悬停无动作。
