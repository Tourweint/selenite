## 一句话

例行规则现在只会"到点就跑"，不会"条件变了才跑"，也不会"上次没新东西就闭嘴"；
执事之间递话只有"发出去了"，没有"对方收到了没有"。本批补这五件。

## 一、触发器加基线比较 + 边沿 + 冷却（七 #29）

1.1 `RoutineTrigger` 的 event 类型加三个可选字段（纯增量，老规则不受影响）：
   - `baseline?: { key: string; delta: number }` —— **比上次变化超过 delta 才触发**（不是"满足条件就说"）。
     实现：每次触发时把当前观测值记一条 `baseline:<key>` 到规则状态里，下次比差值。
   - `edge?: true` —— **只从假变真那一下触发**（状态跃迁），不是每轮都触发。之前的真假记在规则状态里。
   - `cooldownSec?: number` —— 触发后 N 秒内不再触发（防抖）。
1.2 三者可组合，判定顺序：cooldown → edge → baseline → 原 match 条件。
1.3 纯函数放 `routine-conditions.ts`（批 13 已建），可单独测。
1.4 开关 `ROUTINE_TRIGGER_GATES`（默认 true；false → 三个新字段被忽略）。

## 二、brief / 日报卡三规则（七 #41）

2.1 新增常量 `BRIEF_CARD_RULES`（放 `partner-context.ts` 或 `delegation.ts`），注入执事的**汇报/日报**类场景：
   - **没有值得报的就不发**（宁可安静，不要"今天一切正常"这种噪声）。
   - **就地编辑**：同一件事有更新，改原来那条，不要新开一条。
   - **只在"今天第一次打开"或"离开三小时以上回来"时出现**，**永不抢屏**（不弹窗、不打断）。
2.2 触发时机由宿主决定（不在本批做推送通道），本批只落**文案与纪律**。

## 三、run_source 触发来源列（七 #44）

3.1 派单回执与例行 run 记录各加一列 `runSource`：`"human" | "routine" | "routine_self" | "script" | "test" | "device"`。
   - 人直接派 = `human`；例行轮发起 = `routine`；执事 `routine_manage` 自建触发的首轮 = `routine_self`；
     HTTP 端点直接触发 = `script`；探针/测试 = `test`；设备矩阵派发 = `device`。
3.2 存储：`delegations` 库与 routines 状态文件各加可空列/字段，**旧数据为 null（视为 human）**。
3.3 投影：任务详情返回 `runSource`（可空，不出现时前端零影响）。
3.4 开关 `RUN_SOURCE`（默认 true；false → 不写不返，行为回到今天）。

## 四、watch.json 单例交接（七 #47）

4.1 看护类（`until` 型的例行规则，即"一直盯着直到条件达成"那类）**同一时刻最多一个在跑**。
4.2 交接语义：新的一轮要开始时，若已有同 key 的看护在跑 → **本次只交接一次**（把状态传过去），
   旧的不删除只暂停（`enabled=false` + `handedTo` 记新规则 id），避免"两个都在盯"和"盯丢了"。
4.3 落点：`routines.ts` 的 `runOnce` 入口 + 一个 `.data/routine-watch.json`（记录当前谁在看）。
4.4 开关 `ROUTINE_WATCH_SINGLETON`（默认 true）。

## 五、执事递话升级回执语义（七 #30）

5.1 `send_to_agent` 现在只有"递到了"。加**两态回执**：
   - `queued`：已投递到对方会话（submit 成功）。
   - `settled`：对方**真的跑完了一轮**（拿到对方那一轮的结算）。
5.2 回执句式和落点：发送方调用 `send_to_agent` 的返回里带 `queued`；
   对方跑完后，一条 `notice` 帧回流到发送方正在流式的会话（"「B」处理完了你递的那条话：<一句话结果>"），
   并在发送方 transcript 的留言表里记一条 `outcome`（与 8g 的留言镜像同款）。
5.3 **不做多跳**（hop 恒为 1 不变）；**不做 bot_loop_guard**（那是开两跳时才需要的）。
5.4 开关 `PARTNER_RELAY_RECEIPT`（默认 true；false → 只有 queued，行为回到今天）。
