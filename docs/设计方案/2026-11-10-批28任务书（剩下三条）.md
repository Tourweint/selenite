1.2 服务端实现两段式（手机端 UI 另说，但**接口必须先有**）：
   - 第一段：`POST /api/v1/pairing/begin` → 返回 `{ code, expiresAt, confirmToken }`
     （`code` 是给手机扫的短码，`confirmToken` 是给**电脑端**确认用的，**不随二维码下发**）；

   并输进去。这就是"手机绝不代确认"。
1.4 `confirmToken` 一次性、5 分钟过期、与 code 绑定；尝试次数计入既有 attempts 限流。
1.5 保留旧的单段 `POST /pairing/redeem`（回滚用），开关 `PAIR_TWO_STEP`（默认 true；
   false → 走旧单段）。
1.6 单测：两段式成功 / 只有 code 不能完成 / confirmToken 错 → 拒绝 / 过期 → 拒绝 / 一次性（重放失败）/
