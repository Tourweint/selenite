## 一句话

现在"没人看着的时候遇到要花钱 / 要批准的事"只有一策：挂审批等人。人在睡觉就卡死。
本批补**第二策：跳过并明说**，加上"无人值守时的统一结算规则"和"agent 中途主动开口"。

## 一、无人值守权限语义（七 #17）

1.1 新增 `ts/apps/server/src/unattended.ts`：`isUnattended(conversationId)` —— 判定这一轮是不是"没人看着"：
   - 例行任务轮（`isAutonomyTurn`）
   - 任务专线会话（`task-` 前缀）
   - 显式 env `AGENT_UNATTENDED=1`（一键全开，调试/夜间批处理用）
1.2 `resolveUnattendedVerdict(tool, capability)` 返回三态：`allow` / `skip` / `deny`：
   - 纯读 → allow
   - 写文件 / 跑命令 → **skip**（跳过并明说，见 §二）
   - 会让 agent 自己扩权或影响系统（`partner_manage` / `group_manage` / `routine_manage` / 删除类）→ **deny**（显式拒绝带原因）
1.3 **绝不挂起**：无人值守下不再走"落 pending 等人"，而是上面的三态。这是本批最核心的一条。
1.4 开关 `AGENT_UNATTENDED_POLICY`（默认 **false**，开了才生效；false 时行为与今天逐字节一致）。

## 二、跳过花钱步 + 明说（七 #28）

2.1 在 §一 判定为 `skip` 时，工具**不执行**，回给模型一句固定话术（常量 `UNATTENDED_SKIP_MESSAGE`）：
   "现在是无人值守，这一步需要花钱 / 需要人批准，**已跳过**。继续做不需要花钱的部分，
   最后在结果里**明确写出**你跳过了哪些步骤、为什么。"
2.2 结果里必须能看出来：例行 run 记录加 `skipped: true` + 一句原因（只记枚举与步骤名，不记正文）。
2.3 开关同上（`AGENT_UNATTENDED_POLICY`）。

## 三、agent → 用户中途播报（七 #18）

3.1 新工具 `report_progress`：参数 `{ message: string ≤200 字 }`。语义 = **长任务中途主动说一句，不结束本轮**。
   与 steer 正交（那是人→agent）。
3.2 送达方式：写一条 `notice` 帧到**正在流式的主对话**（与 `send_to_agent` 的主知情同款，
   `delegation.ts` 的 emitDelegation 通道），同时落一条到任务专线（若有）。
   **没有开流就收不到、不落盘**——不伪造主人的时间线（照 8d 的口径）。
3.3 频率闸：同一会话**每轮最多 3 条**，第 4 条起返回引导话术"合并成一条再说"（不是错误）。
3.4 只在**执事轮**与**任务专线**里上架；主人对话不上架（主人就在看着，不需要播报）。
3.5 进 `WRITE_TOOLS` 吗？**不进**（不写盘不起进程），但要进 `TOOL_CAPABILITIES` 声明
   （`sideEffectScope: "none"`，`riskLevel: "low"`），**一致性守卫单测会替你检查**。
3.6 开关 `AGENT_PROGRESS_REPORT`（默认 true，false → 工具不上架）。

## 四、例行任务条件门控（七 #19）

4.1 `RoutineDef` 加两个可选字段（纯增量，老规则不受影响）：
   - `until?: { note: string }` —— "达成即提前结束"的**文字条件**。每轮跑完，由**模型自己**判断"条件达成没有"，
     判为达成就把该规则置为 `done`（不删，保留历史）。**不做**通用表达式引擎。
   - `maxRuns?: number` —— 跑满 N 次自动停（简单、确定、可测；比 `ends={after,at,times}` 全套便宜）。
4.2 `lastOutcome` 透出：例行 run 记录里已经有 summary，补一个结构化 `outcome`：
   `"success" | "quiet" | "skipped" | "failed" | "done"`，并在下一次触发时把它带给模型
   （"上一次的结果是 X"），让规则能"接着上次往下做"。
4.3 开关 `ROUTINE_CONDITIONAL`（默认 true；false → 新字段被忽略，行为回到今天）。
