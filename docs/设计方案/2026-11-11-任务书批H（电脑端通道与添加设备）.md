# 任务书：批H——电脑端 mobile/proxy 通道 + 添加设备二维码

> 派活方：总管。执行者：CodeBuddy。前置：批R 已合入（中继有 `/api/v1/*` 反代与 join 端点、presence 帧）。
> 方案全文：`docs/设计方案/2026-11-11-方案（手机经中继连电脑）.md`（本任务书 = 「批H」）。

## 改动范围（lifediary-harness 仓）

### H1 `ts/apps/server/src/relay-channels.ts`
1. 通道白名单 +`mobile/proxy`（默认拒绝原则不变；只有显式列出才可达）。
2. 新 handler：收 `{ kind:"invoke", id, payload:{ method, path, query, headers, body } }`：
   - **在本进程内直接调内部 handler**（复用 Hono app 的 `app.request(...)` 或等价内部调用——不真发 HTTP，免端口自环）；
   - `headers.authorization` 若缺，用本进程 AGENT_TOKEN 补（中继侧第一版约定手机 token=AGENT_TOKEN，这里做兜底）；
   - 返回 `{ kind:"invoke_result", id, payload:{ status, body } }`（body 原样字符串，不解析不脱敏——日志只记计数与 status）。
3. 回滚开关：env `RELAY_MOBILE_PROXY_ENABLED=off` → 通道不注册（fail-closed）。

### H2 `ts/apps/server/web/app.js`（+index.html/style.css 同款风格）
「多端/连接」区块加「添加设备」弹窗：
1. 调中继 `POST /api/relay/join-code`（带 owner 令牌；owner 空 = 本机 loopback 可调）拿 `{joinCode, expiresAt}`；
2. 弹窗渲染：加入码大字 + **二维码**（内容 `lifediary://relay/join?u=<中继地址>&c=<joinCode>`；中继地址取 harness `.env` 的 `RELAY_URL` 对外形态，可在弹窗里手改）+ 过期倒计时 + 「换新码」按钮；
3. 不做手机端轮询回显（手机加没加上，去名册页看）。

## 验证（真跑）
1. `pnpm --filter @lifediary/server test` 现有全绿（relay-auto / relay-mobile-proxy 相关不红）。
2. 新增/扩展 probe `ts/apps/server/scripts/mobile-proxy-probe.ts`（若批R 已在 relay 仓建，这里建 harness 侧端到端版）：
   - 起 harness（`RELAY_ENABLED=on`，随机端口）+ 真连本地 relay；
   - 用 node 客户端模拟"手机"：`join-code`→`join` 拿 deviceToken → 经 relay 反代 `GET /api/v1/agent/chats`（带手机 token）→ 200 且返回 harness 真数据；
   - `RELAY_MOBILE_PROXY_ENABLED=off` 时同请求 404。
3. web 弹窗手测一遍（浏览器打开，点「添加设备」出码出二维码）。
4. `pnpm typecheck` 全仓绿。
