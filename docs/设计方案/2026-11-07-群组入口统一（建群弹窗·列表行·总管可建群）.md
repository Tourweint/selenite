# 群组入口统一（建群弹窗并入设置语言 · 总管可建群）

> 2026-11-07。**状态：已落地**。
> 下沉落点：`接口文档.md` §2.14（模型侧工具一行）+ §4（工具清单）；`系统架构.md` 模块行与工具数。
> 落地记录：`变更记录/2026-11-07-群组入口统一（建群弹窗·列表行·总管可建群）.md`。

## 问题

1. **建群弹窗是另一套语言**。群名/公告两个输入框挂的是 `text-input` —— 这个类在 `style.css` 里
   **根本不存在**，于是退化成浏览器默认控件（2px 直角灰框、14px），和同项目「新建执事」的
   `.modal-input`（12px 圆角、发丝描边、13px）并排像两个产品。成员勾选是原生 `<input type="checkbox">`
   13px 方块（Windows 蓝勾），值日执事一开始是一块空白（勾人后才长出胶囊）。
2. **群组列表页是一张被拉宽的孤卡**。`minmax(240px, 1fr)` 网格在只有 1–2 个群时把卡片撑到 300px+，
   右侧全空；卡片自身却只有「首字圆钮 + 名字 + 两行灰字」，密度比执事花名册（`.pt-card`）低一档。
3. **总管建不了群**。存储与端点一路都接受总管（方案 §2.1「总管可被拉进群当普通成员」），
   建群弹窗里也能勾到他；但**模型侧没有对应工具** —— 总管只能在界面点按钮，对话里说「建个群」
   只能干看着。这与 `partner_manage`（总管能建/停执事）的能力面不对称。

## 决定

### D1 建群弹窗回到模态的既有语言，元素只减不加

- 结构改成 `.modal-field`（`span` 标签 + 控件）+ `.modal-desc` 一句说明，与「新建执事」同拍。
- 控件统一 `.modal-input`；公告从 textarea 降为单行 input（建群时是一句话背景，不是长文；
  长公告进群设置抽屉写，那里给足高度）。
- 成员选择从「原生复选框胶囊」改成**一行一人**（头像 + 名字 + 右侧选中态），与群设置抽屉
  成员页（`.gs-member-row`）同一族。勾人不再需要理解一个 13px 方框。
- 值日执事从「另起一块空胶囊区」合并进成员行右侧：每行一个 `值日` 小键，选中即值日。
  少一块区域、少一次滚动，也不会出现"空着等人勾"的断裂感。
- 动作条用 `.modal-primary` / `.ghost`，与其它模态同高。

**备选（未采纳）**：直接把建群也搬进右侧抽屉（与群设置同骨架）。理由是否 —— 建群是
一次性表单、没有二级页，抽屉的「首页 + 二级页」结构在这里用不上，反而多一层滑动动效。

### D2 群组列表改「一行一群」

`group-grid`（自适应卡片网格）换成与项目列表/花名册同族的紧凑行：
`首字圆钮 + 群名 + 副行（成员 · 值日）+ 右侧人数`。一行一群，1 个群也不会撑成孤零零一大块；
6 个群也不需要横向扫格子。空状态保留原文案。

### D3 总管能建群：新增模型侧工具 `group_manage`

- 形态照 `partner_manage`：一个工具、`action` 枚举，核心实现抽到 `group-manage.ts`，
  **HTTP 端点与工具共用一份**（`group-api.ts` 的 POST 改调同一函数，400 文案逐字不变）。
- v1 只开 `create` 与 `list`：建群 / 看有哪些群。改名、加减人、删群**不做**（见 §明确不做）。
- 成员用**名字**指定（`members: string[]`），值日用 `responder?`（名字，缺省取第一位成员）。
  模型拿不到 uuid，也不该拿到：`list` 的返回同样只给群名与成员名。
- 权限判据与 `partner_manage` 逐字一致：只有总管 / 主对话能调，执事自己的会话拒绝。
- 开关：`GROUPS_ENABLED` + `COMPANIONS_ENABLED` 双闸（关任一个，工具不注册 = 一行回滚）。
  为此把 `GROUPS_ENABLED` / `groupsAvailable()` 从 `group-api.ts`（HTTP 层）下沉到
  `group-manage.ts`（纯核心），`group-api.ts` 原样 re-export 保持既有 import 不变。
- `group_manage` 进 `WRITE_TOOLS`（会新建群与成员关系，与 `partner_manage` 同档）与
  自主轮风险表（`new_task`）。

## 明确不做

- **不做改群 / 删群的模型工具**：改名与加减人是低频且有歧义的操作（删群不可恢复），
  留在界面里由人点。工具只做"从无到有"与"看一眼"。
- **不做按 uuid 指定成员**：对外 id 一律不出网这条口径不破。
- **不改群组数据面**：三张表、路由纯函数、回合编排、SSE 契约一行不动。
- **不动群会话视图**：时间线四形态、成员条、composer、群设置抽屉都不在本次范围。
