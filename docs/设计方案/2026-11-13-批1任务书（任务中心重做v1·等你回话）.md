## 一、交付清单

### 1. 主视图重构（默认视图，替换旧三列看板）
- **响应式一体**：容器宽 ≥1100px 用双列（左 7fr：等你回话 + 在跑；右 5fr：打手手风琴 + 今日回顾卡），
  窄屏退化为单列，顺序：等你回话 → 在跑 → 打手 → 底部链接。注意 style.css 的媒体查询必须排在
  本体定义之后（历史教训）。
- 旧 `renderBoard()` 全套**保留在位不删**，只是默认不再走它（见 §4 回滚开关）。
- 顶栏筛选（领域/项目/排序）随旧看板一起退场：新视图不放这些下拉；`刷新`按钮保留。
- 卡片全部可点回对话：走 `openConversation(card.conversationId)`，**不带 anchor**（落在最新处，
  这是拍板过的 v1 行为）。自动刷新（现 20s 轮询）沿用，注意保持滚动位置（现 renderBoard 有先例）。

### 2. 「等你回话」大区
- 数据：从 `state.tickets` 派生——聚合灯为 `ask` 的对话卡（复用 `groupByConversation`/
  `conversationLamp` 的口径），外加单级 `needs_you` 的直派单。**零新接口**。
- **多条分组**（照原型 12）：一条对话一组；组按**等最久**（组内最早一条 needs_you 的 updated_at）升序排；
  组内留言按时间正序。超过 3 组收进「还有 N 条更早的」折叠条（沿用 foldSection 的交互习惯，
  展开态记会话内存即可）。
- **身份诚实（硬规矩）**：卡面说话人标「总管」。v1 拿不到总管原话，引文只用有据字段——
  任务说明 prompt 摘要（现 workRow 的截断逻辑同款）+ 单上已有的状态原因；没有总管亲口说的话，
  **绝不写成像总管的口气**。若该对话没有唤醒轮产出的可引用文本，卡上标「系统代发」小标
  （原型 12 的样式）。不要虚构任何引文。
- 组头右侧「去处理 →」= `openConversation(conversationId)`；气泡可点同效果。
- 空态：「都回完了，执事们在跑 N 件事。」（N=在跑数；0 就写"都在歇着。"）

### 3. 在跑小卡 + 打手手风琴
- 在跑：两列小卡（头像取对话标题首字 + 标题 + 状态点 + 相对时间），含排队/出错；点卡回对话。
  状态点颜色沿用聚合灯口径（run 蓝 / fail 红 / ask 琥珀 / done 灰）。
- 打手手风琴：每行 = 工具徽章 + 名称 + 在跑数 + 状态点 + 计数徽章 + 展开箭头（照原型 09/10）；
  展开列**该执行者名下的对话行**（从 state.tickets 现算：按 conversationId 分组后过滤 employee），
  行 = 标题 + 状态 + 相对时间，点行回对话。空闲的执行者展开给一句空态文案。
  `TASK_HITTERS` 四项沿用（CodeBuddy/Qoder 国际/Qoder 国内/手机），**不改成动态**（那是另一个立项）。

### 4. 回滚开关（一行 env 退回旧看板）
- `ts/apps/server/src/flags.ts` 的 `FLAG_DEFS` 加一行：
  `{ key: "TASKS_REDESIGN_ENABLED", values: ["true", "false"], defaultValue: "true", hot: true }`。
- web 侧：任务中心加载时读 `GET /api/v1/agent/flags`（现有端点，app.js 12663 行附近有消费先例），
  取 `TASKS_REDESIGN_ENABLED`；值 === "false" → 走旧 `renderBoard()` 全套（含旧筛选栏）；
  端点不可用或没这个键 → 默认新视图。开关值记进 state，别反复拉。

### 5. 今日回顾（独立视图）
- 新路由 `#/review` + 新 main 视图（index.html 加 `view-review`）+ rail 加一个日历图标按钮
  （Lucide 内联 SVG，风格照现有 rail 按钮，data-tip="今日回顾"）。
- 数据：`GET /tickets` 全量按天分组（`updated_at`），无新接口；默认显示今天，可切「前一天/后一天/今天」，
  后一天无数据禁用；「今天」标签写实际日期（如"今天 · 11-13"）。
- 汇总数字**只用有据的**：派活次数（父单行数，`dispatchedCount` 同口径）/ 完结对话数 / 出错数 /
  等你回话数。**不做**"改了 N 个文件"（回执没有 changedPaths，无数据源，不许编）。
- 时间线混排（照原型 11）：完结✓（点回原对话）/ 派活行（工具徽章+摘要+状态）/ needs_you（总管留话款）/ 出错。
