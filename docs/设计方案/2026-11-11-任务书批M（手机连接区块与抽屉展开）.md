## 三件事

### M1 扫码加入中继（免配对核心）
- `core:pairing` +`RelayJoinApi`：`POST {relay}/api/relay/join`，body `{joinCode, deviceName, platform}`，返回 `{deviceId, deviceToken, protocolVersion}` 只落 Keystore（与 agentToken 同档加密）；失败 null 不抛。
- `LifediaryPreferences` +`relayBase`（String?）——注意：**第一版不新增"双通道"抽象**，加入成功后直接把 `serverBaseUrl` 写成 `{relayBase}/api/v1`、`agentToken` 写成 deviceToken（第一版约定 deviceToken=AGENT_TOKEN 时业务零改动；不等价时用户在设置页照旧手改，登记已知简化）。
- 深链：manifest 注册 `lifediary://relay/join`（scheme lifediary, host relay）→ MainActivity 解析 `u`/`c` 参数进 RelayJoin 页面。

### M2 设置页「连接本机 Agent」区块升级（改 `feature/settings` ConnectionSection）
三行新 UI（风格对齐现有 LdSettingsRow/LdGroupCard）：
1. 「扫码加入中继」：打开现有扫码页（PairingScreen 的相机能力复用），识别二维码 `lifediary://relay/join?u=…&c=…` → 解析 → 调 RelayJoinApi → 成功 toast「已加入，可拔掉数据线」；
2. 「扫一扫配对」行为升级：现有配对二维码外，同时识别**连接形态二维码**（payload 为 `{"base":…,"token":…}` JSON 或 `lifediary://connect?base=…&token=…`）→ 直接填地址+令牌并保存（同网/热点形态的用户操作从手输降为扫码）；
3. 现有手输地址/令牌保留（兜底，开发者形态）。
识别失败一律 toast 短词「二维码不是本应用的」，不崩不猜。

### M3 抽屉「对话」组可展开（用户拍板：桌面侧栏风格）
- `feature/chat` HistoryDrawerSheet：**总管行不可展开**（保持单行，点击即进对话）；
- 「近 7 天 / 更早」两个时间组改为**可点击展开/收起**（桌面侧栏同款交互）：组头右侧加 ▸/▾ 旋转箭头（设计令牌 §3 淡入档动画），默认展开状态持久到 SharedPreferences（键 `drawer.group.<label>.expanded`）；组内为空或被收起时不占行。
- 派活行/电脑上的对话分组照旧。
