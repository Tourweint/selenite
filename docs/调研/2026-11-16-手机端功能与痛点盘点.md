## 4. 体验痛点候选（每条带依据）

### 4.1 文档已登记的已知问题

1. **同步是事件驱动、失败静默**（`变更记录/2026-11-14-连接后自动同步与连接页状态顶置.md`"还没做的"节，原文照录）：
   - "周期同步：仍是事件驱动（进屏 / 开抽屉 / 刚连上），没有回前台刷新、也没有定时轮询。"
   - "失败静默：清单拉失败仍是空列表，没有『同步失败』提示，用户分不清『电脑上没有』和『没拉到』。"
   - 该文还记录：真机微信输入法输 `AGENT_TOKEN` 被当成拼音上屏成拼音串（密码框全是点），表现为 403「地址或访问令牌不对」——**配对手填路径的输入法坑至今没有专门处理**。
2. **vivo 厂商冻结**：带前台服务的 worker 进程切后台约 3 分钟仍被 `pem_freezer` 冻结，长轮询 `INFINITE_DEFER`（`变更记录/2026-11-02-手机worker前台服务.md`，实测 cgroup.freeze=1）——"前台服务是必要条件，不是充分条件；要长期后台接活还需系统白名单（本次未改设备设置，未验证加入白名单后的效果）"。
3. **审批轮询 25s 间隔**：手机触发写类工具最长要等 25s 才看到审批弹窗（`ApprovalCoordinator.kt` `POLL_INTERVAL_MILLIS = 25_000`；口径源 `设计方案/2026-10-29-去账号化与改连Harness改造方案.md` 表 11"20–30s 或拉任务页时轮询"）。手机走兼容层、不进自有 SSE 流，没有推送/长连接通道（`needs_you` 通知依赖轮询到事件才发）。
4. **日记镜像 24h 才同步一轮**：冷启动延迟 3s 后检查"距上次成功 > 24h"才跑（`core/diary-sync/DiarySyncTrigger.kt`），需求方原话"手机一天丢了，也就今天这一篇日记丢了"。换机恢复只有"配对成功"立即跑一条路径。
5. **流式侧 `lifediary_tool` 帧手机不解析**：工具活动统一靠回读（`变更记录/2026-11-10-批B`），意味着正在跑的工具步骤显示依赖回读时机，流中看不到 diff。
6. **`fetchTranscript` 早期只解析 role/text/at** 已修（批B），但**流式侧仍只认兼容层帧**，harness 自有端点的 `seq` 补帧机制手机未接（`设计方案/2026-10-29-去账号化…方案.md` 表 14："将来手机要接自有 SSE 流时，重连先 `GET /messages?sinceSeq=` 补帧"——尚未接）。

### 4.2 结合代码的痛点候选

7. **没有"回到前台刷新"**：列表页数据只在进屏 / 从对话返回 / 刚连上时拉（`ChatViewModel.kt:711` `collect { top is ConversationListNavKey -> listRefreshCount += 1 }`），长时间挂在列表页时电脑端新会话/执事变化不会出现。文档 §4.1-1 同源。
8. **会话搜索缺失**：首页会话列表无搜索（`ConversationListScreen`/`ConversationListContent` 无 search/query），总管单会话上翻后"以后要加聊天记录搜索"（`变更记录/2026-11-16-总管单会话按天分块与上翻.md` 尾注留口）——历史越堆越多，找到旧内容只能翻。
9. **单聊无停止按钮**：群聊有 `stop`（`GroupsApi.kt:43`），单聊 ChatViewModel 无对应能力；模型跑偏时手机端只能等流结束（harness 有 `POST /chat/{id}/stop`，手机未调）。
10. **无发图/文件上传**：对话只能发文本（§2 证据）；用户在手机上拍的照片进不了对话，也没有 `POST /agent/attachments` 的调用。
11. **手机端无搜索、无未读徽章、无推送通道**是文档拍板的"刻意没有"（`体验与启动性能.md` §1 首页段"刻意不做：未读徽章（无推送通道）…会话搜索"）——但"无推送通道"同时意味着**提醒/审批/needs_you 全部依赖 App 在前台轮询或本地闹钟**，后台可达性受厂商冻结放大（§4.1-2）。
12. **多设备名册能力不全**：手机只做改名/写描述/设主机，`relay/devices/:id/revoke`、`pair/devices/*`（撤销/删除设备）手机没有入口——丢设备时必须回电脑操作。
13. **课题页只读**：手机不做建课题/编辑/推送/轮询（`接口契约.md:473`；`设计方案/2026-11-08-扫尾批3任务书:27`）——在手机上只能"看课题进展"，想改只能回电脑。

## 7. 附：模块速览

- `core:ai` — LLM 通道（兼容层 SSE + 回读 + 管理端点），`LlmClient.kt` 接口全集。
