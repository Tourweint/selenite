# 桌面端 Web 界面功能全集盘点

- **审计日期**：2026-11-21 全量核对（以代码为准，未跑服务，纯静态盘点）。
- **范围**：桌面端 Web 界面（`ts/apps/server/web/`，应用名 Selenite）+ 支撑它的服务端端点（`ts/apps/server/src/`）。
- **用途**：给「手机端是否移植 / 移植哪些」做决策，逐条列功能与入口。
- **方法**：4 路并行只读盘点（页面视图 / 对话内能力 / 设置与 flags / 服务端端点），全部以代码为据，盘不到的进文末「不确定项」。

前端入口 `ts/apps/server/web/index.html` + `app.js`（app.js 只剩 side-effect import 与启动代码，原单文件已拆成约 80 个平铺模块，见 `ts/apps/server/web/app.js:1-8`）。路由判定集中在 `ts/apps/server/web/route.js`（`currentRoute()` route.js:22-46，`applyRoute()` 按 hash 显隐 7 个 `<main>` 视图容器）。

### 1.2 对话页（chat）

- **入口**：侧栏总管条目（`partners-status.js:296`）、执事花名册行（`partner-roster.js`）、对话分区会话行（`chats-list.js`）、顶栏菜单「新对话」（`shell-window.js:83-90`）。
- **用途**：主聊天界面；空会话是首页态（输入框居中 + 按时段换问候语，`shell.js` GREETING_SLOTS 段）。
- **关键子功能**：
  - composer 全家桶（见 §二）；右上角**会话地图按钮**（`#chat-map-btn`，能力投影 `CHAT_MAP_ENABLED` 收起，`chat-map.js:181-189`）；右上角**对话设置抽屉**（`settings-drawer.js`，见 §二.3）。
  - 总管条目上另有多会话选择按钮（`partners-status.js:139-158`，弹层 `partner-sessions-ui.js`，开关 `PARTNER_SIDE_SESSIONS`）。
- 来源：`index.html`（chat 段注释极详细）、`chat-thread.js`、`chat-open.js`、`composer-send.js` 等。

### 1.3 会话画板（`#/map/<id>`，`chat-map.js`）

- **入口**：对话页顶栏「会话地图」按钮。
- **用途**：单条会话的回合卡 + 分支车道画板，只读（看结构 / 详情 / 进会话 / 从答卡再分一支）。
- **子功能**：最近轮数窗口下拉（5/10/15/20/30）、切换会话、整理、定位、缩放百分比、回合详情抽屉（map-inspector，按需取全文）、答卡「从这里分支」、卡片位置存 localStorage、折叠卡「往前放 N 轮」。

### 1.4 设置页（`#/settings/...`，`settings-router.js` + `settings-base.js`）

- **入口**：展开侧栏底部齿轮（`provider-save.js:409`）、收起轨道齿轮（`shell.js`）；左栏「返回」键回对话。
- **左栏分区导航**（`renderSettingsNav`，settings-base.js:216-256），分三组：
  - **日常**：外观 / 会话 / 项目 / 定时任务。
  - **Agent**：Agent 四 tab 卡（人设 / 上下文 / 工具 / 派活，`AGENT_TABS` settings-base.js:142-172）、关于我、模型、技能、记忆。
  - **系统**：用量、插件（flags 卡片墙）、本机（连接 + 服务与关于）。
- 分区子路由与别名：`SETTINGS_SECTIONS`（settings-base.js:42-133）；别名账 `SETTINGS_ALIASES = { sessions→chats, avatars→agent, archive→chats, service→connect, about→connect }`（settings-base.js:180-187）。
- 各分区内容详表见 §三。

### 1.5 任务中心（`#/tasks`，`tasks-redesign.js` / `tasks-kanban.js` / `tasks-detail.js`）

- **入口**：展开态「对话」分区底部「打开任务中心 →」（`#sec-tasks-all`，`tasks-live.js:182`）；执事行 / 领域行跳 `#/tasks?domain=`。收起轨道无入口（index.html:168-170 拍板退役）。
- **新版 v1**（开关 `TASKS_REDESIGN_ENABLED`，关=回旧三列看板，tasks-redesign.js:112-122）：宽屏双列 = 等你回话 → 在跑 →（右列）打手手风琴 → 今日回顾卡；卡片点击回原会话。
- **旧看板**（tasks-kanban.js）：领域 / 项目 / 排序筛选（写 hash）、刷新、按执行者聚合打手卡、三列对话卡（待你处理 / 出错 / 进行中）、已完结折叠区、「更早的直派」折叠区。
- **详情页**（tasks-detail.js）：返回看板键、阶段 / 子任务、动作按钮（含派活取消，受 `DELEGATION_CANCEL` 下发开关，tasks-kanban.js:79-82）。

### 1.6 今日回顾（`#/review`，`tasks-review.js`）

- **入口**：任务中心右列「今日回顾」卡。
- **子功能**：日期前后切换、当日概览（派活 / 完结 / 出错 / 等你回话）、上午 / 下午 / 晚上分组流水、刷新。数据 = `GET /api/v1/tickets` 按 updated_at 分日，无新接口。

### 1.7 领域负责人（`#/domains`，`domains.js`）

- **入口**：侧栏无占位（已并入执事花名册，index.html:528-531）；只从代码内跳转进入。
- **子功能**：只读 `GET /api/v1/domains`，每行「领域 · 活跃单数 · 状态」，error 行标红，行点击跳 `#/tasks?domain=<domain>`。

### 1.8 群组（`#/groups`、`#/group/<id>`，`groups-list.js` / `groups-thread.js` / `groups-settings.js`）

- **入口**：展开态群组分区底部「所有群聊 →」（`groups-settings-panels.js:406`）、群组分区行、轨道悬停卡；列表页「新建群组」按钮。
- **列表页**：群组卡列表（空态提示受 `GROUPS_ENABLED`）、新建群组。
- **会话态**：成员条（点头像插 @、右键同菜单）、时间线（主人右 / 成员左 / 系统行居中 / 同作者合并）、状态胶囊（谁在忙 / 谁等审批）、@ 点名候选条（重名 400 后插长标签）、群 composer（@ 按钮 + 发送 / 停止分离）；右上角群设置齿轮开右侧抽屉（groups-settings.js：首页 = 群身份 + 群资料 / 成员 / 回应口径三行 + 页尾删除，二级页一次一件事）。

### 1.9 搜索页（`#/search`，`search-page.js`）

- **入口**：对话分区 ⋯ 菜单「搜索旧对话」（shell.js）、设置→会话→「打开搜索」。**界面上唯一的搜索**（index.html:703-705）。
- **子功能**：一次输入同时匹配标题（本地即时）+ 原文（`GET /agent/sessions/search`，默认近一年、20 条/页）；结果按对话分组，每组可展开多处命中；点片段跳回原会话定位到那句（`.msg[data-at]` 闪一下，`chat-open.js:jumpToAnchor`）；「查看更多」翻页；「搜索更早的历史」。

### 1.10 归档（已并入设置→会话，`archive-page.js`）

- **入口**：设置→会话底部「自动归档 / 已归档的会话 / 已归档的项目目录」三节（settings-router.js chats 段，2026-11-18 注释）；旧路由 `#/settings/archive` 经别名仍可达。
- **子功能**：已归档会话按项目分组折叠、标题搜索 + 排序（归档时间 / 最后活跃）+ 项目筛选、行内恢复 / 永久删除（`CHAT_HARD_DELETE` 总闸）、组头全部取消归档。

### 1.11 侧栏结构（index.html:135-325 + `shell.js` + `rail-card.js` + `sec-menu.js`）

**收起轨道**（72px，`#side-rail`，悬停直接浮总览卡，350ms 意图 / 220ms 宽限，rail-card.js:33-41）：
1. 总管首字圆钮（点击开总管会话，悬停浮总管卡）
2. 执事（悬停浮花名册卡）
3. 对话（悬停浮最近会话卡，卡底保留新建 / 搜索）
4. 项目（悬停/点开「工作区根 + 项目」总览弹层，project-switch.js:22-29）
5. 群组（悬停浮群列表卡，无群时 disabled）
6. 底部齿轮 → 设置；状态点已退役（服务状态看顶栏 / 侧栏状态灯）。任务中心 / 今日回顾不进轨道（2026-11-13 拍板）。

**展开侧栏**（`#sidebar-inner`）：
- **总管条目**（固定不折叠，只做「打开总管会话」一件事）。
- **执事分区**：花名册行（头像 / 领域 / 派发权 / 在办单 / 忙因胶囊，partner-roster.js:31-70）；行尾 ⋯ 菜单 = 新建执事（sec-menu.js:16-24）。
- **对话分区**：最近会话行（前 5 条，chats-list.js:22；置顶在前；执事 / 总管 / 群会话不进这张列表）+ 任务对话行（聚合灯）+ 底部「打开任务中心 →」；行尾 ⋯ = 新建对话（Ctrl+K）/ 搜索旧对话。
- **项目分区**：项目列表（工作区根 + 项目平级总览）；行尾 ⋯ = 新建项目 / 添加已有项目。
- **群组分区**：群行列表 + 底部「所有群聊 →」；行尾 ⋯ = 新建群组。
- **底部**：齿轮（设置）+ 状态灯（连接中 / 在线…）。
- 分区折叠状态存 `lifediary.side.<sec>`；≤800px 窄屏展开态变覆盖面板 + 遮罩 `#sidebar-scrim`（shell.js:59-89）。

### 1.12 顶栏（自绘标题栏 `#titlebar`，`nav-history.js` + `shell-window.js`）

- 品牌「Selenite」；**返回 / 前进**（自维护访问栈，Alt+←/→，悬停提示目标页名；两枚都不可用整组 hidden；回滚开关 `?nav=off` / `lifediary.navBack=off`，nav-history.js:169-175；同层兜 Ctrl+R/F5）。
- chrome 区：**侧栏开关**（仅非设置页显示，route.js:260）+ **功能菜单**（汉堡，菜单项目前只有「新对话」）。
- **窗口三键**（最小化 / 最大化-还原 / 关闭）：仅 MyGo 壳内显示（`window.isMyGo()`，shell-window.js:12-18）；拖动区 + 双击最大化。
